# 0259. CLI の書出し先を元パッケージの外へ限定する

日付: 2026-11-04。
状態: 採用（P2-08 の安全性。新しい形式や DSP は追加しない）。

## 背景と再現

GUI は元パッケージ内の出力先を拒否していたが、CLI と `render_to_wav` は同じ境界を持っていなかった。
`render Song.echode Song.echode/project.json --frames 1` が成功し、曲の JSON を WAV へ置き換えられた。
出力を一時ファイルから原子的に公開しても、指定先自体が原本なら保護にならない。
実 CLI の回帰を先に追加し、終了コード 101 と `render must refuse a destination inside its source package` を照合した。
証拠は `target/export-destination-red/` にある。

## 決定: 復旧・発音・一時出力より前に境界を検証する

- CLI とライブラリの共通入口で、元パッケージと出力の親ディレクトリを正規化する。
  出力が元パッケージ自身かその子なら、`choose an output outside the project package` で拒否する。
  JSON・素材・状態・Git に限らず、新規 WAV もパッケージの外へ出す。
- 比較はパスの成分で行い、`Song.echode-exports` のような同じ文字列で始まる隣のディレクトリは許す。
  相対パス、親ディレクトリへの `..`、元パッケージや出力フォルダのシンボリックリンクも正規化して判断する。
- 既存の出力ファイルが元パッケージ内を指すリンクなら、保守的に拒否する。
  外のファイルを指すリンクは従来どおりリンク自身を置換し、その参照先は書き換えない。
- 出力の親が存在しない、解決できない場合はエラーにする。ディレクトリを自動作成しない。
  拒否は `DocumentHost::open` より前なので、復旧・Git の初期化・ジャーナル修復も始めない。
  進捗の開始・`complete`・`exported` は通知せず、実 CLI は終了コード 2 とする。
- 取得済みの正規化した親を一時出力と公開の両方に使い、元の出力フォルダのリンクの差替えで途中から転送しない。
  敵対的なファイルシステム操作全般を防ぐサンドボックスや、外部ファイルの上書き確認を追加するものではない。
  ディレクトリ自体の並行移動・置換は別の境界である。
- 外の既存 WAV の置換・失敗時の原本保持・公開後の耐久性不明・取消は従来の `WavFile` の規則を保つ。
  低水準の `write_wav` はプロジェクトを受け取らず、この制約はレンダーの入口に置く。

## 回帰と基盤

- 必須契約 `export-destination-cli` は実 CLI が JSON を破壊せず拒否し、全ファイルのバイトと成功通知の不在を確認する。
  拒否条件を無効化する反例を `scripts/verification.json` へ登録する。
  実行入口は既存の Makefile の `check-base`・`check-product-contracts` を共有し、選択の回帰も更新する。
- 通常回帰は全既存パッケージファイル・状態オブジェクト・Git・新規出力・リンク経由の拒否を確認する。
  パッケージ外の既存出力・同名接頭辞・相対パス・外向きの出力リンク・存在しない親も検査する。
- 旧 CLI 回帰がパッケージ内へ出していた WAV を、終了時に片付ける独立した出力先へ移す。
  PCM・ディザ・余韻・隔離音源・書込み故障の検証範囲は変えず、一時物の照合先も実際の出力フォルダに合わせる。
- README・設計・進め方・現在の制約と開発／デバッグ手順を更新する。
  音の生成・機器・GUI の挙動は変えず、新しい実機・聴感の確認待ちは追加しない。
