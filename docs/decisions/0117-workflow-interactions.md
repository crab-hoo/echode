# ADR 0117: 制作ワークフローに沿って P2 の操作と状態を分ける

- 日付: 2026-10-18
- 状態: 設計方針を採用。今回の変更は文書のみで、製品への接続は未実装
- 範囲: コード・メロディ・ドラム・ベースの入力、構成・編曲、ミックス、オートメーション、書出し

## 背景

作者と、空トラックに音源を挿し、マウスでコードを置いて聴き直すところから、別パートの追加、構成と編曲、ミックスと書出しまでの操作を確認した。操作要件の正本は [制作ワークフローとインタラクション](../interaction-design.md)。本 ADR は既存設計との関係と状態の境界を決める。モデルの具体的なフィールドや未確認の操作まで確定しない。

P1 の停止位置、ノートのダブルクリック挿入と Return、選択トラックに結び付いた編集対象、トラック別カメラ、ブラウザの追加先は、今回の希望と異なる（[ADR 0052](0052-piano-keyboard.md)、[ADR 0053](0053-workspace-ui-foundation.md)、[ADR 0055](0055-loop-metronome.md)）。これらの ADR と P1 の検査証拠は当時の実装として残し、以下を P2 の置換方針とする。

## 決定

### 操作対象と表示

選択トラック、最後に選択したトラック、ピアノロールの編集対象集合、新規ノートの入力先、デバイスビューのトラック／クリップの対象を区別する。操作の開始時に文書と安定した ID で対象を確定し、遅い読込みや GUI 応答で現在の選択へ付け替えない。ブラウザを開いた時の対象を、後のすべての追加操作へ固定する方式にも統一しない。

アレンジのトラック選択だけではピアノロールの編集対象を変えず、明示的に開いて切り替える。編集対象の切替でも時間方向のズーム・スクロールと音域を保つ。参照表示・編集・ソロ・ミュートは独立させる。単一編集を中心とし、複数編集は既存ノートの一括修正に使う。一括操作では入力先を維持し、入力先が無効になって編集対象が 1 つ残ればそこへ移す。専用の入力先切替 UI は追加しない。

トラック一覧末尾の追加ボタンは末尾へ、ショートカット等は選択トラックの下へ追加する。フォルダは展開中なら最後の子、折りたたみ中なら部分木の直後の外側へ追加し、[ADR 0024](0024-track-order.md) の親子と表示順の不変条件を守る。トラックの通常複製は音源・FX・クリップ・オートメーションを含める。

### 入力と再生

ノートはシングルクリックで記憶した入力長を使い、空白からの左ドラッグは開始位置を固定して右へ伸ばし、左へ戻すと現在のグリッドの最小幅で止める。既存ノートの Shift 伸縮ではグリッド未満にできる。通常の移動ではつかんだノートを絶対グリッドへ合わせ、複数ノートには同じ差分を適用する。

入力長はプロジェクトの編集セッション内でトラック共通に持ち、初回は現在のグリッド幅、以後のグリッド変更では維持する。ノート追加・長さ変更の Undo は記憶も戻し、再読込では記憶せずグリッド幅から始める。一括伸縮では以前の記憶を保つ。ベロシティもトラック共通に引き継ぐが、一括ドラッグ後はつかんだノートの変更後の値を使う。長さだけに決まった Undo・永続化の規則をベロシティへ流用しない。

記憶した再生開始位置、進行中の再生ヘッド、一時停止位置、ループ区間、編集区間、リージョンを区別する。停止は開始位置へ戻り、一時停止はその場から再開する。Space は再生／停止、Return は一時停止／再開とし、停止中はどちらも開始位置から、一時停止中はどちらも一時停止位置から再生する。入力欄と IME のキーを全体操作へ漏らさない。両ルーラーのクリックで開始位置を変更し、再生中は即座にシークする。開始位置はプロジェクトに保存する。

ルーラーのドラッグはループ区間だけを設定する。ループより前から再生すれば終端で戻り、終端以降から再生・シークした場合はそのまま先へ進む。手動スクロールで再生ヘッド追従をオフにし、明示的なオンまで保持する。

### クリップ・構成編集

ノート・クリップは通常ドラッグで移動、Command＋ドラッグで複製移動する。重ねる／置き換える状態をアレンジとピアノロールで独立して持ち、初期値は重ねる。置換の判定は同じトラックの実際の重なりとし、ノートでは同音高も条件とする。別音高の和音を同時刻だけで消さない。

現行モデルの配置重複の拒否と、終了順も開始順に一致する索引の前提は、この P2 要件に合わせて置き換える（[ADR 0022](0022-clip-content-and-placement.md)、[ADR 0071](0071-clip-overlap-index.md)）。不変条件・アクション・保存・可視問い合わせ・音声計画を同時に変更し、オーディオスレッドで全配置を走査しない契約を保つ。クリップ FX バウンスを別トラックへ取り込む既存の安全策は引き続き使う。

オーディオの通常の端ドラッグは非破壊のトリムで、素材終端を越えて自動反復しない。複製は現在のクリップ長を基準に並べる。重なる音声クリップは自動クロスフェード、分割・トリムの切り口は調整・解除できる短いフェードとする。[ADR 0107](0107-mix-controls.md) の手動操作があるだけで、これらの自動処理を完成扱いにしない。

アレンジの右ドラッグはクリップ全体の枠選択、空白からの左ドラッグは時間とまたいだトラックの編集区間とする。区間コピーは中身だけ、Delete は空白を残す。貼付けは現在の再生ヘッドと選択トラックを起点にする。ループ区間からリージョンを作り、選択すると全トラックの編集区間を指定するが、ループは変えない。移動・複製ではオートメーションも伴う。通常の複製・削除で後続時刻は変えない。マグネティックタイムラインは将来の検討候補とする。

### ブラウザ・FX・ミックス

共通サンプルブラウザは登録素材全体のファイル名検索とフォルダ移動を使い、選択だけで素の音を 1 回試聴する。曲の再生中も鳴らし、次の選択で前の試聴を止める。ダブルクリックは選択トラックの現在の再生ヘッドへ正確に音声を置き、ブラウザを開いたままにする。

FX 候補は各トラックの FX 空欄から開く流れを基本とする。ダブルクリックは最後に選択したトラック、右クリックの一括追加は全選択、ドロップはその対象へ追加する。クリップ FX の表示中もダブルクリック先を変えない。[ADR 0059](0059-clip-fx.md) のクリップへの直接ドロップは保ち、Return もダブルクリックと同じ最後に選択したトラックへ追加する。同一チェイン内は通常ドラッグで並替え、Command＋ドラッグで複製、別トラックへの通常ドラッグは元を残すコピーとする。単体追加では GUI を自動表示し、一括追加とトラック複製では手動で開く。

複数選択の音量は同じ dB 差、パンは同じ位置差を適用する。ミュート・ソロはクリック後の状態へ全選択をそろえる。通常のソロは加算する。

センド作成は送り元のドラッグ・一覧と受け側の一覧から同じ接続を編集する。新規センドは FX 後・フェーダー前、0 dB とし、送り元フェーダーと独立させる。送り元のミュートはセンドも止め、ソロは関連するリターンも聴けるようにする。共用リターンの処理に必要な依存と、非ソロの送り元の可聴性を分ける。受け側からの操作を Phase 3 のオーディオレシーバーデバイスの前倒しとは扱わない。

### オートメーションと書出し

オートメーションモード有効時は、全トラックのクリップ表示領域を曲線表示へ置き換え、各トラックで最後に操作したパラメータを自動表示する。無効時は通常のレーンを使い、そのパラメータのレーンを所有トラックの一番上へ自動表示する。表示変更でクリップや曲線を削除せず、パラメータは安定した所有 ID で追う。

点の追加・移動と線の上下ドラッグを中心にし、通常の線ドラッグは両端を同じ量だけ移動、Option は両端を固定して曲率を変える。最初の 1 点は前後にも同じ値を適用する。手動の試聴操作を離した時は現在時刻の曲線値へ戻し、明示的なタッチ・ラッチ・書込みの計画と区別する。詳細は [操作要件](../interaction-design.md#オートメーションの表示と編集)。

書出しの初期範囲は曲全体、通常はミックス 1 ファイルとする。余韻も含め、末尾を調整できるようにする。初回は変更可能な共通デフォルト（初期値 WAV・24 bit・プロジェクトのサンプルレート）、以後はプロジェクトの前回設定を使う。現在のミュート・ソロ・関連 FX を反映する。別プロセスへ固定した版と設定を渡し、処理中の編集を出力へ混ぜない。ステム等の既存計画を取り除く決定ではない。

## 実装時期と残る境界

各要件を [P2 の実装順](../phase2.md) のデバイス・ルーティング・オートメーション・ミックス・編集・書出しへ接続する。ドラムラックは [ADR 0116](0116-folder-drum-rack.md) を使い、再発音では旧音のリリースと新しい音を独立して重ねる。

ループ素材の BPM 自動推定、テンポ追従、音高を保つ伸縮、方式選択、速度 1.0 への復帰と追従基準の更新は希望操作として保持し、実装は既存の後続 Phase のままとする。汎用コンテナ・マクロ・モジュレーターも Phase 3 のままとする。今回の会話を DSP の実装選定や性能測定の根拠にはしない。

境界の数値、区間で切れるノート、置換の前後、フォルダの開閉状態の保持、共用経路のソロ、余韻の終端等は [未決事項](../interaction-design.md#次に詰める点) に集約する。未決事項の全解消や製品実装を、この文書化の完了と混同しない。

## 受入と基盤の保守

操作の正本に [将来の受入・診断要件](../interaction-design.md#実装へ進む時の受入と基盤の保守) を保持する。実 View からの入力、安定した対象、確定・取消・1 回の Undo、保存・復旧、製品バッファと別プロセスの書出しまでつなぐ。モデル変更時は不変条件とランダムな操作列、音を作る経路はブロック長比較と RT、隔離と橋渡しは対応する検査へ追加する。新しい必須契約・検査は既存の登録と選択回帰へ接続する。

診断では選択・編集・入力・FX の対象と、開始位置・現在位置・ループ・編集区間を分け、遅い要求、パラメータ所有、手動値、接続とソロの依存、ボイス、書出しの版と設定を追えるようにする。今回は設計資料だけの更新であり、製品・依存・テスト・診断コードの変更は不要。実機・聴感は未確認のまま残す。

## ミックスの後続実装（2026-10-28）

ヘッダ・インスペクターのミュート／ソロの一括操作を、選択の捕捉・連打の順序・単一 Undo・保存へ接続した。
ピアノ行は単一対象を保つ。相対音量・パンとコンソール表示は残り、実画面・VoiceOver・聴感は未確認である
（[ADR 0189](0189-selected-track-mute-and-solo.md)）。
