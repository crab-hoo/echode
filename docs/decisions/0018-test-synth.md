# 0018. テスト用シンセは wavesynth を使う

- 日付: 2026-10-08
- 状態: 採用。自作の余弦は選択肢にしない

## 背景

外部のプラグインがなくても、打ち込んだ MIDI が音になることを確かめたい。ゴールデンテストでは、同じ入力が同じサンプル列になる必要がある（ARCHITECTURE §10）。

整数位相の余弦を自作して入れたが、これは [0014](0014-existing-implementations-as-options.md) に反する。ハードウェアなしで MIDI を受け、サンプルを返す完成した Rust のシンセがある。

| 実装 | ライセンス | 扱い |
|---|---|---|
| wavesynth 0.1.0（Sine Pad） | MIT OR Apache-2.0。依存の libm 0.2.16 は MIT | 既定。ノートオンとノートオフ、ADSR、ローパスを持つ |
| dasp_interpolate 0.11.0（フロア、線形、sinc） | MIT OR Apache-2.0。dasp_frame、dasp_sample、dasp_ring_buffer も同じ | サンプラーの既定は線形。sinc の窓は 16 フレームで、録音の長さの上限ではない |
| fundsp 0.23 | MIT OR Apache-2.0 | 発振器の部品。今回のテスト楽器にはしない |
| rustysynth | MIT | SoundFont が要る |
| oxisynth 0.1 | LGPL-2.1 | SoundFont が要る |
| FluidSynth | LGPL-2.1-or-later | SoundFont が要る |
| sfizz | BSD-2-Clause | SFZ が要る |

wavesynth の `SynthEngine` は、空きが無いと先頭の声を奪い、鳴っている声の数で割って混ぜる。製品の同時発音数に上限は置かないので、声は `Voice` を呼び出し側のスロットに置き、サンプルは足す。足りないスロットはエラーにする。Sine Pad の構築と、ノートオンから 1 サンプル進める処理は、ヒープを確保しない。

## 決定

- テスト用シンセの既定は wavesynth 0.1.0 の Sine Pad とする
- テスト用サンプラーの再生速度の補間は dasp_interpolate 0.11.0 のフロア、線形、sinc とする。既定は線形で、サンプルの境界では元の値を返す
- 自作の余弦と、自作の線形補間は選択肢に出さない
- 本体のプロセスで動かし、呼び出し側のバッファに足す

## 結果

Apple M4 のリリースビルドで、48 kHz、64 サンプルのブロック、声のスロット 4、ノート 1 つを 1 秒分レンダリングするのに 949 µs だった。1 コアの 0.095% にあたる。デバッグビルドでは、その処理がメモリを確保しないことを検出する。

同じ機械で、長さ 1 秒の PCM を基準音程で 1 秒分読むと、フロアが 278 µs、線形が 279 µs、sinc が 7.2 ms だった。それぞれ 1 コアの 0.028%、0.028%、0.72% にあたる。速さではフロアと線形が並び、音のつながりでは線形と sinc がフロアより細かい。どれも他のすべてで劣るわけではないので、3 つとも選べる。
