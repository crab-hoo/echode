# ADR 0219: 配置の変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。配置の項目と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0022](0022-clip-content-and-placement.md)、[ADR 0218](0218-content-changeset-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

中身に続き、配置も差分・作成と削除・下書き・設定・復元で同じ項目の対応を手で列挙していた。
今回は既存の結果を保つ構造整理であり、配置の編集規則・保存形式・再生音は変更しない。

## 決定

- `changeset_placement.rs` の `placement_fields!` に、中身の ID・開始・長さ・オフセット・種類・ゲイン・両フェードの 8 項目を宣言する。
  `Property`・フィールド・下書きの型・`Value` の種類・読出し・両方向の変換を表に持つ。
  差分、作成と削除、下書き、設定と復元を表から生成する。
- 作成と削除は、所属・中身・開始・長さ・オフセット・種類・ゲイン・入りフェード・出フェード・レーンの順を保つ。
  更新は、所属・開始・長さ・種類・オフセット・中身・ゲイン・入りフェード・出フェードの順を保つ。
  項目の対応は 1 つの表に置き、異なる更新順だけを別に指定する。
- ゲインは下書きと `Value::Gain` では `u32` のビットで持ち、復元時だけ `f32` へ戻す。
  符号付きゼロ・非正規化数・非有限値のビットも低水準 API ではそのまま運ぶ。
  これは公開前の不変条件検査と保存時のゼロの正規化を変更するものではない。
- 配置の ID と所属は項目表の外へ保つ。
  所属は書き換えられるが、`Draft` がトラックの配置 ID 列との一致、重複・欠落・使い残しを検査する。
  中身の参照も `Draft` が存在を検査してから復元へ委譲する。
- `Draft::set` は配置の ID で下書きへ委譲する。
  必須項目の欠落、誤った型、未知の ID、対象外のプロパティと二重作成の拒否を保つ。
- レーンは引き続きタイムラインだけとする。
  作成時は従来どおりレーンの値を読まず、古いテキスト更新は無変更の成功を保つ。
  未知の ID へのレーンのテキスト更新も従来の無変更互換を保つ。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo と配置の編集規則は変更しない。
  テンポ・プロジェクトと保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ回帰を追加し、同じ公開入口で構造整理後の結果を照合した。

- `echode-history/tests/placement_changesets.rs` は項目表を参照しない独立した期待値を持つ。
  任意の整数・ゲインビット、8 項目の全組合せ、作成と更新で異なる順序、削除・逆適用・二重反転・ジャーナルを照合する。
  NaN の異なるビット・無限大・符号付きゼロ・非正規化数も明示し、別の下書きへ復元した同じ値で差分が生じないことを検査する。
- 同じ回帰で所属・中身・全スカラー項目を同時に変え、トラックの配置 ID 列との一致を検査する。
  必須項目・型・未知の ID・二重作成・不正な参照と配置列、レーンの省略・無変更互換も通す。
  任意の整数や非有限ビットの往復を、有効な製品状態としての受入とは区別する。
- 操作列の `properties.rs` に、固定・共有配置、負のオフセット、小さいゲインと非既定フェードからの初期状態を加える。
  不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  モデルの値だけを検査し、素材・プラグイン・音声機器は開かない。

新しい実行入口や依存は追加しない。既存の `check` が回帰を実行するため、検査選択の条件は変更しない。
フィールドと入力を含むアサーションを既存ログへ残し、診断の収集先・手順は変更不要とする。
実機・実画面・聴感の合否と性能の改善は、この構造整理からは主張しない。
