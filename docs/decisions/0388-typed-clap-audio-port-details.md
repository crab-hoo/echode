# ADR 0388: CLAP の音声ポート詳細を所有する型としてフォームからヘルパーへ送る

- 日付: 2026-11-16
- 状態: 現行
- 領域: プラグイン・隔離
- 対象: P2-02・F2・FCA-07 のサラウンド配置と Ambisonic 設定

## 背景と再現

開始時の HEAD は `21112a2`。
[ADR 0387](0387-device-audio-port-change-form.md) のフォームはチャンネル数だけを送り、ヘルパーは常に `port_details = null` としていた。
CLAP 標準のサラウンド配置と Ambisonic 設定を指定できなかった。
文書の製品入口へ詳細付きの要求を通す回帰を先に足し、未知の `details` 欄で拒否されることを確認した。
期待終了コード 101 と固有のアサーションは `target/focused-checks/audio-port-details-red/` に記録した。

## 比べた案と決定

- **任意のポート種別文字列と生のバイト列を送る**: 不採用。
  CLAP の型に応じたサイズ・アラインメント・寿命を呼出し元へ漏らし、ヘルパーで安全なポインターを作れない。
- **標準の詳細を所有する列挙型で送る**: 採用。
  `Surround(Vec<u8>)` と `Ambisonic { ordering: u32, normalization: u32 }` を制御ソケットへ値として送る。
  ヘルパーだけが CLAP の静的な種別文字列と `port_details` を作る。
  サラウンドの配置は元の要求から借り、Ambisonic の ABI 構造体は全件分を確保してからポインターを作り、同期 callback の終了まで動かさない。
- **チャンネル数から特殊な配置を推測する**: 不採用。
  同じ数でも配置は異なる。既存の自動モードはモノ／ステレオだけを推測し、特殊な設定はフォームで明示する。
- **ホストで受理可能な配置を列挙・照会する**: 不採用。
  読取りも無効化を伴う。数値の幅と借用の長さを守り、意味上の対応可否は明示した適用でプラグインに判定させる。

[CLAP の標準ヘッダ](https://github.com/free-audio/clap/blob/main/include/clap/ext/configurable-audio-ports.h) は、
サラウンドを `const uint8_t *channel_map`、Ambisonic を `const clap_ambisonic_config_t *` と定める。
新しい依存や独自の FFI 宣言を足さず、固定済みの `clap-sys 0.5.0` の型を使う。
性能の改善は目的でなく、時間の比較計測はしない。追加の処理・確保は無効化中の制御側だけで、音声側は変えない。

## 境界と回帰

JSON の `details` は省略可能で、`type` が `surround` なら `channel_map`、`ambisonic` なら `ordering` と `normalization` を持つ。
serde は不正型・未知の種類や欄・欠損・幅を超えた数を拒否する。
制御ソケットは種類の 1 バイトと所有する値を運び、不明な種類・途中までの本文・余分な本文を型付きの原因で拒否する。
配置の長さがチャンネル数と違う要求は、プラグインを呼ぶ前に拒否する。空のサラウンド配置も拒否し、無効化・削除は自動モードの 0 で要求する。
ポート数・行数・チャンネル数の独自の上限は足さない。

フォームは配置の入力、順序（FuMa / ACN）、正規化（MaxN / SN3D / N3D / SN2D / N2D）を追加する。
編集・種類の切替え・取消では IPC を行わない。適用は従来と同じ一括要求・状態取得・単一 Undo/Redo とする。
プロジェクトへ配置を重複保存せず、プラグイン自身の状態を正本にする。

`device-audio-port-details-state` は文書要求から実ヘルパーへ詳細を送り、プラグイン状態の印・復元・単一の履歴と拒否後の解放を照合する。
`device-audio-port-details-ui` は実デバイス列から異なる詳細を含む一括送信・単一 Undo/Redo・暗黙の走査なしを照合する。
既存の単体回帰へ配置の順序・ABI の借用・長さ違いで呼ばないこと・入力境界を追加し、隔離・製品ルーティングの回帰も詳細付きにする。
既存の制御 fuzz の種へ両形式を加える。選択・反例は `scripts/verification.json`、実行は既存の Makefile の入口を使う。

## 残る範囲

音声バッファのチャンネルを並べ替えたり、多チャンネルの出力やサラウンド用パンを追加したわけではない。
母線が受けられない構成は既存の `BusMapping` が拒否する。
第三者の詳細解釈・状態保持・聴感、実画面・キーボード・VoiceOver は UC-101 に残す。
独自のポート種別・詳細、曲からの表情生成等は残り、P2-02・F2・FCA-07 全体を完了にはしない。
