# ADR 0145: 制作向けファイルの一覧と音声の位置指定ドロップ

- 日付: 2026-10-22
- 状態: 採用。実画面のドラッグ操作と VoiceOver はユーザー確認待ち
- 範囲: UIF-06・02、P2-02 の共通サンプルブラウザ
- 関連: [操作要件](../interaction-design.md#共通サンプルブラウザ)、[照合](../reviews/2026-10-21-ui-feedback-audit.md)

## 背景と再現

[ADR 0122](0122-sample-library-search-and-placement.md) は登録素材の検索と再生ヘッド位置への配置を接続した。
一覧は一般のファイルを表示する一方、登録範囲の検索は音声だけで、ドラッグ元とアレンジのファイル受け口はなかった。
[ADR 0143](0143-browser-click-and-audition-timing.md) の表へ置き換えた後も、この不足は残った。

`SampleBrowserContentTests` を製品の `FileBrowserState.load` と登録検索へ通し、無関係なファイルの表示と MIDI の検索漏れで失敗させた。
末尾の空間へドロップするにはトラック追加と取込みを同じ Undo にする必要がある。
`DocumentHost::apply` へ実 WAV と ID 参照付きの `track.add`・`audio.import` を渡すと、取込みがホスト専用コマンドとして拒否された。
この失敗も修正前の回帰へ記録した。

## 決定

### 表示とドラッグ元

- フォルダ一覧はフォルダ・対応音声・`.echode`・`.mid` / `.midi` を表示する。
  無関係な通常ファイル、隠し項目、シンボリックリンク、他のパッケージは表示しない。
- 登録範囲の名前検索も音声・MIDI・`.echode` を返す。
  パッケージ自身は検索できるが内部へ入らず、従来の重複排除・取消・古い索引の拒否を維持する。
- MIDI の名前には「MIDI の読込みは未対応」を添える。
  選択はできるが、配置・ドラッグ・試聴はしない。MIDI のインポート機能を完成扱いにしない。
- 表の音声行から公開の `public.file-url`（`NSURL`）を書き出す。
  押した時点で選択・フォーカス・試聴を行い、移動が 4 pt 以上になったらコピーのドラッグを始める。
  押した時点の URL を保持し、一覧の更新で別の行へ付け替えない。
  [ADR 0143](0143-browser-click-and-audition-timing.md) のダブルクリックと Return の配置は変えない。

### アレンジへのドロップ

- ブラウザ専用の形式を作らず、Finder と同じファイル URL を `ArrangeView` で受ける。
  初回は音声ファイル 1 つを扱い、複数ファイル・MIDI・プロジェクト・非ファイル URL・移動専用のドラッグは拒否する。
- ヘッダと分割線の外側のタイムラインにだけ受け付ける。
  現在のヘッダ幅、横スクロール、倍率から tick を、現在の表示用スナップショットと縦のカメラから対象トラックを決める。
  折りたたんだ子は行数に含めず、古い GPU フレームや選択トラック・再生位置を配置先に使わない。
- 現在アレンジが描く 1 拍のグリッドへ四捨五入する。
  Shift 中は丸めず、ポインターの tick を使う。後続の可変グリッドは、その表示と入力を同時に変更する。
- 最終表示行より下の空間では、最上位末尾へファイル名のトラックを追加する。
  空のプロジェクトにも同じアレンジを表示し、最初のトラックをドロップで作れる。
- ドラッグ進入時の文書セッションと、ドロップ時の URL・対象 ID・tick を保持する。
  進入後の文書交換、ドロップ後の文書交換・対象削除を拒否する。
  編集待ち行列の手番でも文書と対象を照合する。コピー元のファイルは変更しない。

### 取込みと単一履歴

- 既存の `DocumentHost` のトランザクション内で `audio.import` を解決する。
  文書スレッドが復号・PCM 保存を行い、確定操作は既存の `audio.place` に変換する。
  新しいモデルアクション、保存形式、音声処理は加えない。
- 新規トラックは `track.add` の結果への ID 参照を使い、取込みと合わせて 1 回の Undo・1 行のジャーナルにする。
  既存行への配置も同じ取込み経路を使う。Redo と復旧は外部パスを読み直さない。
- 復号や後続の要素が失敗したら、トラック・配置・履歴を戻し、Redo を保持する。
  [ADR 0056](0056-audio-import.md) と同様、失敗前に保存した PCM と索引は残り得る。
- 同トラックの配置の重複は、現行モデルどおり拒否する。
  重ねる・置き換える・自動クロスフェードは P2-07 の実装で扱い、この入力追加だけでは不変条件を緩めない。

## 回帰と診断

- `SampleBrowserContentTests` は表示対象・登録検索・MIDI の未対応表示と、音声だけの標準 URL の書出しを検査する。
- `SampleAudioDropTests` は実際の表の書出しとアレンジの受け口を使う。
  吸着・Shift・横スクロール・ヘッダ幅・折りたたみ・端数行・縦倍率・領域外と入力型の拒否を含める。
  AppKit の進入・更新・準備・確定・取消と文書交換も、機器とウィンドウを開かずに検査する。
- 製品の取込み・単一 Undo / Redo・保存再読込・対象削除を Swift から確認する。
  Rust の `audio_import_transaction` は後続失敗・復号失敗と Redo の保持、元ファイル削除後の Redo と復旧を確認する。
- 必須契約は `sample-browser-content-ui`・`sample-drop-ui`・`sample-drop-entry-ui`・`audio-import-transaction`。
  負の対照と選択回帰を既存の `check-product-contracts` へ登録する。
  モデルは既存の `audio.place` と `track.add` を使い、操作生成・ブロック長比較の対象は増やさない。
- 取込み失敗は従来の文書エラーへ返す。一括操作は失敗した要素の番号を保つ。
  [デバッグ手順](../debugging.md) に型の拒否・位置・重複・復号失敗の切分けを加え、収集先は既存の契約ログを使う。

## 残る範囲

Finder とブラウザからの実際のドラッグ、カーソルと行の見え方、フォルダ権限、VoiceOver はユーザー確認とする。
ドラッグ中の自動スクロール・配置予定の波形、複数ファイルの一括配置は未接続である。
波形プレビューと試聴の先読み・出力常駐・音量は、引継ぎ順の次の単位として残す。
