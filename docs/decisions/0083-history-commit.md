# ADR 0083: 失敗した編集は履歴を複製せずに戻す

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-10。文書ホストの編集の確定

## 背景

ジャーナルの追記に失敗したとき、編集前へ戻すために `Session` 全体を複製していた。複製には現在のプロジェクトだけでなく、Undo と Redo の各版と、ジャーナルの全差分が含まれる。ノートを順に足すと、その複製だけで 500 / 1,000 / 2,000 / 4,000 件が 0.157 / 0.648 / 2.403 / 9.877 ms だった。ノート順序の記録形式は [ADR 0084](0084-note-diff.md) で見直す。

## 決定

確定の前に Redo の列だけを退避する。Undo の履歴は複製しない。ジャーナルの追記が成功したら、退避した Redo は捨てる。追記が失敗したら、積んだ Undo を 1 件と、ジャーナルの末尾を 1 行だけ外し、Redo を戻す。操作そのものが失敗したときは、Redo を戻すだけで、Undo は動かさない。

Undo の確定に失敗したときは Redo で戻し、Redo の確定に失敗したときは Undo で戻す。その戻しまで失敗したときは、耐久性が分からないとしてホストを止める。

トランザクションの開始時に Redo を複製する経路は残る。先に Redo を空へ退避するので、その複製は空である。チェックポイントとして現在のプロジェクトを 1 つ持つことは変えない。

## 結果

追記に失敗した編集は、プロジェクトとジャーナルの長さを編集前へ戻す。Undo の列は複製しない。画面での操作確認は未実施である。
