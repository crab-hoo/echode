# ADR 0137: デバイス列の開閉と、可変幅での FX ドロップ

- 日付: 2026-10-21
- 状態: 採用。P2-02 の表示操作の追加。P2-02 全体は未完了
- 範囲: 横並びのデバイス列、文書内の一時的な開閉状態、ドロップ位置

## 背景

[操作要件](../interaction-design.md#デバイスビューと-fx-一覧の役割)には、横スクロールに加えたデバイスごとの開閉が残っていた。
[ADR 0131](0131-device-view-and-responsive-parameters.md)の列は、常に全幅で検索・一覧を表示する。
旧ドロップ判定も列番号と固定幅で挿入位置を求めるため、幅だけを縮めると別のデバイスを挿入先にしてしまう。

## 決定

- 列の左上のネイティブ開閉ボタンで、展開時 300 pt、折りたたみ時 200 pt を切り替える。
  これは表示幅であり、デバイス数・パラメーター数の上限ではない。
- 折りたたみ中は検索・一覧・読み込み／失敗の本文を隠す。
  名前、バイパス、オフライン、並べ替え・複製・削除を残す。
  名前クリックの独自 GUI とタイトルのドラッグは、展開時と同じデバイスを対象にする。
- 開閉はプロジェクトの編集ではなく、開いている文書内の表示状態とする。
  `ProjectController.collapsedDevices` にデバイス ID で保持し、トラック切替・エディタの作り直しでも維持する。
  文書を閉じる・交換する時に破棄し、再オープン時は全列を展開する。
- 同じ ID の並べ替え・削除の Undo では開閉状態を保ち、別 ID のコピー・複製は展開から始める。
  古い文書や削除済みデバイスからの開閉要求は拒否する。
  開閉そのものは保存・ジャーナル・Undo / Redo・音声計画を変更しない。
- 列とパラメーター状態・検索語を捨てず、展開時に最新の状態で一覧を更新する。
  開閉だけでは一覧の再要求・出力の起動・ヘルパーへの通信を追加しない。
  既に進行中の要求やプラグイン独自 GUI の寿命は変えない。
- 本文内の検索やスライダーに入力フォーカスが残っていれば、隠す前に解除する。
  非表示の入力欄に後続のキーを消費させない。
- 列の実際の幅の累積を、配置・スクロール範囲・挿入位置の共通の根拠にする。
  各列の中央より左はそのデバイスの前、右は次のデバイスの前、末尾はチェインの末尾とする。
  同一チェインの通常移動、Command 複製、別トラックからのコピーは同じ判定を使う。
  FX 追加ボタンも可変幅の最終列の右へ追従する。

## 検査と診断

- 実装前の `DeviceDisclosureTests` は、製品の列に開閉ボタンがなく失敗した。
  証拠は `target/device-disclosure-before.log`。最新の正式結果は `target/verification/report.md` を参照する。
- 必須契約 `device-disclosure-ui` は実ボタンを操作し、幅の縮小・一覧と検索の保持・名前の GUI 入口・バイパス・複製を確認する。
  展開列と折りたたみ列が混ざる全境界の左右で、移動とコピーの挿入先を確認する。
  負の対照は中央の判定だけを固定幅へ戻し、期待するデバイス ID の違いで失敗させる。
- 通常回帰は、トラック切替・列の再生成・削除の Undo・複製・保存再読込・旧文書の拒否、通信なし、Redo の保持も確認する。
  オフライン・読み込み中・失敗の開閉、末尾までスクロールした後の幅の縮小、隠れた検索欄のフォーカス解除を含む。
- 製品モデル・ABI・隔離・DSP は変更しないため、新しいブロック長テストや実機の音声検査は追加しない。
  既存の検査選択と必須契約の負の対照を維持し、新契約を登録する。
  診断は[デバッグ手順](../debugging.md)へ追加し、既存の製品契約ログを使うため収集先の追加は不要である。

## 残る範囲

実ウィンドウの操作感と VoiceOver の読み上げはユーザー確認とする。
複数選択時の表示対象、ヘッダの FX 空欄と挿入済み名前の区別、サムネイル等は今回の完了に含めない。
展開・折りたたみでプラグインをオフラインにしたり、音声負荷を下げたりする機能でもない。
