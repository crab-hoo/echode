# ADR 0387: 任意の音声ポート変更を明示フォームと単一の状態編集へ接続する

- 日付: 2026-11-16
- 状態: 一部置換（[ADR 0388](0388-typed-clap-audio-port-details.md)）。フォームに標準のポート詳細を追加
- 領域: プラグイン・隔離
- 対象: P2-03・F2・FCA-07 の `clap.configurable-audio-ports` の画面操作

## 背景と再現

開始時の HEAD は `41a890c`。
[ADR 0385](0385-clap-configurable-audio-ports-and-config-info.md) の任意変更は制御 API までで、デバイス列からはプリセットしか選べなかった。
文書の製品入口 `device::dispatch` に `device.audio_ports.apply` を通す回帰を先に足し、未知の種類で拒否されることを確認した。
期待終了コード 101 と固有のアサーションは `target/focused-checks/audio-ports-ui-red/` に記録した。

## 比べた案と決定

- **画面を開く時に対応能力・現在のポートを走査する**: 不採用。
  既存の構成一覧は無効化を伴う。フォームを開くことや入力を音声の中断に結び付けず、適用だけで往復する。
- **変更するポートだけを行として入力する一時フォーム**: 採用。
  入出力・0 始まりのポート番号・チャンネル数を入力し、行の追加・削除と取消を持つ。
  0 は無効化・削除の要求として通す。全行を一度の `apply_configuration` へ送り、途中の行だけを適用しない。
  実際に受けられる番号・構成と、拡張の対応はプラグインが判定する。特殊な `port_details` は従来どおり null とする。
- **入力のたび、または適用の直前に `can_apply` を呼ぶ**: 不採用。
  読取りだけでも中断し、先に成功した照会は後の適用の成功を保証しない。明示した適用の拒否をそのまま表示する。
- **選択とは別の保存・Undo 経路を作る**: 不採用。
  [ADR 0386](0386-device-audio-configuration-controls.md) の選択と同じ完了処理へ統合し、背景保存の保留・適用・状態取得・単一の状態編集・保留解除を使う。
  要求の配列やポート数をプロジェクトへ複製せず、プラグイン自身の状態を正本にする。

## 境界と検証

C ABI を増やさず、既存の JSON デバイス要求に `device.audio_ports.apply` を追加する。
`requests` の各要素は `input: bool`・`index: u32`・`channels: u32` とし、serde が欠損・不正型・範囲外・未知の欄を拒否する。
Swift の型は同じ幅で符号化し、フォームは空欄・符号・小数・範囲外を適用しない。
行数・ポート番号・チャンネル数には製品独自の固定上限を足さない。
共有領域・ルーティングは [ADR 0382](0382-audio-port-changes-exchange-mapping-and-routing.md) の交換を使い、音声スレッドは変更しない。

フォームの作成・取消・入力はプラグインを呼ばない。
適用済み・取消済みのフォームと、文書の publication をまたいだフォームは既存の要求世代と所有するフォームの同一性で拒否する。
列の開閉・オフライン化・文書交換でも閉じる。新しい世代を別の正本として保存しない。
拒否・時間切れ・取得や記録の失敗で背景保存を解き、自動再送しない。

実ヘルパーで状態の取得・Undo/Redo・再オープン・拒否後の保留解除を確認する `device-audio-ports-state` と、
複数行・一度だけの送信・古いフォーム・暗黙の走査なしを確認する `device-audio-ports-ui` を必須契約へ登録する。
入力の境界・取消・失敗と明示再試行も通常の Swift / Rust テストへ足す。
選択条件・依存入力と反例は `scripts/verification.json` に置き、選択のテストを更新する。
実行は既存の Makefile の `check-product-contracts`・`check`・`check-swift` を使い、新しい検査コマンドは増やさない。
既存の制御 IPC の fuzz が任意ポート要求を通すため、新しいソケット形式や fuzz 対象は不要である。

## 残る確認

第三者の拡張の解釈・状態保持・聴感は UC-98、実画面・キーボード・VoiceOver は UC-100 に残す。
特殊な `port_details`、曲からの表情生成・編集、センド等は残り、P2-03・F2・FCA-07 全体の完了とはしない。
