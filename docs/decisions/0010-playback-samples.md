# 0010. 再生位置はサンプルで持つ

- 日付: 2026-10-08
- 状態: 採用

## 背景

ドキュメントの時間は tick と flick である。音を出すには、テンポを通してデバイスのサンプル位置に落とす必要がある。ブロックの途中でループが戻ると、鳴り終わっていないノートを残したまま先頭のノートが重なる。

## 決定

- 再生位置は、プロジェクト原点からのサンプル番号とする。tick への変換はテンポマップの flick 値を一度だけ丸める
- MIDI は、ノートの開始と終了がブロックのサンプル範囲に入ったとき、そのオフセットでノートオンとノートオフを書く。同じサンプルではノートオフを先にする
- ループでプレイヘッドが飛んだスパンは、飛んだ時点でまだ鳴っているノートを、着地の最初のフレームで止める
- メトロノームは 4 分音符ごとに、小節の頭を強く、他の拍を弱く、呼び出し側のバッファへ足す
- これらの関数は割り当てをしない。イベントとサンプルのバッファは呼び出し側が渡し、その長さはそのブロックの作業領域である。CoreAudio への接続は、鳴らす音源を載せる時に行う

## 結果

120 BPM・48 kHz では 4 分音符が 24,000 サンプルになり、ループをまたいだノートが止まってから打ち直されることをテストで確認する。
