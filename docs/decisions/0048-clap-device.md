# 0048. CLAP デバイスはミキサーの前に置き、スキャンはヘルパーで行う

- 日付: 2026-10-10
- 状態: 採用
- 項目: Phase 1 のプラグインブラウザ

## 背景

ADR 0026 は、各トラックがミキサーを 1 つ持ち、プラグインは後から足すとしている。ADR 0031 はデバイスに `state` を足したが、プラグインが無い間はハッシュを拒否する。一覧はヘルパーがファクトリー記述子だけを読む（ADR 0016）。プロジェクトはパスではなく CLAP の ID でプラグインを参照する（ARCHITECTURE §9.6）。

再生中の製品経路は、まだ内蔵の Sine Pad だけを鳴らす。この項目は、挿入したデバイスをプロジェクトに残し、ブラウザから選べるようにする。ヘルパーで音を鳴らす接続は、その次である。

## 決定

- トラックのデバイスは、0 個以上の CLAP デバイスのあとに、ミキサーが 1 つで終わる。個数の上限はない。同じ CLAP ID を 1 つのトラックに複数置ける。それぞれ別のデバイス ID を持つ
- CLAP デバイスの種類は `clap` である。`plugin` は空でない CLAP ID で、制御文字を含まない。パラメータは空である。状態は `null` のまま拒否する。ミキサーの `plugin` は `null` である
- 並びはデバイス ID の列として ChangeSet に残す。挿入はミキサーの直前、削除は CLAP デバイスだけである。ミキサーは外せない
- アクションは `device.add`（トラックと CLAP ID）と `device.remove`（デバイス ID）である。ID は実行時に採番し、ジャーナルへ残す
- パッケージの版は 2 である。版 1 は各デバイスに `plugin: null` を足してから読む。見本の版 1 はそのまま残す
- ブラウザはインストール済みの CLAP を、`echode-plugin-host --scan` で調べた結果から出す。本体のプロセスはバンドルを読み込まない。キャッシュに同じ版があるバンドルは調べ直さない。失敗した版は、実行ファイルが変わるまで再スキャンしない。1 バンドルの待ちは 5 秒で、これはハングした束の締め切りであり、プラグイン数の上限ではない
- ダブルクリックで挿入したときはブラウザを閉じ、Enter と「挿入」のアクセシビリティ操作では開いたままにする。サムネイルとバックグラウンドのフォルダ監視の画面への配線は、この項目では作らない

## 確認

- プラグインを 2 つ挿すとミキサーが末尾に残り、片方を外してもミキサーは残る。空の ID と制御文字は拒否する。ChangeSet の逆適用で戻る
- 版 1 の見本は今のモデルになる。書き出したトラックは `plugin` を持つ版 2 である
- ヘルパープロセスがテスト用 CLAP の記述子を読み、同じ版の 2 回目はキャッシュを使う
- アプリは挿入した ID をスナップショットから読み、パッケージを開き直しても同じ ID が残る
