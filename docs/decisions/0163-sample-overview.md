# ADR 0163: ブラウザの波形を試聴から分け、選択した素材の全体を表示して残す

- 日付: 2026-10-25
- 状態: 採用。[2026-10-25 の操作の報告](../reviews/2026-10-25-user-feedback.md) の FB-03 への対応。
  [ADR 0151](0151-streaming-sample-audition.md) の「波形は試聴した素材だけを対象とし、先行読込みやキャッシュは持たない」を置き換える。
  実画面の表示の速さはユーザー確認待ち
- 関連: [ADR 0143](0143-browser-click-and-audition-timing.md)、[ADR 0152](0152-browser-audition-controls.md)

## 背景

サンプルの波形が試聴のたびに読み込まれ、停止すると消えるのは不便で、切り替えたらすぐ全体が表示されるのがよいと報告された。
ADR 0151 は試聴の読込みから部分波形を作り、試聴の報告だけを表示していた。
自動試聴をオフにした選択では波形が出ず、試聴の停止で報告が消えると波形も消える。長い素材は再生に合わせて少しずつ伸びる。

## 決定

### 全体の波形は別に読む

- `echode_audio_io::sample_overview` は、AudioToolbox で素材の全体を 65,536 フレームずつ読み、
  試聴と同じ 512 区間の最小・最大を作る。SRC はせず、出力も文書も使わない。
  読込みの大きさと区間数は表示と作業の単位であり、素材の長さの上限ではない。
- C ABI の `echode_sample_overview` は呼んだスレッドで読み、`{"waveform": ...}`・`{"error": ...}`・`{"cancelled": true}` を返す。
  ブラウザごとのチャンネルで、より大きい要求番号の読込みが始まると、同じチャンネルの古い読込みは次の読込みの前に止まる。
  一覧を矢印で送っても、選択から外れたファイルの全体の復号を積み上げない。
  別のウィンドウのブラウザの読込みは止めない。ブラウザの破棄（`echode_sample_overview_end`）でそのチャンネルの読込みを止める。
  最初の実装はプロセス全体で最新の要求だけを生かしていたため、並行するテストが互いの読込みを止め、`make verify` の TSan の実行で検出した。

### 選択で読み、保持する

- ブラウザの選択が音声素材になった時（クリック・キー・検索での付け替えのいずれも）、`SampleOverviews` が全体を読む。
  波形の表示は音を出さないため、ADR 0143 の「試聴は利用者のクリックとキーだけで変わる」とは別の規則とする。
- 読んだ全体は直近 256 件まで保持し、戻った時は読み直さずに表示する。件数は表示用の保持数であり、一覧のファイル数の上限ではない。
  サイズか更新日時が変わったファイルは読み直す。保存・Undo の対象にはしない。
- `SamplePreviewView` は全体の波形を優先して表示する。全体の読込み中だけ、同じ素材の試聴の部分波形を代わりに表示する。
  試聴の停止・終了では全体の波形を消さない。開始位置の線と波形のクリックによる試聴（ADR 0152）は全体の長さで扱う。
- 全体を読めない時は「サンプルをプレビューできません」と表示し、理由をツールチップに示す。試聴が鳴るかどうかとは独立である。

## 検査

- `echode-ffi` の単体テストで、新しい要求が同じチャンネルだけを止め、終了したチャンネルが止まることを確認する。
- 必須契約 `sample-overview` は、読込み単位をまたぐステレオの WAV の全体の長さ・区間数・左右の最小最大、
  試聴が全体を読み終えた時の波形との一致、新しい要求での中断、存在しないファイルのエラーを確認する。
  反例は最初の読込みで終える。
- 必須契約 `sample-overview-ui` は、製品のブリッジで選択だけから全体の波形を読み、
  試聴の部分波形や停止で置き換えないこと、戻った時に読み直さないこと、変更されたファイルを読み直すこと、保持数を超えた古いものを読み直すことを確認する。
  反例は表示で全体の波形を使わない。
- 既存の `sample-preview-ui` は、全体の波形がない時の試聴の部分波形と、別の選択の報告を使わないことを引き続き確認する。
- 試聴の音声経路と RT の処理は変えない。長いファイルの読込み時間の計測と、隣の行の先読みは今回入れない。
