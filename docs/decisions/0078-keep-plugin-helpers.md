# ADR 0078: 変わっていない CLAP デバイスのヘルパーを残す

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 監査 PRO-05。再生計画の差し替えと、プラグインへのノート

## 背景

トラックを足すと計画の列が変わり、全部のヘルパーを起動し直していた。内蔵シンセは前の計画からボイスを引き継ぐので、そのノートオンはプラグインへ再送しない。新品のプラグインはそのノートを受け取っておらず、長音が消えた。

## 決定

ヘルパーはデバイス ID と CLAP ID の組で残す。計画を差し替えるとき、同じ組のプロセスは起動し直さない。消えたデバイスのプロセスは捨て、新しいデバイスだけ起動する。起動に失敗しても、残しているプロセスは落とさない。

前の計画から引き継いだノートオンは、内蔵シンセへは再送しない。すでにそのノートを受け取っているヘルパーへも再送しない。この計画の更新で起動したヘルパーにだけ渡す。タイムラインがこのブロックで出すノートオンは、ループの先頭での打ち直しを含め、シンセと既存のヘルパーの両方へ届ける。

## 結果

長音を受けているプラグインは、空トラックを足したあとも受信数を維持する。鳴っている最中に足したプラグインは、そのノートオンを1つ受け取る。ループを一周したときのノートオフと再打鍵も、既存のヘルパーに届く。
