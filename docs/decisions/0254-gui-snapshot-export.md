# 0254. GUI の書出し設定・専用スナップショット・別プロセス実行

日付: 2026-11-03。
状態: 採用（P2-08 の曲全体の WAV 書出しの先行分。単位全体の受入完了ではない）。

## 背景と再現

CLI の PCM16 / PCM24・RF64・余韻・TPDF は接続済みだったが、アプリに書出しの入口と前回設定の保持がなかった。
開いている元パッケージを CLI に渡すだけでは、文書の排他ロックに加え、準備後の編集が書出しへ混ざる問題がある。
[操作要件](../interaction-design.md#書き出し) の版と設定の固定・別プロセス実行を一緒に接続する。

既存の橋渡しへ `HistoryCommand.exportSnapshot` と Swift の最小回帰を先に追加し、
文書ワーカーが `history command was not recognized` を返すことを製品の入口から再現した。
終了コード 1 と固有の `Export snapshot failed: ...history command was not recognized` を照合した。
証拠は `target/export-red/`。後続の回帰はこの要求を実 CLI の完走まで通す。

## 決定: 確定状態の捕捉

- `history.export_snapshot` は文書ワーカーで現在の不変な `Arc<Project>` を捕捉する。
  復旧への同意待ちなら拒否する。元パッケージの保存・履歴・Undo / Redo は変更しない。
- `freeze_export` は存在しない専用ディレクトリだけを作り、曲の保存形式と、
  その曲が参照する音声・プラグイン状態のオブジェクトだけをコピーする。
  既存のハッシュ照合・リンク拒否・原子的なオブジェクト保存を共有し、ジャーナル・Git 履歴・キャッシュ・無関係な素材はコピーしない。
- 既存のディレクトリ・ファイル・リンクは上書きせず、失敗した新規ディレクトリだけを片付ける。
  コピー中は文書ワーカーの後続要求が待つが、機器を開かず RT の処理へ I/O を持ち込まない。
  巨大なオブジェクトは既存の読込みと同じく一度メモリへ読み、コピーの容量と時間は残る。
- コントローラーは捕捉した `DocumentID` を再照合し、ミックス・パラメーター・プラグイン自身の進行中のジェスチャーを拒否する。
  静止待ちのプラグイン編集は先に記録する。未確定のノート等の下書きや、ライブ状態の無条件の採取はしない。

## 決定: 設定と画面

- ファイルメニュー・⇧⌘E・コマンドパレットに「音声を書き出す」を追加する。
  シートで WAV の PCM24 / PCM16 / float32、整数 Hz のレート、申告値または秒指定の余韻、TPDF の有無を選ぶ。
  保存パネルの取消では書出しも設定保存もしない。
- GUI の初回は PCM24・ディザなし・申告された余韻を使う。
  モデルにはプロジェクト固有の保存レートがまだないため、初回レートは準備済み出力の値、なければ 48 kHz とする。
  将来のプロジェクトレートの要件を完了扱いにしない。CLI 自体の既定の float32 は変更しない。
- 秒指定は出力レートとの積を最近接のフレームへ丸め、CLI の `--tail-frames` へ渡す。
  非有限・負値・ゼロレート・u32 への換算超過と、float＋TPDF は開始前に拒否する。
  曲本体との総長の超過は既存 CLI が拒否する。追加の DSP やフェードは作らない。
- 受理された設定はこの Mac の UserDefaults の `workspace.export.v1.<正規化したパス>` へ保存する。
  不正・旧形式の値は初期値へ戻す。文書のモデル・ジャーナル・スキーマは変えない。
  別名保存・移動・別の Mac への持ち運び、共通デフォルトは未接続である。

## 決定: CLI と寿命・失敗

- ウィンドウ所有の `ExportJob` が一度に一つの要求を保持し、設定シートを閉じてから準備する。
  準備後は専用パッケージを CLI が開くので、元の文書の編集・再生・終了・交換と独立する。
  元パッケージ内部への出力は拒否する。文書交換で結果を次の文書のエラー状態へ書き込まない。
- 開発・配布バンドルに同版の CLI を `Contents/MacOS/echode-cli` として同梱・署名する。
  大文字小文字を区別しないボリュームで GUI の `Echode` と衝突するため、製品バンドルでは `echode` と命名しない。
  CLI の library validation は無効化せず、プラグインは従来どおり別の隔離ヘルパーが読み込む。
- 起動・終了待ちはメインアクターの外で行い、シェルを使わず argv を渡す。
  標準出力は破棄、標準エラーは専用ファイルへ出す。親が待つ間に pipe が埋まるデッドロックを避ける。
  結果表示は元のパス・出力先・設定・終了コードと先頭 64 KiB の診断を保持し、下部の「詳細」で読める。
  64 KiB は診断表示だけの制限で、曲や素材の容量の制限ではない。
- 出力の一時ファイル・同期・rename は既存 CLI を共有する。公開前の失敗では原本を保持し、
  公開後の親の同期失敗は完成ファイルを残す。GUI はその詳細を失敗として表示し、無条件に再実行・削除しない。
  専用パッケージは完了・失敗後に除き、片付けの失敗も詳細に残す。
- 途中取消・進捗率・アプリ終了後の再開は未接続。完了までアプリを終了しない案内を README に置く。
  強制終了後の一時物は自動探索・削除せず、元プロジェクトの復旧とは区別する。

## 回帰と基盤

- `ExportTests` の必須契約 `export-snapshot-ui` は、GUI と同じジョブから実 CLI を起動する。
  PCM の捕捉後に編集・位置移動・終了・元文書削除・次の文書の開始を行い、非ゼロの PCM24 と次の文書の不変性を確認する。
  スナップショットの要求を `.list` へ戻す反例で検出力を確認する。
  この回帰は操作の要求経路であり、シートや保存パネルへの実マウス入力を代用しない。
- `ExportBoundaryTests` は古い文書・元パッケージ内部の出力の拒否、実 CLI のプラグイン不足のエラーと既存出力の保持を確認する。
  設定の分離・不正値は Swift、参照する状態と音声だけのコピー・欠落・破損・既存パスの保全は履歴の `tests/export.rs` で確認する。
- 必須契約の依存入力に CLI を加え、既存の Makefile の CLI ビルド・契約実行をそのまま使う。
  検査選択の回帰と配布署名の回帰を更新した。新しい単独の検査コマンドは追加しない。
- doctor のビルド証跡に同梱 CLI を加え、差替え・欠落で鮮度を失効させる。
  デバッグ手順に状態の切分けと詳細の採取を追加した。自動の debug-report へユーザー文書や一時スナップショットは収集しない。
- 音声処理・WAV 量子化は変更しないため、エンジンへ新しい発音テストやブロック長の検査を重複追加しない。
  書出しの内容の回帰は既存 CLI と製品 PCM の境界を使う。実画面・VoiceOver は UC-53、聴感は既存 UC-52 に残す。
