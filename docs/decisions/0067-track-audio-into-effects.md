# ADR 0067: 配置した音声はトラックのエフェクトの前でシンセと合流する

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 製品再生がトラックの CLAP へ渡す音声。楽器の入力は [ADR 0049](0049-hosted-playback.md)

## 背景

0.25 の音声クリップは、ゲイン 2 の CLAP を挿す前も後も 0.17677669 だった（監査 AUD-08）。製品の順序は内蔵シンセ、CLAP、音声クリップ、フェーダーで、クリップがエフェクトのあとから足されていた。ゲイン 2 なら同じサンプルは 0.35355338 になる。

楽器はノートを受け、音声入力は無音にする、という [ADR 0049](0049-hosted-playback.md) の決まりはクリップを想定していない。クリップを楽器の入力に混ぜると、音を置き換える楽器が素材を消す。クリップをチェインの最後に足すと、楽器のうしろのエフェクトが素材を処理できない。

## 決定

トラックの音声は、内蔵シンセの出力と、そのブロックの配置した音声の和である。エフェクトはこの和を入力にする。

チェインの最初が楽器のとき、その楽器へ渡す音声は無音で、ノートは渡す。配置した音声は楽器の出力へ足してから、後段のエフェクトとそのトラックの出力が読む。最初がエフェクトのときは、配置した音声はすでにその入力に入っているので、楽器の出力へは足さない。

同じトラックの次の段は、前の段が終わったその回収の中で依頼し、同じ締め切りまで待つ。ここで回収を戻すと、後段が終わる前にドライの音声が残る。

プラグインがそのブロックで間に合わなかったときは、これまでどおりそのトラックのブロックを無音にする。配置した音声も、そのエフェクトを通った結果としては残さない。

## 結果

ゲイン 2 のエフェクトは、音声だけ、ノートだけ、その和を、処理前の 2 倍にする。0.25 のクリップの本体は 0.35355338 になる。ゲインを楽器として扱うと、クリップは入力に入らず、無音の出力のあとにそのまま残る。楽器のあとにあるゲインは、楽器の出力とクリップの和を処理する。画面での操作確認は未実施である。
