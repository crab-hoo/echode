# ADR 0086: 時刻の境界は検査してから拒否する

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-13。クリップのリンクと不変条件

## 背景

クリップの開始を `i64::MIN` にしたあと、別の開始へリンクすると、原点の減算が溢れた。終端側では、リンクした窓のノート終端が溢れた。Debug のセッションは panic し、Release のモデルは不正な状態を返した。自動クリップの不変条件も、小節長の乗算で panic した。

## 決定

リンクは、原点と各ノートの絶対終端を、トラックを変える前に検査する。溢れは `InvalidClip` として拒否し、プロジェクトは変えない。ノートの追加は、ローカル位置と長さの和が溢れるとき拒否する。自動クリップの範囲と、不変条件の小節計算は、検査付きの加減乗算で行い、溢れは壊れた不変条件として返す。

## 結果

開始 `i64::MIN` のクリップを時刻 0 へリンクする操作と、終端が溢れるリンクは拒否され、クリップは 1 つのまま残る。不変条件は panic しない。画面での操作確認は未実施である。
