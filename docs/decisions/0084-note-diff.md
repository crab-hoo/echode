# ADR 0084: ノートの差分は変わった中身だけを見る

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-11 と、PRO-10 のノート順序の記録

## 背景

差分は、中身が共有されたままでも、前後の全ノートの対応表を作っていた。ゲインだけの変更で、1,000 / 10,000 / 100,000 ノートが 0.085 / 0.684 / 6.462 ms だった。ノートの順序は、1 件の挿入や削除でも変更前と変更後の ID 列を両方記録していた。

## 決定

中身の `Arc` が同じなら、そのノートは対応表に入れない。ゲインだけの変更は、トラックのパラメータ差分になり、ノートの生成、削除、順序の更新にはならない。

順序が 1 件の挿入か削除だけのときは、位置、ID、挿入か削除かを 1 段として記録する。位置が `u32` に収まらないときと、並び替えが複雑なときは、これまでどおり ID の列を記録する。古いジャーナルの ID 列はそのまま適用する。段の逆操作は、挿入と削除を入れ替える。

## 結果

32 ノートのゲイン変更はノート差分を作らず、往復する。1 件追加した順序は段として記録され、逆操作で戻る。release の 3 回中央値は、無関係なノート 1,000 / 10,000 / 100,000 件のゲイン差分で 2 / 11 / 10 µs だった。修正前の 0.085 / 0.684 / 6.462 ms より短い。100,000 ノートは 5 ms 未満でなければならない。時間の閾値は、この無視した計測にだけ置く。画面での操作確認は未実施である。
