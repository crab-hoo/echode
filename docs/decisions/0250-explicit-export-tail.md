# 0250. CLI 書出しの余韻を明示する

日付: 2026-11-03
状態: 採用（P2-08 の余韻調整の CLI 先行分。GUI・設定保存・DSP の変更は含めない）

## 背景と再現

[書出しの操作要件](../interaction-design.md#書き出し) は末尾の余韻の長さ調整を求めている。
従来の CLI は初期化時の CLAP tail を使うか、`--frames` で先頭からの総長を指定するだけで、曲末に対する長さを指定できなかった。
無限の余韻では利用者が曲の長さも計算する必要があった。

`a77ae25` に実 CLI の `explicit_tails_render_empty_projects_in_every_wav_format` を追加し、
`--tail-frames 0` が `explicit tail export failed: echode: usage: echode render` で失敗することを先に確認した。
終了コード 101 と回帰固有のアサーションを照合し、構文の未対応を製品の入口から再現した。

## 決定

- `--tail-frames N` を追加し、復旧したスナップショットの曲末に、出力レートで N フレームの余韻を足す。
  CLAP の申告値に加算せず、代わりに使う。`0` は余韻なしで、プラグインのない曲には無音を足す。
  空の曲でも明示値を反映し、プラグインがあれば同じ隔離再生器を処理する。
- 両方の長さを省略した場合の自動判定と、`--frames N` の総フレーム数の意味は変えない。
  `--frames` と `--tail-frames` の併用は、順序や値によらずパッケージを開く前に拒否する。
  秒への換算や GUI の表示単位は後続の範囲とし、CLI は既存の整数フレーム指定とそろえる。
- CLAP の `>= i32::MAX` は自動判定でだけ無限として拒否し、両オプションをエラー文で案内する。
  明示値は同じ数でも無限と解釈しない。曲末との和を checked 演算で求め、u32 を超えれば既存の出力を保って拒否する。
  明示値による超過は素材の読込みやヘルパーの起動前、自動 tail による超過はヘルパーの初期化後・出力作成前に分かる。
- 書出しの量子化、RF64 切替、ブロック長、バッファ、ヘルパーの期限、一時ファイルの公開手順は変更しない。
  長さの指定によって余韻を途中で切ることはあるが、新しいフェード・ディザ・無音検出・プラグインのリセットは加えない。

## 回帰と基盤

- `tests/tail.rs` で、float32 / PCM16 / PCM24 の空の曲を、プラグインの有無とゼロ・部分ブロックで検査する。
- 実 CLI と隔離 Sine Pad を 44.1 / 48 kHz で処理し、自動・ゼロ・短縮・延長の長さを確認する。
  同じ総フレーム数の既存の `--frames` と全バイトを比較し、共通区間は既定の書出しとも比較する。
- 配置音声の本体と追加無音、AudioToolbox による独立復号、復旧した編集の曲末と出力の版、文書の不変性を確認する。
  不正値・値の欠落・併用・長さの超過・ゼロレートは、原本と `.part` の後始末、成功ログの不在を照合する。
- `tail_tests` で全範囲の無限申告値と明示値を区別し、u32 最大の総長と加算の超過を巨大な出力なしで確認する。
  実際に無限 tail を返す第三者プラグインとの互換性を保証するテストではない。
- README、オフライン設計、P2-08、デバッグ手順と索引を更新する。
  通常の CLI テストが新しい統合テストを含むため、Makefile・`scripts/verification.json` の入口と選択は変更不要である。
  診断の収集先・ログ形式・外部依存・リアルタイム処理は変えない。

## 残る範囲

GUI の書出しと設定保存、自動の無音検出、ディザ、u32 を超えるフレーム数は未接続である。
P2-08 全体や第三者プラグインの互換性の受入完了ではない。
検査は機器を開かず既存のサンプルを比較するため、新しい実機・聴感の確認待ちは作らない。
