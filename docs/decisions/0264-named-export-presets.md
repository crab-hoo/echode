# 0264. 名前付きの書出しプリセットを既定値から分離する

日付: 2026-11-05
状態: 採用（P2-08 の書出し設定の再利用。デバイスのプリセットや単位全体の完了ではない）

## 背景と再現

[ADR 0263](0263-common-export-defaults.md) は 1 組の共通既定値を保持するが、配布用と保管用など複数の設定は切り替えられなかった。
既定値の自動適用順を増やさず、名前を付けた明示的な選択肢を加える。

非表示の実シートでプリセットを展開し、名前のネイティブ入力欄を要求する回帰を追加した。
製品 View への接続を外した版では終了コード 1 と、固有の `Expanding export presets must expose the preset name field in the real sheet` を照合した
（`target/export-presets-wiring-red/`）。
初期の AX ツリー探索は非表示のシートでは実装後も要素を得られず、受入の証拠には使わない。

## 保存の境界

- 保存先は UserDefaults の `workspace.export.presets.v1`、JSON の版は 1 とする。
  名前から `ExportSettings` への辞書で、形式・レート・余韻・TPDF・ピーク目標の検証を共有する。
  出力先・文書 ID・素材・プラグインの状態は含めない。
- 名前の前後の空白を除き、Unicode を NFC に正規化する。空の名前と内部の制御文字は拒否する。
  正規化後の名前で同一性を比べ、大文字・小文字は区別する。同名の保存では既存の設定を上書きしない。
  変更は別名で保存するか、明示削除してから保存する。プリセット数に固定上限は設けない。
- 欠落した保存物は空として読む。未知の版・不正な形・名前・設定は保存物全体を読めないものとし、警告して保持する。
  読取りだけで修復せず、保存・削除でも壊れた保存物を空の一覧で置換しない。
- 保存・削除・適用のたびに読み直し、別シートで足した項目を古い一覧で消さず、削除済みの選択を適用しない。
  同じアプリ内では主アクターが操作を直列化する。複数アプリ間の競合調停と UserDefaults の電源断耐久性は追加しない。
- この Mac の設定であり、プロジェクトの移動・コピーには含めない。
  共通既定値・パッケージの前回値・旧パス設定の優先順、曲のモデル・Undo・ジャーナル・保存スキーマは変更しない。

## シートの操作

- 開閉できる「書出しプリセット」に、一覧・適用・削除・名前・保存を置く。一覧の選択だけでは下書きを変えない。
  保存は数値欄の文字列を含む全有効入力を検証し、前の有効な数値で代用しない。
- 適用は現在の下書き全体をプリセットに戻す。削除は現在の入力欄を変えない。
  どの操作も書出し・保存パネルを開始せず、プロジェクトの前回値・共通既定値を更新しない。
- 前回値の読込み中と保存パネル中は無効にする。保持されたコマンドも文書 ID を再照合し、文書交換後は拒否する。
  日英の操作名・結果・拒否理由を用意する。音声処理・CLI の設定や既定値は変更しない。

## 回帰と基盤

- `ExportPresetTests` は非表示の実シートとフィールドエディターを通して保存・適用・削除・再読込みを確認する。
  不正数値・同名の拒否、前回値・共通値・履歴との独立、文書交換後の拒否と、削除済みの選択も通す。
- `ExportPresetStorageTests` は名前の正規化・空と制御文字・非有限値・保存往復・未知の版・不正な保存物の保持を確認する。
- 必須契約 `export-presets-ui` は保存の省略、古い数値の保存、適用の省略、文書照合の省略をそれぞれ検出する。
  既存の `check-swift`・`check-product-contracts` と選択回帰へ登録する。新しい実行入口は不要なので Makefile は変更しない。
- README・P2-08・操作要件・UI 設計・開発入口と、プリセットを前回値／共通値から区別するデバッグ手順を更新する。
  診断へ名前や設定値を自動収集しない。DSP を変えないのでブロック長回帰・RTSan の対象は増やさない。
- 自動回帰は実画面のクリック・配置・長い名前・キーボード操作・VoiceOver を代用しない。UC-61 に残す。
  機器・保存パネル・Finder・表示ウィンドウは開かない。
