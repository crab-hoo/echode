# ADR 0070: 書き出しは文書ホストの復旧済み版を使う

- 日付: 2026-10-13
- 状態: 採用
- 範囲: CLI の書き出しが読むプロジェクト。復旧の規則は [ADR 0057](0057-crash-recovery.md)

## 背景

自動保存が作業ツリーへ届く前に止まると、ジャーナルに確定したノートは `recover` で残るが、CLI は `read_package` を読むので WAV が無音だった（監査 AUD-11）。保存途中の複数ファイルをそのまま読むと、古いファイルと新しいファイルが混ざる。

## 決定

`echode render` は文書ホストを開いてスナップショットを受け取る。ホストはジャーナルを直し、読める自動保存があればそれに後続のジャーナルを重ねる。基点が無く `save.pending` があるときは、作業ツリーを読まず失敗する。基点があるときは、保存途中の作業ツリーではなくその基点にジャーナルを重ねた版を書く。

開いたとき基点が無ければ、これまでどおり復旧した版をコミットしてから書き出す。成功した書き出しは、その自動保存の id を標準エラーへ `exported <id>` と書く。

## 結果

作業ツリーが空でも、ジャーナルのノートは書き出しに残る。保存途中で基点が無いパッケージは WAV を作らない。基点がある保存途中は、作業ツリーへ足したノートではなく、その基点の版を書く。ノートだけの基準 WAV は変えていない。画面での操作確認は未実施である。
