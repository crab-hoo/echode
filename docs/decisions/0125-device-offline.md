# ADR 0125: CLAP のオフライン状態を保存と隔離グラフへ接続する

- 日付: 2026-10-20
- 状態: 採用。P2-02 の一部
- 範囲: トラック FX のオフライン切替、保存形式 5、再生・書出し

## 背景

[ADR 0120](0120-device-bypass.md) のホストバイパスは、音を通さない間もヘルパーを保持する。
P2-02 では、デバイスの並び・同一性・記録済み設定を残したまま、そのヘルパーを解放する操作も必要である。
Phase 3 のトラックのレンダリングキャッシュ・フリーズとは別に扱う。

## 決定

- `Device.offline` と `device.offline` をモデル・登録簿・API / MCP・差分・ジャーナルへ加える。
  ミキサーは常にオンラインとし、直接操作・不正な差分・読込・不変条件のすべてで拒否する。
- FX 行の「オフライン」はネイティブのチェックボックスとし、1 回の操作を単一 Undo / Redo へ通す。
  同じ値の再投入を履歴へ積まず、旧文書セッションの操作を拒否する。
  複製は記録済み状態ハッシュと `bypassed` / `offline` を引き継ぎ、デバイス ID は新しくする。
- オフラインのデバイスは解決するプラグイン ID・保存状態の読込・実行チェインから除く。
  未検出のプラグインでもヘルパーを起動せず、音源のノートは無音となる。
  同じトラックの配置音声はドライで次の有効デバイスとフェーダーへ通す。
  オフラインのデバイスはテールの申告と失敗判定にも含まれない。
- 稼働中のオフライン化は既存の計画交換を使う。
  音声側が新計画へ交換し、旧計画を制御側へ返した後にヘルパーを破棄する。
  音声スレッドで解放や終了待ちをせず、再有効化は新しい隔離インスタンスを記録済み設定から作る。
- `state` は既存の文書へ取り込まれた設定を保持する。
  バイパス状態は独立に保持し、オフライン解除で勝手に解除しない。
  将来の GUI・パラメーター編集で未取り込み状態を変更する経路を作る際は、破棄前の取得も同時に接続する。
- オンラインへ戻したプラグインが未検出・読込不能なら、再生準備と書出しは既存のエラーを報告する。
  取得できない音源を別音源へ置き換えない。

## 保存の互換性

- スキーマを 4 から 5 へ進め、4 以前は `offline: false` を補う。
  旧リーダーがオフライン指定を無視してプラグインを鳴らすことを防ぐ。
- 現行形式は真偽値を必須とし、欠落・別の型・ミキサーのオフラインを破損として拒否する。
  旧ジャーナルのデバイス作成差分で値が欠けている場合はオンラインとして復旧する。
- 不変の状態オブジェクトとプラグイン ID は削除しない。
  オフライン中は状態オブジェクトを読み込まず、再有効化時に既存の検証を通す。

## 検査と診断

- モデルの差分反転、設定コピー、ミキサー拒否、ランダム操作列、旧形式の移行と現行形式の破損拒否を検査する。
- FX 行の実操作、単一 Undo / Redo・保存再読込、旧文書の拒否を機器なしで検査する。
  隔離回帰では、存在しないホスト実行ファイルでもオフラインなら生成を試みないことを確認する。
- 7 / 64 / 512 フレームで状態復元と稼働グラフからの除去を繰り返す。
  ステレオ素材は 48 / 96 kHz と複数ブロック長で全サンプルを比較し、RT 禁止操作も検査する。
- 実 CLI の回帰で、オフラインの未検出 FX を含む書出しが素の素材と一致することを確認する。
  この経路で、全オフラインでも隔離ホストを必須にする旧判定の失敗を再現してから修正した。
- 必須契約と負の対照は `scripts/verification.json` を正本とする。
  実機・聴感と実画面の操作は自動回帰とは区別し、未実施を合格としない。
