# 0008. アクションの Undo とジャーナル

- 日付: 2026-10-08
- 状態: 採用

## 背景

ドキュメントモデルは不変のスナップショットになった。次は、その変更を Undo でき、クラッシュ後に同じ状態へ戻せるようにする。モデルが採番を隠すと、ジャーナルを再生した時に ID が変わり、後続の操作が別の対象を指す。

## 決定

- Undo は操作前のプロジェクトを積む。トラック単位の `Arc` をそのまま使うので、変わっていないトラックは複製しない。Undo の段数に固定の上限は置かない
- 確定した操作は、生成した ID を引数に含めてジャーナルへ追記する。1 つの Undo 単位を 1 行の JSON にする
- 復旧は、最後の自動コミットにジャーナルを順に再生する。Undo した操作はジャーナルから外し、やり直し側へ移す。落ちた後に戻るのは、その時点の状態である
- トランザクションは複数の操作を 1 つの Undo 単位にする。途中で失敗したら、プロジェクトもジャーナルも操作前に戻す

## 結果

トラックの追加、ノートの追加と削除、クリップの範囲、拍子、テンポを `echode-actions` で行い、Undo とジャーナルの再生が同じプロジェクトになることをテストで確認する。
