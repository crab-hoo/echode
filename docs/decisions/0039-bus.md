# 0039. バスはチャンネル数を持たず、ステレオのパンはバランスにする

- 日付: 2026-10-09
- 状態: 採用
- 項目: ENG-6

## 背景

ミックスはトラックごとのモノ平面を受け、等電力で左右へ振る（[ADR 0012](0012-fader-after-cache.md)）。ARCHITECTURE §8.1 は、トラックの既定をステレオとし、チャンネル数に上限を置かない。スピーカー配置はサラウンドの布石として持つ。ステレオのパンが、バランスかステレオパンかは決まっていない。

パンのパラメータは 1 つで、-1 から 1 である（[ADR 0026](0026-parameters.md)）。フォルダへのバス加算は Phase 2 である（§8.4）。デバイスのピンとチャンネルの対応表は、この項目では作らない。

## 決定

- バスは、スピーカーが並んだ配置と、同じ長さのチャンネル平面である。平面の数は配置の長さで、呼び出し側が渡す。固定の上限は置かない。処理は確保しない
- 配置に最初から置くのは、モノ（1 チャンネル）とステレオ（左、右）である。並びは左が先である。5.1 などの名前は同じ列に足せる。この項目ではミックスしない
- マスターはステレオのバスである。トラックのノードがバスを出し、ミキサーがそれをマスターへ足す
- モノをステレオへ足すパンは、ADR 0012 の等電力のままである。中央はモノと同じ電力を左右に分け、端では反対側を無音にする
- ステレオをステレオへ足すパンはバランスである。中央は左右をそのまま通す。左へ振るほど右だけを下げ、右へ振るほど左だけを下げる。端では反対側が無音になり、残った側の音量はフェーダーだけが決める。左右を別々に振る操作は足さない
- チャンネル数がマスターと違うバスは、モノからステレオへ、ステレオからステレオへのほかは、ミックスがエラーを返す。無音で穴を埋めない
- ソロ、ミュート、ソロよりミュートが優先、の規則は ADR 0012 のままである。ピークは、フェーダーとパンの後のチャンネルのうち絶対値が最大のもので、トラックごととマスターの両方を出す
- ADR 0012 の「入力はモノ平面」は、この ADR に置き換える。等電力、ソロ、ミュート、ピークの位置は維持する
- テストは、左右が違うステレオのトラックを中央で鳴らし、マスターの左右が素材と一致することを確かめる。左へ振り切ると右が無音になり、左はフェーダー後の左チャンネルのままである

## 結果

`make check` が通った。中央のステレオは左右が素材のままである。左へ振り切り、ゲイン 0.5 では、左が素材の半分になり、右は無音になる。モノの等電力、ソロ、ミュートは前のままである。配置がモノでもステレオでもないバスは拒否する。
