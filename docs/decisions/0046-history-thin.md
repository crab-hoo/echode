# 0046. 自動保存は残すコミットだけをつなぎ、パックにまとめる

- 日付: 2026-10-10
- 状態: 採用（gix と `gix-pack` の版は [ADR 0270](0270-gix-0-90-and-github-advisories.md) で 0.90 / 0.77 へ更新）
- 項目: HIS-5

## 背景

自動保存は、変わったファイルごとに loose object を書く。長い作業では `.git/objects` のファイルが増える。ARCHITECTURE §6.4 は、直近 24 時間を全部残し、1 か月までは 1 時間ごと、それより前は 1 日ごとに間引き、Cmd+S の保存ポイントは残す。定期バックアップは `git bundle` にまとめる。

gix 0.78 には、パックのバイト列を索引へ入れる `gix-pack` の `Bundle::write_to_directory` と、オブジェクトを数えてパック項目を作る `data::output` がある。gc、repack、prune、git bundle の書き出しはない。利用者の Mac に Command Line Tools が無いと `/usr/bin/git` は動かないので、間引きもバックアップも git コマンドには任せない。

残すコミットが、捨てるコミットを親に持つと、その親は到達できるままである。ファイルを消すだけでは間引いたことにならない。

## 決定

間引く単位は自動保存の鎖だけである。Cmd+S など `refs/heads/` が指すコミットは対象にしない。

残すコミットは、時刻が古い方から見て次のとおりである。

- 今から 24 時間以内は全部
- それを過ぎて 30 日以内は、1 時間ごとの最新
- それより前は、1 日ごとの最新

残すコミットは、同じツリーと時刻の新しいコミットに書き直す。親は、直前に残したコミットだけにする。いちばん古いものは親を持たない。`refs/echode/autosave/main` をその先端へ移す。

そのあと、すべての参照から到達できるオブジェクトだけを 1 つのパックにする。デルタは付けない。パックの索引は `gix-pack` が書く。loose object と、置き換わった古いパックは消す。これが prune の代わりである。

git bundle は、`# v2 git bundle` のヘッダのうしろへ、同じパックを続ける。ヘッダを書く関数は gix にないので、ここで書く。前提オブジェクトは置かない。バンドルは履歴のコピーであり、間引きそのものではない。

10 秒ごと、8 時間、2,880 コミットを模した。各コミットは blob、tree、commit が 1 つずつ増える。これは検証の規模で、保存回数の上限ではない。

- 間引く前の loose object は 8,656 ファイル、768,423 byte
- 24 時間以内なので 2,880 コミットは全部残る。パックにすると 18 ファイル、894,229 byte。ファイルは減る。中身が小さいと、デルタのないパックは loose object より大きくなる
- 同じ鎖を 24 時間より 1 日古いものとして 1 時間ごとに間引くと、9 コミットが残る。パックのあと 18 ファイル、16,590 byte。先端の `project.json` は最後の保存のまま読める

この関数は自動保存のたびに呼ばない。履歴のスレッドが、保存の合間に呼ぶ。オーディオスレッドからは呼ばない。

## 結果

採用した。2,880 コミットのファイル数とバイト数は上のとおりである。`git` コマンドは使っていない。
