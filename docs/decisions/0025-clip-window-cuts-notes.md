# 0025. 配置の窓の外のノートは鳴らさない

- 日付: 2026-10-08
- 状態: 採用
- 項目: MOD-5

## 背景

配置を縮めても、窓の外のノートは中身に残る。これは ADR 0022 のとおりで、消さない。スケジューラは窓を見ないので、1 拍目のノートを置いてから配置を 3 拍目からの 2 拍に縮めても、1 拍目でノートオンが出る。

同じ中身を複数の配置が共有する。窓で切る単位は配置であり、中身からノートを消すことではない。

## 決定

- ノートが配置を通して占める時刻は、今どおり `[鳴り始め, 鳴り終わり)` である。鳴り始めは `配置の開始 + note.start - オフセット`、鳴り終わりはそこに長さを足した時刻である。配置の窓は `[開始, 開始 + 長さ)` である。どちらも終端を含まない
- 実際に鳴らす区間は、その 2 つの共通部分である。共通部分が空なら、ノートオンもノートオフも出さない。空でないときは、ノートオンを共通部分の始端に、ノートオフを終端に出す
  - ノートが窓より前から伸びているときは、ノートオンは窓の始端になる
  - ノートが窓の終わりを越えるときは、ノートオフは窓の終端になる
  - ノートが窓を内側に含むときは、ノートオンが窓の始端、ノートオフが窓の終端になる
  - 窓の終端ちょうどに終わるノートは、そこでノートオフになる。窓の終端ちょうどに始まるノートは、共通部分が空なので鳴らない
- 計算は tick で行う。サンプルへの変換は、切ったあとの時刻に今のテンポマップを使う。ブロックの境界では切らない
- この区間は `Placement` が返す。スケジューラと、オフライン書き出しの長さは、それを使う。書き出しの長さは、鳴らす区間の終わりにテスト用シンセのリリースを足したものにする。窓の外だけに伸びるノートでは、ファイルをそこまで延ばさない
- 中身のノートは消さないし、`start` も変えない。配置を伸縮しても、中身は ADR 0022 のままである
- 同じノートでも、配置ごとに区間を計算する。リンクした配置は、自分の窓に重なる部分だけを鳴らす。両方の窓に重なれば、ノートオンは 2 回出る
- ループの継ぎ目で、まだ鳴っているノートを止める処理は残す。止めるかどうかは、切ったあとの区間がその時刻をまたぐかで決める
- ゲイン 0 の無音は、この項目では変えない。オーディオクリップの再生も、まだ接続しない
- この関数はサンプルの引き算と大小の比較だけで、メモリを確保しない。オーディオスレッドから呼べる
- ENG-1 が実行計画を作るときも、同じ区間を使う。計画そのものは、この項目では作らない

## 結果

`make check` が通った。1 拍目の 8 分音符を 3 拍目から 2 拍の窓に縮めると、そのノートのノートオンは出ない。4 拍のノートを 1 拍の窓で聞くと、ノートオフは窓の終端に出て、元の長さの終わりには出ない。窓より前から伸びるノートは、窓の始端でノートオンになる。ブロック長を変えても、その音は一致する。
