# ADR 0075: CLAP の audio-ports 宣言に合わせて処理する

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 監査 PRO-02。プラグインヘルパーと、トラックへ返す音声

## 背景

ヘルパーはプラグインの宣言を見ず、入力2・出力2の1ポートとして `process` していた。入力のない楽器、モノ出力、複数ポートは、共有領域のチャンネル数を合わせても無音になるか、ヘルパーが終了した。

## 決定

プラグインを有効化する前、非アクティブなメインスレッドで audio-ports を調べる。宣言された各ポートのチャンネル数の合計で共有領域を用意し、`process` には宣言どおりのポート配列を渡す。合計が親の仮の 2/2 と違うときは、親がその合計へ割り当て直す。

拡張がない、または使えるポートがないプラグインは、その理由で拒否する。拒否はワーカーを起動する前に親へ返す。ファイルが存在するのに起動できないプラグインは、内蔵音源へ黙って戻さない。

トラックのバスは、最初の出力ポートだけを平均してモノにする。1チャンネルはそのまま、2チャンネルは左右の平均である。それ以外の出力ポートは処理するが、トラックへは混ぜない。入力が複数チャンネルのときは、モノの音源を各チャンネルへコピーする。入力0の楽器には空の入力を渡す。

再起動後も同じ照会をする。テスト用プラグインは、ファイルの有無でポート構成を変えて、再起動後の変更を検査する。

## 結果

入力0のモノ楽器、複数出力ポート、拡張のないプラグイン、再起動後の構成変更を `hosted_playback` で確認した。Test Gain と Test Instrument の従来の音量は維持する。
