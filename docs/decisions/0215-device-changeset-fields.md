# ADR 0215: デバイスの変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。デバイスのスカラー項目と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0214](0214-parameter-changeset-fields.md)、[構造監査](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

パラメーターの項目表に続き、デバイスでも差分・作成と削除・下書き・設定・復元の対応をまとめる。
従来の `changeset.rs` は、バイパス・オフライン・ピン留め・プラグイン ID・状態ハッシュをそれぞれの段で列挙していた。
この作業は既存の結果を保つ構造整理であり、製品の誤動作の修正ではない。

## 決定

- `changeset_device.rs` の `device_fields!` に、5 項目の `Property`・フィールド・型・符号化・作成時の読出し・更新時の解釈をまとめる。
  下書き、スナップショットからの変換、作成と削除、設定の振分け、モデルへの復元をこの表から生成する。
- 表の順序が作成時の順序になる。差分の順序は同じ宣言内の `diff` 列で明示する。
  従来の差分はピン留め・オフライン・バイパス・状態の順であり、作成の順序とは異なるため、並べ替えない。
  プラグイン ID は従来どおり低水準の更新を受け付けるが、差分で変更を生成する対象にはしない。
- ID・所属トラック・不変のデバイス種別はスカラーの表へ入れない。
  パラメーターの ID 順と、その ID から解決する子オブジェクトも別に扱う。
  それらの作成・所有者の照合・復元は維持する。
- 古いジャーナルで省略されたバイパス・オフラインは解除、ピン留めは空を保つ。
  任意のテキストは作成時に省略でき、状態を消す更新は空文字列を使う。
  作成の空ハッシュは拒否し、状態ハッシュの形式、ピンの整列・重複・無効 ID、0 / 1 以外のフラグの拒否を保つ。
- ミキサーのバイパス・オフライン・状態・ピン留めの拒否、既存の `Value` の種類とフィールド順を維持する。
  パッケージのスキーマ 6、ジャーナル、Undo の意味、プラグイン隔離、音声処理は変えない。
- 他オブジェクト、公開列挙型、保存・FFI の項目表への統合は残る。SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードで回帰を追加してから、同じ公開入口を通して構造整理後の結果を照合する。

- `echode-history/tests/device_changesets.rs` は生成マクロを参照しない独立した期待値を持つ。
  4 項目の全組合せ、ランダムな整列済みピンと状態ハッシュ、Unicode のプラグイン ID で、項目間の取り違えを検出する。
  正確な作成・更新のフィールド順、無変更、作成・削除・更新、逆適用・二重反転とジャーナルの符号化・再生を検査する。
- 同じ回帰で、旧ジャーナルの省略値、必須フィールドの欠落、誤った型、任意テキストの重複、空・不正なハッシュを検査する。
  不正なフラグとピン、未知の ID、所属・種別の書換え、ミキサーへの不正な設定も拒否する。
  状態を消す更新と、プラグイン ID の既存の低水準更新も保持する。
- 操作列の `properties.rs` に、状態・バイパス・オフライン・ピンを持つ CLAP デバイス付きの初期状態を加える。
  空・ミキサーだけの初期状態も維持し、不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  ここではプラグイン本体を読み込まず、記録するモデル値だけを扱う。
- 低水準の変更セットの形の検証と、公開前の `DocumentHost` の不変条件検査は引き続き別の境界である。

新しい実行入口や依存は追加しない。通常の `check` が回帰を実行し、検査選択の条件は変更しない。
フィールド名と入力を含むアサーションを既存の検査ログへ残し、診断の収集先と手順は変更不要とする。
機器・実ウィンドウ・聴感の合否はこの構造整理からは主張しない。
