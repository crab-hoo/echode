# 0007. S5 の確定とズームの選び方

- 日付: 2026-10-08
- 状態: 採用

## 背景

S5（ピンチ、触覚、感圧）を M4 の MacBook Air で操作し、確認を得た。縦横を独立して拡大できることは有用だが、縦だけ・横だけを指の動きで狙うのは難しい。通常のピンチの軸を、修飾キーや画面の文脈で切り替えられ、その方式自体も選べる必要がある。

## 決定

- S5 を確定する。Phase 0 の検証はこれで一通り終わる
- ズームの既定は、フォーカス中の画面が決める通常ピンチにする。アレンジ画面とピアノロールでは時間軸（横）を拡大する。Option で反対の軸（トラックの高さ、または音高）、Shift で縦横を同じ比率にする。この割り当てはマウスコマンドとして後から変えられる
- 指の間隔から軸を決めて固定する方式（S5 のモード 2）は残し、設定で選べるようにする
- ジェスチャーの製品実装は Phase 2 のままとする。Phase 1 はドキュメントモデルから始める
- モデルの共有は、まずトラック単位の `Arc` とする。ノート列まで構造を共有しないと Undo が重いと分かってから、永続データ構造（`imbl`）に替える

## 結果

時間は tick と flick、トラックは種別を持たず、スマートクリップの伸び縮みは `echode-model` で確認する。
