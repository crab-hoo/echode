# ADR 0169: クリップはノートを追って伸び、同じトラックの隣のクリップで止まる

- 日付: 2026-10-26
- 状態: 草案。2026-10-26 にユーザーが方針（中身の小節で伸ばす、壁はノート操作による暗黙の拡張だけ、窓の外のノートは表示しない）を選んだ。
  中身の小節と移動・複製での自動状態の保持だけは [ADR 0170](0170-content-relative-auto-bars.md) で先行採用・実装した。
  所属替え・固定窓の小節拡張・壁の制限・解決関数はこの草案のままで、製品は未変更
- 範囲: `note.insert`・`note.edit` のノートの所属と窓の拡張、自動配置の不変条件、`clip.move` の種類、
  ピアノロールのドラッグ表示

## 背景

[ADR 0022](0022-clip-content-and-placement.md) の自動・固定の 2 状態で、固定は「端を手で決めた」に加えて「ノートの入力では伸びない」も意味している。
[ADR 0154](0154-clip-move-and-duplicate.md) は小節の整数倍でない移動でも自動配置を固定にする。
[ADR 0168](0168-note-edit-clip-growth.md) はノートの時刻編集でだけ固定の窓を広げ、他の配置と重なる時は編集全体を拒否する。

トラック単位のピアノロールでクリップを意識せずに書き進めると、次の衝突が起きる。
例は 4/4 で、自動クリップを 1 拍ずらして固定の `[1, 5)` 拍にした状態である。

| 操作 | 現在の結果 |
|---|---|
| 0〜1 拍・5〜8 拍へノートを置く | 固定配置は受け取らず（`placement.rs` の `insert`）、新しい 1 小節の自動配置 `[0, 4)`・`[4, 8)` が重なって拒否される |
| 中のノートを 6 拍へ動かす | 窓が `[1, 7)` へ広がる。置く時と動かす時で固定配置の扱いが逆になる |
| 中のノートを隣の固定クリップの中へ動かす | ノートが元の中身に残ったまま窓を広げて重なり、拒否される |
| 中のノートを 10 小節先へ動かす | 窓が包絡で 10 小節以上に伸びる。自動配置も同じ |

拒否されたドラッグは離した時に元へ戻り、編集が無かったことになる。
また、ピアノロールの問い合わせ（`echode-draw` の `piano_note`）は窓で鳴る区間のノートだけを返す。
窓を広げると、それまで見えていなかったノートが鳴り始める。

上の再現は先行実装前の `864e7a4` の挙動である。
ADR 0170 以降は小節未満の移動だけでは固定にならないため、固定の例は明示的な端の編集で作る。

## 決定

### 用語

- **中身の小節**: 配置の原点 `origin = start - offset` から数えた小節。`k` 番目は `[origin + k·bar, origin + (k + 1)·bar)` である。
  原点が小節線上にある配置では、タイムラインの小節と一致する。
- **壁**: 同じトラックで、配置の窓の左右それぞれに最初にある他の配置の端。左は時刻 0 も壁にする。
  右に配置がなければ壁はなく、時刻の範囲の上限だけが残る。
- **吸着範囲**: 窓の端から 1 小節未満の区間 `[start - bar, end + bar)`。

### ノートの所属

時刻を変える `note.insert`・`note.edit` は、置く時と動かす時で同じ規則を使い、操作後のノートの位置で受け取る配置を決める。

1. 開始位置を窓に含む配置があれば、その配置が受け取る。
2. なければ、ノートの区間が吸着範囲に入る配置を候補にし、窓がノートの開始に最も近い配置が受け取る。同じ距離なら前の配置にする。
   受け取る配置と他の候補がどちらも自動なら、従来どおり 1 つに結合する。
3. 候補がなければ、ノートを含むタイムラインの小節で新しい自動配置を作る。

- 原点が小節線上の自動配置では、吸着範囲は隣の小節と一致し、従来の結合と同じ結果になる。
- 固定配置もノートを受け取る。新しい自動配置が既存の配置に重なる位置なら、そのノートは必ずその配置の吸着範囲に入る。
  そのため、ノートを置けない区間はなくなる。
- 動かしたノートは、別の配置や新しい配置へ移れる。ID・ベロシティ・リリース・アーティキュレーションを保ち、
  ChangeSet ではノートの `Owner` の更新として記録する（形式は既存の結合と同じ）。
  表情の曲線は現在空であることが不変条件なので、曲線の編集を接続する時に、ノートと一緒に移す。
- 遠くへ動かしたノートは元の窓を引き延ばさず、新しい自動配置になる。元の自動配置は空になれば消え、固定配置は空でも残る。
- 音高だけの変更では所属も窓も変えない（ADR 0168 のまま）。
- 中身を共有する配置では、受け取った中身の他の配置にもノートが現れる。その窓の外なら鳴らず、ピアノロールにも表示しない。

### 窓の拡張

- 受け取る配置の窓がノートの区間を含まない時は、ノートを覆う中身の小節の境界まで、足りない側の端を伸ばす。自動と固定で共通にする。
- 伸ばす端は壁で止める。中身の小節の途中で止まった自動配置は固定になる。
- 左へ伸ばす時は開始とオフセットを同じ量だけ変え、中身の原点と他のノートの発音位置を保つ（ADR 0022・0168 のまま）。
- 固定の窓は、ノートの短縮・削除で縮めない。自動の窓は従来どおり中身の小節で最小の範囲へ縮み、ノートがなくなれば消える。
- 中身を共有する他の固定配置の窓は変えない（ADR 0168 のまま）。

### 壁でのノートの制限

窓は壁を越えないので、ノートも壁の向こうでは鳴らない。編集は拒否せず、壁で止めた位置で成立させる。

- 左端・右端の伸縮: 動かした端を壁で止め、反対の端を保つ。最短長は 1 tick とする（[ADR 0167](0167-piano-note-drag-snapping.md)）。
- 移動: 長さを保つ。ノートの終端が受け取る配置の右の壁を越える時は、次の 2 つのうち要求に近い方へ寄せる。同じ距離なら手前にする。
  - 壁の手前に終端が接する位置
  - 壁の向こうの配置の先頭に開始が接する位置。向こう側でも収まらなければ手前にする
  - どちらにも収まらなければ、ノートを動かさない
- 所属は開始位置で決まるため、開始が左の壁を越えることはない。
- 置く時: 押した位置を開始として保ち、終端が壁を越えるなら壁までに縮める。
- グリッドへの吸着と Shift による解除を先に行い、その結果に壁を当てる。
- 時刻の範囲の桁あふれは、従来どおり拒否する。

### 自動配置の不変条件と移動

- 自動配置の窓は、ノートの鳴る区間を覆う最小の中身の小節の範囲と一致する。タイムラインの小節で数える現在の検査を置き換える。
- `clip.move`・`clip.duplicate` は、変位が小節の整数倍でなくても自動配置を自動のままにする。中身の小節は配置と一緒に動くからである。
- 固定になるのは、端の手動編集（`clip.resize`、置き換えでの切詰め・分割）、`clip.link`、壁で中身の小節の途中に止まった拡張に限る。
- 固定は「端が手か壁で決まった」ことだけを表す。固定の配置は縮まず、空になっても消えず、自動配置と結合しない。
  ノートの受け取りと拡張は自動と同じである。

### 窓の外のノート

- ピアノロールは、従来どおり窓で鳴る区間のノートだけを表示する。
  窓の外のノートを薄く表示する案は、他のトラックのゴーストノートと見分けにくくなるため採らない（2026-10-26 のユーザーの判断）。

### 解決関数とアクション

- `echode-model` に純関数を置く。操作の種類（置く・移動・左端・右端・音高）と、要求した開始・長さ・音高を受け取る。
  受け取る配置（新しい自動配置を含む）、壁で止めた開始・長さ、窓の変化を返す。
- ピアノロールは、ドラッグ中の表示と、離した時に送る値の両方にこの関数の結果を使う。Swift 側に同じ規則を持たない。
- `note.insert`・`note.edit` は、所属と窓の拡張を同じ規則で行い、壁を越える値は拒否する。
  解決済みの値だけを受け付け、規則を知らない API の呼び出しには拒否を返す。
- `note.edit` に、新しい自動配置を作る時の配置と中身の ID を足す。`note.insert` と同じく実行時に埋め、ジャーナルに残す。
- ジャーナルの互換: 新しい規則で記録した行に印を持たせる。印のない以前の行は、記録した時の規則（ADR 0168）で再生する。
  [ADR 0161](0161-placed-audio-without-fades.md) と同じ方式である。

### 置き換える判断

- ADR 0022: 「固定の配置は、ノートが増えても動かさない」と、自動配置の窓をタイムラインの小節で合わせる規則。
- ADR 0154: 「自動配置は小節の整数倍の移動だけ `auto` を保つ」。
- ADR 0168: 包絡で広げる、小節へ丸めない、距離に上限なく元の窓を広げる、重なる拡張では編集全体を拒否する。
- 同じトラックでの配置の重複の禁止（ADR 0022、[ADR 0071](0071-clip-overlap-index.md)）は変えない。

## 対象外

- クリップの移動・トリム・リンクは、[ADR 0117](0117-workflow-interactions.md) の重ねる／置き換えるの切替に従い、壁を使わない。
  現行の `clip.move` の置き換え、`clip.resize`・`clip.link` の重なりの拒否もそのままにする。
- 重ねるモードで同じトラックに重なった配置ができた時の所属と壁は、その切替を接続する時に決める。
- 音声の配置は、ノートを持たないので対象外である。

## 受入と基盤（実装時）

- モデル: `note_edit`・`model_tests` に次の回帰を足す。
  - 以前は拒否した例（置けない区間、隣の固定配置への移動、重なる拡張）が、壁で止めた値で成立する
  - 中身の小節での拡張、遠くへの移動での新しい配置、所属替えでの ID と共有リンクの扱い、壁で止まった自動配置の固定化
- 解決関数の結果をそのまま送ると必ず受理され、壁を 1 tick 越える値は拒否されることを確かめる。
- `properties.rs` の操作の生成に、壁の前後、吸着範囲の境界、原点が小節線上にない自動配置の移動を足し、新しい不変条件で検査する。
- 必須契約 `piano-note-clip-bounds`・`piano-note-clip-bounds-ui` を新しい規則へ置き換え、反例を「壁の制限を外す変更」にする。
  `clip-move-model`・`clip-move-ui` の種類の期待も更新する。
- `PianoDragTests` で、実 View のドラッグが壁で止まって描かれること、離した値で単一の Undo / Redo と保存再読込ができることを確かめる。
- ジャーナル: 印のない以前の行が ADR 0168 の結果に再生される必須契約を足す（ADR 0161 の `journal-place-fades` と同じ形）。
- 解決関数を橋渡しへ足すため、橋渡しの ABI の検査を選択に含める。音を作る処理は足さないので、ブロック長比較と RTSan の追加は不要である。
- 採用時に、[設計 §4.5](../architecture/model-and-history.md#45-スマートクリップ)、操作要件の「ノートの入力」、status を更新する。

## 残る境界

- トリムで隠したノートは表示されないまま、窓の拡張で鳴り始めることがある。表示による予告は採らなかったため、
  実画面で問題になれば別の手段を検討する。
- 複数ノートの一括移動では、相対位置を保つため、全体の変位を最も制約の強いノートで止める案を、一括編集の接続時に確かめる。
- 原点が小節線上にない自動配置は ADR 0170 で接続し、保存再読込・ノート編集・挿入・削除を回帰へ含めた。
  この草案の所属替え・壁・結合へ拡張する時も、その原点を維持する。
- 拍子の変更が入った時の中身の小節の数え方。現在のモデルは拍子を 1 つだけ持つ。
- 実画面の操作感（壁で止まる感触、所属替えの見え方）は、ユーザーの確認とする。
