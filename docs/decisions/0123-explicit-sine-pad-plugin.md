# 0123. Sine Pad を明示的な隔離 CLAP 音源にする

- 日付: 2026-10-19
- 状態: 採用。ADR 0018 の音色選定を維持し、ADR 0019 / 0038 の暗黙の製品音源を置き換える

## 問題と再現

モデルに音源がないノート入りトラックでも、`playback_pair` がトラックごとに `TestSynth` を作っていた。
外部音源はその出力を置き換えるため、Sine Pad だけがデバイス一覧・削除・複製・バイパス・保存の対象外だった。
ノートだけの最小プロジェクトで「音源なしなら無音」の回帰を先に実行し、非ゼロ出力で失敗した。

## 決定

- `echode-sine-pad` は `dev.echode.sine-pad` を公開する実体のある CLAP である。
  wavesynth 0.1.0 の Sine Pad を使い、メイン出力はモノとする。
  本体はプラグインを読み込まず、走査・音声処理・状態保存は既存の隔離ヘルパーを使う。
- 開発用と配布用アプリは `Contents/PlugIns/EchodeSinePad.clap` を同梱する。
  CLI とテストではヘルパー隣の `plugins/` を同じ走査・キャッシュ経路に加える。
  音源 ID による再生側の特別分岐は作らない。
- Sine Pad は通常の `DeviceKind::Clap` として追加する。
  追加・削除・並べ替え・コピー・バイパス・Undo / Redo・保存は既存のデバイス操作を使う。
  ノートだけのトラックは無音であり、未解決のプラグインを Sine Pad へ代替しない。
  旧プロジェクトにも暗黙の音源を補わない。従来の既定音を使う時は Sine Pad を明示的に挿す。
- 製品の再生計画からシンセ本体と声の引継ぎを取り除く。
  DSP の声はヘルパーが保持し、継続ノートと新しく追跡するノートの区別は安定した再生 ID で行う。
  配置音声とフェーダー、準備済みキャッシュの境界は維持する。
- ノートの終端計算は音源を仮定しない。
  フレーム数を省略した CLI 書出しは、初期化時の CLAP tail をチェイン内で足し、トラック間の最大を曲の終端へ足す。
  バイパスは余韻に加えず、無限長の場合は `--frames` の明示を求める。
  無限長は [CLAP tail の仕様](https://github.com/free-audio/clap/blob/main/include/clap/ext/tail.h) に従い、`INT32_MAX` 以上の全値を扱う。
  音色変更による実行中の tail 再申告にはまだ追従しない。

## 発音領域とリアルタイム処理

CLAP 標準には、ホストが曲全体に応じたノート領域を事前予約する口がない。
任意実装の拡張 `dev.echode.event-capacity/1` を追加し、ヘルパーの共通経路で呼ぶ。
Sine Pad の ID は判定しない。他の CLAP は拡張がなければ従来どおり動く。

この予算はトラック全体のイベントと追跡ノートを収め、同時に保持するノート ID の数も覆う。
ループで同じ ID を再発音する時は同じ声を使う。
Sine Pad は主スレッドで新領域を準備し、音声側が発音中の声だけを移して旧領域を主スレッドへ返す。
固定の発音数を設けず、確保・解放・ロックを処理区間で行わない。
予約領域全体をサンプルごとに走査せず、処理量は発音中の声に依存する。

macOS の dylib 固有の TLS は、初回アクセス時に dyld が確保する。
デバッグ用の確保検知器を処理内で初めて使うと、RTSan がこの確保を検出した。
ヘルパーが受信準備前に行う最初の `start_processing` で音声スレッドの TLS を初期化する。
再起動後も同じ処理スレッドを使い、通常の処理では検知器を維持する。
未発音のヘルパーへの初回処理を回帰へ加え、子の診断も失敗時に残す。

## 検査と基盤

- 音源なしの製品再生とオフライン経路が無音であることを検査する。
- 同梱バンドルの走査、通常の発音・削除・バイパス、停止・再開・位置移動、状態往復を機器なしで検査する。
- 声の領域拡張時の位相保持、複数ブロック長、RTSan、従来の基準 WAV との一致を検査する。
  基準 WAV の再生成は行わない。
- 音源に依存していた HAL の回帰には明示した音声素材を渡し、シンセの製品回帰は隔離テストへ移す。
- Makefile、検査選択と必須契約、同梱・署名、利用手順・制約・診断を更新する。
  過去の監査・聴感確認・S3 計測は当時の証拠として保持し、新版の合格へ流用しない。
