# ADR 0188: アレンジの単一クリップを直後へ複製する

- 日付: 2026-10-28
- 状態: 採用。P2-07 の先行分。実画面の操作感と VoiceOver はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#アレンジの選択と編集)、
  [ADR 0154](0154-clip-move-and-duplicate.md)、[ADR 0170](0170-content-relative-auto-bars.md)

## 背景と再現

開始時の HEAD は `8f118f6`。クリップ本体の Command＋ドラッグは既存の `clip.duplicate` へ接続済みだが、
Command＋D の直後への複製は未接続だった。
製品の `ArrangePaneView.timeline.keyDown` へ入力する回帰を先に追加し、複製要求が 0 件になることを確認した。
期待終了コード 1 と固有のアサーションを `target/focused-checks/clip-duplicate-red/` で照合した。
このパスはローカルの一時ログであり、永続的な証拠の参照先ではない。

## 決定

- 単一の選択クリップに対する Command＋D は、同じトラックの `start + length` へ通常複製する。
  幅は現在の配置窓で、素材全体・ノート全長・小節・グリッド幅ではない。端数 tick も丸めない。
- 複製の始端と終端を整数の検査付き加算で求める。負の始端、非正の長さ、桁あふれは要求を送らない。
- 既存の `ClipMove`（`copy: true`）を操作時の文書・配置・トラック・始端で確定し、
  `WorkspaceSession.moveClip`・`ProjectController.moveClip`・`clip.duplicate` を共有する。
  非同期実行前の別トラック選択へ付け替えず、文書交換・削除済みの対象は既存の検査で拒否する。
- 中身とノートの独立、音声素材の共有、オフセット・ゲイン・フェード、自動／固定の種類、
  重なる配置の削除・切詰め・分割は既存の複製契約を引き継ぐ。新しいアクションや保存形式は増やさない。
- 成功後は複製側を選択し、単一 Undo / Redo と保存・再読込へ接続する。
  次の表示更新後の再入力は、その複製の直後へ続けられる。ピアノ入力先・入力長・入力ベロシティは変えない。
- キー等価はアレンジ自身が first responder の時だけ受ける。直接届く `keyDown` も同じ処理を使い、二重送信しない。
  入力欄・ピアノロール・他ペインのキーを奪うグローバルなショートカットは登録しない。
- Shift・Option・Control を伴う入力、文書交換中、ルーラー・クリップ・値の未確定操作中は複製しない。
  キーの押し続けによる自動反復は消費するだけとし、古い表示の複製を連続して置き換えない。
- 複数クリップの選択と一括複製、重ねるモード、貼付け、トリム、自動クロスフェードは今回の対象外とする。

## 受入と基盤

- `clip-duplicate-key-ui` は実 View・製品 controller・ABI を通し、固定した端数窓の正確な複製、
  操作後の別トラック選択との分離、独立した MIDI 編集、複製側の選択、単一 Undo / Redo・保存を確認する。
  複製位置の誤りと、複製を移動に戻す誤りを負の対照にする。
- `clip-duplicate-key-guards-ui` は表示しない入力用ウィンドウで実キー等価と文字入力優先を確認する。
  文書・選択の欠落、修飾キー、自動反復、未確定ジェスチャーも拒否し、フォーカス・操作中の保護の欠落を負の対照にする。
- 通常回帰は音声の手動トリム・ゲイン・フェード・置き換え・Undo と旧文書の拒否、整数上端の境界も扱う。
  Makefile の既存契約入口、検査登録と選択回帰、利用手順・現状・Phase 2・領域設計・デバッグ手順を更新する。
- 音を作る処理・モデル・アクションは増えず、既存の複製・再生経路を共有する。
  ランダム操作生成・ブロック長比較・RTSan の追加は不要である。
- 新しいログ・外部入力形式・ヘルパー・成果物の保存先は増えない。
  `doctor` の鮮度照合と `debug-report` の収集範囲は既存のままで有効である。
- 実画面での連続操作と VoiceOver の選択の分かりやすさはユーザー確認に残す。
  機器・実画面の検査を自動回帰の合格に読み替えず、P2 全体の完了とはしない。
- 作業中の通常検査で、既存のスキャン回帰の最初の shell が 2 秒の期限切れとなった。
  単独実行では再現せず、原因は未確定である。期限や検査対象を変えず、正式な検査を再実行する。
  切分けは [デバッグ手順](../debugging.md#オーディオトランスポートプラグイン) に残す。
