# 0016. プラグインの検知は本体の外で行う

- 日付: 2026-10-08
- 状態: 採用

## 背景

プラグインの追加、更新、削除は、再起動なしで一覧に反映する。バンドルを本体のプロセスに読み込むと、スキャン中のクラッシュが DAW ごと落ちる。

## 決定

- 本体は、監視しているフォルダの直下にある `.clap` と `.vst3` のバンドルに気づくだけにする。中身は読み込まない
- 変化が 2 秒止まってから、そのバンドルをスキャン対象にする。書き込みの途中では調べない
- スキャンに失敗したバンドルは、ファイルの更新時刻が変わるまで再スキャンしない
- フォルダの変化は FSEvents で受ける。一覧の差分は、その通知のあとでディレクトリを読み直して決める

## 結果

一時フォルダにバンドルを作り、一覧に現れること、消すと一覧から消えることをテストで確かめる。中身を調べるときは、ヘルパープロセスが CLAP のファクトリー記述子だけを読み、インスタンスは作らない。
