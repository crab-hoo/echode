# ADR 0085: 可視索引は ID で引く

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-12。アレンジの可視問い合わせ

## 背景

可視なクリップごとに、全 content と索引を先頭から探していた。索引の更新は、各トラックで古い配置索引を全検索していた。ノート ID の解決は、トラック上の全ノートを最後まで見ていた。Swift の可視列は、計数のための問い合わせのあと、同じ範囲をもう一度問い合わせて書き込んでいた。

## 決定

content は ID 順なので、二分探索する。配置索引はトラック ID から引く。ノート ID から content ID への対応は、中身が変わらない更新では同じ `Arc` を保つ。ピアノロールの 1 ノートは、その対応と content の索引から、同じ中身のクリップだけを見る。

製品のスナップショットは、可視要素のバッファを問い合わせのあいだ保持する。足りないときだけ伸ばして、同じ範囲をもう一度問い合わせる。容量、書き込んだ件数、入りきらなかった件数は `usize` である。

## 結果

未変更のプロジェクトは content と配置の木を再利用する。短いバッファは溢れた件数を返し、2 回目で書き込む。画面での操作確認は未実施である。
