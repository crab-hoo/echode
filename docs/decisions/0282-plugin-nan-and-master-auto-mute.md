# ADR 0282: プラグインの NaN でトラックを、暴走した出力でマスターを自動ミュートする

- 日付: 2026-11-08
- 状態: 採用。画面の表示は未接続。実機の聴感は未確認。
- 対象: [統合表](../reviews/2026-11-08-open-items-register.md) の R2（[XCA-21](../reviews/2026-11-02-cross-cutting-audit.md#xca-21-製品の設定) の非有限値と出力の扱い）。
- 方針: [ADR 0281](0281-calm-transparent-failure.md)（静かに安全側へ倒し、起きたことと行ったことを隠さない）。

## 問題

- プラグインの段の間で非有限値を除いていなかった。NaN はトラックのフェーダーで捨てられるが、同じトラックの次のプラグインには入る。
  フィルターやリバーブのように過去の値を持つプラグインは、一度 NaN を受けると状態が壊れ、元の異常が収まった後も出力が戻らない。
- 段の後の NaN は、欠けの減衰（`PluginDeclick`）とフェーダーが黙って 0 にしていた。ユーザーには何が起きたかが見えない。
- 有限でも暴走した値は、そのまま機器への出力まで届く。

## 比べた案

| 案 | 内容 | 判定 |
|---|---|---|
| 1 | 段の間の非有限値を 0 にし、出力に上限を置く（ADR 0276 の元の決定） | 採らない。音を作り変えて異常を隠す（ADR 0281） |
| 2 | 異常なプラグインを自動でバイパスする | 採らない。音が変わり、どのプラグインが原因かが音から分からない |
| 3 | 異常を検知したら再生を止める | 採らない。作業を止める。ほかのトラックは正常である |
| 4 | 原因のトラックかマスターを自動ミュートし、再生の開始で解除する | 採る |

## 決定

### トラックの自動ミュート

- 各トラックのチェインで、バイパスしていない段の出力が届いた時（`HostGraph::advance`）に、最初の NaN・無限大を探す。
  見つけたら、その段の出力をその標本から 0 にする。次の段は 0 を受け取り、壊れた値を受け取らない。トラックへ書く値も 0 になる。
- 最初に見つけた段の装置とブロック内の位置を、そのブロックの障害として持つ。上流を 0 にするので、下流で見つかる NaN は、その段自身のものである。
- トラックの出力は、障害の標本から、欠けと同じ 5 ms の減衰で無音にする（[ADR 0245](0245-plugin-deadline-fades.md)）。自動ミュートの間は無音を保つ。プラグインは動き続ける。
- 自動ミュートの記録（装置、最初の標本の位置）は、トラックのメーター（`TrackMeter`）に置く。メーターは制御側と共有され、計画を交換しても同じ物が続くので、記録もそこが唯一の正本になる。
  記録は最初の障害だけを残す。ミュートの間に続く障害では書き換えない（Calm）。
- 欠けではないので、`plugin_missed_blocks` は増やさない。書出しは、その装置が「NaN か無限大を返した」として失敗にする（`plugin_failure`）。書出しの値を黙って変えない。

### マスターの自動ミュート

- 機器への出力だけで、マスターが +18 dBFS（全振幅の約 8 倍）を超えるか NaN になった最初の標本から、出力を 0 にする（`PlaybackOptions::guard_output`）。
  `echode-audio-io` の機器の再生だけがこれを有効にする。書出しは有効にしないので、値は変わらない。
- 値に上限は付けない。超えた標本以降を無音にし、再生の開始まで無音を保つ。最初の標本の値と位置を `PlaybackStatus::master_auto_mute` に出す。

しきい値の比較:

| 値 | 判定 |
|---|---|
| 0 dBFS | 採らない。変換器が既にここで切るので、浮動小数点の余裕を使う普通のミックスでも誤って止まる |
| +6〜+12 dBFS | 採らない。マスタリング前の大きなミックスで、まだ誤って止まり得る |
| +18 dBFS | 採る。REAPER の自動ミュートで利用者が報告する値の上端である。普通のミックスはここまで達せず、達すれば暴走である |
| +40 dBFS 以上 | 採らない。暴走が長く続いてから止まる |

段ごとの大きさは見ない。クリップのゲインは +120 dB まで許しており、大きいだけの有限値はプラグインの障害とは言えない。

### 解除

- 再生の開始（`Play` の命令）で、トラックとマスターの自動ミュートを解除する。自動ミュートしたトラックは、そのプラグインの処理状態を CLAP の `reset` で戻してから音を通す。
  戻りは欠けからの復帰と同じ 5 ms のクロスフェードである。解除の後に同じ異常が起きれば、また自動でミュートする。
- 自動ミュートはモデルに書かない。保存・Undo・書出しの対象にならず、ユーザーのミュートとは別である。

### 知らせ方

- トラック: `TrackMeter::auto_mute`（装置と位置）。マスター: `PlaybackStatus::master_auto_mute`（値と位置）。
- アプリへは `AudioState` の `auto_muted_tracks` と `master_auto_mute` で渡す。値が NaN の時は `peak` を `null` にする。
- 画面・VoiceOver の表示は次の作業で接続する。それまでは、音は止まるが理由は画面に出ない。

## 回帰と基盤

- `echode-test-plugin` に `nan` の障害を足した。2 ブロック目の 10 標本目から NaN を書き、CLAP の `reset` で元に戻る（壊れた内部状態の模型）。
- `hosted_playback::auto_mute::a_plugin_nan_auto_mutes_its_track_until_playback_starts` は、実ヘルパーで次を確かめる。
  - 原因は楽器の装置と判定され、次のエフェクトは NaN を受け取らない。
  - 10 標本目まではそのまま鳴り、そこから減衰し、ミュートの間は無音を保つ。ほかのトラックは影響を受けない。
  - 書出しの失敗理由に NaN が出て、欠けとしては数えない。
  - 再生の開始で解除され、リセットの後に同じ音で戻る。
  
  検出を外すとこのテストが失敗する（従来の黙った 0 への置換に戻る）ことを確かめた。
- `block_size::master_guard` は、ブロック長 1・7・64・512 で、マスターが同じ標本から無音になることと、記録の値と位置を確かめる。
  ガードなし（書出し）では全ての値がそのまま出ること、停止・位置移動では解除されず、再生の開始で解除されることも確かめる。
- オーディオスレッドでは確保・ロック・待ちをしない。記録は原子変数の書込みで、制御側は版の番号で読み直す。

## 残る範囲

- 画面での表示（ミュートの点灯、理由、VoiceOver）は未接続である。接続した後に、実画面の確認を UC へ足す。
- 実在のプラグインの NaN と、実機の +18 dBFS の聴感は未確認である。
- フェーダーの加算・欠けの減衰・マスターの書込みにある「非有限値を 0 にする」処理は残る。段の検出の後は届かない値の防御で、異常を隠す経路ではない。
- しきい値は定数である。設定にするかは、利用者の要望が出た時に決める。
