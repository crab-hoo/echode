# ADR 0220: テンポ点の変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。テンポ点と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0219](0219-placement-changeset-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

配置に続き、テンポ点も差分・作成と削除・下書き・設定・復元でテンポ項目の対応を手で列挙していた。
今回は既存の結果を保つ構造整理であり、テンポ編集・保存形式・時間変換・再生音は変更しない。

## 決定

- `changeset_tempo.rs` の `tempo_fields!` に、テンポ項目の `Property`・フィールド・型・`Value` を宣言する。
  差分、作成と削除、下書き、設定と復元を表から生成する。
- tick はテンポ点の同一性として表の外に保ち、変更可能な項目にはしない。
  作成・更新・削除の各群内で、符号付き tick の昇順を保つ。
  移動は従来どおり別の tick の作成と元の削除として表す。
- `Tempo` は整数の既約分数のまま渡し、BPM の浮動小数点への変換を挟まない。
  負の位置・tick の両端と、分子・分母が `u32` の大きい値でも表記を失わない。
- `Draft` は tick ごとに `TempoState` を持ち、設定をその下書きへ委譲する。
  未知の tick、二重作成、誤ったオブジェクト種別・キー・項目・値の型と、空になるテンポマップの拒否を保つ。
  マップ全体の構築と検証は `Draft::finish` と `TempoMap::try_from_points` に残す。
- 作成時は、従来どおり最初の型が正しいテンポ項目を使い、余分な項目は無視する。
  削除の項目列と更新の `before` は適用の前提条件にしない。
  同じ変更セットの中の削除後の同位置への作成も、最終状態が有効なら受け入れる。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo の方式は変更しない。
  プロジェクトの項目と保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ回帰を追加し、同じ公開入口で構造整理後の結果を照合した。

- `echode-history/tests/tempo_changesets.rs` は項目表を参照しない独立した期待値を持つ。
  任意の tick と既約分数のマップ・同位置の置換、複数の作成と更新と削除の順序を検査する。
  公開差分と適用、逆適用、二重反転とジャーナルの往復を通す。
- 同じ回帰で旧 wire 表記を固定し、必須項目の欠落・型の不一致・未知の tick・二重作成・空マップと種別やキーの混同を検査する。
  作成の余分な項目と最初の有効な値、削除と更新の旧適用規則も照合する。
  任意の tick の保存・差分の往復は、その位置までの実時間変換が必ず範囲内に収まるという主張ではない。
- 操作列の `properties.rs` ではテンポ操作を負の位置と分数へ広げる。
  初期状態にも負の位置・グリッド外の位置と分数テンポを加え、無関係な編集での保持を検査する。
  不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  素材・プラグイン・音声機器は開かない。

既存の `check` が新しい回帰も実行するため、実行入口・依存・検査選択の条件は変更しない。
新しい失敗経路やログ形式は追加せず、入力を含む既存のアサーションと検査ログで区別できるため、デバッグ基盤の変更は不要とする。
実機・実画面・聴感の合否と性能の改善は、この構造整理からは主張しない。
