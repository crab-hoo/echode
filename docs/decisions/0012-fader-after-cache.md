# 0012. フェーダーはキャッシュの後ろ

- 日付: 2026-10-08
- 状態: 採用

## 背景

プレビュー用キャッシュは、デバイスを通った後、フェーダーの前の音を置く（ADR 0011）。音量、パン、ミュート、ソロを動かしても、キャッシュを作り直さない。

## 決定

- ミックスはキャッシュの後ろで行う。トラックの出力はバスで、マスターはステレオである（[ADR 0039](0039-bus.md)）。モノを左右へ振るパンは等電力のままである
- パンは等電力にする。中央のトラックは、モノのときと同じ電力を左右に分ける。左右の端では、反対側をちょうど無音にする
- ソロが 1 本でもあれば、ソロのトラックだけが鳴る。ミュートはソロより優先し、ソロでもミュートなら鳴らない
- ピークは、フェーダーとパンの後のチャンネルのうち大きい方とする。トラックごとと、マスターの両方を出す。ステレオ素材のパンはバランスである（ADR 0039）

## 結果

トラック数は呼び出し側が渡す平面の数で、固定の上限は置かない。処理は割り当てをしない。
