# ADR 0069: CLAP を含む書き出しは再生と同じチェインを使う

- 日付: 2026-10-13
- 状態: 採用
- 範囲: CLI の書き出し。ノートだけの書き出しは [ADR 0019](0019-offline-wav.md) のまま

## 背景

同じプロジェクトの同じサンプルで、隔離した楽器の再生は 0.70710677、オフライン書き出しは内蔵シンセの 0.07418562 だった（監査 AUD-10）。CLI は TestSynth と配置した音声だけを鳴らし、プラグインの記録を処理しない。成功と返しながら音源を置き換えると、書き出したファイルが再生と違うことを利用者は知らない。

## 決定

CLAP デバイスが一つもないプロジェクトは、これまでどおり内蔵シンセと配置した音声で書き出す。ノートだけの基準 WAV は変えない。ループとメトロノームは書き出しに含めない。

CLAP デバイスがあるプロジェクトは、製品の再生と同じヘルパー、同じ経路、同じ状態で書き出す。スキャンキャッシュに無い id、ファイルの無いバンドル、ヘルパーが無いときは、内蔵シンセへ置き換えず書き出しを拒否する。エラーには欠けたプラグインの id を書く。

## 結果

楽器のあとにゲイン 2 のエフェクトを置いた 0.25 のクリップは、再生と CLI で同じ 0.35355338 になる。インストールされていない id は `missing plugin:` のあとに出る。画面での操作確認は未実施である。
