# ADR 0180: 復旧時のジャーナルは各行の不変条件を検査してから受け入れる

- 日付: 2026-10-27
- 状態: 採用
- 対象: [敵対的監査](../reviews/2026-10-27-adversarial-audit.md) の ADV-01
- 関連: [ADR 0033](0033-journal-log.md)、[ADR 0057](0057-crash-recovery.md)

## 背景

パッケージとコミットは `Project::try_assemble` でモデルの不変条件を検査する。
ジャーナルは構文と ID・所有の整合だけを確認し、変更集合をそのまま適用していた。
完結した行の tick が壊れるだけで、不正な配置の公開・自動保存が成立する。
再オープンはそのコミットを拒否して親へ戻るため、その後に確定した編集まで失われる。

## 決定

- `replay_suffix` は、連続した各行の変更集合を適用した直後に `check_invariants` を実行する。
  `edit`・`redo` は順方向、`undo` は逆方向を適用した結果を検査する。
- 検査単位は 1 行（1 トランザクション）とする。
  変更集合の途中の状態は検査せず、後続行で不正な状態が直っても先の行の違反を許さない。
- 不成立なら、行の連番と不変条件の理由を含む `PackageError` で復旧とオープンを拒否する。
  不正な行からの切捨てや、基点だけを成功として返す方法は採らない。
  部分復旧の通知・選択の UI がない現状で、確定済みの行を黙って失わないためである。
- 不正な状態をスナップショットとして公開せず、初回コミット・自動保存・ログの間引きを開始しない。
  完結したジャーナルと既存の先端・作業ツリーを保ち、失敗後もパッケージロックを解放する。
  未完了の末尾の修復は従来どおりで、この決定の対象ではない。
- 低水準の `Project::apply_changeset` は変更しない。
  信頼できるメモリ内の Undo や差分適用へ全体検査の負荷を広げず、外部入力である復旧の境界で検査する。
  スマートクリップの再計算や正規化で、記録された結果を勝手に修正しない。

## 回帰と証拠

`crates/echode-history/tests/audit_recovery.rs` の ADV-01 の 2 件を通常回帰へ移した。
先端なし・先端ありの破損拒否、行と作業ツリー・先端の保持、失敗後のロック解放を確認する。
後者はテスト内で正しい行へ明示的に修復した後の編集と、保存・再オープンも通す。
追加回帰は、有効な前置行の後の不正な edit / undo / redo と、後続行による修復の拒否、
ミキサー値の範囲外・必須パラメーター欠落を扱う。
製品契約の負の対照はこの不変条件検査だけを外す。

修正前の既存の 2 件は debug / release とも期待したアサーションで失敗した。
再生成は次のコマンドを使う。ADV-04 は引き続き `#[ignore]` であり、この実行には含まれない。

```sh
cargo test -q -p echode-history --test audit_recovery
cargo test -q --release -p echode-history --test audit_recovery
```

## 境界と残る制約

- 形式・連番・途切れた末尾・`save.pending` の既存規則は変更しない。
- 不変条件を満たす別の値への改変は検知しない。チェックサムや真正性の保証ではない。
- 既に壊れたコミットから親へ戻る規則と、その通知がない ADV-02 は変更しない。
- 破損行を取り除く製品 UI や自動修復は追加しない。失敗時は原本を保全して調査する。
- 音声処理・ABI・表示の形式は変更しない。実機・聴感検査はこの修正の判定に不要である。
