# ADR 0371: 全 ADR に先頭の状態・領域行を持たせ、領域別の索引を自動生成する

- 日付: 2026-11-15
- 状態: 現行
- 領域: ビルド・検査・開発基盤
- 関連: [PCA-04](../reviews/2026-11-13-professional-cross-audit.md#pca-04-adr-に現行置換の索引がない)、[ADR 0235](0235-reading-budget-and-split-guides.md)、[ADR 0370](0370-domain-status-guides.md)

## 背景

ADR は 0001〜0370 まで 370 件（約 2.5 MB）が時系列で並び、`docs/decisions/` に一覧がなかった（PCA-04）。
どの判断が現在有効で、どの判断が後続の ADR で置換済みかを確かめるには、後続の本文や監査文書を順に追う必要があった。
読む量の上限（[ADR 0235](0235-reading-budget-and-split-guides.md)）に対しても、現行判断をすぐ引ける索引が欠けていた。

## 比べた案

- **案 1: 手書きの一覧 `docs/decisions/README.md` だけを置く**:
  各 ADR を更新しないため、新しい ADR が古い判断を置換した時の更新漏れを検査で止められず、表が大きくなると 1 節 12,000 バイトの上限を超える。
- **案 2: ADR 本文の日本語表記からスクリプトで自動推論する**:
  本文の「接続した」「残る範囲」「置き換える」などの表現が多様で、拡張と置換を誤りなく区別できない。
  既存のヘッダも `- 状態: 採用` と bare の `状態:`、複数行の補足が混在していた。
- **案 3（採用）: 全 ADR の先頭に単一行の `- 状態:` と `- 領域:` を必須化し、`scripts/documentation.py` で領域・状態別索引を生成して `check-verification` で鮮度を検証する**:
  各 ADR の先頭だけで現行か置換済みかが分かり、置換関係が曖昧な推論に頼らず確定する。
  `docs/decisions/README.md` の中身はコードから一意に再生成し、不整合を検査で拒否する。

## 決定

### ADR ヘッダの規約

各 ADR の見出し `# ...` の直後（最初の `## ` 見出しまで）に、次の 2 行を単一行で 1 つずつ置く。既存の本文と歴史的な補足の記録は保持する。

- `- 状態: <区分>...`: 先頭の区分は `現行`、`一部置換`、`置換済み`、`草案` のいずれかに限る。
  - `一部置換` と `置換済み` は直後の丸括弧 `（...）` 内に置換先の ADR への Markdown リンクを 1 つ以上置き、置換先はいずれも自身より後の番号の実在 ADR に限る。
  - 既存の追加補足や未確認番号（`UC-XX`）が長い場合は `- 補足:` 行へ移して保持する。
- `- 領域: <領域名>`: [監査の索引](../reviews/README.md) と対応する 6 領域のどれか 1 つに限る。
  `全体方針・計画`、`モデル・履歴・保存・API`、`音声エンジン・書き出し`、`プラグイン・隔離`、`UI・描画・入力`、`ビルド・検査・開発基盤`。

### 領域別の生成索引と上限対策

- `scripts/documentation.py` に `scan_adrs`、`render_adr_index`、`adr_index_errors` と `--write-adr-index` / `--check-adr-index` を置いた。
- `docs/decisions/README.md` は冒頭に集計表を置き、6 領域ごとに「現行・一部置換」を先、「置換済み・草案」を後に並べる。
- 1 節が `SECTION_BUDGET_BYTES`（12,000 バイト）を超えないよう、40 件を超える一覧は `#### ADR XXXX〜YYYY` で分割する。
- `scripts/agent_context.py` の `COMMON_GUIDES` に `docs/decisions/README.md` を加え、案内文書としての節サイズ上限とローカルリンク・アンカーを `check-verification` で継続検査する。`START_GUIDES` には入れず、開始時の一括読込量は増やさない。

## 測定と検証

- 全 ADR（0001〜0371）371 件へ `- 状態:` / `- 領域:` を付与した（`現行` 303 件、`一部置換` 65 件、`置換済み` 2 件、`草案` 1 件）。
- 生成された `docs/decisions/README.md` は 53,308 バイト（480 行）、最大の節（`#### ADR 0044〜0320`）は 6,441 バイト（上限 12,000 バイト）、
  `make agent-context` の開始時一括読込量は 26,745 / 44,000 バイトで超過（`oversized`）は 0 件だった。
- `check-verification` に正常系（全 ADR ヘッダ検証・索引一致・リンク・行長）と異常系（状態・領域の欠落・無効値・後方置換リンク・リンク切れ・古い索引）を追加し、単体テスト 28 モジュール・450 件（`test_diagnostics` を含む）が通った。
