# 0005. S2 の確定と履歴の検証

- 日付: 2026-10-08
- 状態: 採用

## 背景

S2 の計測結果の確認を得た。ライセンスは 0004 のとおり GPL-3.0-or-later のままである。

## 決定

- S2 を確定する。リアルタイムのコールバックはオーディオスレッドでブロックを完了し、締め切りを超えてワーカーを待たない
- 次の検証は S4（プレーンテキストのプロジェクトと、gix による自動コミット）とする
- 履歴の実装には gix を使う。gix は MIT OR Apache-2.0 で、GPL-3.0-or-later と両立する

## 結果

S4 の合格条件は、1,000 トラック規模の保存で UI が止まらないことと、過去の版を 1 秒以内に読み込めること。
