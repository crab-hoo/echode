# ADR 0092: プレイヘッドの実ウインドウ回帰は明示した計測へ置く

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 検査。監査 CU-02

2026-10-15 追記: 明示した実機検査へ分ける判断は維持する。以下の Swift Testing と環境変数による起動方式は [ADR 0093](0093-product-contract-gate.md) の専用 AppKit プローブへ置き換えた。現在の入口は [検査手順](../verification.md)。

## 背景

`PlayheadTests` の実ウインドウ 4 件は通常の `@Test` だった。再生継続と一時停止の描画は、ウインドウが遮蔽されていないときだけ確認していた。遮蔽された環境の合格は、その項目を確かめたことにならない。時間と実機に依存する検査は、通常の `make check` ではなく `make spike-*` で動かす。

## 決定

世代と操作結果の検査は `make check` に残す。実ウインドウの 4 件は、環境変数 `ECHODE_SPIKE_PLAYHEAD` が `1` のときだけ有効にし、入口は `make spike-playhead` とする。

その実行は、ウインドウが現在の Space にあり、遮蔽も最小化もされていないことを確認してから期待値を見る。`beginMeasurement()` は使わない。確認するのは、停止中の 0→2 拍、再生継続、一時停止、停止中の休止、破棄したビュー、計画の交換、文書の交換である。条件が足りなければ、画面の状態と未検証項目を `target/spike-playhead.json` に書き、終了コードを非ゼロにする。主要な期待値を省略して合格にしない。`spike-app` の合格条件は変えない。

## 結果

フラグを付けない Swift テストでは 4 件は実行されず、世代と操作結果の検査は通過した。この環境の `make spike-playhead` は終了コード 1 だった。画面は 1 枚で点灯し、ウインドウは visible だが現在の Space に無く、遮蔽されていた。未検証は、0→2 拍、停止中の休止、同じ feed を渡しても再描画しないこと、再生継続、一時停止、破棄、開き直したビュー、計画交換、文書交換である。これらは合格にしていない。
