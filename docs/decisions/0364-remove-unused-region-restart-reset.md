# ADR 0364: 未使用の共有領域リセット入口を削除する

- 日付: 2026-11-15
- 状態: 採用
- 関連: [RTA-08](../reviews/2026-11-14-realtime-adversarial-audit.md#rta-08-使われない-reset_for_restart)、[ADR 0042](0042-plugin-ipc.md)

## 問題と根拠

`MappedRegion::reset_for_restart` は共有ヘッダと世代番号を戻すが、親だけが持つ `abandoned` を戻さない。
同じ番号の新しい世代を `collect_ready` が破棄済みとみなす入口だった。
製品の `PluginHost::restart` は既に新しい共有領域を作り、呼出し元は単体テストの 1 箇所だけだった。
製品から届かない入口なので、製品の不具合として失敗する回帰は作らず、呼出し元の全検索と再起動の実装を削除の根拠にする。

## 比較と決定

1. `abandoned` も初期化して入口を残す: 未使用の経路とその検査を維持し、初期化の責務が領域作成と重複する。
2. 入口を削除する: 製品で使っている新規作成だけになり、既存の再起動の挙動を変えない。

2 を採る。メソッドと、それだけを呼ぶ単体テストの末尾を削除する。
不正な共有ヘッダでも親が世代番号を決める単体回帰は残す。
共有ヘッダの配置・通信形式・通常の DSP リセット・再起動時の状態復元は変えない。
実行時の処理は追加せず、性能の比較計測は行わない。

## 回帰と基盤

`crates/echode-plugin-host/tests/isolation/restart.rs` は製品の非同期投入・破棄・再起動・回収を実ヘルパーへ通す。
旧領域の世代 1 を捨て、新しい領域の世代 1 が破棄されず、入力と一致する音声を返すことを検査する。
この回帰は削除前にも通り、既存の製品経路を維持する証拠である。機器や第三者プラグインは使わない。

設計書と監査・索引を更新する。既存の Rust 通常テストが新しい隔離回帰を収集する。
検査入口・選択・外部入力・失敗経路を増やさないため、Makefile・検査ポリシー・fuzz・デバッグ手順は変更不要である。
利用者の制約と実機確認待ちは増やさない。
