# ADR 0071: コールバックは重なる配置だけを選ぶ

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 製品再生が配置した音声を足す処理

## 背景

配置は開始サンプル順に並んでいる。製品のコールバックは、その区間に鳴らない配置も含めて一件ずつ下位の描画へ渡していた（監査 AUD-12）。下位の二分探索は、渡された一件の配列にしか効かない。遠い将来の配置が増えると、鳴っているクリップ数が同じでもコールバックの仕事が増える。

## 決定

配置は重ならないので、終了も開始と同じ順である。コールバックは、区間の開始以前に終わった配置を二分探索で飛ばし、区間の終了以降に始まる配置の手前で止める。ヒープの確保はしない。

時間の比は、正しさのテストには置かない。release の計測だけが、将来の配置を増やしてもコールバックが遅くならないことを見る。

## 結果

ブロックの直前で終わる配置と、ブロックの直後から始まる配置は無音のままである。8,000 個の将来の配置を足しても、鳴っているクリップの波形は変わらない。release で 256 フレームを 2,000 回描くと、鳴るクリップ 1 つは 1.10 ms、同じクリップに 10 万個の将来の配置を足すと 0.85 ms だった。画面での操作確認は未実施である。
