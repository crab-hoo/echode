# ADR 0178: 選択したノートを同じ時刻差・音程差で移動する

- 日付: 2026-10-27
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#ノートの選択)、[ADR 0167](0167-piano-note-drag-snapping.md)、
  [ADR 0176](0176-piano-note-selection-and-deletion.md)、[ADR 0177](0177-piano-batch-note-velocity.md)

## 背景と再現

開始時のソース `f7af77d112a93a52236737aec5e4cc553c90fa5da46346fa88c69a4c818a11ce` では、
複数選択したノートの本体を押すと単一選択へ戻り、つかんだ音だけを移動していた。
実 View の押下とドラッグを通す回帰を先に追加し、選択全体を保持できないことを確認した。
期待終了コードと固有のアサーションは `target/focused-checks/piano-move-batch-red/` に残す。

## 決定

- 編集中の単一トラックで、選択済みノートの本体の通常ドラッグを選択全体の移動とする。
  未選択ノートと左右端は従来の単一選択・単一編集を使う。Option はベロシティ、Command は選択切替のままである。
- 押下時の全 ID・幾何・カメラを保持する。3 pt 以上動いてから仮表示し、クリックと微動では量子化・確定をしない。
  つかんだノートの開始を絶対グリッドへ吸着し、その時刻差と半音差を全対象へ加える。Shift の間は時刻の吸着を外す。
- 時刻差は全対象の最小開始と最大終端、音程差は最低音と最高音で共通に制限する。
  どれかが時刻 0、整数時刻の上端、MIDI 音高の上下端へ達したら全体が止まり、相対間隔・音程を保つ。
  画面外の選択とリンク配置も制限に含む。無効な幾何・非有限値・桁あふれは仮表示しない。
- ドラッグ中はモデルを変えず、移動後の全対象を既存の単一移動と同じ明色の矩形で重ねる。
  表示中の未選択リンクも共有内容の移動を仮表示する。下部の棒と読み上げ用の確定幾何は、モデルの確定後に更新する。
- 解放時の座標と Shift で計算し直し、変更時だけ既存の `note.edit` の配列を単一トランザクションへ送る。
  待機列の手番で全対象の存在と元の幾何を検証し、1 つでも古ければ全体を拒否する。旧文書への要求も受けない。
- 同じ内容のノートは ID ごとに一度だけ変更する。つかんだ配置を優先し、他は安定した ID 順で代表を選ぶ。
  固定窓の拡張は既存のモデルに従い、代表の窓だけを広げる。他の固定リンクのトリムは保つ。
  自動配置の小節基準も保つ。クリップ同士の重なりは現行モデルの拒否を維持し、途中の失敗では全体を巻き戻す。
- 選択、入力長、入力ベロシティ、各ノートの長さ・ID・ベロシティ・表情を保つ。
  履歴と保存は既存経路を使い、1 回の Undo / Redo で全体を戻す。
- Escape・フォーカス喪失・入力取消・スクロール・ズーム・寸法変更・文書と対象の変更・処理中・終了で破棄する。
  選択集合の変更でも取り消し、遅れた解放を確定しない。押下中は再生ヘッド追従を保留する。
  古い仮表示のフレームから次のノート入力を開始しない。

## 受入と基盤

- `piano-note-move-batch-ui` は実 View と製品ブリッジで、吸着・Shift・解放位置、全対象の仮表示、
  選択・記憶値保持、長さ・ベロシティ保持、単一 Undo / Redo と保存再読込を確認する。
- `piano-note-move-batch-targets-ui` は画面外の選択・リンク・共通上下限・整数境界・重複排除と古い対象・旧文書の拒否を確認する。
  通常回帰で固定窓の拡張と Undo、後続の重なり拒否による先行編集の巻戻しも確認する。
- `piano-note-move-batch-cancel-ui` はクリック・微動・各取消、選択変更、追従の保留と古い仮表示の再入力拒否を確認する。
  単一選択化、古いプレビューの確定、仮表示・対象検証・共通制限・重複排除・取消の欠落を負の対照にする。
- Makefile の既存入口、検査選択テスト、README・操作要件・現状・領域設計・デバッグ手順を更新する。
  モデル・アクション・保存形式・DSP は変えず、既存の `note.edit` の履歴・ブロック長回帰を維持する。
  新しいアクション生成や診断収集先は不要である。
- 一括伸縮・Command 複製移動、複数トラック、ゴーストノート、試聴、矢印と読み上げ操作による一括移動は別単位に残す。
  実画面のドラッグと見え方・VoiceOver はユーザー確認とし、自動回帰の合格と区別する。
