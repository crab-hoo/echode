# ADR 0265: 外部宣言をシンボル単位で制限する

- 日付: 2026-11-05
- 状態: 採用
- 対象: FCA-12。ENG-15 の未提供 API と SDK 照合の残りを完了扱いにはしない。

## 問題と再現

`check-ffi.sh` は外部宣言を持つファイルだけを許可一覧と照合していた。
既に許可したファイルへ関数を足しても拒否せず、宣言を一つ消しても不要になった許可を判定できなかった。
`ForeignDeclarations.test_a_new_symbol_in_a_listed_file_is_rejected` は実際の検査入口を小さい Rust ツリーへコピーする。
`f` だけを許可したファイルへ `added` を足すと、修正前は終了コード 0 で抜けた。
期待終了コードと固有のアサーションを照合してから修正した。

## 決定

- 許可一覧はソースの相対パスと Rust の関数・静的変数名の組にする。未使用の組も拒否する。
- シェルの入口は維持し、Python の字句走査で宣言ブロックを調べる。
  ABI なし・別 ABI・改行した波括弧を含め、コメント・文字列・関数定義・関数ポインターとは区別する。
- 許可名を別の外部シンボルへ向ける `link_name` は例外にせず拒否する。
- sandbox とエンジンの待機・起床・QoS は既存の `libc 0.2.190` の公開宣言を使う。
  エンジンの CoreAudio と計測用バッファ・時刻の型は製品 I/O と同じ objc2 の宣言を使い、Mach の時計と signal は libc を使う。
- 問い合わせの順序、スコープの代替、Workgroup の保持、待機の期限と再試行の条件は変えない。
  機器を開く確認は明示依頼がないため実行しない。

Workgroup・bootstrap・一部の Mach IPC・`os_release` の既存宣言は、現在使う libc / objc2 の公開範囲にないため個別に残す。
新しい外部宣言は増やしていない。SDK との全件の照合や宣言の集約は ENG-15 の残りである。

## 回帰と基盤

`ForeignDeclarations` は同じファイルへの追加、同じファイル内の古い許可、static mut、コールバック型を確認する。
空の許可一覧、入れ子のコメント、raw 文字列、`link_name` も照合する。
`test_engine_spike.py` は自作型・宣言の存在ではなく、バインディングの計測用 import が非既定 feature に閉じることを確認する。

Python の実装を `check-base` の依存入力へ登録し、通常のスクリプト検査・隔離回帰・RTSan と動的検査の選択を維持する。
診断手順へ新しいメッセージの読み方を追加する。成果物やログの収集先は変えない。
合否と実機検査の見送り理由の正本は `target/verification/report.md` である。
