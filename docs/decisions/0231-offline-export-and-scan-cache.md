# ADR 0231: オフライン書き出しを実時間の期限から外し、走査キャッシュを置換で書く

- 日付: 2026-11-02
- 状態: 採用
- 関連: [外部監査の精査](../reviews/2026-11-02-external-audit-review.md)の CLI-A1・PLG-A1 (b)(c)、
  [実行指示](../reviews/2026-11-02-fix-instructions.md)の W3

## 背景と再現

開始時の HEAD は `53840fb`。

- CLI-A1: `render_with_plugins` は再生と同じ実時間の期限でブロックを判定し、1 ブロックでも間に合わなければ書き出しを失敗にした。
  ブロック長はテールを足す前の長さで決まるため、`--frames 1` は 1 フレームのブロックで書き出し、毎回期限に間に合わなかった。
  実時間より遅いプラグインは、オフラインでも書き出せなかった。
- PLG-A1 (b): `store_scan_cache` は既存のファイルを切り詰めてから書く。`resolve_installed` は呼ばれるたびに同梱プラグインのキャッシュを書き直す。
  並列の書き出しで、読む側が書き途中のファイルを読み `missing plugin` になった。
- PLG-A1 (c): 走査の標準出力に上限がなく、書き続けるヘルパーがメモリを使い続けられた。

`audit_cli_a1_a_one_frame_plugin_export_completes` は修正前に `did not finish before the deadline` で失敗した。

## 決定

- 書き出しは `PlaybackAudio::render_until` に、ブロックごとに 60 秒先の期限を渡す。
  書き出しは実時間ではないので、ヘルパーの完了を待つ。60 秒は、応答しなくなったヘルパーで書き出しを終えるためだけの値である。
  再生のコールバックの期限は変えない。
- ブロック長は書き出しの長さとテールに依存しない 256 フレームとし、最後のブロックだけ短い。
  音はブロックの切り方に依存しない（AGENTS）ので、出力は変わらない。
- `store_scan_cache` は全行を作ってから、同じディレクトリの一時ファイルへ書き、名前の変更で置き換える。
  内容が同じなら書かない。読む側は古い一覧か新しい一覧のどちらかを読む。
- `resolve_installed` の説明を実際に合わせた。共有キャッシュを引いた後、同梱プラグインのキャッシュを更新してから引く。変わった同梱プラグインは別プロセスで走査する。
- 1 つのバンドルの走査の標準出力に 64 MiB の上限を置く。超えたら切り詰めずに走査を止め、エラーにする。
  1 つのプラグインの記述は数百バイトで、実際のバンドルを大きく上回る。プラグイン数の上限ではない。
  標準エラーは従来どおり 64 KiB までを残し、残りは捨てながら読み続ける。

## 回帰と基盤

- `audit_cli_a1_...` の `#[ignore]` を外した。
- `a_plugin_slower_than_real_time_still_exports` は、テスト用プラグインの新しい故障 `slow-process`（各 `process` で 20 ms 待つ）で書き出しが完了し、
  遅くない時と同じ音になることを確かめる。修正前の CLI では期限切れで失敗した。
- `scan::tests::a_rewritten_scan_cache_stays_whole_for_concurrent_readers` は、同じ内容を書き直さないこと、2 つの書き手の間で読む側が常に全行を読むこと、
  一時ファイルを残さないことを確かめる。修正前の `store_scan_cache` では、同じ内容を書き直して失敗した。
- `scan::tests::endless_scan_output_stops_at_its_bound` は、`/usr/bin/yes` をヘルパーの代わりにして、期限より前に上限で止まることを確かめる。
  上限のない旧版で走らせるとメモリを使い続けるため、修正前の実行はしていない。
- 新しい必須契約・ログは加えない。
