# ADR 0154: クリップの移動と複製移動を置き換えで接続する

- 日付: 2026-10-25
- 状態: 採用。UIF-03（[照合](../reviews/2026-10-21-ui-feedback-audit.md#7-クリップの移動と複製移動uif-03)の 7 番目）を接続。P2-07 のアレンジ編集の先行分。
  重ねるモード・自動クロスフェード・⌘D・複数クリップ・トリムは対象外
  小節未満の移動で自動配置を固定にする規則だけは [ADR 0170](0170-content-relative-auto-bars.md) で置き換えた。

## 背景

[操作要件](../interaction-design.md#アレンジの選択と編集) は、クリップ本体の左ドラッグを移動、Command＋ドラッグを複製移動とする。
2026-10-22 の回答で、移動は別のトラックへもでき、グリッドに吸着して Shift で吸着を解除する。
移動先が同じトラックの配置と重なる時は、「重ねる／置き換える」の切替を接続するまで「置き換える」として扱う。

アクション登録簿に移動がなく、`ArrangeView` はクリップの選択とハンドルの操作だけを扱っていた（照合の UIF-03）。
現行モデルは同じトラックでの配置の重なりを禁じる（[ADR 0022](0022-clip-content-and-placement.md)、[ADR 0071](0071-clip-overlap-index.md)）。
自動配置は、窓がノートの占める小節範囲と一致する不変条件を持つ。

## 決定

- `clip.move` は `clip`・`track`・`start` を受け、配置を移す。
  ID・中身・窓の長さ・オフセット・ゲイン・フェードを保つので、鳴る時刻は配置と一緒に動く。
- `clip.duplicate` は同じ引数で、配置を新しい中身ごと複製して置く。`clip.link`（同じ中身を共有する複製）は別操作として残す。
  複製の配置・中身・ノートの ID は、記録した `seed` と元 ID から [ADR 0129](0129-track-duplication.md) と同じ鍵導出で決める。
  文脈文字列はトラック複製と分け、複製先の編集は元へ伝わらない。音声の中身は同じ素材ハッシュを参照する。
- 移動先トラックで新しい窓と重なる他の配置は、次のように置き換える。
  - 窓の内側に収まる配置は消す。参照されなくなった中身も消える。
  - 窓の端をまたぐ配置は外側の部分を残す。右側は開始とオフセットを同じだけ進め、鳴る時刻を保つ。
  - 窓全体を含む配置は左右に分ける。右の部分は `seed` と元 ID から別の文脈で導出した ID を持ち、同じ中身を共有する。
  - 残した部分は `fixed` にする。新しい切り口のフェードは既定の 5 ms、切っていない端は元のフェードを保つ。
  - 移動するクリップ自身は対象外なので、元の位置と重なる移動ができる。複製では元の配置も置き換えの対象である。
- 自動配置は、小節の整数倍だけ動いた時だけ `auto` を保つ。それ以外は窓がノートの小節範囲と一致しなくなるため `fixed` にする。
- 負の開始、終端・原点・ノート時刻の桁あふれ、存在しない配置・トラック、導出 ID の衝突は拒否し、プロジェクトを変えない。
- 保存形式と ChangeSet の形式は変えない。トラック間の移動は、既存の配置の `Owner` 更新として記録される。
- 画面の操作は次のとおり。
  - `ArrangeView` はクリップ本体の押下を移動の候補にする。選択中の音声クリップのハンドルは、従来のゲイン・フェードの操作を優先する。
  - 3 pt を超えて動くとドラッグになり、着地点にクリップの影を描く（移動は橙、複製は緑）。それまでは選択だけである。
  - 移動先はポインターの行で、トラック一覧の上下端で止める。
  - 開始は、押下時のポインターの拍からの移動量を元の開始へ足し、アレンジが描く四分音符の線の最寄りへ吸着する。Shift はポインターの tick を使う。
    押下時の拍を保持するので、ドラッグ中のスクロール・ズームでも移動量は変わらない。
  - 離した時の Command で複製、Shift で吸着解除を決める。同じ位置、Escape、取り消されたジェスチャーは編集を送らない。
  - 要求（`ClipMove`）は、文書 ID・配置・トラック・開始・複製の別を離した時点で確定する。
    controller は旧文書・消えた配置やトラック・変位のない要求を拒否し、Redo を消さない。
  - 編集後は移動先トラックを選択し、移動したクリップ、複製では複製をフォーカスにする。
- 重ねるモードと自動クロスフェード、⌘D の直後への複製、複数クリップの移動、端での自動スクロール、VoiceOver からの移動、トリムは後続の単位で扱う。

## 受入と基盤

- モデルの単体テスト（`clip_move_tests.rs`）は、別トラックへの移動、窓による削除・切詰め・分割、切り口のフェード、元の位置と重なる移動を確認する。
  自動配置の種類の保持と解除、複製の中身の独立と決定的な ID、音声の素材共有、拒否の理由、ChangeSet の往復も通す。
- `clip_move`（履歴）は、移動と複製を JSON の要求から実行し、Undo / Redo、ChangeSet とアクションだけのジャーナル再生、保存再読込を確認する。拒否した要求は履歴を変えない。
- `clip_move`（CLI）は、移動したクリップの書出しが同じ位置へ直接置いた場合と全サンプル一致し、同じ位置の複製で 2 倍になることを実 CLI で確認する。
- `ClipMoveTests` は、実 View の合成マウスイベントで、別トラックへの移動・四分音符の吸着・Shift の解除・Command の複製と、影の位置を確認する。
  しきい値内の押下・Escape・取り消しで編集がないこと、単一 Undo / Redo、保存再読込、置き換えの切詰め、旧文書・変位なし・負の開始の拒否も通す。
- ランダムな編集列の `properties.rs` に移動と複製を加え、小節をまたぐ 8 分音符単位の開始で種類の保持と解除・切詰め・分割を生じさせる。
- 必須契約 `clip-move-ui` と `clip-move-model` を `scripts/verification.json` に登録する。
- 新しい音の処理はなく、音は既存の配置の再生経路を通るので、ブロック長比較と RTSan の追加は不要である。書出しの一致は CLI で確認する。
- 実画面のドラッグの操作感・影の見え方・VoiceOver はユーザー確認とする。
