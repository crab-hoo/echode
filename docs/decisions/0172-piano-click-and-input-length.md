# ADR 0172: ピアノロールの単クリック入力と入力長の共有

- 日付: 2026-10-26
- 状態: 採用。P2-07 の単一ノート入力。実画面の操作感はユーザー確認待ち
- 関連: [ADR 0117](0117-workflow-interactions.md)、[ADR 0171](0171-piano-blank-drag-insertion.md)

## 背景と再現

[操作要件](../interaction-design.md#ノートの入力) は、単クリックで記憶した長さを入力し、
単一選択・追加・伸縮の長さを全トラックへ引き継ぐ。
`75fcdd8` は空白ドラッグだけを接続済みで、単クリックでは追加せず、入力長も記憶していなかった。
実 View への押下・解放から製品ブリッジへ送る回帰を先に追加し、追加回数が 0 の失敗を確認した。
終了コード 1 と固有のアサーションの照合は `target/focused-checks/note-click-red/` に記録した。

## 決定

- 空白の単クリックも解放時に 1 回だけ追加する。開始・音高・入力長は押下時の値を保持する。
  微小な移動では値を変えず、Shift の開始吸着解除も押下時に決める。
- ダブルクリックの 2 回目は空白から追加しない。最初の追加のスナップショットが未到着でも二重にしない。
  新しいフレームの確定ノートに当たる場合は通常の選択として扱う。
- 3 pt 以上のドラッグは従来どおり開始を固定して終端と音高を調整する。
  記憶長がグリッド未満でもクリックではその値を保つが、新規ドラッグの最短長は 1 グリッドを維持する。
- `ProjectController.noteInput` が、開いている文書内で 1 つの入力長を持つ。
  未記憶時と再オープン時は未指定とし、入力時の現在のグリッド幅を使う。保存形式・ジャーナルへは追加しない。
- 有効な単一ノート選択は、同じノートの再選択・Tab・アクセシビリティ操作も含め、その長さを即座に記憶する。
  選択だけではモデルの編集も Undo の追加も行わない。
- 成功した追加と単一ノートの長さ変更は、操作前後の入力長をモデルの Undo と同じ枠へ記録する。
  移動・音高変更・失敗・無変更では入力長を変えない。
- 無関係なモデル編集、プラグイン状態の記録、履歴復帰も入力長を変えない履歴枠を持つ。
  それらの Undo で後から選んだ長さを巻き戻さず、新規編集では入力長側の Redo 分岐も捨てる。
  選択だけでは Redo を捨てない。
- ジャーナルの書込み待ち中に別ノートを選んだ場合は、新しい選択の長さを遅れた成功応答で上書きしない。
- 入力時に長さをグリッドへ丸め直さない。トラック切替・スクロール・ズームでも記憶を保持する。
  Return とアクセシビリティの既存の追加も同じ長さを使う。
  Return の一時停止への割当は [ADR 0155](0155-remembered-playback-start.md) の残件を保つ。
- 空白の押下の取消と仮表示は ADR 0171 の経路を共有する。取消ではモデルも入力長も変えない。

## 受入と基盤

- 必須契約 `piano-note-click-ui` は実 View・製品ブリッジで、解放時だけの単一追加、押下時の Shift、
  Undo / Redo・保存再読込を確認する。負の対照は単クリックを追加しない旧条件へ戻す。
- `piano-note-input-length-ui` は実 View の選択とトラック間の入力、伸縮と無関係な編集の Undo、
  無変更・旧文書の拒否、二重クリック・分岐・再オープン時の初期化を確認する。
  負の対照は選択の記憶、Undo、Redo、クリックの記憶長、二重クリックの拒否を個別に外す。
- `NoteInputHistoryTests` は未記憶への Undo、非同期応答と選択の順序、未変更枠、Redo 分岐、
  グリッドとズームを変えた幾何・不正な長さ・桁あふれを機器なしで確認する。
- 既存の空白ドラッグと取消の契約を維持し、変更した生成条件の負の対照を更新する。
  検査の選択回帰、Makefile の既存入口の説明、利用手順・操作要件・現在の範囲・領域設計も更新する。
- デバッグ手順に入力長と履歴枠の切り分けを追加する。
  外部入力・ログ・成果物は増やさず、`doctor` と `debug-report` の収集範囲は変更しない。
- モデル・アクション・音声処理は変えず、ランダム操作生成・ブロック長比較の追加は不要である。
  複数選択、共通ベロシティ、試聴は別単位とし、実画面・VoiceOver・聴感はユーザー確認とする。
