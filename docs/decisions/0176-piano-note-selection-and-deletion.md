# ADR 0176: ピアノロールの複数選択と一括削除

- 日付: 2026-10-27
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#ノートの選択)、[ADR 0172](0172-piano-click-and-input-length.md)、[ADR 0175](0175-piano-velocity-lane.md)

## 背景と再現

`dd4b132` では選択が単一の `noteFocus` だけで、右ドラッグと Command＋クリックによる複数選択はなかった。
実 View の右押下・ドラッグ・解放を通す回帰を先に追加し、部分交差した 2 音が選択されないことを確認した。
期待終了コードと固有のアサーションは `target/focused-checks/piano-selection-red/` に記録した。

## 決定

- 編集中の単一トラックで、ノートグリッドの右ドラッグを置換型の枠選択とする。
  一部でも交差した可視ノートを選択し、逆向き・細い枠・表示端で切れたノートも同じ判定を使う。
  鍵盤・度数・ルーラー・下部レーンからは枠選択を始めない。
- 押下位置から 3 pt 以上動いたらドラッグとし、枠と選択の強調を仮表示する。
  確定選択は解放位置から再計算して 1 回だけ置き換える。枠はノートグリッド内に描く。
  空の枠は選択解除とする。自動スクロールは今回追加しない。
- ドラッグしない右クリックは、選択済みノートなら複数選択を保って削除メニューを開く。
  未選択ノートならその 1 音だけを選択する。空白右クリックは選択解除だけで、メニューを開かない。
  メニューは生成時の選択とスナップショットを保持し、対象交換・文書交換・処理中には実行しない。
- Command＋左クリックは選択の追加・解除とする。下部の棒でも同じ切替を使い、値は変えない。
  空白の Command＋クリックは何も追加しない。Command＋ドラッグの複製移動は未接続で、今回は編集を送らない。
- 選択集合を `ProjectController.noteSelection` が保持し、`noteFocus` は集合が単一の時だけその ID を返す。
  同じ文書・トラックでエディタを再生成しても保持する。トラック切替・文書交換では解除し、モデル更新で消えた ID を除く。
  選択自体は保存・Undo の対象にしない。Undo でノートを戻しても選択を再生成しない。
- 単一選択だけが従来どおり入力長と入力ベロシティを記憶する。
  複数選択では任意の代表ノートを記憶せず、単一ノート用の数値欄とインスペクターを表示しない。
  ノートと下部の棒の強調、アクセシビリティの選択値は同じ集合を読む。
  ノートの読み上げ操作に選択追加・解除を加え、既存の削除操作も選択全体へつなぐ。
- Delete / Forward Delete と右メニューは、既存の `note.delete` をまとめた単一トランザクションへ送る。
  待機列の手番で全 ID を検証し、1 つでも古ければ全体を拒否する。
  リンク配置が同じ中身のノートを複数回表示しても、ノート ID ごとに一度だけ削除する。
  Undo / Redo・ジャーナル・保存は既存のトランザクション経路を使う。文字入力中の Delete の経路は変えない。
- Escape・フォーカス喪失・入力取消・スクロール・ズーム・寸法変更・対象や文書の変更・処理中・終了で枠を破棄する。
  取消前の確定選択を枠の遅れた解放で上書きしない。枠の押下中は再生ヘッド追従のページ送りを保留する。
- 一括移動・伸縮・複製移動・ベロシティ変更、複数トラック編集、ゴーストノートと試聴は別単位に残す。
  それまでは通常の左押下が対象を単一選択へ置き換えて従来の編集を行う。複数選択のままの矢印編集は送らない。

## 受入と基盤

- `piano-note-selection-ui` は実 View から部分交差・Command 切替・記憶値保持・再生成・描画と読み上げを確認する。
- `piano-note-selection-cancel-ui` は取消後の右解放が確定選択を置き換えないことを確認する。
- `piano-note-selection-delete-ui` は実キー・右メニューと製品 ABI で、選択保持・単一 Undo / Redo・古い対象の拒否・保存再読込を確認する。
- `piano-note-linked-delete-ui` は同じ中身の二重削除を拒否し、1 回の Undo で全配置を戻す。
  部分交差・選択切替・強調・取消・削除対象数・メニュー選択・重複排除を外す負の対照を登録する。
- 既存の Makefile 入口・検査選択テストと、README・操作要件・現状・領域設計・デバッグ手順を更新する。
  音声 DSP・モデル・保存形式・外部入力・成果物の場所は変更せず、追加の音声ブロック長回帰と診断収集先は不要である。
- 実画面の枠・メニュー・Command の操作感と VoiceOver はユーザー確認とし、自動回帰の合格とは区別する。

後続の [ADR 0177](0177-piano-batch-note-velocity.md) で、選択したノートのベロシティ一括調整を接続した。
