# ADR 0184: Command ドラッグでノートを複製移動する

- 日付: 2026-10-28
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver・聴感はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#ノートの選択)、[ADR 0176](0176-piano-note-selection-and-deletion.md)、
  [ADR 0178](0178-piano-batch-note-movement.md)、[ADR 0181](0181-piano-reference-workflow-and-keys.md)

## 背景と再現

Command＋クリックの選択切替は接続済みだったが、押下時に切り替えて戻るため、複製ドラッグへ進めなかった。
開始時の HEAD は `f917a06`。実 `PianoGridView` の Command 押下・ドラッグ・解放を通す回帰を先に追加し、
選択が押下で変わり、複製の仮表示を取得できないことを確認した。
期待終了コードと固有のアサーションの照合は `target/focused-checks/piano-duplicate-red/` に記録する。
このパスはローカルの一時ログであり、永続的な証拠の参照先ではない。

## 決定

- ノートグリッドの Command 押下では選択を変えず、クリックの解放時に従来の追加・解除を行う。
  3 pt 以上動いたら複製移動とし、選択済みなら選択全体、未選択ならつかんだ 1 音を対象にする。
  端から始めても伸縮せず、Option との同時押下では複製を優先する。棒の Command クリックは従来どおりとする。
- Command の複製意図・対象・新 ID は押下時に保持する。ドラッグ途中で Command を離しても通常移動に変えない。
  解放時の座標と Shift で差分を再計算し、つかんだ開始の吸着・共通時刻差と音程差・画面外を含む上下限は一括移動と共有する。
  しきい値を越えてから元の位置へ戻した場合も、ゼロ差分の複製として扱う。
- `PianoMoveGesture.copies` と `PianoMoveChange.copies` に元ノート ID と複製 ID の対応を持つ。
  元の選択とノートを残して通常の移動と同じ仮表示を重ね、モデルは解放まで変えない。
  Escape は Command を保持したままでも取り消す。フォーカス・文書・対象・選択・寸法の変更等も既存の取消へ通す。
- 待機列の手番で全対象の元の幾何を検証する。共有内容の同じノートは一度だけ、つかんだ配置を優先して送る。
  複製は同じ共有内容に属するため、他のリンクにも現れる。リンクごとに別の複製を追加しない。
- 新しい `note.duplicate` はトラック・配置・元ノート・時刻・音高を受け、新 ID のノートを共有内容へ追加する。
  長さ、16 bit の発音・リリースベロシティ、表情を元から複製し、7 bit の新規入力で作り直さない。
  表情曲線とアーティキュレーションの現行制約（空／未対応）は変えない。
  任意の `copy` ID は衝突を拒否し、省略時は生成する。確定した ID をアクションへ保存して復旧を決定的にする。
- 配置の伸縮は `note.edit` と同じ経路を使う。元のノートは変えず、自動配置の小節基準と固定窓の拡張を保つ。
  所属替えや隣の壁の草案は採用せず、重なり・整数境界・後続の不正 ID ではトランザクション全体を拒否する。
- 成功した単一トランザクションの公開後だけ複製側を選択する。入力長と入力ベロシティは単音でも変更しない。
  複製 ID の組立て用に `PianoNote.ID` の公開初期化子を設けるが、C ABI のレイアウトは変えない。
  Undo / Redo・ジャーナル・保存は既存経路を使い、選択自体の Undo は追加しない。

## 受入と基盤

- `note-duplicate-model` は 7 bit に還元できない強弱・リンクの時刻・元の保持・ID 衝突と不正対象・履歴・復旧・保存を確認する。
  元の強弱を壊す負の対照を持つ。履歴のランダム操作生成にも複製を追加する。
- `piano-note-duplicate-ui` は実入力・仮表示・解放時の座標と Shift・元と記憶値・複製側の選択・単一 Undo / Redo・保存を確認する。
- `piano-note-duplicate-targets-ui` は画面外とリンクの共通境界、重複排除、古い対象・旧文書、未選択・端と Option の分離を確認する。
  通常回帰で固定窓の拡張と後続失敗による全体の巻戻しも扱う。
- `piano-note-duplicate-cancel-ui` はクリック・微動、Command を保持した Escape と各取消、ゼロ差分の複製を確認する。
  複製意図・選択反映・全対象検証・重複排除・Escape の欠落を Swift の負の対照にする。
- `block_size.rs` で明示入力と複製の波形を比較し、通常再生とループのブロック長独立性を保つ。
  DSP・プラグイン隔離・保存形式は変更しない。
- 既存の Makefile の入口へ契約を登録し、検査選択の回帰、利用手順・現状・Phase 2・操作要件・領域設計・デバッグ手順を更新する。
  新しいログや外部入力・ヘルパーはなく、診断収集先の追加は不要である。
- 実画面のクリックとドラッグの操作感・複製の見え方・VoiceOver・聴感はユーザー担当とし、自動回帰から合格へ移さない。
  複数トラック同時編集、試聴、ドラム入力等は残り、P2 全体の完了とはしない。
