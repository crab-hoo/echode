# ADR 0064: 製品のコールバックは締め切りを一つだけ使う

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 製品再生が複数のプラグイントラックを待つ方法。[ADR 0043](0043-plugin-submit-collect.md) の決定を、この経路に合わせる

## 背景

トラックごとに `今 + ブロック長` の締め切りを作り、そのトラックが終わるまで次のトラックへ依頼していなかった。48 kHz / 2,048 フレームでは、ハングが 1 本で約 44 ms、4 本で約 176 ms だった（監査 AUD-07）。これは ADR 0043 の「ヘルパーごとに締め切りを足さない」と食い違っていた。

## 決定

一つのコールバックに、ブロック長から決めた絶対時刻を一つだけ渡す。独立したトラックは、その時刻を待つ前にすべて依頼する。fan-in が動いたら、終わったヘルパーから受け取る。同じトラックの次の段は、前の段が終わってから依頼する。時刻を過ぎたヘルパーは欠落にし、そのトラックのブロックは無音にする。先に終わったトラックの結果は残す。

同じプラグイン id の経路が複数あるときは、トラックの順に一つずつ使う。余ったデバイスは最後の経路を共有する。`fault` はテスト用プラグインの障害注入で、製品の経路では空である。

## 結果

ゲイン 1 本とハング 3 本を同じコールバックに置くと、鳴っているトラックはゲイン後の音になり、ハングしたトラックは無音になる。待ちは 150 ms 未満で、トラック数だけ積み上がった約 176 ms とは分かれる。この 150 ms は積み上がりの回帰を見るための境界で、通常負荷の性能基準ではない。クラッシュと、遅れているが期限内に終わるヘルパーは、この検査では分けていない。画面での操作確認は未実施である。
