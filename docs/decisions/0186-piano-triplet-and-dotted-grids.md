# ADR 0186: ピアノロールの三連符・付点グリッド

- 日付: 2026-10-28
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver はユーザー確認待ち
- 関連: [ADR 0185](0185-piano-auto-and-fixed-grid.md)、[操作要件](../interaction-design.md#構成を考えながら入力する)

## 背景と再現

開始時の HEAD は `62c1a6c`。自動／固定グリッドは通常音価だけを候補に持ち、三連符・付点を選べなかった。
製品の `PianoGridBar` から 8 分三連符を選ぶ回帰を先に追加し、候補に 235,200 tick がないことを確認した。
期待終了コード 1 と固有のアサーションの照合は `target/focused-checks/rhythmic-grid-red/` に記録する。
このパスはローカルの一時ログであり、永続的な証拠の参照先ではない。

## 決定

- 固定グリッドに、全音符〜128 分音符の三連符（通常音価の 2/3）・付点（3/2）を追加する。
  既存のポップアップに通常・三連符・付点の順で並べ、値と読み上げ用の候補名を同じ音価表示にする。
- tick 幅は整数で持つ。最小の 128 分三連符は 14,700 tick、付点 128 分は 33,075 tick となる。
  自動の候補と 18 pt の切替条件は変更しない。
- 音価名は通常音価の分母と種類から作る。例えば 8 分三連符を `1/12` と誤表示しない。
  未登録の幅は、切り捨てた分母を作らず tick 数として表示する。
- 入力・移動・伸縮・複製・矢印・ルーラー・縦線は既存の `camera.grid` を共用する。
  曲の先頭からの等間隔を使い、クリップや小節ごとに位相をリセットしない。
  表示線の間引きは従来どおりで、細かい固定幅でも処理と記憶量を表示幅に限定する。
- 記憶した入力長、Shift の吸着解除、変更時の押下の取消、文書内共有と所有確認は既存の規則を保つ。
  再オープン時は自動へ戻し、モデル・アクション・ジャーナル・保存形式・音声処理は変更しない。

## 受入と基盤

- `piano-rhythmic-grid-ui` は実操作子の両候補・表示名、縦線、クリックの吸着と初期長、矢印とルーラーを扱う。
  入力長の保持・古い押下の取消・単一 Undo / Redo・保存再読込も製品 controller と ABI へ通す。
  三連符の候補欠落・付点の候補欠落・種類名の欠落を、それぞれ負の対照にする。
- 通常回帰は全音価の正確な tick 幅と一意な表示名、ズーム不変、スクロール後の線の位相と密度を確認する。
  `spike-piano-frame` は既存の通常音価の全ケースを保持し、三連符・付点の GPU 読戻しを倍率 1・2 で追加する。
- 検査登録と選択回帰、Makefile の既存入口の説明、利用手順・現状・Phase 2・領域設計を更新する。
  デバッグ手順では基準音価・整数 tick・表示名を区別し、GPU の不一致にグリッド種別も出力する。
  ログの出力先と形式、外部入力、ヘルパーは増えず、`doctor` と `debug-report` の収集先は変更しない。
- 音を作る処理とアクションは増えないため、ブロック長比較とランダム操作生成の追加は不要である。
  実画面の候補の選びやすさ・密度・VoiceOver の読み上げは、自動回帰と区別してユーザー確認に残す。
