# 0033. ジャーナルは追記だけのログにする

- 日付: 2026-10-08
- 状態: 採用
- 項目: HIS-2
- 追補: 復旧する各行の不変条件検査と違反時のオープン拒否は [ADR 0180](0180-journal-replay-invariants.md)。

## 背景

ジャーナルは、書くたびに全体を置き換え、fsync しない。自動保存はコミットのあと、別のスレッドから同じ一時ファイルでジャーナルを空にする。その窓で、コミットに入らなかった操作が消える。基点が最新のコミットと違うジャーナルは、`recover` が捨てる。末尾が途中で切れると、読めるコミットがあっても復旧全体が失敗する。

書き手は HIS-4 の `DocumentHost` に一本化した。記録の中身は、MOD-1 の ChangeSet である。この ADR は、[ADR 0009](0009-package-autosave.md) のジャーナルの基点の規則を置き換える。パッケージの形と、自動保存の参照名は 0009 のままである。

## 決定

- 書き手は `DocumentHost` のスレッドだけにする。自動保存は `journal.jsonl` を触らない
- `journal.jsonl` は 1 行が 1 記録である。先頭の `base` 行は廃止する。古い形は読まない
- 各行に連番 `seq` を付ける。1 から増え、再利用しない。1 つの Undo 単位が 1 行である
- 行の種類は `edit`、`undo`、`redo` である。どれも、その時点の ChangeSet を持つ。`edit` は今の `actions` も持つ。再生は、その時点のプロジェクトへ、`edit` と `redo` は ChangeSet を、`undo` はその `invert()` を当てる。取り消す中身は行自身が持つので、短くして消えた過去の行は要らない
- 再生する行は、基点の連番より大きいものだけである。最初の行の連番は基点の次、その後は 1 ずつ続くときにだけ再生する。飛んでいれば、そのコミットのプロジェクトを結果にし、後続の行は当てない
- コミットメッセージの末尾に `Echode-Journal: <seq>` を付ける。そのスナップショットに入っている最後の連番である。無いコミットは 0 とみなす。ホストは、保存を頼む時に、そのプロジェクトの連番を渡す
- 復旧は、先端から親へ、最初に読めたコミットを見る。ログが連続していれば後続を再生する。連続していなければ、そのコミットだけで復旧する。読めないコミットは飛ばす
- 短くしてよいのは、先端コミットの `Echode-Journal` 以下の行だけである。初期コミットが残っていても、先端まで短くできる。短くしたあとに先端のオブジェクトだけが壊れたときは、親のスナップショットまで戻る。先端と親のあいだで消した行は戻らない
- コミットが一度もないときだけ、作業ツリーを連番 0 にする。ログが 1 から連続し、`read_package` が読めたときだけ再生する。自動保存はファイルを書き換える前に `save.pending` を書いて `sync_all` し、コミットの参照を動かしたあとで消す。`save.pending` があるあいだ、作業ツリーにはログを重ねない。コミットが全部読めないときも、作業ツリーを連番 0 とはみなさず、復旧は失敗する。変わったファイルだけを、一時ファイルからの rename で置き換える（HIS-3）。rename のあいだに落ちるとファイル同士は混ざり得るので、混ざった作業ツリーはログで直さない。製品のオープンは、先端が無いとき編集の前に復旧結果をコミットする。そのコミットの途中で落ちた場合だけ、この失敗が残る（[ADR 0057](0057-crash-recovery.md)）
- ファイルが改行で終わっていなければ、最後の改行より後ろは未完了として捨てる。それより前の行が読めなければ復旧は失敗する
- 追記は、1 行を書いてから `File::sync_all` し、それから操作の結果を返す。まとめて遅らせない。短くする時は、一時ファイルを `sync_all` してから rename し、ディレクトリも `sync_all` する。短くするのはホストだけが行い、自動保存はジャーナルを空にしない

## 結果

`make check` が通った。末尾を切ったジャーナルからは、完了した行の操作だけが残る。コミットより後の行は、そのコミットのあとも再生される。短くしたあとの `undo` は、コミットに入った操作を取り消す。先端を壊すと親のスナップショットで復旧し、飛んだ行は当てない。`save.pending` があるときは、作業ツリーにログを重ねない。
