# ADR 0152: ブラウザ表示中の試聴出力を保持し、音量と手動の開始位置を接続する

- 日付: 2026-10-24
- 状態: 採用。P2-02 の試聴の操作を接続。実機の開始時間・聴感と操作感はユーザー確認待ち。
- 置換: [ADR 0135](0135-sample-audition.md) の表示中のアイドル終了と先頭固定。
  [ADR 0151](0151-streaming-sample-audition.md) の有限の先読み・連続 SRC・部分波形を引き継ぐ。

## 背景と再現

[操作の要望](../reviews/2026-10-21-ui-feedback-audit.md#修正の進め方) の単位 4 の残りを進める。
従来は無音から 5 秒で出力を閉じ、次の選択は機器の準備を待つ。
ブラウザの表示状態、音量、自動試聴の切替、右矢印と波形クリックの手動試聴は未接続だった。

製品の `service` に期限を過ぎた時刻を与える回帰を先に追加し、ブラウザ表示中も出力を閉じる失敗を確認した。
証拠は `target/audition-resident-repro.log` に残す。実機の速さを測った結果とは区別する。

## 決定

### 表示中は無音の出力を準備して保持する

- `echode_document_audition_configure` は表示状態と線形ゲインを試聴スレッドへ直接渡す。
  出力の準備を待たず、文書ワーカー・保存・Undo・トランスポートを通さない。
- ワークスペースの表示・ブラウザの開閉・文書の交換で表示状態を送り、表示中は素材の要求前から出力を準備する。
  表示中は無音でも閉じない。非表示では発音・読込みが終わってから従来の 5 秒で閉じる。
  文書終了時は表示保持も解除する。プラグインのヘルパーは起動しない。
- 機器通知で古い出力を閉じ、表示中は無音で準備し直す。
  出力先の変更は読込みと発音を停止して追従し、勝手に素材を再開しない。
  準備に失敗したら `output_error` を残し、再表示・次の設定または素材要求で再試行する。
  再試行のためだけの短い周期の開閉は行わない。

### 音量は試聴だけをサンプル単位で補間する

- 試聴音量は 0〜1 の線形ゲイン（無音〜0 dB）、初期値は 1 とする。
  非有限値・範囲外は C ABI と制御側で拒否する。
- 制御側からの値は原子的に渡し、コールバックは既存の `dasp_interpolate` で 5 ms の線形補間を行う。
  補間中の変更は現在値から始める。無音中の変更は次の音の先頭から適用する。
  置換時の減衰にも同じ音量を掛け、加算先の曲のバッファは変更しない。
- 音声側の確保・解放・ロック・待機は追加しない。補間の進行はブロックの切り方に依存しない。

### 自動試聴と手動試聴を分ける

- 初期状態は選択時の自動試聴がオン。オフにすると読込み中も含めて停止する。
  オフの間の新しい選択は前の手動試聴を停止し、選んだ素材を自動では鳴らさない。
  オンへ戻すだけでは鳴らさず、次の利用者の選択を待つ。
- 一覧の右矢印と再生ボタンは、自動試聴がオフでも現在の音声素材を先頭から鳴らす。
  右矢印のキーリピートは開始を繰り返さず、修飾キー付きは既存の入力へ渡す。
  停止ボタンは試聴だけを減衰して止める。曲の再生・停止とは独立する。
- 波形のクリックは、元の長さと横位置から元のサンプル位置を切捨てで決める。
  `echode_document_audition_at` は `AudioFileReader` と公開 API の `ExtAudioFileSeek` でその位置へ移る。
  EOF 以降は最後の元サンプルへ丸め、SRC は選んだ部分を連続して変換する。
  低い機器レートで残りが 1 フレーム未満へ丸められる場合は、前の音を止めて正常に終了する。
- 波形の全体の時間軸は維持する。`first_frame` より前は未読として描かず、`loaded_frames` は読んだ範囲の末尾位置を示す。
  `complete` と `decoded_us` は選んだ位置から EOF までの読込み完了を示す。
  先頭以外から読み終えた波形は部分表示と明記し、古い表示から別の選択を試聴しない。
  VoiceOver の波形の押下は先頭からの試聴とする。
- 音量と自動試聴の設定はウィンドウ設定 `workspace.audition.v1` へ記録する。
  素材・開始位置は保存せず、設定の変更もプロジェクトの履歴を増やさない。
  検索・再走査によるブラウザ自身の選択の付け替えが音を変えない規則は引き継ぐ。

## 検査と診断

- 必須契約 `sample-audition-resident` は表示中の保持と非表示後の閉鎖を、期限を過ぎた時刻で確認する。
  通常回帰は無音の事前準備・機器通知からの再準備・出力先変更・準備の失敗と再試行を機器なしで確認する。
- `sample-audition-position` は指定位置、EOF への丸め、等倍・SRC と音量を製品コールバックで比較する。
  `sample-audition-gain` は補間・途中変更と曲のバッファの保持を確認する。
  `block_size.rs` は開始位置・ストリームの塊・音量・停止を組み合わせ、RTSan も通す。
- `sample-audition-controls-ui` は実操作子・右矢印・波形の入力から、自動試聴のオフ・手動の開始位置・音量・
  設定の再読込・履歴との独立・古い表示の拒否を確認する。
  C ABI と Swift の往復も、不正な設定の拒否と開始位置の診断を機器なしで確認する。
- `settings.visible`・`settings.gain`・`output_error` は無音の準備状態、履歴の `start_frame` は要求位置を示す。
  出力先・開始位置・選択の違いを、従来の要求番号・各段の時刻と一緒に調べる。

## 残る範囲

- 実機の開始時間、機器切替時の挙動、2 つの IOProc の加算・聴感、操作子の見え方と VoiceOver の操作感はユーザー確認とする。
- 未試聴の素材の先行読込み・全体波形のキャッシュと、曲のテンポに合わせる試聴は追加しない。
  テンポ追従は Phase 4 の伸縮の範囲である。
