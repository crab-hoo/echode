# ADR 0170: 自動クリップの小節は中身の原点と一緒に動く

- 日付: 2026-10-26
- 状態: 採用。[ADR 0169](0169-clip-growth-follows-notes-and-stops-at-walls.md) の土台だけを先行実装
- 範囲: 自動配置の不変条件・合わせ直し、移動・複製での種類の保持、旧ジャーナルの互換

## 背景と再現

ADR 0169 の検討で、ノート入力時の窓をタイムラインではなく中身の小節で伸ばす方針を確認した。
従来は、タイムラインの小節に一致しない移動を `fixed` にすることで、不変条件を満たしていた
（[ADR 0022](0022-clip-content-and-placement.md)、[ADR 0154](0154-clip-move-and-duplicate.md)）。

`864e7a4` の製品コマンドを通す回帰で、1 小節の自動クリップを小節未満だけ動かすと固定になることを再現した。
`clip_bar_basis` の固有のアサーション `a sub-bar move must preserve the automatic content-bar window` と
期待終了コード 101 を照合した記録は `target/focused-checks/content-bars-red/` にある。

所属替え・固定窓の拡張・壁での制限・ドラッグの解決関数は、アクションと表示をまとめて変更する必要がある。
先に、自動配置を移動した後も内容時刻を保って編集・保存・復旧できる土台を接続する。

## 決定

- 自動配置の窓は、ノートの内容時刻が占める最小の小節範囲に原点 `origin = start - offset` を足した範囲とする。
  長さは小節の整数倍で、左へ広げる時も開始とオフセットを一緒に変え、原点と既存ノートを動かさない。
- `clip.move`・`clip.duplicate` は小節未満の変位でも元の `kind` を保つ。
  端の手動編集・リンク・置き換えで切り詰めた部分は従来どおり固定である。
- 自動配置のノートを編集・挿入・削除した後の合わせ直しと `Project::check_invariants` を同じ基準にする。
  短縮で自動窓は縮む。固定窓の扱いは [ADR 0168](0168-note-edit-clip-growth.md) のままである。
- 桁あふれは拒否し、同一トラックの配置重複を認めない。パッケージと ChangeSet の形式は変更しない。
  原点が小節線上にない自動配置も、新しい不変条件に従って読み込む。
- 移動・複製の新しいアクションに `content_bars: true` を記録する。コマンドの引数は変えない。
  印のない旧アクションは、記録当時の「小節未満の移動で固定になる」規則で再生する。
  ChangeSet のあるジャーナルは従来どおり記録済みの差分を再生する。

## 受入と基盤

- 必須契約 `clip-content-bars` は製品の JSON コマンドで、小節未満の移動・複製、両側の中身の小節を越える編集、
  短縮・挿入・削除、原点と ID・ベロシティ、複製の独立、Undo / Redo・両種のジャーナル・保存再読込を確認する。
- 必須契約 `journal-clip-bar-basis` は印のない移動・複製を復旧し、旧来の固定化と元の中身の保持を確認する。
  新旧規則を入れ替える反例と、中身の原点を足さない反例を登録する。
- `PianoDragTests` の既存の必須契約に、小節未満の移動後の自動窓を追加する。
  左右端・移動、確定フレーム、単一 Undo / Redo、保存再読込を通す。
  固定窓は移動でなく明示的な端の編集で作り、ADR 0168 の回帰も保つ。
- 読込みの回帰は、非整列の原点を持つ正しい自動窓を受理し、タイムラインにだけ合う窓を拒否する。
  `properties.rs` は自動・固定の両方で窓端の 1 tick 外への編集を生成する。
- 新しい必須契約と反例を `scripts/verification.json`、既存の Makefile 入口と選択回帰へ接続する。
  アクションだけの変更でも橋渡しの動的検査を選ぶようにする。
- 音を作る処理・ABI・外部入力・ログ形式は追加しない。既存のブロック長比較と RTSan を使う。
  デバッグ手順へ原点・種類・旧ジャーナルの切り分けを追記する。`doctor` / `debug-report` の収集範囲は変更不要である。

## 残る範囲

- ノートの所属替え・遠い移動での新規配置、固定窓の小節拡張、隣の配置・時刻 0 の壁、共有の解決関数は ADR 0169 の草案に残す。
  挿入先の探索・自動配置の結合は既存の経路であり、隣接窓の拡張で重なる時は今も編集を拒否する。
- 負のノート時刻と自動窓は従来どおりモデルで許す。時刻 0 で止める変更は壁の実装と一緒に行う。
- 旧版の読込み器は非整列の原点の自動配置を拒否する。新しい版で保存した文書を旧版へ戻す互換は提供しない。
- 実画面でのドラッグ・窓の見え方と聴感はユーザー確認とし、今回の機器なし回帰と区別する。
