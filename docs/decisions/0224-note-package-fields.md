# ADR 0224: ノートの項目表をモデルと保存へ共有する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。ノートのモデル・変更セット・パッケージ間の変換
- 関連: [ADR 0216](0216-note-changeset-fields.md)、[ADR 0223](0223-device-package-fields.md)、[ADR 0028](0028-package-schema.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

パラメーターとデバイスに続き、ノートの 6 スカラー項目もモデル宣言・保存・変更セットで別々に列挙されていた。
履歴には `NoteLine`・`NoteFile` と両方向の手書きの変換があり、項目の追加時に同期が必要だった。
既存の結果を保つ構造整理とし、新しいノート操作や保存形式の変更は行わない。

## 決定

- `echode-model/src/note_fields.rs` の crate 内の表を、モデル宣言・Serde と変更セットの生成器で共有する。
  開始・長さ・音高・発音とリリースの強弱・アーティキュレーションの型と変更セットの変換をこの表へ集める。
  ID と所属する中身は表の外に残し、所属とノートの順序の照合は変更しない。
- 宣言の順序は既存の保存キー順・ジャーナルの作成と差分の順序を保つ。
  時刻は `Tick` の符号付き 64 bit 整数、音高は 8 bit、強弱は 16 bit、任意の参照は `Option<Id>` をそのまま使う。
- 履歴の `NoteLine`・`NoteFile` を除き、モデルの `Note` を直接符号化・復号する。
  Serde は形だけを検査し、未対応のアーティキュレーションと表情の曲線の拒否は履歴へ残す。
  音高・長さ・終端の桁あふれ・ID の重複・ノートの順序は従来どおりプロジェクトの組立てで検査する。
- 保存の formatter・キー順・1 ノート 1 行・末尾の改行は保つ。
  現行スキーマ 6 と旧版の段階変換、アーティキュレーションの省略と明示的 null の互換も保つ。
  必須項目への省略値や、不正な整数の丸め・自動修復は追加しない。
- 不正なノート ID は形の復号で拒否するため、従来の理由に `content json:` の文脈が付く。
  不正なアーティキュレーション ID の文字列も同じ段階で拒否し、正しい ID の未対応機能の拒否と区別する。
  どちらも従来から受入不可であり、拒否時に原本を書き換えない。
- ほかのオブジェクトの保存と FFI の統合は残り、SPG-09 全体の完了とはしない。
  アクション・Undo・ジャーナル・共有内容・音声処理は変更しない。

## 回帰と診断

製品コードの変更前に `echode-history/tests/note_package.rs` の公開保存経路の回帰を追加し、同じ入口で整理後を照合した。

- スカラーの全組合せ、負の開始・整数の端点・MIDI 7 bit へ丸められていない 16 bit の強弱を通す。
  独立したキー順・整数表記・1 ノート 1 行の期待値、空のノート列と再保存時のバイトを検査する。
- 必須項目の欠落・型の誤り・範囲外の整数・未知の項目・不正 ID を拒否し、任意参照の省略を受け入れる互換を保つ。
- モデルの直接復号で任意の整数・参照を保持できることと、パッケージとして受け入れられることを区別する。
  不正な音高・長さ・終端、ID の重複、ノートの順序と未対応の表情を受入前に拒否し、原本を保持する。
- 旧スキーマの段階変換と、共有内容を持つ `DocumentHost` の複製・Undo / Redo・保存・コミットからの再オープンを通す。
  既存の `note_changesets.rs`・保存のスナップショット・操作列の性質テストも維持する。

通常の `check` が新しい統合テストを含むため、実行入口・依存・検査選択は変更しない。
デバッグ手順に形・未対応機能・プロジェクトの検証の区別と回帰の場所を追記する。
実機・実画面・聴感や性能の改善は、この構造整理の合否からは主張しない。
