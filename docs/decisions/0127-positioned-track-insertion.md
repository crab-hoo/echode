# ADR 0127: 選択位置への空トラック挿入と末尾追加を分ける

- 日付: 2026-10-20
- 状態: 採用。P2-02 のトラック追加位置を接続。折りたたみ表示と通常複製は未実装

## 背景

[操作要件](../interaction-design.md#音源を挿して編集に入る) は、一覧末尾のボタンと選択位置への追加を分ける。
従来の `track.add` は最上位の末尾だけに追加し、controller は末尾の行を選択していた。
[ADR 0024](0024-track-order.md) の兄弟ごとの分数インデックスは保持し、末尾以外の挿入を見送った判断をここで置き換える。

## 決定

- `track.add` は最上位末尾への追加として維持する。
  `track.insert` は `after`、`into_folder`、`name` を受け、新規トラックとミキサーの ID をジャーナルへ記録する。
- `into_folder = true` で対象に子があれば、最後の直接の子として追加する。
  それ以外は対象と同じ親の兄弟として、対象の部分木と次の兄弟の間へ追加する。
  対象がなければ拒否し、別の位置へ代替しない。
- 既存の `fractional_index` を使い、新規トラックのキーだけを決める。
  既存の親・キー・内容・デバイスは保持し、保存形式 5 と ChangeSet の形式は変えない。
- ⌘T、メニュー、ツールバー、パレットの追加は操作時のフォーカストラックの下へ追加する。
  選択がなければ末尾へ追加する。アレンジ下部の「末尾にトラックを追加」は選択によらず最上位の末尾へ追加する。
- UI は `TrackInsertionRequest` に文書セッションと追加先を保持してから非同期処理へ渡す。
  同じ編集の排他区間で新規 ID を差分から選択し、後の選択変更や並びに依存しない。
  旧文書の要求や Undo で消えた対象を拒否して、部分追加と Redo の消失を防ぐ。
- 空トラックはミキサーだけを持ち、音源候補を自動では開かない。
  現在のフォルダはすべて展開表示で、UI は `into_folder = true` を使う。
  折りたたみ表示の接続時は `false` で部分木の直後の外側へ追加する。
  このモデル経路の検査は、折りたたみ UI の実装済みという証拠にはしない。

## 受入と基盤

- `TrackInsertionTests` は、コマンドと末尾ボタンの共通処理、操作時の対象、単一 Undo / Redo、保存再読込を通す。
  入れ子・無選択・古い文書・消えた対象も確認する。実ウィンドウの操作確認はユーザー担当とする。
- `track_insertion` は、既存 `Arc` の保持、フォルダ内外と兄弟間の順序、反復挿入、ID 衝突の拒否を確認する。
  ジャーナルは ChangeSet とアクションのみの両方で再生し、保存・再読込を通す。
- ランダムな編集列の `properties.rs` に新しいアクションを加える。
  必須契約は `scripts/verification.json` に登録し、選択のテストと診断手順も更新する。
- DSP・プラグイン隔離・音の生成処理は変えず、音源なしの無音の既存契約を維持する。
  GUI・パラメーター編集・折りたたみ表示・通常複製等は P2-02 に残す。

## 後続の接続
