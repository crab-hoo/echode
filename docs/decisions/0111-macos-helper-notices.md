# ADR 0111: ヘルパーの致命信号、Workgroup の待合、未実装の macOS 境界

- 日付: 2026-10-17
- 状態: 採用
- 範囲: プラグインヘルパーのクラッシュ印、Workgroup ポートの受け渡し、スキャンの権限、稼働表明のフラグ。AU とプラグイン GUI は実装しない

## 背景

静的な監査は、POSIX 互換のままなので macOS 上で遅延や二重処理が残っていると指摘した。照合先は `echode-sandbox` の共有領域と Workgroup、`echode-plugin-host` のスキャンと稼働表明、objc2-foundation の `NSActivityOptions`、ADR 0061、ADR 0079、ADR 0080、S3 である。新しい終了時間の計測はしていない。

## 採用

ヘルパーは、処理区間の外で `SIGABRT` に加えて `SIGSEGV`、`SIGBUS`、`SIGILL` のハンドラを入れる。ハンドラは共有領域へ二つのアトミックを書き、既定の動作に戻してから同じ信号を上げ直す。印の値は従来の `SIGABRT` と同じ 2 である。プロセス終了だけを見た監視は `dead` だけを立て、この印は立てない。

これで、クラッシュレポートが終了を遅らせても、次に共有領域を読むブロックはハングと区別できる。すでに `os_sync_wait_on_address` に入ったブロックは、印だけでは戻らない。締め切りか、終了を見た起床まで待つ。終了までの 123 ms から 1 秒超は S3 の測定のままで、今回のハンドラはその時間を消さない。

## 採用しない

Mach の例外ポートは取らない。`task_set_exception_ports` は公開の `libc` に無く、手での宣言は増やさない。例外ポートを取ると ReportCrash との取り合いになり、測っていない。信号に変換されない例外は、これまでどおり終了通知で知る。

`NSActivityOptions::UserInteractive` は objc2-foundation 0.3.2 で `UserInitiated | LatencyCritical` である。`LatencyCritical` を重ねてもフラグは増えない。再生、CLI の書き出し、処理中のヘルパーの表明はそのままである。

## 今回は作らない

Workgroup の送信権は、ヘルパーの `bootstrap_check_in` と親の `bootstrap_look_up` のまま渡す。特別ポートでは届かなかった（S3）。`bootstrap_look_up` は待たないので、親は起動時の制御スレッドで最大 5 秒、2 ms 間隔で探す。音声スレッドはこの待ちに入らない。公開の `libc` に、この名前が現れるまでブロックする関数は無い。間隔を替えるには受け渡しを測り直す必要がある。

AUv3 は未実装である。OS は AUv3 を XPC extension として別プロセスで動かす。再生ヘルパーの中で `AUAudioUnit` をさらに読むと、本体、ヘルパー、extension の二段になる。実装する時は AUv3 にヘルパーを重ねない。AUv2 は今のヘルパーに置く。

プラグイン GUI の独立ウィンドウは未実装である。実装する時は、そのウィンドウをキーウィンドウにしてメニューバー、ショートカット、Space を奪わない。
（2026-10-21 追記: [ADR 0132](0132-helper-plugin-windows.md) で、ヘルパーを非アクティブのまま保つパネルとして実装した。
中をクリックした後のキーの転送は未実装である。）配布用ヘルパーの `LSUIElement` は、library validation を外す署名の設定であり、プラグインウィンドウではない（ADR 0061）。

`--scan` に Seatbelt は掛けない。再生ヘルパーはプラグインの読み込みに広い権限が要るので、同じ制限は使えない。`sandbox_init` は非推奨で、公開の `libc` にも無い。記述子を読むだけの子を制限する公開のプロファイルは、プラグインの置き場所を読める形でまだ無い。

## 検査

- `ECHODE_TEST_FAULT=crash` のヘルパーは、これまでどおり SIGABRT（信号 6）で終了する。
- `ECHODE_TEST_FAULT=segfault` は `process` でヌルへ書き、親はプロセスを回収する前に印 2 を読む。2 秒以内に印が無いときは失敗である。終了までの時間は測らない。
- 実機のクラッシュレポート所要時間、AUv3、プラグインウィンドウ、スキャンのサンドボックスは自動検査の対象にしない。
