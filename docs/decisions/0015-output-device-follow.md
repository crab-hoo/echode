# 0015. 出力デバイスは制御スレッドが追従する

- 日付: 2026-10-08
- 状態: 採用

## 背景

再生の出力は、ヘッドフォンの抜き差しや、選んだインターフェースが消えることに追従する必要がある。その判断をオーディオスレッドで行うと、デバイスの再起動やロックが音の締め切りに入り込む。

## 決定

- 既定の設定は、システムの出力デバイスに追従する
- 特定のデバイスを選んだら、それが CoreAudio の一覧にあるあいだは、システムの既定が変わっても切り替えない
- 選んだデバイスが一覧から消えたら、システムの出力に落とす。一覧に戻ったら、そのデバイスに戻す
- いま開いているデバイスのサンプルレートやバッファサイズが変わったら、デバイスは変えずに再生側の設定を合わせる
- 切り替えと再設定は制御スレッドが行う。オーディオスレッドは、いま開いているデバイスのコールバックを処理するだけにする

## 結果

どのデバイスを開くかは、デバイスの一覧とシステムの既定と、利用者の選択だけで決まる。実機の一覧に、システムの既定が含まれていることも確認する。
