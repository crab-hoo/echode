# ADR 0175: ピアノロール下部の単一ノート用ベロシティレーン

- 日付: 2026-10-26
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver・聴感はユーザー確認待ち
- 関連: [ADR 0173](0173-piano-note-velocity.md)、[操作要件](../interaction-design.md#ベロシティの編集)

## 背景と再現

Option＋上下ドラッグは接続済みだが、下部から値を見比べて調整する入口はなかった。
`20b4f40` の実 View で下部の棒に相当する位置を押してドラッグすると、ベロシティの仮表示にならずノート追加が始まる。
回帰を先に追加し、固有のアサーションと期待終了コードを `target/focused-checks/velocity-lane-red/` に記録した。

## 決定

- ノートグリッドの下に最大 72 pt のベロシティレーンを常時置く。
  小さい表示面ではルーラーを除く高さの 1/3 までに縮め、残りをノートグリッドへ割り当てる。
  レーンと鍵盤・ノート・ルーラーは同じ Metal フレームで提出し、それぞれの範囲でクリップする。
- 編集トラックの表示時刻内の全音高を問い合わせ、発音窓内の開始位置に棒とつかむ頭を表示する。
  音高スクロールで隠れたノートも扱い、継続音が左端から入る時に偽の開始位置を作らない。
  同時刻の音は頭の位置で区別し、同じ頭が重なる時は選択ノートを優先する。
  音高は MIDI の 0〜127 であり、ノート数の固定上限は追加しない。
- 棒の左押下は単一選択だけで値を変えない。上下ドラッグは押下時の値とつかむ位置からの相対量で変更する。
  上下の余白を除く高さが 0〜127 に対応し、0 でも頭を残す。
  横移動、Shift、Option、時間と音域の倍率では意味を変えない。空白からは追加しない。
- Option ドラッグと同じ `PianoVelocityGesture`、`PianoVelocityPreview`、`note.velocity` を共有する。
  ノート下端・下部の棒・数値は同じ仮の値を読み、解放時の座標で再計算して変更がある時だけ 1 回確定する。
  Undo / Redo・保存、幾何保持と次回入力値の記憶は ADR 0173 のままとする。
- 取消と古い描画の拒否も既存のベロシティ操作と共通化する。
  Escape、フォーカス喪失、入力取消、スクロール・ズーム、寸法・文書・対象変更、処理中、終了後の解放は記録しない。
- アクセシビリティの問い合わせ時に、時刻内の各棒を値 0〜127 のスライダーとして公開する。
  音高と開始拍で識別し、増減を同じ編集へ送る。再描画通知で要素を作らない。
  処理中・対象変更・古いスナップショットからの操作は拒否する。
- レーンの開閉・高さ変更、複数ノートの一括編集、ゴーストノート、ノートの試聴はこの単位に含めない。
  Return の割当も ADR 0155 の判断待ちを維持し、ノート挿入を変更しない。

## 受入と基盤

- 必須契約 `piano-velocity-lane-ui` は実 View・controller・製品 ABI で、押下時の不変、解放時の単一確定、
  幾何保持、入力値の共有、Undo / Redo、保存再読込を確認する。
- `piano-velocity-lane-frame-ui` は音域外、0・127、同時刻の頭、左端と仮表示、アクセシビリティの値・矩形・増減と拒否を確認する。
- `piano-velocity-lane-cancel-ui` は取消後の解放と空白クリックを確認する。
  負の対照はレーン分岐・全音高の問い合わせ・棒の仮表示・取消を個別に外す。
- `spike-piano-frame` は倍率 1・2 と値 0・64・127 で棒の頭の GPU 画素を読み戻す。
  既存の鍵盤・度数・ノートの比較範囲を新しいグリッド端へ合わせ、古い drawable の重なりと余白の比較も保つ。
- Makefile の既存入口と検査選択・契約・選択テスト、README・現状・操作要件・領域設計・デバッグ手順を更新する。
  音声 DSP・モデル・保存形式・外部入力・ログ出力先は変えないため、音声の新規ブロック長回帰や診断収集先の追加は不要である。
- 自動回帰は実画面の操作感や第三者音源の音を保証しない。実画面・VoiceOver・聴感はユーザー確認として区別する。
