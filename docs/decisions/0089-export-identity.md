# ADR 0089: 書き出しの成功は版と連番を完成後に示す

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-16。CLI の書き出し

## 背景

ADR 0070 は、成功した書き出しの標準エラーを自動保存の id だけにした。WAV は復旧したスナップショットから作る。後続のジャーナルがあるとき、その id だけでは同じ音を再現できない。表示も、WAV が完成する前に出ていた。ADR 0070 の「成功は自動保存の id だけを書く」という一文は、この決定で置き換える。

## 決定

書き出しの識別は、自動保存の先端 id と、適用したジャーナルの連番である。両方を、文書を開いている間に制御スレッドから読む。ワーカーの中からは読まない。

標準エラーへ `exported <id> <連番>` と書くのは、WAV の終端まで書けたあとだけである。プラグインが失敗した書き出しは、ファイルを消してから戻り、この行は出さない。

## 結果

プラグインのない書き出しと、プラグインを含む書き出しは、ファイルが閉じたあとにだけ版と連番を書く。失敗した書き出しは行を出さない。画面での操作確認は未実施である。
