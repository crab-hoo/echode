# 0255. CLI と GUI の書出し進捗

日付: 2026-11-03。
状態: 採用（P2-08 の進捗表示。途中取消と単位全体の受入は含まない）。

## 背景と再現

[ADR 0254](0254-gui-snapshot-export.md) の GUI 書出しは、準備と実行中の表示だけで、長い曲の処理済み範囲を示せなかった。
実 CLI へ `--progress-json` を渡す回帰を先に追加し、オプション未認識の終了コード 2 による失敗を確認した。
テストの終了コード 101 と固有の `progress export failed` を照合した証拠は `target/export-progress-red/` にある。

## 決定: 任意の進捗ストリーム

- `echode render ... --progress-json` は標準出力へ版 1 の NDJSON を出す。未指定時の標準出力は従来どおり空にする。
  `version`、`phase`、`rendered_frames`、`total_frames` を持ち、フレーム数はチャンネル数で倍にしない。
- 分母は書出す総フレーム数で、申告された余韻と明示の余韻を含む。準備中は総長が未確定なので率を出さない。
  `rendering` は初期値と整数パーセントが変わるブロックの書込み後に出し、最大 101 件に抑える。
- 全フレームの処理後に `finalizing`、WAV の flush・同期・rename・親の同期の成功後にだけ `complete` を出す。
  空の曲も 0 / 0 の `rendering`、`finalizing`、`complete` を出す。失敗では `complete` を出さない。
- 進捗は RT のコールバック内では出さず、音声・量子化・ブロック長・出力保全の処理は変えない。
  診断と `exported <revision> <seq>` は標準エラーに保つ。
- 観測先の切断は通知を無効にするだけで、書出しを取り消したり、公開済みの WAV を失敗へ変えたりしない。
  パイプの観測者は実行中に読み続ける必要がある。進捗は取消・期限・完了判定の API ではない。

## 決定: GUI の受信と完了判定

- `ExportJob` は専用 stdout パイプを実行中に排出し、stderr は従来の診断ファイルへ出す。
  ブロックする読込みと終了待ちはメインアクターの外で行い、受け取った更新だけを順にメインアクターへ渡す。
- 読込みは利用可能なバイトだけを受け、100 ms の poll で CLI の終了も調べる。
  子孫が stdout の記述子を引き継いでも、その EOF をジョブの終了条件にしない。
  CLI 終了後の未読の通知は捨てても、終了結果は必ず読む。
- `ExportProgressDecoder` は改行で区切り、1 レコードを 4 KiB に制限する。
  不正 JSON・版違い・未知の状態・範囲外・分母変更・後退・重複・未完の末尾を無視し、大きすぎる行は次の改行まで捨てる。
  制限は通信レコードだけに適用し、曲や素材には適用しない。
- 準備と率の未着時は不定の進捗、実行中はバーと率、全フレーム処理後は「書出しを仕上げ中」を示す。
  `complete` を受けても 99% に留め、CLI の正常終了後だけ 100% と完了表示にする。
  受信できない場合も正常終了とエラーの扱いは従来どおりである。
- ジョブの文書交換からの独立は維持する。途中取消・残り時間の予測・準備のコピー率は未対応。

## 回帰・基盤・未確認

- CLI の `tests/export_progress.rs` は opt-in、WAV のバイト列の不変性、余韻、端数ブロック、空の曲、公開失敗、観測者の切断を実プロセスで確認する。
  プラグインを使う分母は隔離した Sine Pad の申告値を通す。
- Swift の `ExportProgressTests` は分割・結合・不正・巨大な行・後退を確認する。
  必須契約 `export-progress-ui` は UI の受信まで終了を待つ子プロセス、大量の stderr、stdout を保持する子孫、完了通知後の失敗を通す。
  通知を UI へ渡さない反例で検出力を確認する。既存の実 CLI 契約にも正常終了後の 100% の確認を加える。
- 既存の通常テストと製品契約の実行入口を共有し、新しい検査コマンドは増やさない。契約一覧と選択の回帰を更新する。
  デバッグ手順に進捗と最終結果の切分けを追加する。ユーザー文書や生の音声を新しく収集しない。
- バーの見え方・VoiceOver は UC-54 のユーザー確認待ち。自動の通知回帰を実画面の確認にはしない。
