# ADR 0179: 選択したノートの左右端を同じ量だけ伸縮する

- 日付: 2026-10-27
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#ノートの選択)、[ADR 0167](0167-piano-note-drag-snapping.md)、
  [ADR 0168](0168-note-edit-clip-growth.md)、[ADR 0172](0172-piano-click-and-input-length.md)、
  [ADR 0178](0178-piano-batch-note-movement.md)

## 背景と再現

`f905f7c` では複数選択の本体移動は接続済みだが、端を押すと単一選択へ戻り、その音だけを伸縮していた。
実 View の押下を通す回帰を先に追加し、選択全体を保持できないことを確認した。
期待終了コードと固有のアサーションは `target/focused-checks/piano-resize-batch-red/` に残す。

## 決定

- 編集中の単一トラックで、選択済みノートの端の通常ドラッグを選択全体の一括伸縮とする。
  未選択ノートの押下は従来の単一選択・編集を保ち、Option はベロシティ、Command は選択切替のままとする。
- 押下時の全 ID・幾何・カメラ・つかんだ端を保持する。横に 3 pt 以上動いてから仮表示を始める。
  クリック・横の微動・縦だけの移動では量子化や確定をしない。
- つかんだ端の絶対時刻をグリッドへ吸着し、その差を全対象の同じ側の端へ加える。Shift の間は吸着を解除する。
  長さの比率ではなく差をそろえる。左右どちらの伸縮も反対端と音高を保つ。
- 画面外とリンク配置も含む全対象から共通制限を求める。
  左端は最小開始と最短長、右端は最短長と最大終端で制限し、最短 1 tick・開始 0・整数上端で全体を止める。
  最短長は Shift の有無に依存しない。不正な幾何・非有限値・桁あふれでは仮表示も確定もしない。
- `PianoResizePreview` は全対象と表示中の未選択リンクを、既存の移動と同じ明色で仮表示する。
  モデルは解放まで変更しない。下部の棒と読み上げの確定幾何はモデルの確定後に更新する。
- 解放時の座標・Shift で再計算し、変更時だけ `note.edit` の配列を単一トランザクションへ送る。
  待機列の手番で全対象の存在と元の幾何を検証し、1 つでも古ければ全体を拒否する。旧文書へは送らない。
- 共有内容のノートは ID ごとに一度だけ編集する。つかんだ配置を優先し、残りは安定した ID 順で代表を決める。
  固定窓の拡張・他の固定リンクのトリム・自動配置の小節基準は既存のモデルに従う。
  配置重複の拒否と失敗時の全体巻戻しも維持する。隣のクリップで止める仕様は別途接続する。
- 選択と入力先を保ち、入力長・入力ベロシティは変えない。ノートの ID・ベロシティ・表情を保持する。
  単一 Undo / Redo・保存は既存経路を使う。一括伸縮の Undo / Redo でも入力長を巻き戻さない。
- 取消は一括移動と共通の `cancelNoteTransforms` にまとめる。
  Escape・フォーカス喪失・入力取消・スクロール・ズーム・寸法変更・文書や対象や選択の変更・処理中・終了で破棄する。
  遅れた解放と古い仮表示からの次の押下を拒否し、押下中の再生ヘッド追従を保留する。

## 受入と基盤

- `piano-note-resize-batch-ui` は実 View と製品ブリッジで、両端・吸着と Shift・解放時の再計算・全対象の仮表示、
  選択と両入力記憶の保持、単一 Undo / Redo・保存再読込を確認する。
- `piano-note-resize-batch-targets-ui` はリンクと画面外の選択・最短長と時刻の共通制限・整数境界・重複排除・古い対象と旧文書の拒否を確認する。
  通常回帰で固定窓の拡張と Undo、後続の重複拒否による先行編集の巻戻しも確認する。
- `piano-note-resize-batch-cancel-ui` は両端のクリックと横微動・各取消・選択変更・追従の保留・古い仮表示の再入力拒否を確認する。
  単一選択化・古いプレビューの確定・仮表示・共通制限・全対象検証・重複排除・取消の欠落を負の対照とする。
- 検査選択の回帰、Makefile の既存入口、利用手順・操作要件・現状・領域設計・デバッグ手順を更新する。
  モデル・アクション・保存形式・DSP は変更しない。既存のランダム操作生成・ブロック長回帰を維持する。
  外部入力・ログ・成果物の追加はなく、診断収集先の追加は不要である。
- Command 複製移動、矢印と読み上げ操作の一括伸縮、複数トラック・ゴーストノート・試聴は別単位に残す。
  実画面の端のつかみやすさ・仮表示と VoiceOver はユーザー確認とし、自動回帰の合格と区別する。
