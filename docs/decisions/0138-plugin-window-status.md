# ADR 0138: 独自ウィンドウの寿命をデバイスの名前の横へ表示する

- 日付: 2026-10-21
- 状態: 採用。P2-02 の表示操作の追加。P2-02 全体は未完了
- 範囲: 制御ソケットの寿命通知、活動 JSON、デバイスビューとインスペクターの窓アイコン

## 背景

[ADR 0132](0132-helper-plugin-windows.md) で独自ウィンドウを開けるようになったが、どのデバイスの窓が開いているかを一覧に表示していなかった。
[ADR 0134](0134-plugin-window-lifetime-and-shortcuts.md) の一時非表示は、閉じる操作とは異なる。
既存の活動の `window` は「値やキーが届いた時に窓が開いていた」という履歴の文脈であり、現在の寿命ではない。
活動をまとめる時も論理和を使うため、閉鎖後の表示へ流用できない。

## 決定

- 制御ソケットの受信順で `PluginActivity.window_state: Option<bool>` を更新する。
  `GuiShown` は画面上の `visible` にかかわらず開、`GuiClosedReply`・`GuiClosed`・切断・ヘルパー再起動は閉とする。
  同じ状態の前面化や繰り返した切断では追加通知を作らない。拒否だけでは開にしない。
- `window_state` がない活動は寿命を変更しない。
  活動のマージと FFI の未読蓄積の圧縮では、最後の値を残す。
  以前の `closed` と編集時の `window` は履歴の証拠として保ち、表示の値へ置き換えない。
- 既存の活動 JSON に省略可能な `window_state` を加える。Swift は古い JSON も読める。
  C の関数・構造体、プラグイン IPC のメッセージ形式、プロジェクトの保存形式は変えない。
- 画面は順序を保って届く活動だけで `openPluginWindows` を更新する。
  開く要求の返答から楽観的に表示を更新しない。閉鎖通知の後に遅れた返答が届いても、表示を開へ戻さないためである。
  表示の遅れは既存の活動収集の手番によるものであり、新しい同期の問い合わせやポーリングは追加しない。
- デバイス列とインスペクターの名前の横に、開いている時だけ窓のアイコンを付ける。
  列を折りたたんでも表示し、名前のクリックによる前面化は従来どおり使える。
  アイコンには日本語・英語の説明とアクセシビリティラベルを持たせ、名前と重ならない幅を確保する。
- 状態はデバイス ID ごと、開いている文書内だけに保持する。
  選択トラックの変更では消さず、コピーやトラック複製では引き継がない。
  削除・オフライン化・文書終了で消し、Undo や保存再読込で窓を開き直さない。
  旧文書・欠けたデバイス・オフラインのデバイスの通知は無視する。
- 「開」は画面上で見えることを保証しない。別アプリの操作中に隠れた窓も開である。
  浮動型プラグイン自身の表示規則と第三者プラグインの実画面の保証範囲は、従来の制約を保つ。

## 検査と診断

- 実装前の `PluginWindowStatusTests` は、製品の列に窓のアイコンが存在せず失敗した。
  証拠は `target/plugin-window-status-before.log`。最新の正式結果は `target/verification/report.md` を参照する。
- 必須契約 `plugin-window-state` は実制御ソケットで非表示の窓の作成、閉鎖と再表示の順序、拒否、切断を確認する。
  負の対照は成功した表示を閉として扱う。
- 必須契約 `plugin-window-status-ui` はネイティブの列のアイコン・説明・配置と名前の前面化の操作を通す。
  同じプラグインの独立、選択・列の開閉・コピー・オフライン・削除・Undo・文書交換・保存対象外を確認する。
  負の対照は、寿命ではなく編集時の過去の `window` を現在の状態として使う。
- 実ヘルパーの既存 GUI 契約へ寿命の確認を加え、ヘルパーの再起動でも閉になる通常回帰を追加する。
  JSON の順序と未読圧縮、旧 JSON の Swift 読込、寿命だけでは背景保存を保留しないことも回帰する。
- DSP と音声バッファの処理は変えないため、新しいブロック長比較は不要である。
  制御側の変更に対する既存の隔離・RT・橋渡し検査の選択は維持する。
- 切り分けは[デバッグ手順](../debugging.md)へ追加する。
  既存の製品契約ログを使うため、診断資料の収集先は増やさない。

## 残る範囲

実ウィンドウと第三者プラグイン、VoiceOver の実際の読み上げはユーザー確認とする。
トラックヘッダの FX 空欄と挿入済みの名前の入口、複数選択時の表示対象、サムネイルは今回の完了に含めない。
