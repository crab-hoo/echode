# 0258. 書出しへ任意のサンプルピークノーマライズを接続する

日付: 2026-11-04。
状態: 採用（P2-08 の先行分。LUFS・トゥルーピーク・単位全体の受入完了ではない）。

## 背景と再現

形式・余韻・ディザ・GUI と前回設定の保存の後も、ノーマライズは未接続だった。
CLI の製品入口から静かなステレオ素材を読み、最後のブロック近くの最大値を目標へ合わせる回帰を先に追加した。
終了コード 101 と `peak-normalized CLI export was rejected` を照合した。証拠は `target/export-normalization-red/` にある。
既定のバイト列と既存の原本保全・取消の境界は変えない。

## 決定: 一度だけミックスし、量子化前に一定のゲインを掛ける

- CLI の `--normalize-peak-db DB` は任意指定で、範囲は有限の −120〜0 dBFS とする。省略時は従来どおり無効。
  不正値は文書や出力を開く前に拒否する。この範囲は目標だけで、曲・トラック・チャンネル数の上限ではない。
- ミュート・ソロ・FX・選んだ余韻・長さを反映したステレオ出力の絶対最大値を使う。
  左右共通の `10^(DB/20) / peak` を全標本に掛け、左右比・定位・ダイナミクスを変えない。
  無音のゲインは 1。有限の f32 の微小値と大きな値にも対応するため、計算は f64 とする。
- ゲインの適用後に既存の WAV ライターへ渡し、その後で TPDF・丸め・PCM の飽和を行う。
  float / PCM16 / PCM24 と RF64 の既存の形式選択は維持する。
  0 dBFS の正側の飽和とディザ後の微小な差は、既存の量子化規則のままである。
- LUFS、トゥルーピーク、リミッター、ノイズシェーピングは追加しない。
  新しい解析器や DSP ライブラリは導入せず、標準の最大値・乗算と既存の WAV / ディザ処理を接続する。
  この変更はリアルタイムの発音・再生バッファや SRC を変えない。

## 決定: メモリと一時領域・原本保全

- プラグインを再度発音させて測定と書出しを分けない。
  1 回だけ得た float のミックスを出力と同じフォルダの一時ファイルへ保存し、その列を再読込みする。
  `create_new` と mode 0600 を使い、開いた直後にリンクを外す。正常終了・取消・失敗・プロセス終了で記述子とともに破棄する。
- 一曲分の配列は持たず、レンダーブロックと固定長の符号化バッファだけを使う。
  最終 WAV に加えて、ステレオ float の 1 フレーム 8 バイトの一時領域を必要とする。
  空き容量の予約や推定残時間は追加しない。I/O の失敗は `normalization scratch I/O failed` として原本を保持する。
- ノーマライズ有効時は float でも非有限値を拒否する。無効時の既存の float の挙動は変えない。
  WAV の原子的な公開と同期の境界は既存の `WavFile` を共有する。
- 再読込みと符号化は `finalizing`（GUI は最大 99%）の中で行う。
  各ブロックと公開直前の取消を維持し、取消済みなら原本を置き換えない。
  発音を作り直していないため、分割不変性はエンジンではなくこの後段変換の回帰で検査する。

## 決定: GUI と前回設定

- 書出しシートへ切替と目標を追加する。初期状態は無効で、有効化時の目標は −1 dBFS。
  無効時は目標欄を操作できず、不正値では書出しを確定できない。
- `ExportSettings.normalizePeakDb` は optional とし、`export.json` と旧 UserDefaults の既存の形式に追加する。
  旧レコードにキーがなければ無効。版 1 の他の項目・優先順位・移行・文書の寿命は変えない。
  目標は前回設定として持ち運び、モデル・Undo / Redo は消費しない。

## 回帰と基盤

- `export-normalization-cli` は全ミックスの共通ゲインを float / PCM16 / PCM24 と目標の両端で確認する。
  ゲインを 1 に戻す反例で、単なるファイル生成だけの検査への退行を止める。
  通常回帰は無音・空・不正値・原本保持と、隔離した Sine Pad の余韻を含む出力も通す。
- `normalization_tests.rs` は入力ブロック長・TPDF の分割不変性、微小値・フルスケール超過・非有限値、読取り失敗と片付けを検査する。
  ファイルを書く単体テストは、故障注入を共有する既存の `WRITER` mutex を取る。既存の取消回帰も同じ排他へそろえる。
- `export-normalization-ui` は実 GUI ジョブ・実 CLI で目標の出力、前回設定、履歴の独立を検査する。
  CLI 引数の引渡しを削る反例を用意する。旧パッケージ・旧 UserDefaults・不正目標の回帰も追加する。
- 必須契約と選択の回帰を `scripts/verification.json` と既存の選択テストへ登録する。実行入口は既存の Makefile を共有する。
  README・設計・進め方・制約・開発とデバッグの手順を更新し、一時音声を診断収集に追加しない。
- 実画面・VoiceOver・聴感は UC-57 のユーザー確認待ちとする。自動の数値比較を聴感の証明にはしない。
