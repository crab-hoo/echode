# ADR 0217: トラックの変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。トラックのスカラー項目と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0024](0024-track-order.md)、[ADR 0216](0216-note-changeset-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

パラメーター・デバイス・ノートに続き、トラックの名前・親・兄弟順も項目表へ集める。
従来は差分・作成と削除・下書き・設定・復元の各段で、同じ対応を別々に列挙していた。
今回は既存の結果を保つ構造整理であり、製品の誤動作の修正や新しいトラック操作の追加ではない。

## 決定

- `changeset_track.rs` の `track_fields!` に、3 項目の `Property`・フィールド・型・`Value` の種類・読出しを宣言する。
  差分、作成と削除、下書き、両方向の変換、作成の適用、設定の振分けを表から生成する。
- 表の順序は従来の名前・親・兄弟順とし、名前と分数インデックスは `Text`、任意の親は `Parent` の表現を保つ。
  クリップとデバイスの ID 列は、この順にスカラーの後へ記録する。
- ID と子オブジェクトの解決はスカラーの表に含めない。
  `Draft` は子の所属・存在・使い残しを照合し、最後の `arrange_tracks` が親の木・分数インデックス・兄弟順を検証する。
  子の解決と木の検証は、トラックの復元への委譲で省略しない。
- `Draft::set` はトラック ID で下書きへ委譲する。
  必須項目、誤った `Value` の種類、未知の ID と対象外プロパティの拒否を保つ。
  既存の `Lane` のテキスト更新は、トラックでも無変更として受け付ける互換動作を保つ。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo の意味、音声処理は変更しない。
  他オブジェクトと保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ回帰を追加し、同じ公開入口で構造整理後の結果を照合した。

- `echode-history/tests/track_changesets.rs` は生成表を参照しない独立した期待値を持つ。
  任意の名前、親の有無と変更、異なる有効な分数キー、3 項目の全組合せを検査する。
  子の追加と同時に全スカラーを更新し、正確なフィールド順・作成と削除・逆適用・二重反転・ジャーナルを照合する。
- 同じ回帰で、必須項目の欠落・誤った型・未知の ID・対象外プロパティを拒否する。
  親の欠落・循環、不正または重複した兄弟キー、解決できない子の ID 列の拒否と `Lane` の無変更互換も検査する。
- 操作列の `properties.rs` に、入れ子のフォルダとノート・CLAP 設定を持つ子からの初期状態を加える。
  不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  プラグインを読み込まず、モデルの値だけを検査する。

新しい実行入口や依存は追加しない。既存の `check` が回帰を実行するため、検査選択の条件は変更しない。
フィールドと入力を含むアサーションを既存ログへ残し、診断の収集先・手順は変更不要とする。
実機・実画面・聴感の合否はこの構造整理からは主張しない。
