# ADR 0174: ピアノロールの表示範囲をトラック間で共有する

- 日付: 2026-10-26
- 状態: 採用。P2-07 の表示状態。実画面の操作感はユーザー確認待ち
- 関連: [ADR 0117](0117-workflow-interactions.md)、[ADR 0053](0053-workspace-ui-foundation.md)

## 背景と再現

[操作要件](../interaction-design.md#コードを参照してメロディを入力する) は、編集トラックを切り替えても同じ小節・音域を保つ。
`9036e20` ではトラック別のカメラを復元し、初めて開くトラックは既定値へ戻していた。
さらに選択ノートの自動表示が切替時の表示範囲を動かしていた。
実 View でスクロール後に別トラックを開く回帰を先に追加し、表示位置の不一致を再現した。
期待終了コード 1 と固有のアサーションは `target/focused-checks/piano-viewport-red/` に記録した。

## 決定

- `CanvasNavigationState.pianoCamera` が文書内で共通の時間原点・音高原点・両軸の倍率・グリッドを持つ。
  ADR 0053 のトラック別カメラだけを置き換え、スクロールごとに SwiftUI を更新しない所有関係は保つ。
- トラック切替とエディタの再生成では共通のカメラを復元する。
  切替先で既に選択されているノートが画面外でも、切替だけではその位置へ移動しない。
- 同じトラックでの明示的なノート移動・Tab・アクセシビリティ操作の表示と、再生ヘッド追従は従来どおり行う。
  切替中のドラッグは既存の取消を通し、古いフレームのヒット領域を再利用しない。
- トラックを削除しても共通カメラは残す。文書セッションが変わった時だけ初期化する。
  保存・Undo の対象にせず、プロジェクトの再オープンでも初期値から始める。
- 記憶の書戻しは文書セッションと現存トラックを確認する。
  同じトラック ID を持つ別文書でも、旧ビューから新しい記憶を上書きできない。
- ビュー自体を再利用して別文書を表示する場合も、旧カメラを新しい記憶へ書き込む前に対象を外す。

## 受入と基盤

- `piano-shared-viewport-ui` は実 View のスクロール、異なる音域・時刻のノートを持つトラック間の切替、
  エディタの再生成、空トラック集合、旧文書の書戻し拒否、別文書での初期化と明示的なノート移動を確認する。
- 負の対照は共通カメラの復元、切替時の自動表示の抑止、書戻しの所有確認をそれぞれ外す。
  既存の再生成回帰も共通カメラの仕様へ更新し、検査登録・選択回帰・Makefile の案内をそろえる。
- 操作要件・現在の範囲・領域設計・開発手順とデバッグ手順へ共有状態の所在と境界を反映する。
  新しいログや外部入力はなく、`doctor` と `debug-report` の収集範囲は変えない。
- モデル・アクション・音声は変更しないため、操作生成とブロック長比較の追加は不要である。
  ゴーストノート、トラックセレクター、編集対象とアレンジの選択の分離は別単位であり、実装済みとは扱わない。
- 実画面の切替時の見え方と VoiceOver はユーザー担当とする。
