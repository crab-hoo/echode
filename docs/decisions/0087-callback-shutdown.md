# ADR 0087: 完了コールバックからの停止は自分を待たない

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-14。文書の C ABI

## 背景

完了コールバックは文書ワーカーの上で走る。そこから同じ文書の停止を呼ぶと、そのワーカーを `join` していた。自分を待つことは `Resource deadlock avoided` で中断し、C ABI の境界で SIGABRT になった。

## 決定

停止は、先に待ち行列を閉じる。呼んだスレッドがワーカー自身なら、`join` せずに戻る。あとの停止か解放が、別のスレッドからハンドルを受け取って待つ。ミューテックスを持ったままは待たない。

コールバックから解放したときは、ワーカー自身なので待たずに戻り、ハンドルの破棄はスレッドを切り離す。待ち行列はすでに閉じているので、ワーカーはコールバックのあとで終了する。

## 結果

コールバックからの停止、解放、停止後の再送は中断しない。停止と、別スレッドからの停止を重ねても中断しない。再送は文書スレッドが止まったというエラーになる。画面での操作確認は未実施である。
