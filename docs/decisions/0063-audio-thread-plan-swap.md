# ADR 0063: 音声スレッドは用意した箱とイベント列を使い回す

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 再生計画の交換と、ブロック内のイベント整列。プラグインの締め切りは [ADR 0064](0064-one-callback-deadline.md)

## 背景

プラグインのグラフを交換するとき、コールバックが古いグラフを箱から取り出し、新しい箱を確保していた。イベント整列は標準ライブラリの安定ソートで、作業用のメモリを確保していた。どちらもデバッグの確保検出で停止した（監査 AUD-04）。

## 決定

`HostGraph` は箱のままリングを往復する。コールバックは箱を交換するだけで、箱の確保と解放はしない。

イベント整列は、その場で安定に並べる。比較が小さいときだけ隣と入れ替え、同じキーは書かれた順のまま残る。整列のためのヒープは使わない。

## 結果

空のプラグインチェインでも、トラック構成の交換と 1,000 件の整列は、確保検出を有効にしたコールバックで停止しない。実在の CLAP を接続した Undo / Redo と、RTSan での同じ操作は、この検査ではまだ見ていない。画面での操作確認は未実施である。
