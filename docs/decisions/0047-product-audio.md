# 0047. 製品の音声出力とトランスポートを接続する

- 日付: 2026-10-10
- 状態: 採用
- 項目: ENG-14、ENG-15（製品の CoreAudio）

## 決定

- CoreAudio の製品経路を `echode-audio-io` に置く。HAL は `objc2-core-audio`、バッファと時刻の型は `objc2-core-audio-types` 0.3.2 を使い、OS の宣言や定数を新しく手書きしない。ライセンスは Zlib OR Apache-2.0 OR MIT である。
- 文書の制御スレッドが、機器の一覧・名前・安定した UID、現在のサンプルレートとバッファの長さを読む。通知の block はアトミックな印だけを付ける。HAL が block と参照を保持するので、通知の取り外しと発火が重なっても文脈のポインタを解放しない。
- 既定はシステムの出力である。明示選択は一時的な HAL ID ではなく UID で保ち、消えたら既定へ、再接続で戻す。現在の機器・レート・バッファが変わったらコールバックを終了してから作り直し、拍の位置を新しいレートのサンプルへ変換する。設定の列挙と通知登録の隙間も再確認する。
- 出力ストリームの構成と仮想形式の変更も通知で監視する。通知の世代が制御側で確認した世代と違う間は、コールバックはバッファを無音にして時計を止める。形式が変われば作り直し、同じなら確認した世代を渡して再開する。通知を消してから設定を読む順序にはせず、確認中に届いた次の通知も残す。
- 再生を始めるまでデバイスは開かない。停止・一時停止・文書の終了も制御スレッドで行い、音声コールバックとその保持する計画を UI スレッドで破棄しない。文書の編集だけなら音声機器を問い合わせず、ヘッドレスで動く。
- 制御スレッドで、既存の再生計画、ノートのカーソル、内蔵音源のボイス、イベントとサンプルの領域をまとめて準備する。計画の往路・復路と、Copy のトランスポート操作のキューは別である。復路の空きを確かめてから差し替え、解放は制御側で行う。キューの深さは滞留数であって、トラック数やノート数の上限ではない。
- 再生中の編集では、引き続き鳴るノートのボイスを移して位相と包絡を保つ。旧トラックとノートは制御側で用意した ID の索引で探し、トラックの総当たりをしない。再生位置を置く時は、ノートの終了位置の木で重なるノートだけを探す。削除したノートは次の計画で止まり、途中への移動ではその位置に重なるノートを打ち直す。クリックを避けるフェーダーや切り替えの補間は ENG-13 の残りである。
- Phase 1 の最初のアプリ接続は内蔵 Sine Pad とステレオマスターである。HAL の float32 の平面・インターリーブを扱い、先頭 2 チャンネルへ出す。他のチャンネルは無音、モノ出力は等電力で加算する。機器のチャンネル数には固定上限を置かない。非 float32 の仮想形式は理由を返して拒否する。物理形式の変更やサラウンドのルーティングはまだ行わない。
- サンプル位置を進める `ClockSource` を、既存の `Transport` と製品の再生へ渡せるようにする。実装する中身は `InternalClock` だけであり、外部同期は Phase 5 で追加する。時計の処理はメモリ確保・ロック・待機をしない契約である。
- 再生・一時停止・停止・位置移動・出力設定はセッションの操作で、プロジェクトの Undo やジャーナルを消費しない。停止と一時停止は再生位置を保ち、次の再生はその位置から始まる。C ABI は非同期の完了と不変の状態を返す。描画は保持した文書のアトミックな位置を読むので、MainActor の表示更新で時計を進めない。

## 確認

- 製品の再生を 1・7・64・512 フレームに分けても、既存の CLI と同じ書き出しにビット単位で一致する。
- ノートが鳴っている時に空のフォルダを追加してトラックの順序を変えても、音源の位相と包絡は同じである。停止・一時停止・シーク、音を鳴らすノートの削除、計画の繰り返す差し替えを単体検査する。出力バッファの検査では、機器の変更通知中は無音と位置の保持、確認後は再開することも確かめる。
- デバッグの確保検出と RTSan は、製品の再生と HAL の出力バッファを処理する関数を対象にする。大きくなったバッファは無音と制御側の再設定で扱い、コールバックで確保しない。
- `make spike-audio` は画面を開かず、実際の機器で無音の再生と終了を繰り返す。物理的な抜き差しと聴感、アプリの描画・操作の実機確認は、この検査に含めない。実行結果は変更に対する `target/verification/report.md` に残す。
