# ADR 0156: ルーラーのループ範囲指定と、終端以降からの通常進行

- 日付: 2026-10-25
- 状態: 採用。P2-07 のトランスポートの続き
- 範囲: ピアノロールのルーラー。アレンジのルーラーと既存ループ端のハンドルは含まない

## 背景と再現

[操作要件](../interaction-design.md#ループ再生) と [ADR 0117](0117-workflow-interactions.md) は、
ルーラーのドラッグで範囲だけを変更し、ループのオン／オフと開始位置を変えない。
[ADR 0155](0155-remembered-playback-start.md) のルーラーは押下で開始位置を変えていたため、
そのままドラッグを加えると、範囲を決めるだけで再生中の位置が動いてしまう。
実 View の押下とドラッグで、離す前に開始位置の要求が出ることを再現した。

製品の再生器は、位置がループ終端以上なら無条件で先頭へ戻っていた。
製品バッファの回帰で、ループ 200〜640 サンプル、再生中に 740 へシークして 1 フレーム処理すると、
期待の 741 ではなく 201 になることを確認した。

## 決定

- ピアノロールのルーラーは、押下では位置を変えず、離した時にクリックとドラッグを分ける。
  - 横に 3 pt 未満ならクリックとし、従来の開始位置変更を送る。
  - 一度 3 pt 以上動いたらドラッグのままとし、逆向きでも両端を小さい順にする。
  - 両端は現在のノートグリッドの最寄りへ吸着し、Shift で両端の吸着を外す。負の tick は 0 に止める。
  - 吸着後の長さが 0 のドラッグは何も送らず、開始位置変更にも戻さない。
  - ドラッグ中は帯だけを仮表示し、離した時に範囲を 1 回送る。音声側の準備をイベントごとに要求しない。
  - Escape、スクロール、ズーム、サイズ変更、フォーカス喪失、文書・トラック・スナップショットの変更、終了で取り消す。
- 範囲は既存のセッション内の下書きと共有する。オフ中は下書きだけ、オン中は `transport.loop` も更新する。
  開始位置・現在位置・選択・Undo は変更しない。遅れた確定は文書 ID で拒否する。
- ルーラーに範囲の帯を描き、オンは緑、オフは灰色で区別する。
  鍵盤の見出しとノート領域へはみ出さず、開始位置の印は帯の上へ描く。
  トランスポートの範囲欄も同じ下書きを表示し、入力中の文字は置き換えない。
- `PlaybackAudio` と検証用 `Transport` は、位置移動と範囲変更で「終端へ向かうか」を記憶する。
  - 終端より前へ置いた場合だけ、終端を通過して先頭へ戻る。ループ前の助走もそのまま鳴る。
  - 終端ちょうど、またはその後へ置いた場合は通常進行する。オンの状態と範囲そのものは保持する。
  - 処理の結果ちょうど終端に着いた場合は、次のブロックで折り返す。一時停止／再開と同じ範囲の計画交換でも保つ。
  - 停止で開始位置へ戻す `Rewind` と、未発音の開始の取消でも、新しい位置から判定し直す。
  - バイパス中は素材・停止減衰・メトロノームへも有効なループ境界を渡さず、過ぎた終端で素材を切らない。
- ループの範囲とオン／オフは引き続き保存・Undo の外で、再オープン時はオフの 0〜4 拍に戻る
  （[ADR 0055](0055-loop-metronome.md)）。保存形式とモデルのアクションは変えない。

## 受入と基盤

- 必須契約 `piano-ruler-loop-ui` は実 View の合成イベントから範囲を決め、製品ブリッジを通して、
  オフ維持・オン中の更新・開始位置と Undo の不変・逆向き・Shift・取消・旧文書の拒否を確認する。
  通常回帰は帯のクリップと有効／無効の色、既存の開始位置クリックも確認する。
- 必須契約 `loop-entry` は製品のステレオ素材で、48 / 96 kHz とブロック長 1・7・64・512 を比較する。
  助走、終端直前・ちょうど・以降からの開始、再生中の範囲外シーク、境界の一時停止／再開・計画交換、`Rewind` を通す。
  バイパス中の素材は元の全サンプルと一致することを要求する。RTSan も同じテストを実行する。
- 検証用 `Transport` にも助走・境界・範囲外シークと、一時停止後の折返しの回帰を置く。
- 反例はドラッグをシークへ置き換えるものと、無条件の巻戻しを戻すものとする。
  既存 `plugin-state-poll` の反例は、範囲変更時だけの分岐に入らないよう音声処理の先頭へ移す。
- 新しいログ形式・依存・外部入力はない。診断の収集範囲は変えず、デバッグ手順に境界の識別方法を追記する。
- 実画面の帯の見え方・ドラッグの操作感・VoiceOver と、実機・第三者プラグインの聴感はユーザー確認とする。
  アレンジのルーラー、既存端のドラッグ、自動スクロール、Return の割当は未接続のまま残す。
