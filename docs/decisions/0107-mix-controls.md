# ADR 0107: トラックと音声クリップの画面操作を製品経路へ接続する

- 日付: 2026-10-16
- 状態: 採用
- 範囲: アレンジのトラック音量・パン・ミュート・ソロ・ピークメーター、音声クリップのゲイン・フェード、インスペクター

## 背景と操作

モデルのミキサーパラメーターと音声クリップのゲイン・フェードには、アクション・保存・音声処理があった。画面からの操作が未接続だったため、既存の `param.set`、`clip.set_gain`、`clip.set_fades` へ接続する。アクションや保存形式は追加しない。

トラックヘッダに音量・パンのスライダー、M / S、ピークを置く。行高60ポイント以上・幅120ポイント以上で表示し、縮めた行では選択したトラックのインスペクターを使う。描画とヒットテストの配置を共有し、画素は名前やレーンと同じMetalフレームへ描く。ネイティブの透明な入力領域とアクセシビリティの子を使い、別々の表示時刻によるずれを持ち込まない。

インスペクターは音量をdB、パンを−100〜100%で入力する。数値欄は、横に出している単位と無音ラベルと同じマイナス（−）を受け付ける。無音は −∞、-inf、-infinity でも確定する。トラックヘッダの読み上げも同じ単位にする。スライダーが保持する数値は線形0〜4と−1〜1のままで、入力もその範囲へ変換する。読み上げの増減は音量 1 dB、パン 5% である。スライダーの下端は無音で、無音からの増加は −59 dB に置き、−60 dB 以下への減少は無音にする。下端と同じ位置に見える線形 0.001 を最初の段にしない。連続した増減は、アクセシビリティの木を作った時の値ではなく、直前に送った段から計算する。前の編集が文書へ書き終わる前に次の段が来ても、その編集は捨てずに、いまの編集のあとへつなぐ。中央のステレオは振幅を維持し、ステレオのパンはバランスである。M / Sは既存のミュート・ソロ解決を使う。

音声クリップは選択して、中央のゲインハンドルを上下に、上端の両フェードハンドルを左右にドラッグする。インスペクターでもゲインdBとフェードmsを入力できる。ドラッグの表示は下書きで、離すと既存アクションを1回送る。Escape・入力の中断・文書変更・ビューの破棄は下書きを捨てる。アクセシビリティのクリップ選択からもインスペクターへ移れる。

ゲイン・フェードは音声クリップに限定する。MIDIノートのベロシティやプラグイン出力へ配置ゲインが掛かるように見せない。既存の制約は [ADR 0022](0022-clip-content-and-placement.md) と [ADR 0068](0068-clip-gain.md) を参照する。時間は保存形式のflick（1秒=705,600,000）を使う。横方向の操作と表示はスナップショットのテンポマップでtickとflickを相互変換し、現在のBPMの定数倍に置き換えない。重なるフェードも既存の音声処理に従う。

## ドラッグの試聴と確定

音量・パンを動かすたびにジャーナル・Undo・音声計画を作り直さない。文書に属する一時的な `audio.preview_fader` を使い、UIは要求を1件だけ送信中にし、残りは最新値1件へまとめる。音声側は準備済みのフェーダーへ既存の5ms補間で適用する。音声出力がまだ無い場合は意図を保持し、初回の出力より前に適用する。

音声側の試聴対象は、制御側で構築したID索引で解決する。操作のたびに全トラックを探索せず、前と次の対象だけを補間し、ほかのトラックの目標には触れない。

離すと1回の `param.set` を確定する。試聴の解除は、確定した再生計画の版が音声側へ到着するまで待つ。先行する古い計画が交換待ちでも、元の音量が一瞬戻ることを防ぐ。取消では確定済みの値へ補間して戻る。一時値はUndoや保存へ入れない。文書を閉じる・開き直す操作は進行中の送信と終了処理を待ち、前の文書の操作を次へ混ぜない。

## ピークの所有権

各トラックのフェーダー後、マスター加算前の左右の絶対値の最大を表示する。音声側だけがアトミックなセルへ書き、読取側は破壊的なリセットをしない。即時アタック・24dB/秒のリリースを音声フレーム数から決め、停止中のコールバックでも減衰する。1回のコールバックでは、ブロックを混ぜ終わったあと各メーターへ1回だけ書く。処理の途中で減衰値を公開しない。表示の下限は −60 dB（線形 0.001）で、そこへ達した保持値は 0 になる。聞こえていない開始を取り消したブロックはメーターを 0 に戻す。インスペクターの dB はそれ以下を数え続けず −∞ を示し、バーはトラックヘッダと同じ `MixScale.meter` の割合を補間なしで、画面の更新周期に合わせて描く。再生も減衰も終わったらその更新は止める。フェーダーの試聴中もメーターは操作欄と別に明るいままである。停止のフレームでピークが下限以下でも、表示リンクは 200 ms のあいだ減衰と遅れて届くテールを描ける。0 dB は無音ではなく基準振幅である。これはRMS・ラウドネス・トゥルーピークの計測器ではない。

リリースの係数は1ブロックで1回計算し、各トラックで指数関数を繰り返し計算しない。

セルは制御側で確保してトラックIDで再利用し、計画交換でメーターを初期化しない。文書のワーカーはセルへのハンドルを公開し、描画・インスペクターは文書キューへ要求を積まずに読む。公開表の読取ロックはUI・描画側だけが使い、音声コールバックはこの表に触れない。音声側は既存トラックのセルを直接保持する。文書を閉じた後に保持したfeedも0を返す。

アレンジは再生中とメーターが減衰中、および停止直後の 200 ms だけ表示リンクを維持する。静止した後のメーターのためにワークスペース全体をポーリングしない。インスペクターは画面の更新周期でメーター行だけを読み、再生も減衰も終わったら止める。

## 検査と限界

必須契約 `track-mix-ui` は実Viewのマウス入力から音量・パン・M / S、1回のUndo、取消、保存・再読込を通す。`clip-mix-ui` は製品アレンジの配置と実View入力からゲイン・両フェードを確定し、保存とUndoを確認する。`live-mix-meter` は48 / 96kHz・1 / 7 / 64 / 512フレームで試聴・確定・取消・保留計画・実ピーク・停止中の減衰を確認し、波形のブロック間一致も要求する。各契約は誤りを戻したコピーの期待値で失敗することを検査する。

通常検査には、保留した試聴送信の集約とclose、初回出力前の試聴、テンポ変更をまたぐフェードとABIのnull・寿命を含める。ライブ処理はRTSan、橋渡しはASan / TSan / Miriの既存入口へ含める。結果の正本は `target/verification/report.md`。実表示・VoiceOver・聴感・機器の期限内処理はユーザー担当であり、画面を開かない入力検査や波形比較で合格へ変えない。実機検査のためにアプリを操作しない。通常のビルド先は `target/Echode.app` とし、起動中のアプリは更新しない。

入力の境界検査では、モデルで有効なゲイン `1e-8` / `1000` が、動かさないハンドルのクリックで0 / 約15.85へ変わり、不要なUndoを作ることを再現した。ハンドルの通常範囲の外でも元の値を保持し、ドラッグを現在値から始めるように修正した。数値欄からも入力できる `1e-4` を加え、クリックの不変性と1dBの相対変化を同じ必須契約へ含める。

クリップより長い有効なフェードも、表示上の端をクリックするだけでは短くしない。ゲインと両フェードのいずれも、移動しない場合と開始点へ戻した場合は元の下書きを復元する。1秒の音声に4秒・5秒のフェードを保存した境界を必須契約で確認する。

## 後続の一括操作（2026-10-28）

ヘッダ・インスペクターのミュート／ソロを、操作時の選択全体へ単一 Undo で適用した。
連打の現行値解決・選択外のソロ保持とピアノ行の単一対象は [ADR 0189](0189-selected-track-mute-and-solo.md) に定める。
音量・パンの相対一括変更とミキサーのコンソール表示は未接続のままである。

音量・パンの数値入力は [ADR 0191](0191-selected-track-numeric-mix.md)、
ヘッダの読み上げ増減は [ADR 0192](0192-selected-track-accessibility-steps.md) で後日接続した。
一括ドラッグ・既定値リセットとコンソール表示は残る。
