# 0019. オフラインの書き出しはテスト用シンセで WAV にする

- 日付: 2026-10-08
- 状態: 採用

## 背景

Phase 1 の完了条件には、同じプロジェクトを CLI で WAV にすると基準のファイルと一致することがある（PLAN、ARCHITECTURE §16）。音を出す内蔵デバイスは wavesynth の Sine Pad になった（[0018](0018-test-synth.md)）。

## 決定

- `render_offline` は、プロジェクトを先頭から指定フレーム数だけ、トラックごとに Sine Pad で鳴らしてステレオに足す。フェーダーはユニティで中央
- フレーム数を省略したときの長さは、最後のノートの終わりに Sine Pad のリリース 0.4 秒を足したもの
- 1 ブロックの作業バッファは 64 フレーム。これは書き出し全体の長さの上限ではない
- WAV は 32bit 浮動小数点、ステレオ、余分なチャンクなし。データが 4 GiB を超えるファイルは、この書き出しでは出さない
- コマンドは `echode render PACKAGE WAV [--sample-rate 48000] [--frames N]`

## 結果

同じプロジェクトを 2 回書き出すと、WAV のバイト列が一致することをテストで確かめる。
