# ADR 0068: 配置のゲインは準備した音声に掛ける

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 製品の再生と CLI の書き出しが読む配置の線形ゲイン。[ADR 0022](0022-clip-content-and-placement.md)

## 背景

配置の gain を 1 / 0 / 2 にしても、準備された音声の最大値は 0.25 のままで、書き出しのピークも 0.17677669 のままだった（監査 AUD-09）。モデルはゲインを保存するが、読み込みが `placement.gain` を使っていなかった。フェードは接続されている。

## 決定

制御スレッドが配置をデバイスレートへ揃えたあと、そのサンプルへ配置の線形ゲインを掛ける。再生も CLI の書き出しも、この準備済みのバッファを使う。フェードは、掛けたあとのサンプルに対して、ブロックを混ぜるときに掛ける。0 は無音。負と非数は読み込みで拒否する。

Undo / Redo と保存・復旧は、モデルのゲインを変えたプロジェクトを同じ読み込みで準備し直す。

## 結果

0.25 の定数は、ゲイン 0 / 0.5 / 1 / 2 で無音、半分、同じ、2 倍になる。パンのあとの本体は、ゲイン 1 で 0.17677669 である。画面での操作確認は未実施である。
