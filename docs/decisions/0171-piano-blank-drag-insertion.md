# ADR 0171: ピアノロールの空白ドラッグでノートを追加する

- 日付: 2026-10-26
- 状態: 採用。P2-07 のノート入力の先行単位。実画面の操作感はユーザー確認待ち
- 関連: [ADR 0117](0117-workflow-interactions.md)、[ADR 0167](0167-piano-note-drag-snapping.md)

## 背景と再現

[操作要件](../interaction-design.md#ノートの入力) は、空白からの左ドラッグで開始位置を固定し、
右への移動で長さ、上下への移動で音高を調整してノートを追加する。
`ff6086a` の `PianoGridView` は、空白の単クリックでカーソルを置き、ダブルクリックの押下時に追加するだけだった。
空白からドラッグしても既存ノートの `PianoGesture` がないため、追加も仮表示も行わなかった。

実 View へ合成した押下・ドラッグ・解放を送り、製品の `insertNote` と履歴・保存へつなぐ回帰を先に追加した。
期待した追加が 0 回のため、終了コード 1 と固有のアサーションで失敗した。
記録は `target/focused-checks/piano-insertion-red/` に置く。

## 決定

- 空白の押下は `PianoInsertion` に開始位置・音高・カメラを保持する。モデルへはまだ送らない。
- 3 pt 以上動いたらドラッグとし、横の終端・縦の音高を仮表示する。
  右端は絶対時刻のグリッドへ吸着する。開始は押下時の値のまま動かさない。
- Shift は押下時の開始と追跡・解放時の終端の吸着を外す。
  新規ノートは左へ戻っても最短 1 グリッドで止める。既存ノートの伸縮の最短 1 tick とは異なる。
- 音高は MIDI の範囲内、開始は 0 以上、長さは正の値とし、非有限値や時刻の桁あふれは追加しない。
- 解放時の座標・Shift で計算し直し、`onInsert` から既存の `note.insert` を 1 回だけ送る。
  追跡中は書き込まず、二度目の解放も追加しない。Undo / Redo・ジャーナル・保存形式は既存の経路を使う。
- 新規の仮表示はモデル ID を持たない `PianoRenderInput.insertion` とする。
  既存ノートのプレビューと同じ矩形・色で描くが、可視ノート列や VoiceOver の確定要素へ混ぜない。
  仮表示を含む古いフレームからは新しい押下を始めない。
- Escape・フォーカス喪失・スクロール・ズーム・リサイズ・処理中への移行・スナップショットやトラックの変更・
  入力取消・終了で下書きを捨て、遅れた解放から追加しない。押下中は再生ヘッド追従のページ送りを保留する。
- 単クリックはまだカーソル移動のまま、ダブルクリックと Return は現在のグリッド幅の追加を保つ。
  ダブルクリックだけも解放時に確定するため、ドラッグや取消と二重にならない。
- 記憶する入力長・単クリック追加・共通ベロシティ・試聴・複数ノート編集は別の実装単位である。
  Return の割当は [ADR 0155](0155-remembered-playback-start.md) のユーザー判断待ちを保つ。

## 受入と基盤

- 必須契約 `piano-note-insert-ui` は実 View・製品ブリッジを通し、押下時の開始と解放時の長さ・音高・Shift、
  追跡中の無編集、単一 Undo / Redo、保存再読込を機器なしで確認する。
  負の対照は、空白の追跡を始めない、古いプレビューを確定する、開始と長さを動く端から決め直す、の 3 つとする。
- 必須契約 `piano-note-insert-cancel-ui` は取消後のプレビュー破棄と、遅れた解放での無編集を確認する。
  負の対照は `cancelGesture` で新規の下書きを残す。
- `PianoInsertionTests` は通常回帰で、単クリックとダブルクリック、新規の最短長、描画矩形、
  古い仮表示からの押下の拒否、音高上下端・ズーム・非有限値・桁あふれも確認する。
- 契約と選択の回帰、Makefile の既存入口の説明、利用手順・操作の正本・現在の範囲・領域設計を同時に更新する。
  新しい Makefile の検査入口は不要で、既存の `check-shell` と製品契約の実行器を使う。
  既存の `playhead-follow-ui` の負の対照も、新規の押下保留を残してルーラーの保留だけを外す差分へ更新した。
  選択の回帰で、その差分が現行ソースへ 1 回だけ一致することを確認する。
- デバッグ手順に入力・幾何・取消の切り分けを追加する。
  新しい外部入力・成果物・ログはなく、`doctor` と `debug-report` の収集範囲は変えない。
- モデル・アクション・音声処理を変えないため、新しいランダム操作生成やブロック長比較は追加しない。
  実画面のドラッグ・仮表示・VoiceOver・聴感の確認はユーザー担当とし、自動回帰の合格から推定しない。

## 後続の変更

単クリックと記憶する入力長は [ADR 0172](0172-piano-click-and-input-length.md) で接続した。
本 ADR の単クリック・ダブルクリック・Return の暫定動作は後続の決定へ置き換える。
開始を保持するドラッグ、最短長、解放時の確定と取消の決定は維持する。
