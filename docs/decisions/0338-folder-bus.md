# ADR 0338: 子の音を親トラックのバスへ通す（フォルダバスの接続）

日付: 2026-11-13
状態: 採用。聴感と Reaper との比較はユーザー確認待ち（UC-73）
関連: [ADR 0277](0277-reaper-style-folder-bus.md)、[ADR 0244](0244-folder-mute-and-solo-gates.md)、[ADR 0337](0337-mono-instrument-on-stereo-source.md)、
[ADR 0003](0003-audio-thread-does-not-wait.md)、[FCA-06](../reviews/2026-11-03-full-code-audit.md#fca-06-フォルダのミックス操作が子に効かない)、[P2-03](../phase2.md#p2-03-ルーティングフォルダバスpdc)

## 問題

開始時の HEAD は `e54d455`（準備の [ADR 0337](0337-mono-instrument-on-stereo-source.md) は `a6f7f80`）。
監査の残りが ADR 0278 の順で終わり、Phase 2 へ戻った。P2-02 の残りはサムネイル・GUI の MCP 入口・P2-03 と P2-06 に依るドラムラックで、
P2-03 のフォルダバスは意味が ADR 0277 で決まっていたので、これを接続した（統合表の F1、FCA-06）。

コールバックは全トラックを一度にヘルパーへ出して待ち、各トラックをフェーダーでマスターへ直接足していた。
親の音量・パン・FX は親自身の音にしか掛からなかった。

## 比べた案

### 処理の順番

1. **深さごとの段**: 葉の全トラックを処理して待ち、その親を処理して待つ。単純だが、遅いヘルパーが同じ段の無関係な親まで遅らせる。
2. **依存の数え上げ（採用）**: 子を持たないトラックを一度に全部出し、親は最後の子が終わった時に始める。
   遅いヘルパーは自分の祖先だけを遅らせる。ADR 0003 の「残りのノードがどれも実行中の時だけ待つ」と同じ形である。
   制御側で親子のリンクと数を作り、コールバックは数えて押して取り出すだけにする。
3. **1 ブロック遅らせて親へ渡す**: 待ちは要らないが、ADR 0116 と ADR 0277 が禁じる遅延になる。

### ミュートとソロのゲートの位置

ADR 0277 は「ADR 0244 の意味を保ったまま始め、Reaper と違うと分かったら合わせる」と決めた。
子だけをソロにした時に Reaper が親自身の素材を鳴らすかは、手元の資料で確かめられなかった。そのため ADR 0244 の聞こえ方を保つ。

1. **境界だけで閉じる**: 鳴らない部分木の一番上のフェーダーだけを閉じる。入れ子の変化が 1 本の直線の補間になるが、
   ミュートしたフォルダから子を外すと、開いたままの子のフェーダーが 5 ms だけ鳴る。親の付替えで音が飛ぶ。
2. **各トラックが自分の経路で閉じる（採用）**: 祖先のミュート・ソロを引き継いで各フェーダーを閉じる（ADR 0244 の実効フェーダー）。
   付替えの前後で子自身のフェーダーが閉じているので音が飛ばない。入れ子の変化では経路上の補間が掛け合わさるが、5 ms で終わり、標本単位でブロック長に依らない。

## 決定

- 子を持つトラックは、子のフェーダー後の和を自分の配置音声に足し、自分のチェインとフェーダーへ通す。
  最初の音源があれば、配置音声と同じく音源の出力の後に入る（ADR 0095）。和は親ごとに計画の順で `f64` で取り、到着順に依らない。
- 子を持つトラックの素材はステレオとする。モノの最初の音源は等電力でステレオへ上げ（ADR 0337）、モノ入力の最初のエフェクトは `BusMapping` で拒否する。
- 準備済みのキャッシュは、子を持つトラックでは読まない。1 つの平面は子のバスを表せない。
- `playback_faders.rs::track_routing` が各トラックのゲートと親の位置を作る。
  フェーダーは、祖先を含むミュートがなく、全体にソロがないか、祖先を含むソロか、ミュートされていないソロの子孫がある時に開く。
  自分の音（配置音声と最初の音源）のゲートは、子孫のソロのためだけに開いているトラックで閉じる。5 ms のゲートで補間し、計画の交換で引き継ぐ。
- `playback_bus.rs::Bus` が親子のリンクと待つ子の数を持つ。`Block` はブロックごとに、子のないトラックから始め、
  親の最後の子が終わったら和を足して始める。最上位のトラックは計画の順でマスターへ足すので、フォルダのない曲の和の順は前と同じである。
- `HostGraph::progress` は、1 つ以上のトラックが終わるか期限が来るまで待つ。期限の後に始まる親も一度はヘルパーへ出し、
  ブロックの出来事を届けてから見捨てる（`abandon_track`）。ノートオフを失わず、取りこぼしとして扱う。
- 親のメーターは子を含むフェーダー後の値である。子のメーターは前と同じく自分のフェーダー後で、閉じた経路では 0 である。
- 保存形式・アクション・Undo は変えない。親子関係は既に保存されている。

## 回帰と基盤

- `block_size/folder_bus.rs`: 親の音量とバランス・入れ子・親自身の素材の和が製品再生とオフラインで一致し、メーターも合う。
  子だけのソロで親の音量を通り、親と中間の自分の素材が 5 ms で消えて戻る。親へ渡したキャッシュは読まない。
  ソロの子を外して中間が子を失っても、閉じていた自分の音のゲートは補間で開く（全トラックがゲートの領域を持つ。親だけにすると一度に戻って失敗した）。
  3 件とも変更前のエンジンで失敗した。48・96 kHz、ブロック長 1・7・64・512 で全標本を照合する。
- `block_size/folder_mix.rs`: ADR 0244 の聞こえる集合は変えず、メーターを部分木の和にした。
  補間の回帰は、各トラックのゲートと経路から期待値を独立に組み、入れ子で掛け合わさる補間と付替えを照合する。
- `hosted_playback::a_parent_chain_processes_its_children_under_rtsan`: 実ヘルパーで、親のエフェクトが子を処理し、
  親のモノの音源が子と並んで昇格し、子だけのソロで親の音源が消えることを確かめる。変更前は親のエフェクトが子を通さず失敗した。
- `hosted_playback::a_hung_child_costs_its_folder_one_deadline_and_spares_other_tracks`: 子のヘルパーが止まっても、ブロックは 1 つの期限で終わり、
  フォルダの外のトラックは鳴る。
- `playback_bus_tests`: リンクの順、任意の終了順での親の準備、深さ 10,000 の連鎖を確かめる。
- `audit_fca06_a_folder_mute_and_solo_reach_its_children` に、親の音量が子へ届くことを足した。
- 検査の選択と契約は変えない。変更したテストは既存の `check` の対象である。デバッグ手順のフォルダの節を書き直した。

## 計測

`make spike-plugin-tracks`（release、機器なし、フォルダのない構成）を、前回の記録（2026-11-12）と比べた。cpu の p50 は次のとおりで、取りこぼしは 0 だった。

| 場合 | 前回 | 今回 |
|---|---:|---:|
| プラグイン 256 トラック | 1,043.3 µs | 1,057.2 µs |
| 和音だけ 256 トラック | 144.2 µs | 154.8 µs |
| プラグインとループ 256 トラック | 1,236.2 µs | 1,232.5 µs |

前回は別の時刻の単回の記録である。和音だけの約 7% の差が、ブロックごとの手順の増分か揺れかは分けていない。
フォルダを含む構成と深い入れ子の計測は、spike にまだない。

## 残る範囲

- PDC は未実装である。親の FX の遅延は子の全体に同じだけ掛かり、兄弟の間のずれは補正しない（ADR 0277）。
  2026-11-13: [ADR 0339](0339-plugin-delay-compensation.md) で兄弟・親の素材と音源を揃えた。書出しの余韻も経路の和にした。
- ヘルパーの段は親の深さだけ直列になる。深い入れ子にプラグインが多いと、同じ期限の中で使える時間が減る。
- 子だけをソロにした時に親自身の素材を鳴らさないことが Reaper と同じかは未確認である（UC-73）。違えば、このゲートを外して ADR 0244 を置き換える。
- センド・サイドチェイン・ドラム用の MIDI 配布は P2-03 の残りである。
