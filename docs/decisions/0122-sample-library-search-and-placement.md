# ADR 0122: サンプル素材の登録検索と入力時点の配置先を保持する

- 日付: 2026-10-19
- 状態: P2-02 の共通サンプルブラウザの検索・配置を接続。単発試聴は未実装
- 範囲: フォルダ登録・解除・設定保持、全登録素材の名前検索、音声配置の対象と位置

## 背景

[操作要件](../interaction-design.md#共通サンプルブラウザ) は、フォルダ移動と登録素材全体の名前検索を併用する。
従来のファイル欄は表示中のフォルダだけを絞り込み、登録範囲を持たなかった。
音声取込みでは定期更新の `audio.tick` を使い、操作イベントが作る非同期タスクの開始後に選択トラックを解決していた。
再生ヘッドが最後の状態応答より進んだ条件では、素材が古い位置へ入ることを機器なしの製品経路で再現した。

## 決定

- 選択ダイアログで開いたフォルダを登録し、登録一覧をユーザー設定へ保持する。
  文書の保存形式とジャーナルは変えない。メニューから移動・登録解除でき、解除は素材そのものを削除しない。
- 検索が空なら現在のフォルダを表示し、入力があれば全登録フォルダ配下の音声ファイルを名前で絞る。
  同名の素材は親パスも表示し、登録が重なった同一パスは 1 件にする。
  名前順を基本に、同名はパス順とし、トラックやフォルダ深さに固定の上限は設けない。
- 素材の索引は制御側の非同期処理で作り、音声スレッドへファイル探索を入れない。
  隠しファイル、シンボリックリンク、パッケージ内部を巡回しない。
  明示的に選んだ登録ルートは実パスへ正規化する。これは外部変更との競合を防ぐファイルシステムの隔離機構ではない。
- 素材の追加・削除は更新ボタンで再読込し、読めない登録範囲を画面へ表示する。
  後発の索引要求は古い要求を取り消し、完了順が逆でも古い結果を公開しない。
  監視による自動更新・登録数に比例しない検索索引・音声の試聴は今回の範囲に含めない。
- ダブルクリック、Return、取込みボタンは同じ `WorkspaceSession.importSample` を使う。
  入力イベントで `AudioImportRequest` に文書セッション・選択トラック・ライブの再生 tick を確定する。
  グリッドへ丸めず既存の `audio.import` へ渡し、単一 Undo / Redo とパッケージ保存・復旧を共有する。
- タスク開始後の選択変更で追加先を変えず、対象削除と文書交換は拒否する。
  同じパッケージを開き直した場合も、文書セッションが違えば古い要求を拒否する。
  共通の編集待ち行列へ入った後も文書セッションを照合する。

## 検査と診断

- `SampleBrowserTests` で全登録フォルダの検索・名前の大文字小文字・重複排除・設定復元・解除を確認する。
  パッケージ、循環リンク、登録外へのリンク、隠し素材、消失したフォルダと古い索引要求も含める。
- 実 WAV を既存の製品取込み経路へ通し、古い定期更新値から独立した位置を確認する。
  ブラウザの共通操作直後に選択を変え、操作時の対象と丸めない tick、単一 Undo / Redo、保存・再読込を検査する。
  対象を Undo で削除した要求と、再オープン前の要求は拒否する。
- `sample-library-search` と `sample-import-target` を必須契約へ登録する。
  現在フォルダだけの絞込みへ戻す差分と、非同期実行時の選択へ付け替える差分で、それぞれ期待値が失敗する必要がある。
  既存の必須契約入口、選択回帰、Swift の ASan / TSan に接続する。
- 診断では登録範囲・索引世代・読込失敗、操作要求の文書・トラック・tick を区別する。
  既存の契約ログを使うため `debug-report` の収集先は増やさない。

## 未確認と残る範囲

検索・配置は機器と実ウィンドウを開かない回帰で検査する。
実際のクリック・キー操作・フォルダ権限の画面表示と聴感はユーザー担当であり、自動検査の合格から推定しない。
選択時の単発試聴と曲に重ねる試聴経路は未実装で、P2-02 全体も未完了である。
新しい DSP、ブロック分割、ヘルパー隔離、音声処理の計画交換は変更しない。
