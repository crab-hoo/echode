# 0260. GUI の書出し先をスナップショット準備前に固定する

日付: 2026-11-04。
状態: 採用（P2-08 の原本保護。音声処理・形式・操作子は変更しない）。

## 背景と再現

[ADR 0259](0259-export-destination-boundary.md) は CLI が読む元パッケージと、その正規化した出力先の境界を保護した。
GUI が CLI へ渡す入力は専用スナップショットなので、元文書のパッケージは CLI には分からない。
`ExportJob.start` は出力先を検証したが、実行にはリンクを含む元の URL を渡していた。
検証後に出力フォルダのリンクを元文書へ切り替えると、CLI が元文書の `project.json` を WAV へ置き換えて成功した。
また、パッケージ内から外を指す葉リンクは、完全に解決した参照先だけの比較では拒否できなかった。

`ExportDestinationTests.contractExportPinsTheDestinationBeforePreparingItsSnapshot` を製品と同じジョブ・実 CLI から先に実行した。
主アクターを待機させる前にリンクを切り替え、書出し準備との実時間の競争をなくした。
終了コード 1 と `Export must not follow a retargeted output directory into the source package` を照合した。
証拠は `target/export-destination-ui-red/` に残す。

## 決定

- `ExportJob.start` の最初の待機より前に出力の親フォルダを解決し、元の葉の名前を結合する。
  準備・CLI の起動をまたいで、この URL を使う。出力フォルダのリンクを後から切り替えても追従しない。
- 親を解決した出力パスと、既存の葉リンクまで解決した参照先の両方を、元文書のパッケージと比較する。
  パッケージ自身・子・内部を指す外の葉リンク・内部から外を指す葉リンクは、スナップショット作成前に拒否する。
  比較にはパス成分の区切りを含め、`Song.echode-exports` のような隣のフォルダは拒否しない。
- パッケージ外の葉リンクが外のファイルを指す場合は、葉を解決せず CLI へ渡す。
  既存の原子的な公開がリンク自身を置き換え、参照先は変更しない。リンク先のファイルへの書出しへ意味を変えない。
- 下部の「詳細」の `Output:` は固定した出力パスを示し、後で転送先が変わったリンクのパスだけを表示しない。
  既存のエラー文・完了表示・取消・既存出力の保全・親フォルダがない場合の CLI のエラーは維持する。
- ディレクトリ自体の並行移動・置換や、任意の敵対的なファイルシステム操作を防ぐサンドボックスではない。
  CLI 側の入力パッケージの境界は引き続き ADR 0259 が担当する。

## 回帰と基盤

- 必須契約 `export-destination-ui` は、元文書と既存出力を用意し、開始直後に出力フォルダのリンクを元文書へ切り替える。
  実 CLI の完走、元の JSON のバイト保持、当初の外のフォルダへの WAV 公開、固定パスの診断と Undo の不変を確認する。
  CLI への引渡しを元 URL へ戻す反例で検出力を確認する。
- 通常回帰はパッケージ自身・内外の葉リンク・フォルダのリンクの拒否を確認する。
  パッケージと同じ接頭辞を持つ外のフォルダは受理し、外の葉リンクだけを置き換えて参照先を保つことも実 CLI で確認する。
- `scripts/verification.json` に契約を登録し、選択の回帰を追加する。
  Makefile の既存の Swift・製品契約の入口がそのまま実行するため、新しい単独コマンドは不要。
- README・設計・進め方・開発／デバッグ手順と現在の制約を更新する。
  ログや収集先を増やさず、ユーザー文書を自動収集しない。画面の操作子と DSP は変わらず、新しい実画面・聴感の項目は追加しない。
  既存の書出しの実画面・VoiceOver・聴感は UC-52〜57 の確認待ちを維持する。
