# 0006. S4 の確定と入力の検証

- 日付: 2026-10-08
- 状態: 採用

## 背景

S4 の計測結果の確認を得た。ライセンスは GPL-3.0-or-later のままである。

## 決定

- S4 を確定する。保存の依頼は呼び出し側を止めず、コミットは履歴スレッドで行う。過去の版は git のオブジェクトから読む
- 次の検証は S5（縦横が独立したピンチ、触覚、キーボード和音を押さえたままの感圧）とする
- 触覚は AppKit の `NSHapticFeedbackManager` を使う。macOS の Core Haptics はトラックパッドを鳴らせない

## 結果

S5 の合格条件は、M4 の MacBook Air 上でその 3 つの操作が成立すること。ピンチの比率、格子をまたいだ判定、和音とプレッシャーの対応は自動テストで確認し、実機の操作は専用のウィンドウで確認する。
