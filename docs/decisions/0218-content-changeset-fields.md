# ADR 0218: 中身の変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。中身の音声参照・テイク ID 列と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0022](0022-clip-content-and-placement.md)、[ADR 0217](0217-track-changeset-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

パラメーター・デバイス・ノート・トラックに続き、中身の音声参照・テイク ID 列も項目表へ集める。
従来は差分・作成と削除・下書き・設定・復元で同じ対応を別々に列挙していた。
今回は既存の結果を保つ構造整理であり、音声の処理やテイクの編集操作を追加するものではない。

## 決定

- `changeset_content.rs` の `content_fields!` に、2 項目の `Property`・フィールド・型・`Value` の種類・読出しを宣言する。
  差分、作成と削除、下書き、両方向の変換、作成の適用、設定の振分けを表から生成する。
- 作成と削除は音声参照・テイク ID 列・ノート ID 列の順に記録する。
  更新は従来どおりノートの並びを先に記録し、その後に音声参照・テイク ID 列を置く。
  ノートの単一挿入・削除は `OrderStep`、それ以外は全 ID 列とする既存の規則を保つ。
- ID とノートの解決は表へ含めない。
  `Draft` がノートの所属・存在・重複・使い残しを照合してから、中身の復元へ委譲する。
  未接続の表情の曲線を空にする既存の動作も変えない。
- `Draft::set` は中身の ID で下書きへ委譲する。
  必須項目、誤った型、未知の ID と対象外プロパティの拒否を保つ。
  ノート列の単一差分では、範囲外の挿入と、位置・ID の合わない削除を拒否する。
- 古いジャーナルの音声なしの値 `Parent(None)` を、作成と更新の両方で受け付ける。
  `Parent(Some(_))` は拒否する。既存の `Lane` のテキスト更新は無変更の成功を保つ。
- 音声参照の整数・ハッシュ、テイク ID 列の順序と重複をそのまま運ぶ。
  低水準 API の往復と、公開前の `check_invariants`・ジャーナル読込み時の音声参照検証は区別する。
  テイクの存在検査や編集操作は今回追加しない。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo の意味、音声処理は変更しない。
  配置など他オブジェクトと保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ回帰を追加し、同じ公開入口で構造整理後の結果を照合した。

- `echode-history/tests/content_changesets.rs` は生成表を参照しない独立した期待値を持つ。
  音声の有無と全メタデータ、任意のテイク ID 列、全項目の組合せを検査する。
  正確なフィールド順・作成と削除・逆適用・二重反転・ジャーナルを照合する。
- 同じ回帰でノートの追加と同時に音声・テイクを更新し、ノートの単一差分と旧形式の全 ID 列を検査する。
  旧 null 音声・`Lane` の無変更互換、必須項目の欠落・誤った型・未知の ID・重複作成・対象外プロパティも通す。
  ノートの欠落・誤った所属・重複・使い残しと、不正な単一差分の拒否を照合する。
- 操作列の `properties.rs` に、共有ノート・音声参照・空でないテイク列からの初期状態を加える。
  不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  モデルの値だけを検査し、素材・プラグイン・音声機器は開かない。

新しい実行入口や依存は追加しない。既存の `check` が回帰を実行するため、検査選択の条件は変更しない。
フィールドと入力を含むアサーションを既存ログへ残し、診断の収集先・手順は変更不要とする。
実機・実画面・聴感の合否はこの構造整理からは主張しない。
