# ADR 0386: 音声構成を明示読込みのデバイス操作と単一の状態編集へ接続する

- 日付: 2026-11-16
- 状態: 一部置換（[ADR 0389](0389-live-clap-audio-config-listing.md)）。一覧の読込みは音声を中断しない。明示読込みは別の理由で保つ
- 領域: プラグイン・隔離
- 対象: P2-03・F2・FCA-07 の音声構成メニュー

## 背景と再現

開始時の HEAD は `6760dcb`。
ADR 0384・0385 の制御 API はあるが、文書のデバイス要求と画面から構成を選べなかった。
製品の `device::dispatch` に新しい要求を通す回帰を先に加え、未知の種類として拒否されることを確認した。
終了コード 101 と固有のアサーションの照合は `target/focused-checks/audio-config-ui-red/` にある。

## 比べた案と決定

- **列の表示・活動通知で一覧を取得する**: 不採用。
  CLAP は一覧取得にも無効化を求めるため、トラックの選択や Undo が意図せず音声を中断する。
- **明示ボタンで一覧を読み、ネイティブのポップアップから ID を選ぶ**: 採用。
  中断の説明をボタンのヘルプへ置き、同じ名前の構成も ID を併記して区別する。
  `current_config` が無い場合は選択中の印を推測しない。
- **選択と commit を別々の画面要求にする**: 不採用。
  選択の dirty 通知を背景保存が先に取ると、利用者の編集が Undo の対象から外れる。
- **文書要求で選択と状態取得を一緒に行う**: 採用。
  ワーカーが背景保存を保留し、デバイスレーンで選択・取得した後、既存の `commit` が単一の状態編集として記録する。
  選択・取得・記録の失敗でも保留を解き、自動再送しない。
- **構成 ID をプロジェクトへ別に保存する**: 不採用。
  プラグインの状態を正本にし、保存・復旧・Undo/Redo は通常の状態ハッシュとオブジェクトを使う。
  構成だけを別に復元してプラグインの状態と食い違う経路を増やさない。
- **一覧の改訂番号を新しく追跡する**: 不採用。
  一覧は明示要求の応答だけを一時保持し、文書の publication ごとに保守的に破棄する。
  無関係な編集の後も再読込みが必要になるが、状態復元を見落として古い選択肢を表示し続けない。
  取得中は再クリックをまとめ、publication をまたぐ古い応答も捨てる。暗黙の再取得はしない。

## 境界と検証

C ABI の関数は増やさず、既存の JSON デバイス要求へ `device.audio_configs` と `device.audio_config.select` を追加する。
選択の `id` は u32 のプラグイン ID であり、列番号ではない。未知の項目・欠損・範囲外を serde で拒否する。
一覧は ID・名前・ポート数・主ポートのチャンネル数・任意の現在 ID だけを画面へ運ぶ。
任意のポート変更は既存の制御 API のままとし、今回の画面へは足さない。
共有領域とルーティングは ADR 0382 の交換を使い、音声スレッドの処理は変えない。

`device_config_tests.rs` は実ヘルパーを文書の round trip と commit へ通し、実際の状態バイト・Undo/Redo・再オープン・拒否後の保留解放を照合する。
`DeviceAudioConfigTests` は実デバイス列のボタン・ポップアップ、単一編集、明示読込み、再試行、取得中の編集と古い応答・文書の拒否を照合する。
画面側の fixture は状態を模擬するため、実際のオブジェクト保存は Rust の回帰が担当する。
必須契約と反例は `device-audio-config-state`・`device-audio-config-ui`、選択と依存入力は `scripts/verification.json` に登録する。
検査コマンドは既存の `make check-product-contracts` と通常テストを使い、別のビルド構成や fuzz 対象は増やさない。
新しい外部ソケット形式はなく、既存の制御ソケットの fuzz が一覧の本文を扱う。

## 残る確認

第三者による状態への構成保持は UC-97、実画面・VoiceOver と操作感は UC-99 でユーザーが確認する。
任意変更の UI・非標準 `port_details`・曲からの表情生成・センド等は残り、P2-03・F2・FCA-07 全体を完了にはしない。
