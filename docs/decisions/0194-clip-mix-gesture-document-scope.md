# ADR 0194: クリップの値操作を押下した文書と編集先へ束縛する

- 日付: 2026-10-29
- 状態: 採用。実画面・VoiceOver の文書切替はユーザー確認待ち
- 関連: [ADR 0153](0153-value-control-clicks-and-typed-entry.md)、
  [ADR 0193](0193-header-mix-gesture-document-scope.md)

## 背景と再現

開始時の HEAD は `6f44cf8`。
ヘッダと異なり、クリップのゲイン・フェードの押下と数値欄は文書交換で取り消されなかった。
`setSnapshot` は下書きだけを消し、押下・リセット待ち・数値欄を残していた。
ドラッグの確定と数値欄は、その時の `onClipEdit` を読み直していた。

同じプロジェクトを再オープンすると配置 ID は同じまま文書 ID とコールバックが変わる。
旧押下からのドラッグと旧数値欄の送信が、新文書の値・Undo・保存内容を変更することを製品入力で再現した。
`ClipGestureDocumentTests` を先に失敗させ、終了コード 1 と固有のアサーションを照合した。
一時ログの所在は `target/focused-checks/clip-gesture-document-red/` であり、永続的な証拠へのリンクではない。

## 決定

- `ArrangeView` のクリップ押下は、対象・元の値・幾何に加え文書 ID と編集コールバックを保持する。
  ドラッグとリセットの開始、数値欄の生成で押下の文書を照合する。
- `audioDocument` が変わったら、クリック状態機械とタイマーを取り消し、押下・下書き・編集先を破棄する。
  数値欄は送信せず閉じる。ビュー終了も同じ取消を使う。
- ドラッグとリセットの終了は開始時に保持した編集先を使い、現在のコールバックを借りない。
  数値欄も押下時の編集先を使い、主スレッドに投入済みの送信は実行時に文書を再照合する。
- 同文書のコールバック更新は操作の編集先を変更しない。
  単クリック・相対ドラッグ・既定値・数値入力の規則とモデルの編集経路は変えない。
  新しいアクション・ABI・保存形式・DSP・依存は加えない。

## 回帰と基盤の保守

- `clip-gesture-document-ui` はゲイン・両フェードの押下、ドラッグ、リセット待ち、数値欄を再オープンで取り消す。
  実 View・製品 controller / ABI と保存再読込を通し、旧入力による履歴・保存の変更を拒否する。
  投入済み数値入力の文書解除も確認する。
  文書交換時の取消漏れと、投入済み入力の文書照合漏れをそれぞれ負の対照にする。
- `clip-gesture-callback-ui` は同文書の更新後もドラッグ・リセット・数値入力が元の編集先へ届き、
  単一 Undo / Redo・保存を保つことを確認する。終了と数値入力の最新コールバック借用を負の対照にする。
- 待ちは明示的な `settle` で進め、経過時間を合否条件にしない。機器・ウィンドウは開かない。
- 検査登録・選択回帰・既存 Makefile 入口、現状・領域設計・開発と診断手順を更新する。
  診断は文書 ID、クリック状態、押下と実行中の編集先、入力欄の投入済み処理を区別する。
- 音声処理とモデルの境界は変わらず、追加のブロック長回帰・アクション生成は不要である。
  ログ形式・出力先・外部入力は増えず、`doctor` と `debug-report` の収集範囲は変更不要である。
- 実画面での文書切替と入力欄のフォーカス、VoiceOver・聴感はユーザー確認に残す。
