# ADR 0344: サンプル試聴の最終出力を共通のガードで止める

日付: 2026-11-14
状態: 採用
関連: [ADR 0282](0282-plugin-nan-and-master-auto-mute.md)、[ADR 0276](0276-priority-order-and-delegated-decisions.md)、[NFA-06](../reviews/2026-11-13-finite-overflow-audit.md#nfa-06-試聴の出力にガードがない)

## 問題と証拠

開始時の HEAD は `9e1a4f1`。試聴は専用の IOProc なので、曲のマスターのガードを通らない。
監査の `audit_nfa06_*` の無視を外し、修正前に失敗することを確かめた。
+40 dBFS の素材は値 100 のまま、3.0e38 の素材の置換は無限大のまま出力バッファへ届いた。
実機・アプリ・第三者プラグインは使っていない。

## 比べた案

- **読込み時に素材のピークを拒否する**: 音量を下げれば安全な素材も断り、置換の和とモノ機器の等電力加算を見落とす。
- **リミッター・クリップを入れる**: 値を作り変えて異常を隠す。ADR 0282 の出力保護と意味が違う。
- **最終値を見て、最初の異常な標本から止める（採用）**: 音量・旧音の減衰・置換の和・モノ変換の後に判定する。
  通常の音を変えず、停止した理由を残す。次の試聴が新しい試行になる。

しきい値は ADR 0282 と同じ +18 dBFS で、左右のどちらかの NaN・無限大も止める。
`output_guard::first_fault` に述語を集め、曲のマスターと試聴が同じ規則を使う。しきい値の再選定と性能改善の主張はしない。

## 決定

- `AuditionAudio::mix` は最初の異常な標本の直前までを保ち、その標本以降と後続ブロックを無音にする。
  `mix_mono` は左右を等電力で加算した値を検査し、両方の面へ同じ値を返す。IOProc では再びモノ変換しない。
- 停止時に現在の声と旧音の減衰を両方とも返却リングへ渡す。音声側では解放しない。
  次の `Play` だけが停止を解除する。旧音の余韻を新しい試聴へ持ち越さない。
- 原因は要求 ID だけを atomic で公開し、最後の異常の ID を保持する。新しい要求は別の ID なので古い理由を引き継がない。
  EOF の公開はガードの後にし、制御側も EOF、異常の順で読む。短い素材の終端を異常より先に正常終了にしない。
- 制御側は `AuditionFault::OutputGuard` を `phase: failed`・`error`・要求の履歴・製品ログへ出す。
  出力は開いたまま再利用し、先読み中なら消費されなくなったリングを待たず復号を終える。
- 完成した波形があっても、プレビューの説明・ツールチップ・アクセシビリティ値へ停止理由を出す。
  別の選択の理由は出さず、次の試聴で説明を戻す。保存形式・Undo・文書編集は変えない。

## 回帰と基盤

- `output_guard_tests.rs`: 正負の境界、片側の NaN・無限大、最初の異常の位置。
- `audition_tests.rs`: 70 標本の正常な先頭、ブロック長 1・7・64・512 の同じ停止位置、停止の保持、尾を残さない復帰、置換の和、モノ変換。
- `audition_guard_tests.rs`: float WAV の製品読込みから実 IOProc の関数を通す。短い EOF と先読みより長い素材の異常を区別する。
  次の選択を出さずに設定の更新が処理されることも見て、復号側がバックプレッシャーで止まらないことを確かめる。
  モノ機器のバッファは最終値を止め、安全な次の試聴を二重変換せず出す。
- `SamplePreviewTests`: 完成した波形を保ったまま停止理由を表示し、読み上げへ渡す。別の選択と再試聴で理由が消える。
- 必須契約と負の対照を既存の検査へ登録し、選択のテストを更新する。RTSan は通常どおり全体の段階に任せる。
- 設計書、監査の状態、デバッグ手順を更新する。実画面・VoiceOver・実時間の復帰は UC-78 でユーザーが確認する。

## 残る範囲

HAL が曲と試聴を加算した後の値は、このガードでは見ない。2 つの IOProc の実時間の重なりは UC-16 のままである。
NFA-01〜05・08 は直していない。書出しの有限値のあふれと、エンジンの素材の入口は別の作業である。
