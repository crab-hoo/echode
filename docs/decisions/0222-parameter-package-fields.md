# ADR 0222: パラメーターの項目表をモデルと保存へ共有する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。パラメーターのモデル・変更セット・パッケージ間の変換
- 関連: [ADR 0214](0214-parameter-changeset-fields.md)、[ADR 0028](0028-package-schema.md)、[ADR 0196](0196-lossless-package-floats.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

変更セット内のパラメーターの項目表は、モデル本体と保存の列挙を共有していなかった。
`document.rs` は保存用と読込み用の型、両方向の変換で同じ 4 項目を別々に宣言していた。
今回は既存の結果を保つ構造整理とし、項目の追加や保存形式の変更は行わない。

## 決定

- `echode-model/src/parameter_fields.rs` の crate 内の項目表を、モデルと変更セットの生成器へ渡す。
  最小値・最大値・既定値・現在値の宣言はこの 1 か所だけに置く。
  表の順序はパッケージのキー順と変更セットのフィールド順の両方を表す。
- `Parameter` のスカラー宣言・ビット単位の等価比較・Serde と、従来の変更セットの変換を同じ表から生成する。
  モデルは `f32`、変更セットの下書きは `u32` のビットのまま持つ。
  ID と不変のキーはスカラー表の外へ残す。
- 履歴の `ParameterLine`・`ParameterFile` と両方向の手書きの変換を除き、モデル型を直接保存・読込みする。
  `ParamKey` の Serde は既存の `as_str`・`parse` を使い、名前の一覧を増やさない。
  ID も既存の `Id` の Serde を使う。
- 保存側は履歴の既存 formatter を通し、キー順・1 パラメーター 1 行・浮動小数点の表記とゼロの正規化を保つ。
  スキーマは 6 のままとし、1〜5 からの段階変換も変更しない。
- Serde は必須項目・型・未知の項目・キーと ID の形だけを検査する。
  値の範囲・制御ごとの端点と既定値・並び・ID の重複は、組立てと公開前の既存の検証に残す。
  モデル型の直接復号を、有効なプロジェクトとしての受入と混同しない。
- 不正 ID・不明なキーはトラックの復号時点で拒否するため、従来の理由に `track json:` の文脈が付く。
  不正なパッケージの原本は変更しない。新しいログや収集先は追加しない。
- ほかのオブジェクトの保存と FFI の統合は残り、SPG-09 全体の完了とはしない。
  アクション・Undo・ジャーナル・再生音は変更しない。

## 回帰と診断

製品コードの変更前に `echode-history/tests/parameter_package.rs` を追加し、同じ公開入口で整理後を照合した。

- 4 制御の保存を独立したキー順・数値表記と比較し、スキーマ 6・再読込み・再保存時のバイトを検査する。
- 全必須項目の欠落・誤った型、未知の項目・キー、不正 ID と数値の文字列化を拒否し、原本の不変を確認する。
- 形が正しい範囲外の値・端点・既定値、制御の入替え・ID の重複を、プロジェクトの受入前に拒否する。
- 旧スキーマの段階変換と、`DocumentHost` の編集・Undo / Redo・保存とコミットからの再オープンを通す。
- 既存の `parameter_changesets.rs` の任意ビット、`float_roundtrip.rs` の小さい値・増分保存・履歴復帰、
  `properties.rs` の操作列の性質テストも維持する。

既存の `check` が新しい統合テストを含み、実行入口・依存・選択条件は変わらない。
新しい失敗経路は追加しないが、復号と不変条件の区別、回帰の場所をデバッグ手順へ追記する。
実機・実画面・聴感や性能の改善は、この構造整理の合否からは主張しない。
