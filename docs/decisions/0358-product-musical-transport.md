# 0358. 曲の時刻をブロックごとに作り、全プラグイン段へ渡す

- 日付: 2026-11-15
- 状態: 現行
- 領域: 音声エンジン・書き出し

## 背景

ヘルパーは時刻 0 の通知を `clap_process.transport` へ渡せるが、製品エンジンは通知を作らなかった。
テンポ同期の FX・音源には、再生・停止・位置移動・ループとテンポの変化が届いていなかった。

## 比べた案と決定

- **ブロック先頭の状態だけを送る**: 不採用。
  途中のテンポ変更・ループ折返しを失い、音がコールバックの切り方に依存する。
- **トラックごと・段ごとに作る**: 不採用。
  同じ計算と、停止・ループの規則を複数の場所へ持つ必要はない。
- **全イベントを全トラックへ複製してから振り分ける**: 不採用。
  トラックを持たない時刻の通知のために、全体のイベント格納量と探索を増やす。
- **制御側で時刻の境界と容量を準備し、音声側で一度だけ通知を作る**: 採用。
  各チェインは、借りた通知をトラックのノート列と既存の `event_cmp` で併合する。
  既存のステージ配布で、音源・後段 FX・フォルダ FX の全てへ渡す。

`playback_transport.rs::Timeline` はモデルの整数 `TempoIndex` から境界の sample と flick を得る。
テンポの積分を別に実装せず、その境界からの小数の拍位置を算出する。
先頭位置を整数 tick へ丸めるとブロックごとに量子化誤差が変わるため、サブ tick の精度を保つ。
サンプルへ丸めた同じ位置に複数の点があれば、最後のテンポを使う。
原点前は整数 index と同じ右端を基準にし、遠い負の点との差で小さな拍位置を失わない。
サンプル位置の i64 範囲より先の点は送らず、範囲より前の点は最終の外挿用の基準だけを保つ。

## 意味と容量

先頭と折返しの各 span、span 内のテンポ境界に通知を置く。
停止中と停止の音源フェード中は、進める音源の位置ではなく、保持した位置と停止の状態を時刻 0 に送る。
録音は未接続なので false、テンポは段階値なので増分は 0 とする。
拍子は曲全体の値、ループ範囲は準備した設定を両方の時刻系で示す。
ループ終端以降の助走禁止状態でも、選択されたループの設定は通知に残す。
時刻はプロジェクト位置であり、段ごとの PDC の遅れを戻す補正は今回足さない。
小節番号は i32、拍子は既存の `Transport` と同じ u16 の表現範囲へ飽和させ、桁あふれで折り返さない。

確保量は 1 ブロックのテンポ点の最大密度とループの span 数から求め、1 サンプルに最大 1 通知で抑える。
通常の一定テンポは 1 枠、全体のテンポ点数やトラック数の固定上限は設けない。
前の計画のノート解放用の予約でチェイン容量を更新する時も、時刻の予約分を残す。
音声側で確保・解放・ロック・時計の追加読取りをせず、借用はそのブロックだけで終える。
保存形式・IPC・C ABI・依存は変更しない。

## 回帰と基盤

実ヘルパーの製品経路は、修正前に終了コード 101 と `engine transport missing or block-dependent` で失敗した。
証拠は `target/focused-checks/engine-transport-red/` に残す。
4 段（子の 2 FX・親・独立トラック）を通し、1・7・64・127 フレームで拍位置・テンポ・再生フラグを比較する。
負の位置からの再生、ブロック内のテンポ境界、30 サンプルのループ、停止中の保持位置を確認する。
時間の閾値を測るテストではなく、実機を開かない波形の回帰である。

単体回帰は両時刻系・小節・7/8 拍子・ループの全メタデータ、同じサンプルへ丸める点と予約の密度を検査する。
通常の音源と時刻通知の共存は `tests/block_size/tempo.rs` で、1・2・13・31 サンプルのループと複数のブロック長を比較する。
必須契約 `plugin-musical-transport` は先頭の生成を外す反例を持ち、通常の検査と既存の RTSan 選択に含める。
Makefile の契約入口と通常テストの入口は既存のものを使い、選択条件を重複させない。
診断手順・コードの所在・設計・Phase 2・制約を更新する。
第三者の同期モードと聴感は自動検査では判定できないため、UC-85 に残す。
