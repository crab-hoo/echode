# ADR 0088: スキャンの出力は子の実行中に読む

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-15。プラグインフォルダのスキャン

## 背景

スキャンは、子プロセスの終了を待ってから標準出力と標準エラーを読んでいた。パイプの容量を超える出力は子の書き込みを止める。正常な一覧でも 5 秒で打ち切り、そのバンドルの版として失敗が残った。

## 決定

子を起動したあと、終了を待つ前に両方を読む。標準出力は最後まで読む。標準エラーは 64 KiB まで保持し、超えた分は捨てて末尾に省略を付ける。期限で打ち切るときも、成功したときも、読んだスレッドの終了を待ってから結果を返す。期限は 5 秒のままである。

## 結果

標準エラーへ 256 KiB を書き、128 件のプラグインを返す子は、実行中に読み終わる。128 件がプラグインとして残る。画面での操作確認は未実施である。
