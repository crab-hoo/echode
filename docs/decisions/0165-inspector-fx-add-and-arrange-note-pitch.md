# ADR 0165: インスペクターの FX 追加ボタンと、アレンジの MIDI クリップの音高表示を要件へ加える

- 日付: 2026-10-25
- 状態: 採用。インスペクターの FX 追加は接続済み、音高表示は未実装。[2026-10-25 の操作の報告](../reviews/2026-10-25-user-feedback.md) の FB-07・FB-08
- 関連: [ADR 0118](0118-track-fx-chain-editing.md)、[ADR 0134](0134-plugin-window-lifetime-and-shortcuts.md)、
  [ADR 0139](0139-track-header-fx-names.md)、[ADR 0050](0050-arrange-viewport.md)

## 背景

2026-10-25 に、次の 2 件の追加の要望が届いた。

- インスペクターにも FX 追加ボタンが欲しい。
- MIDI クリップは、他の DAW のようにノートの位置の上下関係を表示して欲しい。

既存の仕様を照合した結果、どちらも未定義だった。

- [操作要件](../interaction-design.md#デバイスビューと-fx-一覧の役割) は、トラックヘッダ・インスペクター・ミキサーを FX の一覧を扱う場所とする。
  追加の入口は、トラックヘッダの FX ボタン（ADR 0118・ADR 0139）と、デバイスビューの最後のデバイスの右（ADR 0134）だけである。
  インスペクターは挿入済みの名前（独自 GUI を開く）と削除だけを持つ。
- アレンジは、ノートを時刻の位置にレーンの高さの 72% の帯として描く（`echode-draw` の `note_element`）。
  音高は描画にも可視列にも使っていない。操作要件・設計書・Phase の計画に音高の表示はない。

## 決定

### インスペクターの FX 追加（P2-02 で実装する）

- インスペクターの「プラグイン」の一覧の末尾に、FX 追加ボタンを置く。チェインが空でも表示する。
- 押すとそのトラックを入力先に選び、既存の非モーダルの候補パネルを開く。トラックヘッダの FX ボタンと同じ経路
  （`WorkspaceSession.openPlugins(on:)`）であり、候補パネル・追加先の確定・単体追加後の独自 GUI の規則は変えない。
- 文書の交換・終了の排他（`busy`）の間だけ無効にする。インスペクターの一覧の名前のクリックで独自 GUI を開く規則（ADR 0132）は変えない。
- P2-02 へ接続済み。`WorkspaceInspectorView` の `InspectorAddFX` が既存の入口を呼び、モデル・保存・音は変えない。

### アレンジの MIDI クリップの音高表示（P2-07 のアレンジ編集の最初に実装する）

- MIDI クリップの中のノートを、時刻に加えて音高の上下関係で描く。高い音ほど上に置く。
- 縦の範囲はクリップの中身（content）ごとに、そのノートの最低音から最高音までとする。
  表示中の時刻の範囲で縮尺を変えず、同じ中身を共有する配置は同じ見え方にする。
  範囲が 12 半音より狭い時は 12 半音として中央に置き、1 音だけのクリップも細い線として見える。
- ノートの高さはクリップの描画域の高さを範囲の半音数で割った値とし、1 pt を下限にする。
  クリップの名前・ハンドルの帯は避ける。色は従来どおりトラックとクリップの色に従う。
- 表示だけの変更とする。アレンジのクリックは従来どおりクリップの選択・移動に使い、ノートを直接編集しない。
  ノートの可視要素（VoiceOver）は残し、位置と大きさを描画と一致させる。
- 範囲は中身の索引（`ArrangeIndex` の中身ごとの情報）を作る時に一度だけ求め、フレームごとにプロジェクト全体を走査しない。
  トラック数・ノート数・音域に固定の上限は設けない。
- 時期: P2-07 のアレンジ編集の最初に置く。枠選択・編集区間・重なりのモードに依存せず、コード→メロディの制作シナリオで
  曲の構成を見渡すのに先に効くためである。トランスポートの残り（Return の割当）とは独立に進めてよい。

## 受入の条件

- インスペクター: 実 View のボタンから候補パネルの文書と入力先トラックが決まり、空のチェインでも開けることを、
  トラックヘッダの FX ボタンと同じ必須契約の形で確認する。
- 音高表示: `echode-draw` の可視列のテストで、音高から縦位置への対応、12 半音未満の中央寄せ、1 pt の下限、
  クリップの帯を避けることを確認する。Swift ではオフスクリーンのアレンジのフレームで、描画とアクセシビリティ要素の位置の一致を確認する。
  S1 の描画計測（[S1](../spikes/S1-drawing.md)）の範囲で、可視ノートの問い合わせの時間が増えないことを確かめる。
- 実画面の見え方と VoiceOver はユーザー確認とする。
