# 0251. CLI の整数 WAV へ TPDF ディザを接続する

日付: 2026-11-03。
状態: 採用（FCA-16・P2-08 の CLI 先行分。GUI・設定保存・聴感確認は含めない）。

## 背景と再現

PCM16 / PCM24 と RF64 の後も、整数への書出しは丸めだけで、低レベルの音に相関した量子化誤差を緩和する選択肢がなかった。
既存の余韻の指定（[ADR 0250](0250-explicit-export-tail.md)）と出力保全は維持する。
実 CLI の `dither_cli_reproducible_tpdf_at_both_integer_depths` を先に追加し、`--dither tpdf` が usage で拒否されることを確認した。
期待した終了コード 101 と固有の `TPDF CLI export failed: echode: usage: echode render` を照合した。

## 既存実装の採用

[ADR 0014](0014-existing-implementations-as-options.md) に従い、三角分布と疑似乱数生成を自作しない。
`rand_distr` 0.5.1 の `Triangular(-1, 1, 0)` と、既存の依存グラフにある `rand_chacha` 0.9.0 の `ChaCha8Rng` を採用する。
いずれも MIT OR Apache-2.0 で、GPL-3.0-or-later と両立する。
`rand_distr` の標本生成を確認し、対称な三角分布を直接使う。二つの一様乱数の差と同じ密度であり、矩形のノイズにはしない。
既存の `fastrand` は一様分布の PRNG で三角分布を提供しないため、今回の標本生成には選ばない。
外部の ffmpeg プロセスへの委譲は行わず、既存の WAV ライターの量子化の境界へ接続する。

`std_math` を使い、オフラインの書込み側だけで標本を作る。
固定 seed の 262,144 標本で、支持域 ±1 LSB、平均 0、二乗平均 1/6、左右と隣接標本の相関を回帰検査する。
速度は `make spike-render` の 60 秒・48 kHz・ステレオで、PCM16 / PCM24 のディザ有無を同じ製品ライターで比較する。

### release 計測

Apple M4・macOS 27.0（26A428）で、60 秒の定常ステレオを 256 フレームずつ書いた 1 回の値である。
ファイル同期と公開までを含み、プラグインの処理時間や実機の再生時間ではない。

| 形式 | ディザなし | TPDF |
|---|---:|---:|
| PCM16 | 56.9 ms | 150.8 ms |
| PCM24 | 44.8 ms | 155.5 ms |

ログは `target/verification/spike-render.log`。全組合せに既存の一括書込みと同じ 2 秒の基準を適用する。
ファイルシステムのキャッシュや同期時間で変動し、機種一般の性能保証や他実装との優劣の証拠にはしない。

## 決定

- `echode render PACKAGE WAV --format pcm16|pcm24 --dither none|tpdf` を追加する。
  既定は `none`。float の既定と公開 Rust の `render_to_wav` / `write_wav` の出力を変えない。
- TPDF と float の併用、不明なディザ名はプロジェクト読込み・ヘルパーの開始・出力作成より前に拒否する。
  オプションの順序は問わない。空の PCM 出力も受け付ける。
- 非有限値の検証の後、既存の f64 の `sample × 2^(bits-1)` へ三角分布の標本を足し、最近接へ丸めて飽和する。
  半整数をゼロから遠ざける既存の規則を保つ。非クリップ領域の差は最大 1.5 LSB、量子化誤差の二乗平均は 1/4 LSB² である。
  ノイズシェーピング・ノーマライズ・ゼロ入力の抑制はしない。無音にもノイズがあり、クリップ済みの音を復元するものではない。
- ファイルごとに `[0x45; 32]` の seed から開始し、LRLR の順に標本を消費する。
  ブロック境界・空の書込み・出力先・長さから seed を作らず、左右に同じ標本を流用しない。
  同じロック済み依存・入力・設定なら再書出しと先頭部分は一致する。将来の実装・依存更新をまたぐバイト互換は保証しない。
- ヘッダ・RF64 の切替・余韻・復旧したスナップショット・一時ファイルと公開手順は共用する。
  公開前の失敗では原本を保ち、公開後の親の同期失敗では完成ファイルを残して耐久性不明を返す。

## 回帰と基盤

- `tests/dither.rs`: 実 CLI の両深度、空・短い・部分ブロック、再書出し・先頭一致、無音の分布、独立した AudioToolbox 復号、入力拒否と出力保全。
  配置音声と隔離 Sine Pad を float と比較し、形式・LR の順序・長さ・最大誤差を検査する。
- `src/dither_tests.rs`: 既存標本器の分布、分数 LSB の入力に対する平均と二乗平均、左右・隣接標本、ライターの分割不変性、極大値の飽和。
  非有限値と書込み・flush・rename・親の同期の故障を両深度で確認する。
  全書込みテストは既存の `WRITER` mutex を取り、プロセス共通の故障注入と直列化する。
- エンジンの発音・製品バッファを変えない。ブロック長の回帰は新しい音源としてエンジンへ足さず、実際に変わるファイル変換の境界で検査する。
- 通常回帰は既存の CLI テストへ含める。`spike-render` に整数 PCM と TPDF の比較を登録し、Makefile・検査の目的・選択回帰を更新する。
  時間のしきい値は ignored の release 計測だけに置く。
- README・設計・P2-08・現在の制約・監査の対応参照を更新し、再現時に形式・ディザ・復旧版・Cargo.lock を集めるデバッグ手順を追加する。
  ログ・成果物の形式と収集先は変えないため、doctor と debug-report の収集範囲は変更不要である。

## 残る範囲

GUI の書出し、プロジェクトごとの設定保存、ノイズシェーピング、ノーマライズ、他形式、u32 を超えるフレーム数は未接続である。
実機での小音量・余韻と利用者の読み手による聴感確認は UC-52 とし、自動の分布・復号・誤差比較で代用しない。
