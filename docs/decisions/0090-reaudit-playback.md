# ADR 0090: 再監査の再生・状態・期限

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 REA-01 から REA-10、および HAL コールバックの期限

## 背景

2026-10-14 の再監査は、イベント容量、追跡ノートの配送、プラグイン状態、共有ノートの時刻、スキャンの待ち、復旧ラベル、波形の素材位置、HAL の期限に残件を見つけた。ADR 0089 の「書き出しの識別は自動保存の先端 id」という一文は、この決定で置き換える。

## 決定

イベント領域は、ループに掛かるノートだけを、最大ブロックをループ長で割った回数ぶん用意する。ループが無ければ各ノートは一度である。追跡枠は同時発音数で、フレーム数では倍にしない。容量は制御スレッドで準備し、ループの変更と一緒に差し替える。

追跡のノートオンは、整列済みの通常イベントへ時刻順に混ぜる。同じ時刻ではオフが先で、追跡は先に書いた側として残る。配送は、未送信、この世代で送信、処理が成功してから受信、の三段である。失敗した世代は送り直さず、次の準備でヘルパーを作り直す。

保存バイトはデバイスの id に付ける。同じ CLAP id でも別デバイスである。バイトが変わった段だけ制御スレッドで作り直し、他の段と保持中のノートは残す。dirty は音声スレッドでは待たない。制御スレッドが保存を依頼し、応答が来てからオブジェクトへ書き、その後に文書のジャーナルへハッシュを載せる。保存中に再度 dirty になった分は、その応答では確定しない。

ノートの時刻か長さを変える操作は、成功を返す前に、その中身を指す全部の配置で原点、絶対開始、絶対終端を検査する。溢れる操作は拒否し、プロジェクトとジャーナルは変えない。

スキャンの期限は開始時の一つで、子の終了と両パイプの読取を含む。パイプは非ブロックで poll する。期限ではハンドルを閉じ、そのスキャンのプロセスグループだけを止めて回収する。

復旧のラベルは、実際に読めたコミット id と、そこへ適用したジャーナル連番である。文書を開いたときに一度決め、後から先端コミットで作り直さない。書き出しはこの組と、同じ時点のスナップショットを使う。

波形の列は、再生が読む素材範囲である。配置の offset と長さを、ファイルのサンプルレートでフレームへ換算する。ファイルを超えたサンプルは無音である。表示はゲインとフェードの前の素材である。換算する区間は配置原点から窓の開始までで、負のオフセットは無音である（[ADR 0109](0109-placement-bounds-and-plugin-capture.md)）。

HAL の期限は、コールバックに入った時刻に、準備したレートでのブロック長を足した絶対時刻である。形式検査のあとに現在時刻から取り直さない。

## 結果

各項目の回帰は、対応する `audit_rea` テストで確認する。画面での操作確認は未実施である。
