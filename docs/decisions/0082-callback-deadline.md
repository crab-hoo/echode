# ADR 0082: コールバックの期限は入口で決める

- 日付: 2026-10-14
- 状態: 採用
- 範囲: 監査 PRO-17。再生コールバックの期限

## 背景

ADR 0079 は、複数のヘルパーが同じ期限を共有するようにした。その期限は、イベントの整列、内蔵音源、クリップの混合、プラグインへの依頼が終わったあとに、その時点から 1 ブロック先として作っていた。前段が長いほど、プラグインに残る時間は短くなり、最後のフェーダーと混合の分も残らなかった。

## 決定

デバイスのコールバックは、入った瞬間に絶対期限を決める。期限は入口の時刻に、そのブロックの長さを足したものである。プラグインから結果を受け取る期限は、そこからブロック長の 8 分の 1 を引いた時刻にする。残った時間は、フェーダー、混合、メトロノームに使う。8 分の 1 はこのブロックの取り分であり、トラック数の上限ではない。

時刻を読むのは、確保を禁止する区間の外である。受け取りと比較は、これまでどおりコールバックの中で行う。ライブ再生は期限を超えても失敗フラグを立てない。書き出しだけが、その超過を失敗として読む。

## 結果

ハングしているヘルパーの隣に健康なトラックがあるとき、前段を飛ばして期限を入口時刻にした受け取りは、1 ブロックより前に戻る。ライブ再生の失敗フラグは立たない。画面での操作確認は未実施である。
