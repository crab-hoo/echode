# 0017. フォルダは親の ID で表す

- 日付: 2026-10-08
- 状態: 採用

## 背景

トラックに種別はない。フォルダは、子トラックの出力を受けるバスでもある（ARCHITECTURE §8.4）。深さに上限は置かない。バスとして音を足す処理は Phase 2 で、今は並びと所属だけを残す。

## 決定

- 各トラックは親の ID を 1 つ持つか、最上位なら親を持たない
- 子トラックは、親の直後から、その親の既存の子孫のうしろまでに入る
- 親を変えても、子は付いたまま動く。並べ替えはしない
- 自分自身や、自分の子孫を親にはできない
- 保存するトラックの JSON に `parent` を書く。無いファイルは最上位として読む

## 結果

子が親のうしろに並ぶこと、循環と欠けた親を拒否すること、64 段まで辿れることをテストで確かめる。64 はテストが辿る段数であり、モデルの上限ではない。
