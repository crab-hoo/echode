# 0277. フォルダは Reaper と同じく、子の音を親トラックへ通す

- 日付: 2026-11-08
- 状態: 採用（意味の決定。製品への接続は未実装）
- 関連: [ADR 0024](0024-track-order.md)、[ADR 0116](0116-folder-drum-rack.md)、[ADR 0191](0191-selected-track-numeric-mix.md)、
  [ADR 0244](0244-folder-mute-and-solo-gates.md)、[FCA-06](../reviews/2026-11-03-full-code-audit.md#fca-06-フォルダのミックス操作が子に効かない)、
  [設計書 8.4](../architecture/audio-engine.md#84-フォルダ)、[P2-03](../phase2.md#p2-03-ルーティングフォルダバスpdc)
- 置き換え: [ADR 0276](0276-priority-order-and-delegated-decisions.md) の「フォルダの音量・パン（FCA-06）」の行

## 背景

ADR 0276 は、バス化までの間、祖先の音量とバランスを子孫の実効フェーダーへ係数の積として掛けると決めた。
この方式は、親に FX がない時だけバスと同じ結果になる。親の FX は親自身の音にしか掛からず、親のトラックだけが普通のトラックと違う振る舞いになる。

2026-11-08、ユーザーが Reaper に従うと指定した。
Reaper では、子トラックの音は親トラックを通り、そこで親のフェーダー・パン・FX を受ける。親と子の操作は互いに独立している。
Echode もトラックに種別を作らない（[PLAN の Phase 1](../PLAN.md#phase-1-打ち込んで鳴らして残す完了)「種別のないトラック」、[ADR 0024](0024-track-order.md)）。
したがって、親のトラックも普通のトラックと同じに扱う。

## 決定

- 子を持つトラックは、子の出力を受けるバスを兼ねる。
  子の出力は親トラックの入力へ加算し、親自身の素材と音源の出力と合わせて、親の FX チェイン・親の音量とパンの順に通す。
  その結果を、さらにその親へ、最上位ならマスターへ送る。入れ子の深さに上限を置かない。
- 子を持つかどうかで、操作子・FX チェイン・素材の扱いを変えない。親にもクリップ・音源・FX を置ける。
- 操作は独立させる。親の音量・パン・FX を変えても、子の保存値を書き換えない。子の操作も親の値を変えない。
- 親と子を同時に選んで一括で変えた時は、それぞれのトラック自身の値を変える。音の上で二重に効くことを防がない（Reaper と同じ）。
  [ADR 0191](0191-selected-track-numeric-mix.md) が P2-03 へ残した二重適用の判断は、これで決める。
- 親のメーターは、子の和を含む親のフェーダー後の値になる。
- ミュート・ソロは、[ADR 0244](0244-folder-mute-and-solo-gates.md) の意味を保ったまま実装を始める。
  子だけをソロにした時の親自身の素材の扱いなど、Reaper と違う点が分かったら Reaper に合わせ、実装の ADR で ADR 0244 を置き換える。
- 暫定の係数の積は実装しない。保存形式とアクションは変えない（親子関係はすでに保存されている）。

## 実装と受入

- P2-03 のうちフォルダバスを、センド・サイドチェインより先に、FCA-06 の解決として実装する。PDC は P2-03 の残りとする。
  親の FX の遅延は子の全体に同じだけ掛かる。兄弟の間の遅延のずれは、今と同じく未補正のまま残る。
- 計画は制御側で作り、子を親より先に処理する順序と加算をそこで決める。オーディオスレッドで木をたどらない。確保・ロックを足さない。
- 受入は [P2-03](../phase2.md#p2-03-ルーティングフォルダバスpdc) に従う。少なくとも次を製品バッファで確かめる。
  親に FX がある・ない場合の子の和、入れ子、親自身の素材と子の合流、親の音量・パン、ミュート・ソロ、親の付替え、
  ブロック長 1・7・64・512、48・96 kHz、製品再生と書出しの一致、RTSan。
- 既存のプロジェクトで、親の音量・パン・FX が子へ効き始めると、音が変わる。
  これは意図した変更であり、基準音声が変わる時は [ADR 0276](0276-priority-order-and-delegated-decisions.md) の `make bless` の条件に従う。聴感は UC-47・49 に足す。
