# ADR 0384: CLAP の音声構成を明示要求で走査・選択する

- 日付: 2026-11-16
- 状態: 現行
- 領域: プラグイン・隔離
- 対象: P2-03・F2・FCA-07 の `clap.audio-ports-config` の制御境界
- 関連: [ADR 0382](0382-audio-port-changes-exchange-mapping-and-routing.md)、[ADR 0199](0199-owned-helper-control-requests.md)

## 背景と再現

開始時の HEAD は `99be8f3`。
プラグイン自身の音声ポート変更は追えるが、ホストからポート構成のプリセットを選ぶ入口がなかった。
CLAP の [audio-ports-config.h](https://github.com/free-audio/clap/blob/main/include/clap/ext/audio-ports-config.h) は、一覧の走査と選択を無効化中の主スレッドへ限定している。

検査用プラグインの音声ポートの probe に構成のホスト拡張と rescan の呼出しを加えた。
修正前の実ヘルパーは `audio-port capability/lifecycle probe failed`、終了コード 101 で失敗した。
証拠は `target/focused-checks/audio-config-red/` にある。
最初の実行は古い fixture と不完全なテスト名で 0 件になったため、red の根拠には使わない。

## 比べた案と決定

- **再生中にそのまま走査・選択する**: 不採用。CLAP の生存期間の規則に反し、処理器とポートが食い違う。
- **起動時の一覧を保持し、rescan ごとに再構築する**: 今回は不採用。
  メニューが未接続の段階で、保持する一覧・改訂・再走査の状態と、その同期規則を増やす。
  rescan だけで音声を中断することにもなる。
- **明示した制御要求の時だけ無効化して読む／選ぶ**: 採用。
  一覧を保持せず、`rescan` は何も呼び戻さない。次の要求は常にその時点の一覧を読む。
  一覧の読取りでも処理器を再有効化するため音声を中断する。周期的なポーリングには使わない。

`PluginControl::audio_port_configs` と `select_audio_port_config` を制御専用の入口にする。
今回 GUI・C ABI・文書アクションは足さない。メニュー接続時は明示操作と状態取得・Undo の経路を組み合わせる必要がある。
現在選ばれている ID の永続キャッシュや、プロジェクトの保存項目は増やさない。
選択の保存はプラグイン自身の状態に依存し、検査用の保存・復元を回帰に含める。

## 所有権と交換

- 既存の `MainRequests` に無効化が必要な要求を区別する述語を足す。
  通常の主スレッド処理では取らず、音声スレッドが処理器を返し、deactivate が戻った後にだけ取る。
- 制御側の `call_main` が既存の再起動世代で停止と主スレッドへの引渡しを進める。
  主スレッドは要求を実行し、共通の `reactivate` で音声・ノートのポート、遅延、余韻を読み直してから応答する。
  既に完了した世代について、再開済みの処理器が止まるのを制御ループが再び待たない。
- 選択が拒否されても、ポートを読み直して再有効化する。
  成功した選択は dirty とし、既存の状態取得へ流す。
  `PortsChanged` は応答より先に送り、単独の利用者も直後の `follow_ports` で追えるようにする。
- ポートの共有領域とルーティングは ADR 0382 の交換をそのまま使う。
  不一致の間は無音とし、曲のノートの再送と計画の拒否も既存の経路に従う。
- 時間切れの要求は入力と応答の所有権を残し、結果不明として返す。自動再送しない。
  無効化・再有効化に失敗して停止した場合も、成功した選択とは報告しない。
- 音声側にロック・確保・解放・時計・IPC は追加しない。
  一覧の記憶域は構成数に比例し、ID の重複は集合で検出する。固定の構成数の上限は設けない。

内部 IPC には一覧要求・一覧・選択・完了・拒否（39〜43）を足す。
一覧は ID・名前・ポート数・主ポートのチャンネル数の要約で、選択後の正確な構成は必ず `audio-ports` から読む。
optional な型のポインターは追わず、名前は固定長の記述の範囲だけを複写する。
欠けた callback・不正な ID・重複・記述の失敗・主ポートの矛盾と選択の拒否は型付きの原因で返す。
ソケットからの一覧は既存の `Cursor` で読み、予約を本文の長さで制限し、切詰め・不正 UTF-8・末尾の余分を拒否する。

## 回帰と基盤

`isolation/audio_ports.rs` は一覧・列番号とは異なる ID・主スレッドかつ無効化中の呼出し、選択後の境界変更と古い共有領域の無音を通す。
1・32・127・256 フレーム、選択の往復・拒否後の復帰・拡張なし・状態の保存と復元を照合する。
`hosted_playback/audio_ports.rs` は製品のデバイス制御から選択し、母線への等電力の接続と書出し再開の合図を照合する。
単体回帰は所有権、欠けた callback、不正な記述、名前の境界、内部応答の型とソケット本文の構造を確認する。

必須契約 `plugin-audio-config-selection`・`plugin-audio-config-routing` と反例、変更領域の選択のテストを登録する。
既存の Makefile・通常の隔離回帰・`audio_ports` の RTSan 入口を使い、新しい検査コマンドは増やさない。
fuzz は既存の制御ソケットの対象が新しいメッセージも通すため、対象を増やさない。
設計・制約・進捗・監査の現在欄・コードの所在・診断とユーザー確認を更新する。

一覧走査の中断時間と、第三者の選択の保存・互換性・クリックは未計測で UC-97 に残す。
構成メニュー・`audio-ports-config-info`・`configurable-audio-ports`・曲の表情生成等は残り、P2-03・F2・FCA-07 全体を完了とはしない。
