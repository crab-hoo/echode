# ADR 0173: 単一ノートの Option ドラッグと共通入力ベロシティ

- 日付: 2026-10-26
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver・聴感はユーザー確認待ち
- 関連: [ADR 0027](0027-note-expression.md)、[ADR 0117](0117-workflow-interactions.md)、[ADR 0172](0172-piano-click-and-input-length.md)

## 背景と再現

[操作要件](../interaction-design.md#ベロシティの編集) は、ノート上の Option＋上下ドラッグと入力値の共有を求める。
`484fcda` では Option を押しても通常の移動が始まり、新規ノートは常にベロシティ 100 だった。
実 View の押下・ドラッグ・解放を通す回帰を先に追加し、幾何編集が送られる失敗を確認した。
終了コードと固有のアサーションは `target/focused-checks/note-velocity-red/` に記録した。

## 決定

- 単一ノートの Option＋左ドラッグをベロシティ専用とする。端でも移動・伸縮へ入らない。
  押下時にモードと元の値を保持し、途中で Option を離しても変更しない。Command 付きはこの操作へ入れない。
- 上へ 1 pt で 1 段増加、下へ 1 pt で 1 段減少し、`0..=127` へ制限する。
  時間グリッド、Shift、ズーム、横方向の移動から独立する。0 は無音である。
- ドラッグ中はモデルを変えず、ノート下端の値の比率と数値を同じ Metal フレームで仮表示する。
  解放時の座標から再計算し、変更がある時だけ 1 回送る。クリックのみ・元へ戻る操作は履歴を増やさない。
- Escape、フォーカス喪失、入力取消、スクロール・ズーム、リサイズ、スナップショット・トラック交換、処理中、終了で破棄する。
  遅れた解放は記録しない。描画が古い時は新しい押下を受けない。
- 製品アクション `note.velocity` は `track`・`clip`・`note` と MIDI 1.0 の `velocity` を受ける。
  対象配置の中身に属するノートだけを変更し、同じ内容をリンクした配置にも反映する。
  ノートの ID・時刻・音高・リリースと表情、配置の窓と自動／固定を保ち、再配置・窓の拡張はしない。
- 保存値は既存どおり 16 bit で、ADR 0027 の変換を使う。選択と表示は保存値の上位 7 bit を使う。
  任意の 16 bit 入力と編集は今回の範囲に追加しない。保存形式と旧 `note.edit` の意味は変えない。
- 単一選択と成功した調整で、全トラック共通の次回入力ベロシティを記憶する。
  次回のクリック・ドラッグ・Return・既存の挿入ボタンは同じ値を使う。
  ジャーナル応答待ち中の新しい選択を、古い調整の応答で上書きしない。
- 入力長と異なり、入力ベロシティは最後に選択・調整した値を保ち、Undo / Redo では巻き戻さない。
  プロジェクトへ保存せず、文書を開くたびに従来の既定値 100 で始める。
  Undo / Redo はノートの実際の値を戻す。入力長の履歴枠は従来どおり維持する。

## 受入と基盤

- `piano-note-velocity-ui` は実 View・controller・製品 ABI で、解放時の単一確定と幾何保持、
  仮表示・入力値共有・無変更と不正要求・Undo / Redo・保存再読込を確認する。
  負の対照は Option の分岐、解放時の再計算、選択の記憶、入力の値、応答後の記憶を個別に外す。
- `piano-note-velocity-cancel-ui` は取消後の解放を検査し、負の対照で取消を外す。
  通常回帰では上下限、不正座標、後続の選択と応答の順序も扱う。
- `note-velocity-model` は共有内容と固定窓、0・1・64・127、不正対象、履歴、
  ChangeSet あり／なしのジャーナル再生と保存を通す。ランダム操作生成にもアクションを追加する。
- `block_size.rs` は編集後の音量と無音を複数ブロック長で比較する。既存の音声 DSP と隔離処理は変更しない。
- 既存の `check-shell`・製品契約・ASan / TSan と検査選択を維持し、README・操作要件・現状・領域設計とデバッグ手順を更新する。
  外部入力や成果物・ログは増やさず、`doctor` と `debug-report` の収集範囲は変更不要である。
- 下部のベロシティレーン、複数選択の同量増減、ノートの試聴、Command 複製移動は未接続のまま残す。
  実画面の操作感・VoiceOver・音源ごとの聴感は、自動回帰の合格と区別してユーザー確認とする。
