# ADR 0155: 記憶した再生開始位置と、停止・一時停止を分ける

- 日付: 2026-10-25
- 状態: 採用。P2-07 のトランスポートの最初の単位。
  アレンジのルーラー、ルーラーのドラッグによるループ範囲、Return による一時停止は対象外

## 背景

[操作要件](../interaction-design.md#再生の開始位置) と [ADR 0117](0117-workflow-interactions.md) は、
記憶する「再生開始位置」と再生で進む「現在位置」を分ける。
停止は開始位置へ戻り、一時停止はその場から再開する。両ルーラーのクリックで開始位置を変え、再生中は即座にシークする。
開始位置はプロジェクトに保存し、開き直しても保つ。Space は再生／停止、Return は一時停止／再開とする。

実装では、`transport.stop` と `transport.pause` が同じ処理で、どちらも現在位置を保っていた。
Space は再生／一時停止で、開始位置の概念はトランスポートの「開始拍」欄の位置移動だけだった。
ルーラーはピアノロールにだけあり、クリックを受けていなかった。アレンジにはルーラーがない。

停止で位置を戻すために既存の `Locate` を使うと、エンジンは停止の余韻を打ち切り、プラグインの DSP をリセットする
（[ADR 0099](0099-transport-plugin-state.md)）。
これは、停止・一時停止でもプラグインの処理と余韻を続けるという [ADR 0133](0133-stopped-plugin-processing-and-edit-input.md) と衝突する。

## 決定

- 音声セッションが開始位置（tick）と一時停止の状態を持ち、`audio.status` で `start` と `paused` を返す。
  - `transport.stop` は一時停止と同じく停止し、続けて再生位置を開始位置へ戻す。
  - `transport.pause` はその場で止める。再生中か一時停止中に受けた時だけ `paused` にする。
  - `transport.play` は現在位置から鳴らす。停止後は開始位置、一時停止後は止めた位置になる。
  - 新しい `transport.set_start { tick }` は開始位置を記憶して保存し、再生位置をそこへ動かす。
    再生中は従来の位置移動と同じくシークして再生を続ける。一時停止は解除する。
  - `transport.locate` は現在位置だけを動かし、開始位置を変えない。
- エンジンに `PlaybackCommand::Rewind(sample)` を足す。
  再生中なら停止を始め、時計と譜面のカーソルだけを移す。プラグインのリセットと停止の余韻の打ち切りはしない。
  停止の余韻は自分の位置から描くので、時計を動かしても途切れない。
  シーク（`Locate`）は従来どおり余韻を消してリセットする。
- 未発音の開始の取消（`cancel_unheard_start`）は、同じブロックで停止を処理済みなら時計を戻さない。
  戻すと、一時停止の位置から始めた再生をすぐ止めた時に、`Rewind` で戻した開始位置を上書きする。
- 開始位置はパッケージ直下の `transport.json`（`{"version":1,"start":<tick>}`）に置く。
  モデル・ジャーナル・Undo の外であり、自動保存のツリーはモデルからだけ作るので、履歴にも入らない。
  - 原子的に置き換え、fsync はしない。クラッシュ後は直前か新しい値のどちらかが残る。
  - 無い・壊れた・新しい版・負の値のファイルは 0 として読む。次の変更で置き換わる。
  - リンクは辿らない（読込みは 0、書込みは失敗）。
  - 書込みに失敗した `transport.set_start` はエラーを返し、開始位置も再生位置も変えない。
  - 文書を開く時に読み、初期の再生位置も開始位置にする。
- ループ範囲は従来どおり保存しない（[ADR 0055](0055-loop-metronome.md)）。
- アプリの操作は次のとおり。
  - Space（メニューの「再生／停止」）は、再生要求中なら停止、それ以外は再生する。
    コマンド名は `Play / Stop` に改め、プラグインの独自ウィンドウから中継する名前（`PluginCommand::name`）も同じ名前にした。
  - トランスポートの再生ボタンとメニューの「一時停止」は一時停止／再開である。停止ボタンと ⌘. は停止。
  - ピアノロールのルーラーの押下で開始位置を変える。ノートと同じグリッドの最寄りへ吸着し、Shift で吸着を外す。
    鍵盤とディグリーの見出し部分では変えない。
  - ルーラーには開始位置に緑の印（縦線と旗）を描く。ルーラーの外にある時は描かない。
  - トランスポートの「開始拍」欄は開始位置を表示し、確定で `transport.set_start` を送る。入力中の下書きは保つ。
  - controller は `playbackStart` を位置の定期取得と別に公開し、ルーラーは開始位置が変わった時だけ描き直す。
- Return による一時停止は未接続とする。メニューのキー割当にすると、ピアノロールのノート挿入・ブラウザの配置・入力欄の確定と衝突する。
  割当はユーザーの判断を待つ。
  2026-11-08 注記: [ADR 0181](0181-piano-reference-workflow-and-keys.md) で Return を一時停止へ割り当てた。以後のキー割当は [ADR 0276](0276-priority-order-and-delegated-decisions.md) でエージェントが決める。
- アレンジのルーラー（クリックで開始位置、ドラッグでループ範囲）は、アレンジの行の配置を変えるため次の単位で扱う。

## 受入と基盤

- 必須契約 `stop-return-tails` は実ヘルパーとテスト用 CLAP で、`Pause` と `Rewind` の後も時計が開始位置にあり、リセットせずに余韻が続くことを確認する。
  ノートオフで発音が終わり、再生すると開始位置のノートが再び鳴ることも 7・64・512 フレームと 3 つのチェインで確認する。
- 必須契約 `playback-start` は機器なしの出力で製品セッションを動かし、停止が開始位置へ即座に戻りつつ素材の減衰を切らないことを確認する。
  一時停止の保持と再開、再生中の開始位置の変更がシークして続くこと、パッケージへの保存と再オープンでの読込みも通す。
- ブロック長比較 `a_stop_returning_to_the_start_replays_the_same_audio_for_every_block_size` は、
  停止して開始位置へ戻った後の再生が 1 回目と全サンプル一致し、ブロック長 1・7・64・512 で同じことを確認する。
- `an_unheard_start_cancelled_after_a_stop_returned_keeps_the_start` は、未発音の開始の取消が `Rewind` の位置を保ち、再生中の取消は開始時の位置へ戻すことを確認する。
- `transport::tests` は、ファイルの往復、壊れたファイルと新しい版の既定値、負の値の拒否、リンクを辿らないことを確認する。
- 必須契約 `playback-start-ui` は、実ブリッジで Space が停止して開始位置へ戻ること、再生ボタンが一時停止を送ることを確認する。
  開始位置が Undo を増やさず、閉じて開き直すと戻ることも通す。
- 必須契約 `piano-ruler-start-ui` は、ピアノロールの実 View への合成クリックで、吸着・Shift・見出しとノート欄の除外、印の描画範囲を確認する。
- 実画面の操作感、ルーラーの印の見え方、停止で戻る時の聴感はユーザー確認とする。
