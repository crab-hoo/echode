# 0377. 自動配置の探索と参照更新を重ならない窓から切り離す

- 日付: 2026-11-16
- 状態: 現行
- 領域: モデル・履歴・保存・API
- 対象: 統合表の F12（[構造の評価の精査](../reviews/2026-11-08-structure-assessment-review.md)）
- 関連: [ADR 0022](0022-clip-content-and-placement.md)、[ADR 0117](0117-workflow-interactions.md)、[ADR 0170](0170-content-relative-auto-bars.md)

## 背景

現行の公開モデルは同一トラックの重複配置を拒否する。
重ねるモード・自動クロスフェードへ進む前に、監査が指摘した次の 2 つの前提を除く。

- `refit_hosts` は開始順の窓を左右へ一度ずつたどる。非重複なら終端も単調だが、包含する窓では成り立たない。
  小節範囲 `[-10, 0]`、`[-5, -5]` の右から `[0, 0]` を起点に探索すると、短い窓との隙間で止まり、長い窓も見落とす。
- 編集トラック `current` と `tracks` の古い写しが共存する。
  別トラックでの結合が古い写しを付替え、配置 ID の索引で `current` へ戻すため、新規配置は漏れ、変更済みのオフセットは古い値で上書きされる。
  現行の操作順は再適合前にそのような配置編集をしないが、複合編集を足すと破れる。

## 比べた案

| 案 | 判定 |
|---|---|
| 重複を許す時も、探索に使う全窓は非重複に限定する | 不採用。固定配置の壁と編集中の一時的な窓にも別の規則が要り、機能ごとに探索を分ける |
| 変化がなくなるまで全候補を反復走査する | 不採用。正しさの独立した対照には使うが、逆向きの連鎖で二乗になる |
| 左候補を終端順にし、参照の付替えは編集中の正本へ直接行う | 採用。永続索引と同期用の状態を増やさず、現在の非重複入力の線形探索を保つ |
| 編集トラックを先に `tracks` へ複製して、結合後に丸ごと戻す | 不採用。中間の複製と公開先の切替を増やす必要がない |

## 決定と実装

- 自動配置の発見は、開始順の窓から作る小節の閉区間を使う。窓の重複・包含・開始の一致を許す。
  起点は編集後のノートの範囲であり、元の窓の位置で探索を制限しない。
- 起点より開始が左の候補だけを、終端の降順で訪ねる。右候補は開始の昇順で訪ねる。
  左の包含窓が右の前線も広げ得るため、左を先に終える。
  隙間でその側を止め、接する候補を取り込むごとに範囲の和を取る。
- 左の終端が既に単調なら整列をしない。候補の収集・訪問は O(P + A)、左の終端が逆転する時だけ O(A log A) の整列を加える。
  P は配置数、A は自動配置数で、追加領域は O(A)。固定壁の費用は別に数える。
- 固定配置は結合しない。結合後の範囲が固定窓の占める小節に触れる候補は飛ばす。
  壁に阻まれた候補で探索を止めず、同じ小節を共有する別の候補も調べる。
  `FixedBars` は既に終端の累積最大を使っており、固定窓の重複や配列順に依存しないので変更しない。
- `refit_current`・`merge`・`retarget` には、別トラックから編集している時だけ、その編集トラックを可変借用で渡す。
  結合を行うトラックと編集トラックの 2 つを正本とし、`tracks` 内の両者の古い写しは読まず、書き換えない。
  その他のトラックは従来どおり対象のリンクがある時だけ複製する。
- 付替えは共通の処理で内容 ID を変え、現在のオフセットへ原点の差を加える。
  配置の追加・削除と、窓・ゲイン・フェードを保持する。ID の索引による事後同期は除いた。
  整数超過はエラーとし、呼出し元の非公開スナップショットを破棄する。元のプロジェクトは変えない。

## 回帰と測定

変更前に、次の回帰を終了コード 101 と各アサーションの文面まで照合した。

- `placement::host_tests::nested_left_windows_do_not_hide_a_reachable_host_behind_a_gap`: `nested left host discovery`。
- `placement::tests::linked_refit_retargets_staged_windows_without_resurrecting_deleted_links`: `retarget only content and the staged offset`。

重複配置を受け入れる製品入口はまだないため、重複の回帰は製品編集が使う `refit_hosts` を直接通す。
参照更新の回帰は正常な製品スナップショットから始め、編集側だけに配置の追加・削除・オフセット変更を段階化して再適合する。
現在の製品入口の回帰は、追加・編集・複製・削除・別トラックの固定リンク、変更セットの往復を引き続き通す。

- `placement::host_tests` は非重複と重複の両方を、独立した i128 の反復走査と照合する。
  固定壁、同じ開始、包含、負の時刻、整数上下端、元の窓から離れた起点を含む。
- `placement::tests::linked_refit_rejects_overflow_in_staged_link_offsets` は新規リンクの付替えでの整数超過を拒否する。
- 時間に依らない計数では、編集側の 1・64・256 配置を結合時に各一度だけ訪ね、結合しない時は 0 回と確かめる。
  同じ入力で、別トラックの再適合に伴うトラック複製は結合時も 2 回から 1 回へ減った。
  複数トラックのリンクを持つ 4・64・256 自動配置の結合でも、リンク側からの編集の複製は 3 回から 2 回へ減った。
  候補訪問は収集を含めて自動配置数の 2 倍以下を保つ。整列の比較と編集全体の時間はこの計数に含めない。

## 重なりを製品へ接続する時の境界

F12 は探索と参照更新の前提の対応であり、重ねるモード・クロスフェードの実装ではない。
公開するアクション、保存・ジャーナルの形式、不変条件、可視問い合わせ、音声索引、再生結果は今回変えない。

- 自動の結合は引き続きスマートクリップの規則とする。利用者が独立した層として明示的に重ねる配置は、同じ編集内で `fixed` に確定してから重ねる。
  自動の再適合で層を吸収したり、共有する中身を暗黙に統合したりしない。
- 複数窓に入るノートの追加先は、編集対象の配置 ID をアクションに記録する。
  現在の位置だけで最初の窓を選ぶ入口を、重複のある入力にそのまま流用しない。旧ジャーナルの解釈は維持する。
- 固定壁はノートの自動結合にだけ使う。重ねる着地やクロスフェードの対象選択には流用せず、重なる固定配置を消さない。
- 重複の受入は共通の不変条件から変更し、全組の可視問い合わせと発音を確認する。
  明示的な層の保持、複数の交差、フェード、Undo / Redo・ジャーナル・保存再読込・ブロック長の独立性を、その機能の回帰に含める。
