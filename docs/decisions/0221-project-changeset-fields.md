# ADR 0221: プロジェクトの変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。プロジェクトと変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0024](0024-track-order.md)、[ADR 0220](0220-tempo-changeset-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

テンポ点に続き、プロジェクトの拍子も差分・下書き・設定・復元で同じ項目の対応を手で列挙していた。
今回は結果を保つ構造整理であり、拍子編集の制約・保存形式・時間変換・再生音は変更しない。

## 決定

- `changeset_project.rs` の `project_fields!` に、拍子の `Property`・取得名とフィールド・型・`Value` を宣言する。
  差分、`ProjectState` の下書き、設定、`Project::from_arcs` による復元を表から生成する。
  宣言順は従来の更新順と復元の引数順を表す。
- プロジェクトは常に存在し、作成・削除の変更は追加しない。
  テンポ点・中身・トラックの集合の解決と検証は従来どおり `Draft` に残す。
  拍子の更新はテンポ更新の後、中身・トラック等の更新の前に置く。
- 拍子の分子・分母を整数のまま保つ。同じ小節長になる `6/8` と `3/4` も同じ値へ正規化しない。
  通常の `with_meter` はクリップのある文書を拒否するが、変更セットの適用は記録した拍子を書き、クリップを合わせ直さない。
  公開前の不変条件検査と、低水準の差分適用の責務は混同しない。
- 旧 `TrackOrder` と `Value::Ids` の組は無変更の成功として受け入れるが、状態へ保存せず差分にも出さない。
  順序は各トラックの親と分数キーから再構築する。余分な ID・重複 ID を持つ旧配列も従来どおり無視する。
- 更新の `before` は前提条件にしない。誤った値の型・項目・オブジェクトキーの拒否は保つ。
  後続の変更を拒否しても元のスナップショットは変更しない。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo の方式は変更しない。
  保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ独立した回帰を追加し、同じ公開入口で整理後の結果を照合した。

- `echode-history/tests/project_changesets.rs` は項目表を参照せず、拍子だけの差分の期待値を持つ。
  大きい分子・1 tick の小節・同じ小節長の別表記を、空文書と入れ子のトラック・固定配置・ノートを持つ文書で検査する。
  差分・適用・逆適用・二重反転とジャーナルの往復で、拍子以外の部分を保持する。
- 同じ回帰でテンポ・パラメーターを含む更新順、旧 wire 表記、不正な拍子の復号拒否、型とキーの混同を検査する。
  プロジェクト宛ての作成と削除を拒否し、更新の `before` と旧トラック配列の適用規則も照合する。
- 操作列の `properties.rs` では拍子の分子と分母を広げ、非 `4/4` の空の階層と固定配置のある初期状態を追加する。
  各編集の不変条件・拒否時の保持、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  素材・プラグイン・音声機器は開かない。

既存の `check` が新しい回帰も実行するため、実行入口・依存・検査選択の条件は変更しない。
新しい失敗経路やログ形式は追加せず、入力を含む既存のアサーションと検査ログで区別できるため、デバッグ基盤の変更は不要とする。
実機・実画面・聴感の合否と性能の改善は、この構造整理からは主張しない。
