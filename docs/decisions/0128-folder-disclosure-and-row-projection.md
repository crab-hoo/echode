# ADR 0128: フォルダ開閉を表示用スナップショットへ分離する

- 日付: 2026-10-20
- 状態: 採用。P2-02 のフォルダ開閉と折りたたみ時の追加位置を接続

## 背景

[ADR 0127](0127-positioned-track-insertion.md) は、追加位置を接続し、折りたたみ表示を残していた。
既存のアレンジはプロジェクトのトラック配列の添字をそのまま行番号としていた。
ヘッダだけから子を隠すと、タイムラインの矩形、ミックス値、選択、FX のドロップ先が別のトラックを参照する。
フォルダを閉じても、子の音声・モデル・履歴は変更しない必要がある。

## 決定

- 製品 ABI に、元のプロジェクトと索引を共有する表示用 `Snapshot` を加える。
  `echode_snapshot_project_arrange` は、折りたたむ UUID の列から、表示行と元トラックの添字の対応だけを作る。
  隠れる親の子孫を順に除外し、再帰もネストの上限も使わない。
- 名前、ID、デバイス、ミキサー、階層情報は同じ行対応を使う。
  描画は対応する可視行だけを単一問い合わせで訪ね、その表示行から配置・ノートの y 座標を作る。
  描画のための全トラック走査はプロジェクト変更時の階層作成と、UI 側の開閉時の表示対応作成に限る。
  選択に使う表示順もスナップショットと開閉状態が同じ間は再利用する。
- `TrackTreeInfo` は親 ID、子の有無、深さを保持する。
  空フォルダという別の種類は作らず、子があるトラックだけに開閉操作を出す。
  表示用ハンドルは元のハンドル・文書の終了後も保持でき、再生・ピアノロールの ID 問い合わせ・Undo は元のままとする。
- 展開状態は `WorkspaceState` に置き、ウィンドウ内の一時的な表示設定とする。
  開閉をジャーナルや Undo に積まず、プロジェクトを開き直した時は展開へ戻す。
  親を閉じても、入れ子の子フォルダの開閉状態は同じ文書を開いている間は保持する。
- Metal のヘッダに開閉記号と階層の字下げを描く。
  ヒット領域、左右矢印、VoiceOver の開閉ボタンを同じヘッダへ接続する。
  深い階層では字下げをヘッダの幅でクリップし、深さを制限しない。
- 選択中の子を隠した時は、見える親へフォーカスと選択を戻す。
  Shift 選択は表示順だけを対象にし、隠れた子を選択範囲へ混ぜない。
  FX のドロップとミックス操作も表示行から同じトラックを参照する。
- `TrackInsertionRequest` に操作時の `intoFolder` を保持する。
  展開中は最後の子、折りたたみ中は部分木の直後の兄弟へ追加する。
  非同期処理を待つ間の開閉変更で追加位置を変えない。

## 受入と基盤

- `FolderDisclosureTests` は、機器・ウィンドウなしの実ヘッダ入力から、行・配置・ノート・ミックス値の一致を確認する。
  Shift 選択、FX ドロップ、単一 Undo、折りたたみ時の追加と保存再読込、入れ子と左右キーも通す。
- `snapshot_ownership` の表示用ハンドル検査は、元ハンドル解放後の行・階層・ミックス値、再展開を確認する。
  null、ID 数のオーバーフロー、短い出力配列と canary を含め、既存の Miri の全 seed へ接続する。
- 必須契約を既存の `check-product-contracts` へ登録し、選択・負の対照・診断手順を更新する。
  表示用ハンドルは描画キャッシュの版も変え、古いフレームの入力反映を拒否する。
- 音声の処理、保存形式 5、フォルダのバス処理は変更しない。
  プラグイン GUI・パラメーター編集・通常複製等は P2-02 に残る。実表示と聴感の確認はユーザー担当である。
