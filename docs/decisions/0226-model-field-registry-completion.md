# ADR 0226: モデル項目の表を保存・ジャーナル・スナップショットまで共有する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の残り全体
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0028](0028-package-schema.md)、[ADR 0225](0225-track-package-fields.md)
- 監査: [SPG-09](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

[ADR 0214](0214-parameter-changeset-fields.md)〜[ADR 0221](0221-project-changeset-fields.md) で変更セットの生成を集め、
[ADR 0222](0222-parameter-package-fields.md)〜ADR 0225 でパラメーター・デバイス・ノート・トラックの保存も共有した。
中身・配置・テンポ点・プロジェクトの保存、ジャーナルの型と名前の対応、FFI 内のスカラーの転記は別に残っていた。
これらを完了し、音声処理や新しい編集機能の追加と混同しない。

## 決定

### 項目の宣言と保存

- 各オブジェクトの `*_fields.rs` を、モデル宣言と変更セットの共通の正本にする。
  差分・作成・下書き・設定・復元の生成と、作成と更新で異なる既存の順序を維持する。
- 中身は `ContentMetadata`、プロジェクトは `ProjectMetadata` の宣言・Serde・モデルとの変換も表から生成する。
  パッケージではスキーマ・同一性・子を別に復号し、残りのキーをメタデータで検査する。
  `flatten` と `deny_unknown_fields` の未対応の組合せは使わない。
- 配置はモデル型を直接 Serde へ通し、ゲインのビット等価比較も同じ表から生成する。
  レーンは引き続きタイムラインだけとし、未知のレーン・種類を受け入れない。
- テンポ点は tick を同一性とし、テンポ項目と保存用の平らな分数表現・両方向の変換を同じ表から生成する。
  分数の検証とマップの整列・重複・空マップの拒否は保持する。
- `AudioRef` の Serde を保存に使い、履歴の別の音声参照型と変換をなくす。
  形の復号と `AudioRef::check`、組立て後の不変条件検査は区別する。
- 保存のキー順・改行・1 ノート 1 行・浮動小数点表記・整数の精度を維持する。
  スキーマは 6 のままで、旧版の段階変換と省略時の互換も維持する。
  `document_track.rs` のレイアウト専用 formatter をメタデータ全体で共有する。

### ジャーナルの語彙

- `Property` の宣言と名前の符号化・復号を、モデル内の 1 つの登録簿から生成する。
  モデルのフィールド名と wire 名の相違（`min` / `minimum` 等）を保持する。
- `change_values.rs` の 1 つの登録簿から `Value`、保存用の形、両方向の変換を生成する。
  新しい項目が既存の値の種類を使う場合、値の登録簿への追加は不要である。
- actions のジャーナルはモデルの Serde を使い、別の `ValueRecord` と手書きの変換・名前の表を持たない。
  出力時は値を借用し、形の復号の失敗は従来どおり `CorruptJournal` へまとめる。
  ビット値、旧 null 音声の省略メタデータ、ID 列の順序と重複を保持する。

### 製品スナップショット

- デバイス・トラック・配置の表に、既存の公開スナップショットへの投影か非公開かを明記する。
  `echode-ffi` の安全なスカラー問い合わせと配置コントロールへの転記を表から生成する。
- C の関数・構造体のレイアウト、ポインタ検証と借用の寿命、Swift ラッパーは変更しない。
  新しい ABI を自動公開せず、公開対象の追加は明示的な ABI 設計として扱う。
- 階層・表示行・描画幾何、ミキサーのキー別の操作子、テンポ積分したフェード長は派生値であり、スカラー転記とは分ける。
  これらと子の解決・同一性の検査・編集規則は、生成のために汎用化しない。

## 回帰と診断

製品の保存・読込みとスナップショットの公開 ABI へ独立した期待値の回帰を先に追加してから置き換えた。

- `echode-history/tests/schema_fields.rs`: 残りのオブジェクトの保存バイト・再保存・差分・逆適用・ジャーナル。
  未知の項目、必須項目、型、レーン、参照、分数と値の範囲の拒否、原本の保持も検査する。
- `echode-history/tests/change_value_wire.rs`: 全種類の値の既存の wire 表記と全プロパティ名。
  整数端点、非有限の浮動小数点ビット、旧 null 音声、異常な型・ID・未知の項目の拒否を検査する。
- `echode-ffi/src/snapshot_fields_tests.rs`: 保存再読込みから元スナップショットの解放後の名前・プラグイン ID・
  バイパス・オフライン・ピン・配置の整数とゲインビットを製品 ABI で照合する。機器・ヘルパーは開かない。
- 既存のオブジェクト別の回帰・操作列の性質テスト・保存スナップショット・Swift の操作契約を維持する。

通常の `check` が追加したテストを含むため、新しい検査コマンドや選択条件は不要である。
診断は形・参照・組立て後の不変条件と ABI の寿命を区別し、収集先は増やさない。
SPG-09 の機械的な重複の整理は完了とするが、今後の項目追加に伴う編集規則・移行・エンジン・UI の設計は省略しない。
実機・実画面・聴感・性能改善は今回の構造整理の合否から主張しない。
