# ADR 0074: パッケージ内のファイル操作を、保持した親ディレクトリから行う

- 日付: 2026-10-13
- 状態: 採用
- 範囲: 監査 PRO-01。製品の JSON、ジャーナル、ロック、無視設定、音声保管庫とピークキャッシュ

## 背景

空の `tracks` / `contents` は読み込み時のリンク検査を省略していた。初回の自動保存はそのパスを走査し、パッケージ外の参照されない JSON を削除した。既存コミットからの復旧では作業ツリーの検査自体を通らない。保存の一時ファイルや `.gitignore` も、リンク先を直接書き換える経路があった。

パスを検査してから通常のファイル操作をするだけでは、検査の後のディレクトリ置換を防げない。

## 決定

`echode-history` の非公開 `package_io::Directory` は、親のファイル記述子を保持する。所有する子ディレクトリとファイルは `openat` と `O_NOFOLLOW`、種別の検査は `fstatat` と `AT_SYMLINK_NOFOLLOW`、削除と置換は `unlinkat` / `renameat` で、その親を基準に行う。OS の宣言と定数は既に使用している `libc` を使う。

利用者が選んだルートの別名は、DocumentHost の既存の正準化と所有権の契約を保つ。ファイル操作時はそのルート自体も `O_NOFOLLOW` で開き、開いたあとにルートがリンクへ置き換わった場合も拒否する。ルート以下の所有するパスもリンクを拒否する。空の一覧でも検査し、既存コミットから復旧する場合も省略しない。空の一覧に対応するディレクトリがまだ無いパッケージは受け付ける。

一時ファイルは排他的に新しい inode を作り、同じ親内で置換する。処理ごとに名前を分け、並行するキャッシュ書き手が互いの未完成ファイルを置換しないようにする。旧形式の一時名に残った通常ファイルは unlink し、リンクが置かれている場合は拒否する。ハードリンクした一時ファイルを truncate しない。直接書き換えるジャーナルやロック、コミット列の記録は、通常ファイルかつリンク数1を確認する。

外部 JSON の削除を再現したテストを通常検査へ移す。空・非空、先端コミットの有無、読み込み・復旧・初回保存・差分削除、一時ファイル、制御ファイル、ディレクトリ置換とハードリンク、保管庫の中間ディレクトリを検査する。並行する一時書き込みの結果も、いずれか一つの完成した内容であることを確認する。

保存スキーマとアクションは変えない。検査の対象は既存の `check` の Rust / Swift 検査に含まれ、選択は `verification.json` の history 領域を使う。

## 結果

修正前の回帰テストは、外部ファイルが消失して失敗した。修正後は読み込み・復旧・オープンを拒否し、外部の内容を維持する。保存系の回帰テストと、既存の保存往復・ジャーナル復旧・操作列の検査を通した。全体と動的検査の結果は `target/verification/report.md` に記録する。
