# 0263. 書出しの共通既定設定をこの Mac に保持する

日付: 2026-11-04
状態: 採用（P2-08 の共通既定設定。単位全体の受入完了ではない）

## 背景と再現

操作要件で未決だった共通デフォルトの保存先を、プロジェクトごとの前回設定とは分けて決める。
[ADR 0257](0257-portable-export-settings.md) のパッケージ設定は移動先でも戻るが、新しいプロジェクトへ同じ設定を使うには毎回入力する必要があった。

変更前の `68b723b` に、共通設定を用意して製品の `ProjectController.loadExportSettings` から新しい文書の設定を読む回帰を追加した。
`A fresh project must use this Mac's common export defaults` と終了コード 1 を照合した（`target/export-defaults-red/`）。
最初のコンパイル診断はこの red の証拠に含めない。

## 決定: 保存と優先順

- 共通値は UserDefaults の `workspace.export.default.v1` に JSON 文字列として保持する。
  既存の `ExportSettings.storedJSON` の版 1 と全値の検証を共有する。
  形式・レート・自動余韻・秒数・TPDF・ピーク目標だけで、出力先やプロジェクトのパスは含めない。
- 優先順は、正常なパッケージの前回値、正常な旧パス設定、正常な共通既定値、アプリの初期値とする。
  欠落・未知の版・不正な値は次の候補へ戻し、読取りだけでは書換え・修復しない。
- 共通値がなければ、従来どおり 24 bit PCM・出力のレート（未準備なら 48 kHz）・自動余韻・ディザなし・ノーマライズなしとする。
- 共通値はこの Mac だけの選択で、プロジェクトのコピー・移動には含めない。
  明示的な共通値の保存で、既存プロジェクトの前回設定を置換しない。
  共通値を採用して書出しを準備した後は、従来どおりそのプロジェクトの前回値になる。
- 曲のモデル、Undo / Redo、ジャーナル、保存スキーマ、CLI の既定値・引数・DSP は変更しない。
  UserDefaults の電源断耐久性や複数アプリ間の更新調停は追加しない。

## 決定: シートの操作

- 「既定設定として保存」は、[ADR 0262](0262-export-numeric-drafts.md) と同じ全入力の検証を通った値だけを共通値へ保存する。
  不正な文字列を前の数値へ置き換えて保存しない。
- 「既定設定を使う」は現在の入力欄だけを共通値へ戻す。
  「既定設定を初期化」は共通値を削除し、現在の入力欄もアプリの初期値へ戻す。
  パッケージの前回値と旧パス設定は消さない。
- どの操作も書出し・保存パネルを開始せず、文書へ設定を書かず、Undo を消費しない。
  前回値の読込み中と保存パネル中は無効にし、保持された古いシートのコマンドも文書 ID の再照合で拒否する。
- 日英の操作名と結果メッセージを用意する。
  下書きとシートの処理状態は参照型の表示状態として保持し、非同期読込みとコマンドが同じ状態を見るようにする。

## 回帰と基盤

- `ExportDefaultsTests` は非表示の実シートのフィールドエディターから入力し、製品の保存・適用・初期化コマンドを呼ぶ。
  不正入力の保存拒否、修正後の値、別プロジェクトへの適用、前回値・履歴の保持、文書交換後の拒否を検査する。
  共通値の未知の版・不正値と、旧パス・パッケージの優先順も検査する。
- 必須契約 `export-defaults-ui` は、共通値の書込み省略、古い数値での保存、共通値の自動適用省略の各反例を検出する。
  既存の `check-swift`・`check-product-contracts` を使い、契約と選択回帰を追加する。新しい実行入口は作らない。
- README・P2-08・UI 設計・開発入口と、共通値／前回値を区別するデバッグ手順を更新する。
  設定値やユーザー文書を診断へ自動収集しない。音声生成は変えないので、新しい DSP・ブロック長回帰は不要である。
- 自動回帰は実ボタンのクリック・配置・キーボード操作・VoiceOver を代用しない。
  これらは UC-60 に残し、機器・保存パネル・Finder・表示ウィンドウは開かない。
