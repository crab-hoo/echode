# ADR 0189: 選択トラックのミュート・ソロを一括で切り替える

- 日付: 2026-10-28
- 状態: 採用。P2-06 の先行分。実画面・VoiceOver・聴感はユーザー確認待ち
- 関連: [ミックスの操作要件](../interaction-design.md#ミキサーの複数選択)、
  [ADR 0107](0107-mix-controls.md)、[ADR 0117](0117-workflow-interactions.md)、
  [ADR 0124](0124-selected-track-fx-batches.md)、[ADR 0182](0182-noop-edits.md)

## 背景と再現

開始時の HEAD は `9e1992f`。トラックの複数選択は接続済みだが、ヘッダとインスペクターの Mute / Solo は単一の `param.set` だけを送っていた。
製品のヘッダへ入力し、従来と同じ単一編集の callback へ接続する回帰を先に追加した。
混在した 3 トラックの選択のうち、押したトラック以外の未切替値が残ることを再現した。
期待終了コード 1 と固有のアサーションを `target/focused-checks/mixer-switch-red/` で照合した。
これは一時ログの所在であり、永続的な証拠の参照先ではない。以後の回帰は製品の共通 action factory を直接使う。

## 決定

- アレンジのヘッダとインスペクターのミュート・ソロを、押したトラックの操作後の値へ全選択トラックをそろえる入口にする。
  非選択トラックを直接操作する場合は、そのトラックだけを対象にする。フォルダの子孫を暗黙に追加しない。
- 対象の文書セッション・トラック順の選択 ID・押したトラック・フィールドを入力イベント内で値として確定する。
  非同期実行前の選択変更で対象を付け替えず、文書交換・欠けた ID・重複 ID は部分適用せず拒否する。
  共通 action factory のフェーダー操作も捕捉した文書を照合し、古い View の callback が新文書のプレビューを操作しない。
- ヘッダのマウスとアクセシビリティは反転要求を送り、controller の待ち列で入力順を保つ。
  表示更新前に 2 回押した場合も、編集の手番の現行値を順に反転し、各操作を独立した 1 回の Undo にする。
  `EditTurn.busy` だけを理由にクリックを捨てたり、古い表示値を 2 回確定したりしない。
- インスペクターの Toggle は指定された絶対値を同じ経路へ渡す。
  全対象がその値なら何も送らず、Undo・Redo・ジャーナルを変えない。
- 進行中の単一トラックのフェーダープレビューがあれば、先に既存の終了経路で確定する。
  M / S は全対象を検査し、変更が必要な `param.set` だけを既存のアクション配列として 1 回送る。
  単一 Undo / Redo・ジャーナル行・音声計画更新と配列の巻戻しは ADR 0124 の橋渡しを再利用する。
- 選択外のソロは解除しない。通常のソロは既存どおり追加・解除であり、排他的ソロへ変えない。
- ピアノロール右側の Solo / Mute は、編集・参照の状態から独立したトラック別操作のまま保つ。
  アレンジの複数選択を流用しない。音量・パンの相対一括変更とコンソール表示は P2-06 の残りに置く。
- 新しいモデル・アクション・ABI・保存形式・DSP は追加しない。トラック数の固定上限も設けない。

## 回帰と基盤の保守

- `mixer-switch-batch-ui` は実ヘッダと製品の controller / ABI から、混在値・入力時の対象捕捉・非選択ソロの保持、
  単一 Undo / Redo・保存再読込を確認する。対象を単一へ戻す誤りと配列の先頭だけの適用を負の対照にする。
- `mixer-switch-order-ui` は編集の手番を保留し、表示更新前の連打・現行値の反転・操作ごとの Undo を確認する。
  インスペクター相当の絶対値と no-op、ピアノ行の実ボタンの単一対象、文書交換後の拒否も確認する。
  常にオンになる反転と、文書の照合漏れを負の対照にする。
- 通常回帰は、不正値・欠けた対象・履歴で消えた対象の部分適用なし、Redo の保持、フェーダープレビューの先行確定も扱う。
  Makefile の既存入口、検査登録と選択回帰、利用手順・現状・Phase 2・領域設計・デバッグ手順を更新する。
- 音声・隔離・橋渡しの実装は変えず、既存のミュート優先・ソロ合成・補間・配列編集を共有する。
  新アクションのランダム操作生成や、新 DSP のブロック長回帰を加える変更ではない。
- 診断では文書、捕捉した ID 群、anchor、反転／絶対値、待ち列、確定スナップショットを区別する。
  新しいログ形式・外部入力・保存先は増えず、既存の `doctor` の鮮度照合と `debug-report` の収集で足りる。
- 実画面での選択の分かりやすさ、VoiceOver、再生中の一括切替の聴感はユーザー確認に残す。
  描画・機器・性能検査の見送りを自動回帰の合格へ読み替えず、P2-06 全体の完了とはしない。
- 全体検査で再発した走査期限の失敗は、期限を変えずネイティブ fixture と状態到達の検査へ修正した。
  切分けと診断の拡充は [ADR 0190](0190-native-scan-deadline-fixtures.md) に記録する。
