# ADR 0099: 停止と位置移動でプラグインの旧音を消す

- 日付: 2026-10-15
- 状態: 採用
- 範囲: 停止・一時停止・位置移動・準備取消、保持した CLAP ヘルパーの処理状態。ADR 0097 に不足した境界を補う。

## 原因と仕様

ADR 0097 は出力とヘルパーを保持して再開の準備を省いたが、停止ではノートオフを1ブロック送るだけだった。ノートオフはリリースを始める命令であり、残響・ディレイ・発音状態を消す命令ではない。停止中は処理が進まないため、内部に残った音が再開した空白位置で出た。既存の検査はイベントの到達と停止中の無音を確認し、この再開後の音を確認していなかった。

Phase 1 のトランスポートは次の挙動とする。

- 停止と一時停止は現在位置を保つ。直ちに出力を無音にし、以前の発音・残響を次の再生へ持ち越さない。出力機器、プラグインのプロセス、設定値は保持する。
- 位置移動は移動前の発音状態を消す。再生中なら移動先に重なるノートを打ち直し、音声素材は移動先から読む。停止中の移動では発音しない。
- 再生は現在位置から始める。そこに重なるノートは途中からでも鳴る。以前の位置の音だけが再び出る動作は不具合とする。
- 通常再生でノートが終わった時のリリースやエフェクトの余韻は処理を続ける。ループでもエフェクトの余韻を毎周消さない。空白区間を一律にミュートする実装にはしない。

## プラグインの境界

共有メモリの命令に `CMD_RESET_PROCESS` を追加した。次のブロックのイベントを処理する前に、ヘルパーの音声スレッドで CLAP `reset()` を呼ぶ。[CLAP の契約](https://github.com/free-audio/clap/blob/main/include/clap/plugin.h) は内部バッファとボイスの消去、パラメーター値の保持である。プロトコルの magic の版を3へ上げ、古いヘルパーとの取り違えを拒否する。

設置済み Vital では `reset()` と CLAP `NOTE_CHOKE` だけでは音が残った。宣言された MIDI 入力ポートには、MIDI 1.0 の全16チャンネルへ CC120（All Sound Off）も送る。ポートは制御側で列挙し、イベントを準備する。16は MIDI 1.0 の規約であり、トラックやプロジェクトのチャンネル数の上限ではない。通常のイベントより前に送り、処理中の確保・ポート列挙・制御ソケットの操作をしない。

リセット要求は投入に成功するまで保持する。成功した命令はヘルパーが世代順に処理するため、期限を過ぎた古い出力を新しいブロックへ採用しない。制御側がグラフを保持している間の不連続操作も保留し、旧状態のまま時計を進めない。連鎖するエフェクトにも同じ処理を適用する。

## 検証と限界

`contract_stop_seek_resume_does_not_replay_plugin_tails` は、実際に残響を持つ別プロセスの楽器・エフェクト・連鎖を使う。修正前は停止中の出力が0でも、再開先に0.24609375の出力が出て失敗した。停止・一時停止・取消、同じブロックへまとまった停止→移動→再生、移動なしの再開、再生中の移動を検査する。重なるノートが再び鳴ることと、自然に終わった音の余韻が残ることも要求する。

`contract_midi_lifecycle_stops_all_declared_ports` は、標準リセットを無視し、3番目の入力ポートの MIDI 停止で音が消えるプラグインを使う。必須契約はリセット呼出し・MIDI 停止の省略をそれぞれ期待値で拒否する。`reset_clears_delay_state_under_rtsan` は両方の処理経路を禁止操作の検出付きで動かす。復元した設定値がリセット後も変わらないことは状態保存の既存回帰へ追加した。

設置済み `/Library/Audio/Plug-Ins/CLAP/Vital.clap` の既定プリセットを、音声デバイスを開かず製品の再生器へ通した。48 kHz・64フレームで停止前のピーク0.35831672、標準リセット／NOTE_CHOKEだけの再開後は0.32947028、MIDI 停止も送った再開後は0だった。128ブロックを読んだ結果であり、全プリセット・全プラグインの互換性を保証するものではない。ローカル資料は `target/tail-audit/` の `vital.rs` と `vital-*-result.txt` で、別の環境に存在するとは限らない。ユーザープロジェクトは変更していない。最終ソース全体の合否は検査レポートで確認する。

## 後続の変更

2026-10-16 の [ADR 0101](0101-live-output-discontinuities.md) で、ライブ出力は突然0へ切り替えず5 ms以内に収束させる。時計と発音状態は直ちに止める。上記の内部処理状態の消去と自然な余韻の区別は維持し、旧音を再開する処理にはしない。
