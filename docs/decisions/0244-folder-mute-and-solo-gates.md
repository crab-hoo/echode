# ADR 0244: フォルダのミュートとソロを子孫のフェーダーへ反映する

日付: 2026-11-03
状態: 採用（FCA-06 のミュート・ソロ部分）
関連: [FCA-06](../reviews/2026-11-03-full-code-audit.md#fca-06-フォルダのミックス操作が子に効かない)、[ADR 0024](0024-track-order.md)、[ADR 0116](0116-folder-drum-rack.md)

## 背景

製品の `Prepared::new` は、各トラック自身のミュートと、全体のソロの有無だけから可聴性を決めていた。
子を持つトラックでミュートしても子は鳴り、ソロすると逆に子が無音になった。
監査の `audit_fca06_a_folder_mute_and_solo_reach_its_children` を修正前に実行し、`muting the folder left its child audible` で失敗することを確認した。
入れ子と兄弟を持つ製品バッファの回帰も、修正前に期待振幅との不一致で失敗した。

フォルダのバス化は P2-03 のままだが、ミュートとソロの既定の意味は監査の実行指示で確定している。
音量・パンを子へ掛けるか、バス化まで操作子を無効にするかは、ユーザーの判断を待つ。
2026-11-08 注記: [ADR 0277](0277-reaper-style-folder-bus.md) で、Reaper と同じく子の音を親トラックへ通し、親の FX・音量・パンを掛けるバスにすると決めた。未実装である。

## 決定

- 自身または祖先がミュートなら、そのトラックの出力を無音にする。子自身のソロや祖先のソロで解除しない。
- 自身または祖先がソロなら、ソロの対象として扱う。全体にソロが一つもなければ、従来どおりミュート以外を鳴らす。
  複数のソロは部分木の和集合となり、入れ子のソロから外側の兄弟へ広がらない。
  ミュートされたトラックのソロも、全体のソロの有無には数える。従来の単一トラックの規則を変えない。
- `playback_faders.rs::track_faders` が、モデルと計画の同じトラック順から実効フェーダーを作る。
  モデルの親優先・部分木が連続する順序を使い、祖先の実効フラグを可変長のスタックに保つ。
  各要素の出入りは一度ずつで O(トラック数)、追加の祖先領域は O(深さ)。再帰や深さの固定上限を使わない。
- 計画の準備と交換で解決を終え、音声スレッドは従来のフラットなフェーダーを使う。
  再生中の切替は既存の 5 ms の標本単位の補間を保ち、親の付替えでも実効フラグを再計算する。
- MIDI の配送とプラグイン処理は変えず、出力段で可聴性を決める。配置音声、準備済みのキャッシュ、デバイス出力、停止中の出力にも同じゲートが掛かる。
  音量・パンの試聴で実効ミュートを迂回しない。メーターは各トラック自身のフェーダー後であり、フォルダの合計値ではない。
- モデルに保存するミュート・ソロの値は自身の値のまま保つ。子のパラメーターを連動編集せず、保存形式・アクション・Undo の単位は変えない。

## 回帰と基盤

- 監査の再現から `#[ignore]` を外す。
- `tests/block_size/folder_mix.rs` は、入れ子・兄弟・外側のトラックに独立した振幅のステレオ音声を置く。
  親と子のミュート／ソロ、ミュート優先、複数ソロ、子だけのソロを、期待する可聴集合・左右の標本・各トラックのメーターと照合する。
- 48 / 96 kHz、ブロック長 1 / 7 / 64 / 512 で、製品再生とオフライン出力を一致させる。
  再生中の切替・親の付替え・復帰は、5 ms の期待振幅とブロック長を変えた全標本の一致で検証する。
  準備済みキャッシュと音量の試聴を併用しても、祖先のゲートを保つ回帰を置く。
- 既存の crate テストと RTSan が新しいモジュールを実行するので、検査の選択条件と Makefile の入口は追加しない。
  デバッグ手順に、保存値・親子関係・実効ゲート・フェーダー後の標本の切分けを追加する。

## 残る境界

2026-11-13: フォルダバスを [ADR 0338](0338-folder-bus.md) で接続した。下の聞こえ方は保ち、親のメーターは子を含むフェーダー後の値になった。
子だけのソロで親自身の素材を鳴らさない区別は、親の自分の音のゲートとして実装した。以下は接続前の記録である。

子の音声を親へ加算するフォルダバス、親の FX・音量・パンの子への適用、PDC、ドラム用の MIDI 配布は未実装のままである。
親のソロで子孫を開いても、子だけをソロにした時に親自身の別の素材を鳴らすことはない。
将来のバス化では、子の経路を開くことと親自身の素材を鳴らすことを区別する必要がある。
実画面・VoiceOver・実機の切替時の聴感は UC-49 でユーザー確認を待ち、自動波形の一致をその合格とはしない。
