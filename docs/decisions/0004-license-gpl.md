# 0004. ライセンスを GPL-3.0-or-later に変える

- 日付: 2026-10-08
- 状態: 採用

## 背景

0001 では MIT OR Apache-2.0 を採用した。そのため、GPL の Rubber Band と Ableton Link、LGPL の LAME を同梱できなかった。Echode は主に作者自身が使うもので、他人が使う時の条件よりも、作者が使えるライブラリの多さを優先する。

## 決定

- ライセンスを GPL-3.0-or-later にする。全 crate と Swift のコードに同じライセンスを適用する
- 依存ライブラリは、GPL-3.0-or-later と両立するライセンスなら使ってよい。寛容なライセンス、MPL-2.0、LGPL、GPL-2.0-or-later、GPL-3.0、AGPL-3.0 が使える。詳細は `docs/PLAN.md` §2.1
- 版 2 にしないのは、Apache-2.0 だけで配布されているライブラリ（Apple の Swift パッケージなど）と組み合わせられないため。「-only」にしないのは、将来の版で配布されるライブラリも使えるようにするため。AGPL-3.0 にしないのは、GPLv3 の第 13 条で AGPL のライブラリとも組み合わせられ、使えるものが増えないため

## 結果

- 使えなくなるのは GPL-2.0-only のライブラリなど、GPL-3.0 と両立しないものだけ。今の依存はすべて MIT、ISC、zlib のいずれかを選べるので、そのまま使える
- ソース非公開のプラグインも、今まで通り読み込める。GPL が条件を付けるのは配布で、利用者が手元でプラグインを読み込むことには条件がない
- バイナリを配布する時は、同じ版のソースを公開する
- Mac App Store では配布しにくくなる。GitHub Releases での配布と、将来の公証には影響しない
- 今は著作権者が作者ひとりなので、ライセンスはいつでも変え直せる。外部からの貢献を受け入れた後に GPL 以外へ変えるには、貢献者の同意が要る
