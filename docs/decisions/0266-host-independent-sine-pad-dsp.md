# ADR 0266: Sine Pad の DSP をホストから分離する

- 日付: 2026-11-05
- 状態: 採用
- 対象: FCA-15。音色選定と隔離の経路は ADR 0018・0123 を維持する。

## 問題と再現

同梱 CLAP はホストの `echode-engine` を依存に持ち、`TestSynth` と確保の検出を取り込んでいた。
楽器の DSP にホストの再生器・機器問い合わせ・隔離制御を依存させる理由はない。
`test_sine_pad.py` は Cargo の製品用依存をたどり、音源からホストへ到達しないことを確認する。
修正前は `Sine Pad links the host engine` で失敗し、期待終了コードとアサーションを照合した。

## 決定

実装を持つ `echode-dsp` を追加し、`SinePad`・声・wavesynth の処理・確保の検出を移す。
依存は既存の `echode-realtime` と `wavesynth 0.1.0` だけで、モデル・ホスト・機器に依存しない。
CLAP はこの製品名の DSP を直接使い、エンジンの `TestSynth` は既存の単体検査のための薄いアダプターとして残す。
DSP のエラーは小さい列挙型で返し、エンジン境界で従来の `PlaybackError` へ網羅的に変換する。

発音順序、16 bit から MIDI 7 bit へのベロシティ変換、余韻、事前領域の拡張と声の引継ぎは変えない。
DSP 検査用の状態 `\x01SinePad` と、CLAP の既存ペイロード `SinePad1` は区別して両方を保持する。
新しい保存形式・スキーマ・暗黙の音源は加えない。
確保の検出の TLS はエンジンと同梱 CLAP で同じ実装を使い、CLAP 固有の初回非 RT 初期化を維持する。

## 回帰と基盤

- `sine_pad_tests.rs` はピン留めした wavesynth の直接出力と、複数のベロシティ・二声・note-off の標本をビット単位で照合する。
- 保持中・release 中の声の引継ぎ、無音化、状態の拒否、余韻と遅延、未準備の容量と不正な時刻を確認する。
  処理と声の引継ぎにはデバッグの確保検出を維持する。
- 既存の `synth_tests.rs`、`block_size.rs`、CLI の基準音声と隔離ヘルパーの製品回帰を引き続き使う。
  基準音声の再生成はしない。
- 新しい crate の音声・隔離・書出しの選択を `scripts/verification.json` へ登録し、選択の回帰を追加する。
  テストは workspace の既存入口に載るため、Makefile に別の実行入口は増やさない。
- モジュールの索引・領域別設計・デバッグ手順を更新する。ログ形式と採取先は変えない。

機器・第三者プラグインの聴感を証明する変更ではなく、新しいユーザー操作も追加しない。
実機項目はユーザー担当として見送り、合否と理由は `target/verification/report.md` に記録する。
