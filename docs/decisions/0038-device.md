# 0038. 内蔵デバイスは処理、イベント、状態、遅れ、余韻を持つ

- 日付: 2026-10-09
- 状態: 採用
- 項目: ENG-5

## 背景

`render_offline` はテスト用シンセを直接呼ぶ。PLAN §5 は、内蔵デバイスのインターフェースを先に決め、テスト用シンセと基本エフェクトで確かめるとしている。ARCHITECTURE §10 は、内蔵デバイスを CLAP と同じ考え方（パラメータ、イベント、状態）にし、本体のプロセスで動かすとしている。

声のスロットは呼び出し側が渡し、足りなければエラーにする。同時発音数の製品上限はない（[ADR 0018](0018-test-synth.md)）。ブロックのイベントは ADR 0037 の列である。チャンネル数とパンの規則は ENG-6 が決める。

## 決定

- `Device` は `echode-engine` に置く。テスト用シンセとテスト用サンプラーが実装する。トラックごとに 1 つ作る。`render_offline` はシンセをこのトレイトで鳴らす。サンプラーは同じトレイトのテストで鳴らし、ゴールデンの書き出しには使わない
- オーディオスレッドが呼ぶのは `process` だけである。引数は、チャンネル平面の可変長スライス、ADR 0037 のイベント列、サンプルレートである。平面の数は呼び出し側が決める。固定の上限は置かない。処理は呼び出し側のバッファへ足し、確保もロックもしない。テスト用の 2 つは、渡されたすべての平面に同じモノを足す。ステレオのパンはここではない
- 声のスロットはデバイスが持つ。数は制御スレッドが、そのトラックのノート数まで、処理の前に用意する。処理中には増やさない。足りなければ今どおりエラーにする。これは同時発音数の上限ではない
- イベントは ADR 0037 の列をそのまま読む。テスト用シンセはノートオンとノートオフだけを声に使う。サンプラーも同じである。パラメータ値のイベントは、そのデバイスの番号だけを見る。テスト用シンセにパラメータはない。サンプラーの補間は 1 つで、0 がフロア、1 が線形、2 が sinc である。既定は線形のままである（ADR 0018）
- 状態の保存と復元は制御スレッドで行う。バイト列で、先頭に版を置く。中身は設定だけである。シンセは楽器の識別、サンプラーは補間の番号である。鳴っている声の位相は状態に入れない。PCM の中身も状態に入れない。呼び出し側が渡したままである
- レイテンシはサンプル数で返す。この 2 つは 0 である。余韻もサンプル数で返す。シンセは Sine Pad のリリース 400 ms を、そのサンプルレートで換算する。サンプラーは 0 である。オフラインの書き出しの長さは、この余韻の最大を使う。400 ms を書き出し側に直書きしない
- ホストしたプラグインは、後で同じトレイトを実装する。この項目ではヘルパーを包まない。計測用の共有メモリも変えない

## 結果

`make check` が通った。`render_offline` はテスト用シンセを `Device` で鳴らす。渡した平面は同じモノになる。書き出しの長さはシンセの余韻 19,200 サンプル（48 kHz）を足す。サンプラーは同じトレイトで鳴り、補間のパラメータと状態の復元ができる。レイテンシはどちらも 0 である。
