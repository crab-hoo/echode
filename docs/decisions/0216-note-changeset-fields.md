# ADR 0216: ノートの変更セットを項目表から生成する

- 日付: 2026-11-02
- 状態: 採用
- 対象: SPG-09 の続き。ノートのスカラー項目と変更セットの間の変換
- 関連: [ADR 0021](0021-changeset.md)、[ADR 0215](0215-device-changeset-fields.md)、[構造監査](../reviews/2026-10-30-structure-audit.md#spg-09-モデルの項目追加の手数)

## 背景

パラメーターとデバイスに続き、ノートでも差分・作成と削除・下書き・設定・復元の対応をまとめる。
従来の `changeset.rs` は開始・長さ・音高・ベロシティ・リリース・アーティキュレーションを各段で列挙していた。
今回は既存の結果を保つ構造整理であり、製品の誤動作の修正や新しいノート操作の追加ではない。

## 決定

- `changeset_note.rs` の `note_fields!` に、6 項目の `Property`・フィールド・型・`Value` の種類・作成時の読出しを宣言する。
  差分、作成と削除、下書き、両方向の変換、作成の適用、設定の振分けを表から生成する。
- 表の順序は従来の開始・長さ・音高・ベロシティ・リリース・アーティキュレーションとする。
  tick は符号付き整数、音高は 8 bit、発音とリリースの強弱は 16 bit、任意の参照は `Parent` の表現を保つ。
- ID と所属する中身はスカラーの表へ含めない。
  所属変更は従来どおり低水準 API で受け付け、差分ではスカラーより前に記録する。
  復元時には中身のノート順と所属を照合し、存在しない中身や順序と矛盾する所属を拒否する。
- `Draft::set` はノート ID で下書きへ委譲し、共有の開始・長さ・所属プロパティをクリップ側の分岐から分離する。
  既存の `Lane` のテキスト更新はノートでも無変更として受け付ける互換動作を保つ。
- 必須フィールド、誤った `Value` の種類と未知の ID の拒否を保つ。
  低水準 API の任意の整数・参照の往復と、公開前の不変条件検査は区別する。
  不正な音高・長さ・アーティキュレーションを有効なプロジェクトとして受け入れる変更ではない。
- 公開列挙型、ジャーナル、パッケージのスキーマ 6、Undo の意味、音声処理は変更しない。
  他オブジェクトと保存・FFI の項目表への統合は残り、SPG-09 全体の完了とはしない。

## 回帰と診断

生成前の製品コードへ回帰を追加してから、同じ公開入口で構造整理後の結果を照合した。

- `echode-history/tests/note_changesets.rs` は生成表を参照しない独立した期待値を持つ。
  任意の整数と参照、6 項目の全組合せ、整数の端点で項目間の取り違えと無変更を検査する。
  正確な作成・削除・更新のフィールド順、逆適用、二重反転、ジャーナルの符号化・再生を通す。
- 同じ回帰で、作成の必須フィールドの欠落・誤った型、更新の誤った型・未知の ID・対象外プロパティを拒否する。
  所属と中身の順序を一緒に更新する往復、順序と矛盾する所属の拒否、`Lane` の無変更互換も検査する。
- 操作列の `properties.rs` に、共有する中身と MIDI 7 bit へ丸められていない発音・リリースの強弱を持つ初期状態を加える。
  空・ミキサー・CLAP 設定済みの初期状態も保ち、不変条件、操作列全体の差分、Undo / Redo、ジャーナルと保存往復を通す。
  アーティキュレーションは未対応なので、製品として有効な初期状態には入れない。

新しい実行入口や依存は追加しない。既存の `check` が回帰を実行するため、検査選択の条件は変更しない。
フィールドと入力を含むアサーションを既存ログへ残し、診断の収集先・手順は変更不要とする。
実機・実画面・聴感の合否はこの構造整理からは主張しない。
