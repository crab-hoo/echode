# ADR 0060: プラグインフォルダの変化を、開いているブラウザへ届ける

- 日付: 2026-10-13
- 状態: 採用
- 範囲: Phase 1 の CLAP 一覧。VST3、AU、サムネイル、使用中インスタンスの差し替え、見つからないデバイスの表示は含まない

## 背景

フォルダの監視と、変化が止まってからヘルパーで記述子を読む処理は、本体の外に既にある（[ADR 0016](0016-plugin-scan-is-outside.md)）。ブラウザは開いた時と再スキャンの操作で一度調べるだけで、インストールのあとに一覧が変わらなかった（[ADR 0048](0048-clap-device.md)）。

クリップ FX は Phase 2 の計画として足してある（[ADR 0059](0059-clip-fx.md)）。この項目では実装しない。

## 決定

ブラウザを開くと、プロセスがいるあいだ CLAP のフォルダを監視する。対象は `/Library/Audio/Plug-Ins/CLAP`、`~/Library/Audio/Plug-Ins/CLAP`、`CLAP_PATH` である。`ECHODE_CLAP_ROOTS` があるときはそれだけを見る。まだ無いフォルダは、現れてから監視に加える。

変化のたびにディレクトリを読み直し、バンドルの版が変わっていなければ調べ直さない。新しい版は 2 秒止まってから `echode-plugin-host --scan` に渡す。失敗した版は、実行ファイルが変わるまで再スキャンしない。結果は今までと同じ `clap-scan.jsonl` に書く。削除は待たずに一覧から外す。

本体のプロセスはバンドルを読み込まない。監視スレッドはオーディオのコールバックではない。

最初に公開した一覧は新着にしない。そのあと現れた ID だけ `fresh` を立て、ブラウザは「新着」と出す。開いているあいだは改訂を待ち、変わったら一覧を読み直す。選択中の ID が残っていれば選択は維持する。

監視の型は `echode-plugin-host` に置く。`echode serve` は、この項目では始めない。

## 結果

一時フォルダにテスト用 CLAP を置くと一覧に新着で現れ、消すと一覧から消える。待ちは 2 秒より短い試験用の値で、製品の監視は 2 秒である。画面での操作確認は未実施である。
