# ADR 0191: 選択トラックの音量・パンを数値入力で相対調整する

- 日付: 2026-10-28
- 状態: 数値入力の先行分を採用。一括ドラッグ・読み上げの増減・コンソールは未接続
- 関連: [操作要件](../interaction-design.md#ミキサーの複数選択)、
  [ADR 0107](0107-mix-controls.md)、[ADR 0153](0153-value-control-clicks-and-typed-entry.md)、
  [ADR 0189](0189-selected-track-mute-and-solo.md)

## 背景と再現

開始時の HEAD は `bc581d7`。
ミュート・ソロは選択全体を扱うが、音量・パンの数値入力は単一トラックの `param.set` だった。
製品ヘッダの数値欄から入力する回帰を先に追加し、音量 0.5 と 0.25 の選択で、基準へ 0 dB を入力した。
期待値 1 と 0.5 に対し、他方は 0.25 に残った。
`target/focused-checks/mixer-value-red/` で終了コード 1 と固有のアサーションを照合した。
これは一時ログの所在であり、永続的な証拠へのリンクではない。

既存のライブ試聴は単一トラック専用である。
今回は数値入力だけを独立した完了単位にし、グループの表示と音声を異なる対象へ試聴する変更は行わない。

## 決定

- ヘッダのトリプルクリックとインスペクターの数値入力を `MixActions.enter` へ分離する。
  ドラッグ、ダブルクリックの既定値、アクセシビリティの増減は既存の単一対象を保つ。
  インスペクターにこの範囲の説明を出す。
- 入力を確定したイベント内で文書・基準 ID・選択 ID 群・要求値を捕捉する。
  基準が選択外なら単一対象とし、子孫を自動追加しない。
  数値欄を開いた時の文書に属する callback を保持し、再オープン後の同じトラック ID へ送らない。
  `ValueEntryField` の同期 submit はイベント内で対象を捕捉し、欄の終了だけを後へ送ってフォーカスの再入を避ける。
  プラグイン等の非同期の値変換は従来の async commit を保つ。
- 離散的な数値入力とミュート・ソロは `mixerSwitchTail` を共有し、投入順に処理する。
  単一フェーダーの試聴中なら先に既存の終了経路で確定し、数値入力は次の手番で現行値から計算する。
  旧スナップショットの絶対値の組を後から書き戻さない。
- 音量は線形値の比を全対象へ掛け、同じ dB 差を適用する。
  上限 4 と、正の最小値が `Float.leastNonzeroMagnitude` を下回らない範囲で共通倍率を制限する。
  パンは全対象へ同じ差分を加え、最も外側の対象が ±1 になる差分で全体を止める。
  各値を別々にクランプして相対関係を壊さない。結果は保存値の Float 精度に丸める。
- 有限の音量比による変更では、無音のメンバーは 0 のまま保つ。
  基準が 0 で要求が正なら比が定まらないため、一括入力を拒否して単独選択か有音の基準を案内する。
  有音の基準への −∞ 入力は全体を 0 にする。既に基準が要求値なら no-op とする。
  単一対象は従来どおり 0 から任意の有効値へ変更できる。
- 文書・全 ID・重複・フィールド・有限値・範囲を検証し、欠けた対象へ部分適用しない。
  変更のある `param.set` だけを既存の配列編集へ 1 回渡す。
  1 回の Undo / Redo・ジャーナル・保存・音声計画更新を共有し、no-op は Redo を消さない。
- 新しいアクション、ABI、保存形式、DSP、トラック数の上限は加えない。
  親子を選んだ場合も各 ID のパラメーターを一度ずつ編集する。
  将来のフォルダバスの音声上の二重適用は、P2-03 のルーティング受入で別途判断する。

## 回帰と基盤の保守

- `mixer-value-batch-ui`: 実ヘッダの数値入力・製品 controller / ABI を通す。
  共通音量比・パン差、入力時の対象、選択外の保持、単一 Undo / Redo・保存再読込を確認する。
  対象を単一へ戻す誤り、全音量を同じ絶対値にする誤り、入力イベント外で対象を捕捉する誤りを負の対照にする。
- `mixer-value-bounds-ui`: インスペクター共通の factory から上下限・no-op の Redo 保持・旧文書の拒否を確認する。
  音量とパンの共通制限の除去、文書の照合漏れを負の対照にする。
- 通常回帰は入力順、手番の現行値、試聴の先行確定、無音・最小正値・不正値・欠けた対象も扱う。
  検査登録、選択回帰、Makefile の既存入口、利用手順、現状、P2、領域設計とデバッグ手順を更新する。
- 音を作る処理と音声側の禁止操作は変えず、既存の配列編集とフェーダー補間を使う。
  新しいアクションのランダム生成や DSP のブロック長回帰を追加する変更ではない。
- 新しい失敗は、無音の基準、共通限界、古い文書、欠けた対象を診断上区別する。
  ログ形式・保存先・外部入力は増えず、`doctor` と `debug-report` の収集範囲は変更不要である。
- 実画面の説明と数値欄、VoiceOver、再生中の一括確定の聴感はユーザー確認とする。
  機器を開く検査やアプリ操作は行わず、見送りを自動回帰の合格へ読み替えない。
