# ADR 0159: 両エディタを再生ヘッドへ追従させ、手動の時間スクロールで解除する

- 日付: 2026-10-25
- 状態: 採用。P2-07 のトランスポートの続き
- 関連: [ADR 0155](0155-remembered-playback-start.md)、[ADR 0157](0157-arrange-ruler.md)、[ADR 0117](0117-workflow-interactions.md)

## 背景と再現

[操作要件](../interaction-design.md#構成を考えながら入力する) は、再生ヘッドが画面の端を越える時に表示を追従させる。
手動スクロールで追従を解除し、明示的にオンへ戻すまで停止・再開後もオフを保つ。
追従オフの永続化は [次に詰める点](../interaction-design.md#次に詰める点) の 5 に残っていた。

変更前のアレンジとピアノロールには、再生位置からカメラを動かす経路がなかった。
再生ヘッドは描画スレッドが表示範囲内の時だけ描き、範囲外では消えたままになる。
`PlayheadFollowTests.contractBothEditorsPageToThePlayheadUntilATimeScroll` は、
製品ブリッジで開始位置を 20 拍へ置いた時に両カメラが 20 拍へ移ることを期待値とし、判定を欠いた反例では 0 拍のまま失敗する。

## 決定

- 追従は表示状態であり、`WorkspaceState.followsPlayhead` に置く。
  プロジェクト・ジャーナル・Undo・`transport.json` には入れない。
  文書を開くたびにオンで始め、同じ文書の間は値を保つ（次に詰める点の 5 をこの値で決める）。
- 再生ヘッドが表示範囲（左端を含み右端を含まない半開区間）の外に出たら、そのエディタの時間の原点を再生ヘッドへ移す。
  毎フレームの連続スクロールではなく、1 画面ごとのページ送りとする。
  ループで戻る、停止で開始位置へ戻る、位置移動で離れた場合も同じ規則で表示する。
  アレンジとピアノロールは別々のカメラのまま、それぞれの幅で判定する。縦方向（トラック・音高）は動かさない。
- 横方向が優勢なホイール・トラックパッドのスクロールを手動の時間スクロールとし、そのエディタで即座に追従を止める。
  続けてワークスペースの値をオフにし、もう一方のエディタも止める。
  縦方向が優勢なスクロールとピンチのズームは追従を解除しない。
- オンへ戻す入口は、トランスポートの「再生ヘッドに追従」トグル、再生メニューのチェック付き項目、コマンドパレットとする。
  キーの割当は Return と同じくユーザーの判断を待ち、今回は付けない。
  オンにした時は、停止中でもその時点の再生ヘッドを表示する。
- 押下中の操作がカメラに依存する間は、ページ送りを保留する。
  アレンジはルーラー・クリップ移動・クリップの値の操作・数値入力欄・音声ファイルのドラッグ、
  ピアノロールはノートのドラッグとルーラーの押下が対象である。解放後の最初のフレームで追従する。
- 判定は主スレッドの `PlayheadFollower` が `PlaybackFeed` の原子的な位置を読んで行う。
  エディタごとの `NSView.displayLink` は、追従中かつ再生中の間と、
  再生・一時停止・停止・位置移動、追従のオンから 0.3 秒の間だけ動き、それ以外は休止する。
  停止・位置移動は命令の応答後に公開位置へ届くため、この猶予で新しい位置を拾う。
  描画は従来どおり描画スレッドの `CAMetalDisplayLink` が行い、位置の取得のために SwiftUI の観測や文書ワーカーを通さない。
- 停止中にズームなどで再生ヘッドが範囲外になっても、次のトランスポートの変化までは動かさない。
  利用者の表示操作と追従を競合させないためである。

## 受入と基盤

- 必須契約 `playhead-follow-ui` は、実アレンジと実ピアノロールへ製品ブリッジの再生位置を送る。
  範囲外へのページ送り・表示中の不動・戻り方向、ルーラー押下中の保留、縦スクロールとズームでの継続を確認する。
  横スクロールによる各エディタの解除と通知、再オンでの即時表示、Undo と開始位置の不変も確認する。
  反例は判定の右端の欠落、アレンジの軸の取り違え、ピアノロールのルーラー押下中の保留の欠落とする。
- 必須契約 `playhead-follow-state-ui` は、メニュー・パレットの切替、同じ文書での保持、別の文書でのオンを確認する。
  反例は文書交換時の初期化の欠落とする。
- 通常回帰で、ページ送りの境界と非有限値、時間スクロールの判定、表示リンクの休止条件を確認する。
  SwiftUI のキャンバスがワークスペースの値を両方向に受け渡すことも、ホストした実 View で確認する。
- 音声処理・モデル・保存形式・外部入力・ログの形式は変えないため、ブロック長比較と RT の検査は追加しない。
  デバッグ手順へ、追従しない時に値のオフ・押下による保留・リンクの休止を区別する手順を加える。
- 実画面でのページ送りの見え方、追従中の描画の滑らかさ、トグルの VoiceOver はユーザー確認とする。
  Return の一時停止／再開とキーの割当は、この単位には含めない。
