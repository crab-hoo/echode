# 0013. サンプルレート変換は窓付き sinc

- 日付: 2026-10-08
- 状態: 補間の方式は [0014](0014-existing-implementations-as-options.md) で置き換え。自作の実装は選択肢に出さない

## 背景

オーディオクリップは、ファイルのサンプルレートのままデコードし、デバイスのレートへリアルタイムに変換する。変換の計算はオーディオ処理の中で行い、その場でメモリを確保しない。

## 決定

- 補間は Hann 窓をかけた sinc とする。窓の半径は、変換元の 32 サンプルである。これは変換の品質であり、クリップの長さの上限ではない
- 出力のサンプル 0 は、入力のサンプル 0 に対応する。範囲の外は無音とする
- 上げるときと、同じレートのときは、入力の帯域をそのまま通す。同じレートの整数位置は、元のサンプルがそのまま出る
- 下げるときは、変換先のナイキスト周波数の 0.95 倍で帯域を切る
- 呼び出し側が出力バッファを渡す。変換の関数は割り当てをしない

## 結果

一定の音は、レートを変えても中央で同じレベルを保つ。インパルスを 2 倍に上げると、山はそのサンプルに残り、左右は対称になる。
