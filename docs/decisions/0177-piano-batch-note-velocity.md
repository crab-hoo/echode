# ADR 0177: 選択したノートのベロシティを同じ量だけ調整する

- 日付: 2026-10-27
- 状態: 採用。P2-07 の先行分。実画面・VoiceOver・聴感はユーザー確認待ち
- 関連: [操作要件](../interaction-design.md#ベロシティの編集)、[ADR 0173](0173-piano-note-velocity.md)、[ADR 0175](0175-piano-velocity-lane.md)、[ADR 0176](0176-piano-note-selection-and-deletion.md)

## 背景と再現

`54294c9` では複数選択できたが、Option ドラッグと下部の棒の押下で単一選択へ戻っていた。
実 View で 2 音を選択して Option ドラッグする回帰を先に追加し、選択全体を保持できないことを確認した。
期待終了コードと固有のアサーションは `target/focused-checks/note-velocity-batch-red/` に残す。

## 決定

- 編集中の単一トラックで、選択済みノートの Option＋上下ドラッグと選択済みの棒の上下ドラッグを、選択全体の調整とする。
  未選択のノートや棒は従来どおりその 1 音だけを選択して調整する。Command の選択切替と通常の移動・伸縮は変更しない。
- 押下時の全対象と保存値を保持し、つかんだノートの移動量から共通の整数差分を求める。
  ノートは 1 pt で 1 段、棒はレーンの高さで 0〜127 の全幅を調整する。横移動・Shift・途中の Option 解除には依存しない。
- 差分を全対象の最小値・最大値から制限し、どれかが 0 または 127 に達したら全体をそこで止める。
  各音を個別に切り詰めて強弱差を崩さない。0 と 127 を両方含む選択では差分が 0 となり履歴を増やさない。
- ドラッグ中はモデルを変えず、同じ差分をノート下端・棒・読み上げ用の値へ仮表示する。
  同じ内容をリンクした配置の別表示も同じ値を示す。画面外の選択も差分の制限と確定に含む。
- 解放時の座標で計算し直し、変更時だけ既存の `note.velocity` の配列を単一トランザクションへ送る。
  待機列の手番で全対象の存在と押下時の保存値を検証し、1 つでも古ければ全体を拒否する。
  同じ内容のノートは ID ごとに一度だけ変更し、ノートの幾何・表情・配置の窓・自動／固定を保つ。
- 選択は維持し、入力長は変えない。成功した調整で、つかんだノートの変更後の値を全トラック共通の入力ベロシティへ記憶する。
  入力値は従来どおり Undo / Redo では巻き戻さず、再オープン時に 100 へ戻す。
  応答待ち中の別の複数選択・選択解除も記憶の世代を進め、古い応答に上書きさせない。
- 下部の読み上げ用スライダーの増減も、選択済みなら同じ共通差分・単一確定へ送る。
- 従来の取消条件に加え、選択集合が変わったら押下を取り消す。
  Escape・フォーカス喪失・スクロール・ズーム・寸法変更・文書と対象の変更・処理中・終了での取消後に、遅れた解放を確定しない。

## 受入と基盤

- `piano-velocity-batch-ui` は実ノートと棒の入力、仮表示、共通上限、解放位置、単一 Undo / Redo、入力記憶・幾何保持・保存再読込を確認する。
- `piano-velocity-batch-targets-ui` はリンク配置と画面外の選択、共通下限・上限、読み上げ操作、重複排除、古い値・不正対象・旧文書の全拒否を確認する。
- `piano-velocity-batch-cancel-ui` は両入口の選択変更・選択解除と従来の取消を確認する。
  選択の単一化・つかんだ音だけの上下限制限と仮表示・対象検証の欠落・重複処理・記憶の世代と取消の欠落を負の対照にする。
- Makefile の既存入口と検査選択テストを更新し、README・操作要件・現状・領域設計・デバッグ手順をそろえる。
  モデル・アクション・保存形式・DSP・外部入力・成果物の場所は変えない。
  既存の `note.velocity` の履歴・ブロック長回帰を維持し、新しいアクション生成や診断収集先は不要である。
- 一括移動・伸縮・Command 複製移動、複数トラック編集、ゴーストノートと試聴は別単位に残す。
  実画面の操作感・VoiceOver・音源の聴感はユーザー確認とし、自動回帰の合格と区別する。
