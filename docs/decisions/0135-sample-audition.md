# ADR 0135: サンプルの単発試聴を文書ワーカーから独立した出力で鳴らす

- 日付: 2026-10-21
- 状態: 採用。P2-02 の共通サンプルブラウザの単発試聴を接続。実機の聴感はユーザー確認待ち
- 範囲: ブラウザ選択からの試聴要求、試聴スレッドと専用 IOProc、試聴ボイスの置換・停止、診断

## 背景

[操作要件](../interaction-design.md#共通サンプルブラウザ) は、サンプルを選ぶと素の素材音で 1 回自動試聴し、
別のサンプルを選んだら前の試聴を止めて新しいサンプルだけを鳴らす（曲の再生中も重ねる）と定める。
[ADR 0122](0122-sample-library-search-and-placement.md) は検索と配置だけを接続し、試聴は未実装だった。

既存の出力はプロジェクトの再生器と一体で、開く時に全プラグインのヘルパーを準備する。
音声コマンドは文書ワーカーで処理されるため、停止中の最初の出力準備やデバイスの往復を待つ間は後続の要求も待つ
（[status](../status.md) の残る制約）。
選択のたびの試聴をこの経路へ載せると、試聴がヘルパー起動と全素材の準備を待ち、長い素材の読込みが編集を待たせる。
[処理中も作業を続ける](../interaction-design.md#処理中も作業を続ける) の要件に反する。

## 決定

### 試聴は文書ワーカーを通らない

- 文書ごとに試聴スレッド（`echode-audition`）を 1 本持つ。要求は FFI の `echode_document_audition` から直接届き、
  文書ワーカー・編集の待ち行列・トランスポートの取消世代を通らない。Undo・保存・ジャーナルの対象外である。
- 要求には単調増加の番号を付ける。新しい要求は、読込み中・待機中の古い要求を取り消す。
  スレッドは待ち行列の最新だけを処理し、読込み・出力準備・受け渡しの各段で最新かを確かめる。
  読込みは 16384 フレームごとに取消を確かめる。SRC は途中で取り消さない。
- 読込みは既存の AudioToolbox の復号（`echode_history::decode_audio_file`）、SRC は配置音声と同じ
  `device_planes`（既定の rubato）を使う。パッケージへは書かない。
  素材全体を制御側で読み込む Phase 1 の方式を引き継ぎ、ディスクストリーミングは既存の未実装範囲に残す。

### 専用の IOProc でプロジェクトの出力に重ねる

- 試聴はプロジェクトと同じ出力機器（明示選択の UID、なければシステム出力）に専用の IOProc を開く。
  プロジェクトの出力ストリームを開かず、プラグインのヘルパーを起動しない。曲の再生中は HAL が 2 つの IOProc の出力を加算する。
- 機器の選択は文書の音声セッションが `audio.output` の時に試聴へ伝える。
  機器一覧・既定機器・レート・バッファ・ストリーム形式の通知を受けたら試聴の出力を無音にして閉じ、次の要求で開き直す。
- 最後の音が終わって 5 秒たつと出力を閉じる。フォルダ内を続けて選ぶ間は機器を開き直さない。
  文書を閉じると取消を送り、最後のハンドルが落ちた時点でスレッドが出力を閉じて終わる。終了時に読込みの完了を待たない。

### 試聴ボイスはブロック分割から独立する

- `echode-engine` の `AuditionAudio::mix` が、選んだ素材を先頭のサンプルから等倍で加算する。
  トラックの FX・フェーダー・パン・メーターを通さない。モノラルは左右へそのまま出す。
  出力機器がモノラルの時は、既存の出力と同じ等電力の和にする。
- 新しい素材は次のブロックの先頭で採用し、その先頭サンプルから鳴らす。
  鳴っていた素材は停止の減衰と同じ 5 ms の余弦で消す。採用前に置き換えられた素材は鳴らさない。
  1 回の減衰中にさらに置き換えた場合だけ、減衰中の古い素材を切る。
- 位置と減衰はサンプル単位で進め、ブロック長に依存しない。音声側は確保・解放・ロック・待機をしない。
  素材は受け渡しのリングで返し、制御側が解放する。受け渡し中の素材は 4 個までとし、
  それを超える要求は制御側で最新 1 件だけを待たせる。ファイル数・トラック数・チャンネル数の上限ではない。

### UI はブラウザの選択に従う

- ブラウザの一覧の選択が変わるたびに `WorkspaceSession.auditionSelection` を呼ぶ。
  表示中の行の音声素材は試聴し、フォルダ・プロジェクト・非音声・選択解除は試聴を止める。文書がなければ鳴らさない。
- ダブルクリック・Return・取込みによる配置（[ADR 0122](0122-sample-library-search-and-placement.md)）は変えない。
  配置しても試聴は止めず、ブラウザは開いたままにする。トランスポートの停止は試聴を止めない。

## 検査と診断

- エンジンの単体回帰で、等倍の再生・モノラルの複製・置換時の先頭からの開始と 5 ms 減衰・停止・採用前の置換・受け渡しの上限と不正な平面を確認する。
  `block_size.rs` で置換と停止を含む出力を全ブロック長でビット一致させる。
- `echode-audio-io` の回帰は出力を差し替えて機器を開かず、実際に復号した WAV で試聴スレッドと製品のコールバックを通す。
  44.1 kHz の素材の SRC、連続選択で最新だけ鳴ること、読めない素材、停止、出力の追従と機器変更時の閉鎖を確認する。
  コールバックはインターリーブ・プレーナ・モノラル出力と機器変更後の無音を確認する。
- 必須契約 `sample-audition`（減衰を外すと失敗）と `sample-audition-ui`（非音声も試聴すると失敗）を登録した。
  FFI と Swift ブリッジは読めない素材の報告と停止を機器なしで確認する。
- スナップショットの音声状態 `audition` に、最新の要求番号・処理済みの番号・パス・段階
  （`loading` / `sounding` / `ended` / `stopped` / `failed`）・エラー・開いた出力のレートを載せる。
  要求が届いたか、処理されたか、出力が開いたかを区別できる。
- 実機の出力は無音の素材で開閉する無視したテストを `spike-audio` に含める。

## 未確認と残る範囲

- 2 つの IOProc の加算、機器切替時の挙動、聴感はユーザーの実機確認を待つ。自動検査の合格から推定しない。
- 長い素材は全体を読み終えるまで鳴らない。読込み中の表示、試聴の音量、プレビュー専用の出力先は未実装・未決である。
- P2-02 の他の残り（デバイスの展開・折りたたみ、ドラムラック、GUI アプリの MCP 入口、停止中の最初の出力準備）は変わらない。
