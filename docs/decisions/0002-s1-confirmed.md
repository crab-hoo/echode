# 0002. S1 の確定と S2 への進行

- 日付: 2026-10-07
- 状態: 採用

## 背景

S1（1,000 トラック・10 万ノートの Metal 描画）を実機で測り、表示の確認を得た。

## 決定

- S1 の結果を確定する。描画は、見えている範囲だけを Rust でインスタンスに変換し、Metal で 1 回のインスタンス描画にする
- 計測値は 60Hz の画面で、540 フレームの取りこぼし 0、CPU 時間の p99 が 0.62ms。詳細は `docs/spikes/S1-drawing.md`
- 次の検証は S2（CoreAudio と Audio Workgroup 上の 1,000 ノード）とする。S3 で残した「リアルタイム優先度での末尾の遅延」は、プラグイン処理をこのエンジンに載せる時に測り直す

## 結果

S1 のシーン件数は計測用であり、製品の上限にはしない。
