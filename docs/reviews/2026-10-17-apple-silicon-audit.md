# 2026-10-17 Apple Silicon 前提の最適化監査

静的な指摘を、PLAN、ARCHITECTURE、ADR 0058、S1〜S3、現行の描画とピークの経路と照合した。指摘側は新しいテストやコマンドを実行していない。採用した変更の自動検査は `make verify` の結果を正とする。

## 採用

- 表示リンクの 60 Hz 固定は、PLAN の「ディスプレイのリフレッシュレートに追従する」と S1 の式に反していた。画面の最大へ合わせる。120 Hz を全機種の固定値にはしない。
- 波形の `MTLBuffer` を毎フレーム確保していた。インスタンス用の 3 枠と同じく、飛行中の枠ごとに再利用する。
- ピークキャッシュが当たっても正準 PCM を全読込し、モノラルを常駐させていた。キャッシュヒットではピラミッドだけを使い、64 サンプル未満の端だけを読み取り専用マップから読む。
- 再生、CLI の書き出し、処理中のヘルパーに `NSProcessInfo` の `UserInteractive` を表明する。蓋閉じは止めない。
- ピアノロールの可視バッファを、問い合わせのたびに確保しない。

## 採用しない

- 全対象機が SME / ARMv9.2-A である、という前提。
- 音声スレッドとピーク生成への Accelerate。ADR 0058 の測定と、確保し得る API をリアルタイム経路へ置かない制約による。
- ページ境界を満たさない `bytesNoCopy`。
- ホスト時刻を持たないプレイヘッドの表示時刻補間。描画 tick は供給 tick と一致させる。

## 残す

同一ヘルパーの 1 往復化、IOSurface のサムネイル、APFS の clonefile、再生準備の全ファイル mmap は、対応する製品経路がまだ無い。可視要素をロックの外の Swift 配列へコピーする段と、見えている波形列の組み直しは残す。
