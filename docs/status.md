# 現在の範囲と制約

更新: 2026-10-16。製品の完成状況を案内する文書であり、最新ソースの合格証ではない。合否は `make verify` の結果、実操作は日付付きの監査記録で確認する。

## 進捗

Phase 0（S1〜S5）は確定済み。Phase 1 は、モデルとアクション、保存・復旧、CLI / API、音声出力、CLAP の隔離、3 ペインの開発用アプリまで接続した。履歴復帰、音声取り込み、Metal のアレンジとピアノロールもある。Phase 1 の全完了条件を満たしたとは宣言していない。

2026-10-13 の AUD / PRO の修正は各監査の対応欄と ADR に残す。2026-10-08 の設計・計測の未着手項目は元の一覧が正本で、後続の監査で指摘がなかったことを理由に完了へ変えない。

## 利用時に残る制約

- プラグインの GUI は未実装。ブラウザからの挿入と処理があることから、GUI やパラメーター編集まで使えると推測しない（[設計 §9.5](ARCHITECTURE.md#95-gui-とデバイスビュー)、[ADR 0093](decisions/0093-product-contract-gate.md)）。
- CLAP の楽器は Sine Pad を置き換え、エフェクトは入力を処理する。macOS のディレクトリ形式のバンドルを再生前に除外していた CU-06 は修正し、実バンドルのスキャンから処理までを通常検査へ追加した。全メーカーの互換性や実機の聴感を保証するものではない。
- 再生開始時の位置の一瞬の巻き戻り（CU-04）と、トラックヘッダが Space を消費する経路（CU-05）には必須回帰検査がある。2026-10-15 にユーザーが他アプリから戻った時の再生ボタンの反応を確認した。ショートカット全経路の実機確認とは区別する。
- 再生準備中の停止を投入時に音声側へ伝え、遅れた再生応答も停止を上書きしない。停止後は準備済み出力を再利用する。保持したプラグインの発音状態は停止・一時停止・位置移動で消し、通常の余韻とは分ける（[ADR 0099](decisions/0099-transport-plugin-state.md)）。初回の素材・プラグインの初期化時間は残る（[ADR 0097](decisions/0097-cancellable-retained-transport.md)）。ペイン縮小時の描画漏れは製品 View の中間状態の検査へ加えた（[ADR 0098](decisions/0098-pane-render-boundaries.md)）。
- 定期保存確認がプラグインを一時バイパスする問題を修正し、停止・一時停止の出力は、鳴っている波形を5 ms以内に減衰させる（[ADR 0103](decisions/0103-live-stop-waveform.md)）。ユーザーは修正版でも、ループ無効・複数種類の音源で停止クリックが残ることを確認した。実出力の診断（[ADR 0104](decisions/0104-stop-output-diagnostics.md)）から、減衰後の破棄する処理がヘルパーの完了を待ち、呼出が1周期以上欠落する不具合を特定した。ライブの後片付けを待機なしに変更し、完了前の再開は無音と時計の保持を維持する（[ADR 0105](decisions/0105-nonblocking-stop-cleanup.md)）。この修正版の聴感はユーザー確認待ち。準備中の取消は発音しない。構造更新にも音声側の排他的な所有権を適用し、共有ロックと一時バイパスを削除した。準備中は現在の計画で処理を続け、準備完了後に交換する（[ADR 0102](decisions/0102-exclusive-audio-graph.md)）。
- 素材・CLAP 間・書き出しのステレオ保持、配置音声のループ継ぎ目、5 ms のフェーダー補間と製品の f64 加算を接続した（[ADR 0095](decisions/0095-product-audio-buses-and-continuity.md)）。暗黙のステレオ→モノ変換はエラーになる。先読み・キャッシュ、Ogg、プラグインのサムネイルや音量等の画面操作は残る。
- 2026-10-14 の画面監査は特定の操作と一時プロジェクトの確認。保存復旧や全入力、聴感、機器の抜き差しを一括して合格にしない。

## 検査基盤で区別すること

無音からVital Initが発音する時のクリックの報告は、48 / 96 kHz・3種類のブロック長で、直接の音源出力と製品の再生・出力補正後の全サンプルが一致した。今回の条件ではEchodeによる追加の不連続は再現せず、音源のアタックは変更しない。Reaperの実出力と聴感の比較は未検証（[ADR 0106](decisions/0106-natural-plugin-onsets.md)）。

通常の回帰検査、誤りを戻したコピーの拒否、画面を開かない GPU 検査、実ウィンドウのプローブ、Computer Use、聴感はそれぞれ違う証拠になる。実ウィンドウの `spike-playhead` は AppKit のイベントループで動かす。遮蔽などで期待値を検証できなければ非ゼロで終わる。

長時間の音声計測は、途中停止・機器変更・中断を完走として合格にしない。旧計測器の判定漏れ、無効な合格と再現記録は [ADR 0096](decisions/0096-measurement-completion.md) に残す。

終了フックのスクリプトを直接呼ぶ検査と、アプリが実イベントからフックを呼んだ確認も別である。GitHub Actions の設定があることを、リモート実行済みと扱わない。環境別の未確認事項は最終報告に残す。
