# 現在の範囲と制約

更新: 2026-10-17。製品の完成状況を案内する文書であり、最新ソースの合格証ではない。合否は `make verify` の結果、実操作は日付付きの監査記録で確認する。

対象方針は macOS 27 以降、M4 ファミリー以降の Apple Silicon。2026-10-17 のユーザー指定を [ADR 0112](decisions/0112-m4-minimum.md) に反映した。Rust・C / C++・Swift と補助コードの M4 向けコンパイル設定、製品・依存・検査の最低 OS 27.0 を接続した（[ADR 0114](decisions/0114-m4-build-baseline.md)）。チップ名による起動時の機種判定と SME 最適化、実機性能の改善量は未確認である。

## 進捗

Phase 0（S1〜S5）は確定済み。Phase 1 は、モデルとアクション、保存・復旧、CLI / API、音声出力、CLAP の隔離、3 ペインの開発用アプリまで接続した。履歴復帰、音声取り込み、Metal のアレンジとピアノロールもある。トラックの音量・パン・ミュート・ソロ・ピークと、音声クリップのゲイン・フェードを画面へ接続した（[ADR 0107](decisions/0107-mix-controls.md)）。2026-10-17にユーザーの聴感確認を受領し、ループ先頭の保持とフェーダー前の差し替え口を製品へ接続した。PLANのP1完了条件との[最終照合](reviews/2026-10-17-phase1-acceptance.md)を行い、P1を完了とする。全設計や全実機検査の完了ではなく、現在の自動検査の合否は検査レポートで確かめる。

2026-10-13 の AUD / PRO の修正は各監査の対応欄と ADR に残す。2026-10-08 の設計・計測の未着手項目は元の一覧が正本で、後続の監査で指摘がなかったことを理由に完了へ変えない。

## 利用時に残る制約

- プラグインの GUI は未実装。ブラウザからの挿入と処理があることから、GUI やパラメーター編集まで使えると推測しない（[設計 §9.5](ARCHITECTURE.md#95-gui-とデバイスビュー)、[ADR 0093](decisions/0093-product-contract-gate.md)）。
- CLAP の楽器は Sine Pad を置き換え、エフェクトは入力を処理する。macOS のディレクトリ形式のバンドルを再生前に除外していた CU-06 は修正し、実バンドルのスキャンから処理までを通常検査へ追加した。全メーカーの互換性や実機の聴感を保証するものではない。
- 再生開始時の位置の一瞬の巻き戻り（CU-04）と、トラックヘッダが Space を消費する経路（CU-05）には必須回帰検査がある。2026-10-15 にユーザーが他アプリから戻った時の再生ボタンの反応を確認した。ショートカット全経路の実機確認とは区別する。
- 再生準備中の停止を投入時に音声側へ伝え、遅れた再生応答も停止を上書きしない。停止後は準備済み出力を再利用する。保持したプラグインの発音状態は停止・一時停止・位置移動で消し、通常の余韻とは分ける（[ADR 0099](decisions/0099-transport-plugin-state.md)）。初回の素材・プラグインの初期化時間は残る（[ADR 0097](decisions/0097-cancellable-retained-transport.md)）。ペイン縮小時の描画漏れは製品 View の中間状態の検査へ加えた（[ADR 0098](decisions/0098-pane-render-boundaries.md)）。
- 定期保存確認がプラグインを一時バイパスする問題を修正し、停止・一時停止の出力は、鳴っている波形を5 ms以内に減衰させる（[ADR 0103](decisions/0103-live-stop-waveform.md)）。ユーザーは修正版でも、ループ無効・複数種類の音源で停止クリックが残ることを確認した。実出力の診断（[ADR 0104](decisions/0104-stop-output-diagnostics.md)）から、減衰後の破棄する処理がヘルパーの完了を待ち、呼出が1周期以上欠落する不具合を特定した。ライブの後片付けを待機なしに変更し、完了前の再開は無音と時計の保持を維持する（[ADR 0105](decisions/0105-nonblocking-stop-cleanup.md)）。2026-10-17にユーザーから聴感確認済みの報告を受けた（確認範囲は[最終照合](reviews/2026-10-17-phase1-acceptance.md)）。準備中の取消は発音しない。構造更新にも音声側の排他的な所有権を適用し、共有ロックと一時バイパスを削除した。準備中は現在の計画で処理を続け、準備完了後に交換する（[ADR 0102](decisions/0102-exclusive-audio-graph.md)）。
- 素材・CLAP 間・書き出しのステレオ保持、配置音声のループ継ぎ目、5 ms のフェーダー補間と製品の f64 加算を接続した（[ADR 0095](decisions/0095-product-audio-buses-and-continuity.md)）。暗黙のステレオ→モノ変換はエラーになる。P1のループ先頭は全素材を準備して保持することで先読みし、ループ変更では読み直さない。フェーダー前の出力元の差し替えも製品接続した（[ADR 0108](decisions/0108-phase1-loop-readiness.md)）。初回の全素材読込時間・メモリ使用、範囲を順次読むディスクストリーミング、Phase 3のレンダリングキャッシュ本体とライブ切替、Ogg、プラグインのサムネイルは残る。クリップのゲインは 0 以上 1048576 以下で、音声クリップだけに効く。負の配置オフセットはファイルより前の無音で、内容位置 0 は `start - offset` のテンポ積分に置かれる。プラグインの自動保存は Undo に積まない。停止テールの準備済みトラックは、未開始なら無音で、ループ終端を超えて読まない。平坦なキャッシュの内部にある後発の発音は分離しない（[ADR 0109](decisions/0109-placement-bounds-and-plugin-capture.md)）。トラックのメーターはフェーダー後の左右の最大ピークで、ラウドネスやトゥルーピークではない。表示リンクは画面の最大リフレッシュレートに合わせ、波形の Metal バッファは飛行中の枠ごとに再利用する。ピークキャッシュが当たった粗い列は正準 PCM を全読込しない。再生・CLI 書き出し・処理中のヘルパーは App Nap とアイドルスリープを避ける表明を持つが、蓋を閉じたスリープは止めない（[ADR 0110](decisions/0110-apple-silicon-draw-and-peaks.md)）。
- プラグインヘルパーは `SIGSEGV`、`SIGBUS`、`SIGILL` でも共有領域にクラッシュの印を書く。プロセス終了を遅らせるクラッシュレポートと、いま待っているブロックの締め切りは残る。AUv3 の二重隔離、プラグインウィンドウのフォーカス、スキャンの Seatbelt、Workgroup ポートの 2 ms ポーリングの置き換えは未実装（[ADR 0111](decisions/0111-macos-helper-notices.md)）。
- macOS 27 の[最適化監査](reviews/2026-10-17-macos27-optimization-audit.md)の M27-01 / 02 / 03 に対応した。製品は選択デバイスの Workgroup を取得し、ヘルパーの追加・保持・再起動へ渡す。変更通知では出力を再準備し、取得・参加の失敗はエラーにする。Rust・C / C++・Swift を M4 向け、最低 OS を27.0に揃えた。Swift の指定は Clang import にも同じ CPU を渡して不一致を解消した。スパイク・直接の検査プログラム・Xcode の入口も含む（[ADR 0114](decisions/0114-m4-build-baseline.md)）。組立前に本体とヘルパーの Mach-O を検査する。同じ素材の変換と同じ配置結果の PCM は共有し、未参照の素材をキャッシュから外す。短いトリムだけのために全素材を追加常駐させない。M27-04 は可視列・波形・ノートの再問い合わせを版とカメラで省くところまで対応し、インスタンス配列・波形連結・アップロードは残る。CPU の並列グラフ、ヘルパーのメーカー単位の集約、SME、Metal 4 は比較候補であり未実装。機器・画面・聴感での改善量は未測定（[ADR 0113](decisions/0113-product-macos-workgroup-and-caches.md)）。
- 2026-10-14 の画面監査は特定の操作と一時プロジェクトの確認。保存復旧や全入力、聴感、機器の抜き差しを一括して合格にしない。

## 検査基盤で区別すること

2026-10-17 の TSan は、UI の世代更新テストが実 HAL を開き、OS 所有の出力バッファ書込みと保存処理の書込みを同じアドレスとして報告した。UI テストは機器なしの応答へ修正したが、実 HAL の警告の原因は未確定である。自動検査の合格をその解決へ読み替えず、抑制もしない。実機の追加調査は明示依頼を受けて行う（[ADR 0113](decisions/0113-product-macos-workgroup-and-caches.md)）。

M4 ビルドの統一後には、以前の終了済みスレッドと新しいスレッドの errno 警告も再発した。同じ M4 / macOS 27・nightly・Apple ランタイムで、製品を含まない標準ライブラリの独立プログラムでも再現した。内部原因は未確定で、抑制や検査条件の緩和は行わない。実 HAL の警告とは別に記録し、正式な再実行の合否は検査レポートを参照する（[ADR 0114](decisions/0114-m4-build-baseline.md)）。

無音からVital Initが発音する時のクリックの報告は、48 / 96 kHz・3種類のブロック長で、直接の音源出力と製品の再生・出力補正後の全サンプルが一致した。今回の条件ではEchodeによる追加の不連続は再現せず、音源のアタックは変更しない。Reaperの実出力と聴感の比較は未検証（[ADR 0106](decisions/0106-natural-plugin-onsets.md)）。

通常の回帰検査、誤りを戻したコピーの拒否、画面を開かない GPU 検査、実ウィンドウのプローブ、Computer Use、聴感はそれぞれ違う証拠になる。実ウィンドウの `spike-playhead` は AppKit のイベントループで動かす。遮蔽などで期待値を検証できなければ非ゼロで終わる。

長時間の音声計測は、途中停止・機器変更・中断を完走として合格にしない。旧計測器の判定漏れ、無効な合格と再現記録は [ADR 0096](decisions/0096-measurement-completion.md) に残す。

終了フックのスクリプトを直接呼ぶ検査と、アプリが実イベントからフックを呼んだ確認も別である。GitHub Actions の設定があることを、リモート実行済みと扱わない。環境別の未確認事項は最終報告に残す。
