# S5: ピンチ、触覚、感圧

- 日付: 2026-10-08
- 状態: 確定（実機で確認）
- 実装: `spikes/input`

## 何を確かめたか

3 つの操作を、AppKit の入力から切り離した規則と、それを使うウィンドウに分けた。

- モード 1 は、ジェスチャー開始時の指の間隔を基準に、縦横を同じ比率で拡大する
- モード 2 は、横か縦かが分かるまで倍率を動かさない。決まってからは、その時点の指の間隔を基準に、その軸だけを拡大する
- ドラッグで 40 ポイントの格子をまたいだ時だけ、整列の触覚を出す。触覚は `NSHapticFeedbackManager` で、ドラッグ中か感圧の最中にしか鳴らない
- キーボードの和音（A が C3、S が D3、D が E3。黒鍵は W E T Y U）を押している間だけ、トラックパッドの圧力を 0 から 1 に収めてその和音のプレッシャーにする。和音がなければ圧力は送らない。感圧の段が変わった時は、段階の触覚を出す

規則のテストは 12 件、すべて成功した。M4 の MacBook Air で、ピンチ・格子の触覚・和音を押さえた感圧が操作として成立することを確認した。

製品のズームは、この 2 つのモードを両方残した上で、既定を「画面と修飾キーで軸を決める通常ピンチ」にする。決め方は [ADR 0007](../decisions/0007-s5-confirmed-phase1.md)。

## 実機での見方

```sh
make spike-input
```

ウィンドウが開いたら、次を行う。

1. 普通にピンチし、X と Y が同じように変わること。指の上下を入れ替えても、倍率が飛び過ぎないこと
2. キー `2` のあと、はっきり横または縦にピンチし、その軸だけが変わること。始まりで倍率が揺れないこと。キー `1` で通常に戻る
3. 四角をドラッグし、格子をまたいだ瞬間にトラックパッドが鳴ること
4. A と D を押したままトラックパッドを強く押し、`pressure C3 E3` と圧力の数値が動くこと

ウィンドウを閉じると終了する。
