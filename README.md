# Echode

macOS 専用のオープンソース DAW。Phase 1 を完了し、Phase 2 を開始しました。[現在の範囲と制約](docs/status.md)、[Phase 2 の進め方](docs/phase2.md)、[資料の入口](docs/README.md)、[計画](docs/PLAN.md)、[設計](docs/ARCHITECTURE.md) を参照してください。

## 開発を始める

M4 ファミリー以降の Apple Silicon、macOS 27 以降、Xcode 27 と Rust を使います。Rust は `rust-toolchain.toml` に固定しています。CPU の対象方針は [ADR 0112](docs/decisions/0112-m4-minimum.md) を参照してください。

```sh
make doctor           # 環境、アプリと検査結果の古さを確認
make setup            # 通常検査の追加ツールを初回に用意
make setup-bridge     # 橋渡しの動的検査用ツールを初回に用意
make app              # target/Echode.app を作る
make verify-plan      # 変更に応じた検査を確認
make verify           # 作業ごとの完了確認。自動検査と実機検査の記録を確認
make verify-full      # 節目の確認。サニタイザと全反例を含む自動検査の全件
make verification-profile  # 保存された検査時間・再利用・時間履歴を表示
make debug-report     # 既存の検査ログと診断資料を収集
```

エージェントは [AGENTS.md](AGENTS.md) と [開発手順](docs/development.md) を読んで作業してください。検査の実行・見送りと有効期限は [検査手順](docs/verification.md)、失敗の調査は [デバッグ手順](docs/debugging.md) にまとめています。`make check` は通常検査と必須の製品回帰を実行し、追加検査の選択は `make verify` が行います。`just` が入っていれば、定義された同名レシピも使えます。

`make app` は、ログインキーチェーンに `Echode Local` があればその証明書で、なければ ad-hoc で署名します。証明書は `make sign-setup` で作成できます。配布は `make dist`、XcodeGen のプロジェクト生成は `make xcode`。Xcode のライセンスに未同意なら、利用者がターミナルで `sudo xcodebuild -license` を確認してください。

## 開発用アプリの操作

`target/Echode.app` を開き、開始画面・ツールバー・Command-N の「新規プロジェクト」から、保存先と名前を指定して `.echode` パッケージを作成します。
起動時に前回のプロジェクトを開けなかった場合も、エラーを閉じて新規作成できます。
最新の保存版が壊れて古い版へ戻る場合は、編集を始める前に復旧元と読めない版を表示して確認します。
「キャンセル」で原本のコピーを保全し、内容を確認してください。
「復旧した版から続行」を選ぶと、その状態を新しい保存点へ記録してから編集できます。
失われた最近の編集を復元する操作ではありません（[ADR 0183](docs/decisions/0183-recovery-consent.md)）。
トラックを追加して、下部のピアノロールで打ち込めます。
空白の左ドラッグで開始位置を固定してノートを追加し、横移動で長さ、上下で音高を変えて、離した時に確定します。
Shift で開始・終端の吸着を解除できますが、新規ドラッグの最短長は現在のグリッド幅です。
ピアノロール上端で「自動グリッド」または全音符〜128 分音符の通常・三連符・付点の固定幅を選べます。
自動は横ズームに合わせて細分化し、固定はズームしても音価を保ちます。記憶済みの入力長は丸め直しません。
吸着幅とは別に毎拍と 4 拍ごとの目印を残すため、粗い固定幅や縮小表示でも時間の位置を追えます。目印自体には吸着しません。
選択した幅は入力・ノート編集・矢印・ルーラーで共通です。トラック切替とエディタ再生成では保ち、再オープンで自動へ戻します。
空白の単クリックでノートを追加します。単一ノートの選択・追加・長さ変更で、その長さを次の入力へ引き継ぎます。
入力長は全トラックで共通、追加・長さ変更の Undo / Redo でも戻ります。グリッドに丸め直さず、プロジェクトの再オープン時に初期化します。
ダブルクリックの 2 回目は追加を重ねません。Return は挿入ではなく、その場での一時停止／再開です。
編集トラックを切り替えても、ピアノロールの時間・音域・ズームを保ちます。
エディタを閉じて開き直しても保ち、プロジェクトを開き直すと初期化します。
アレンジでトラックを選ぶだけでは、ピアノロールの入力先を変えません。
アレンジの空白または MIDI クリップをダブルクリックすると、そのトラックと位置を開きます。再生開始位置は変えません。
右側の一覧の「編集」で入力先を選び、「表示」で他トラックの薄い参照ノートを切り替えます。
参照ノートは直接編集せず、その上のクリックでも現在の入力先へ追加します。重なる編集ノートがある時は、そのノートを優先します。
「表示」「編集」は音と保存・Undo から独立し、「ソロ」「ミュート」は通常のトラック編集として保存・Undo へ反映します。
既存ノートはドラッグで移動、両端のドラッグで長さを変更します。
Shift を押している間はノートの移動・伸縮のグリッド吸着を解除し、グリッド未満の長さにもできます。
Option＋上下ドラッグでは、音高・時刻・長さを変えずベロシティだけを変更し、離した時に 1 回の Undo として確定します。
値は 0〜127（0 は無音）で、下端の棒とドラッグ中の数値に表示します。単一選択・調整後の値を全トラックの次の入力へ引き継ぎます。
入力ベロシティの記憶は Undo で戻さず、文書を開き直すと 100 に戻ります。ノートの値自体は Undo / Redo・保存の対象です。
ピアノロール下部のベロシティレーンでも、棒を上下ドラッグして同じ値を編集できます。
棒のクリックだけでは値を変えず、空白からノートを追加しません。音域表示の外のノートも、表示時刻内なら棒を表示します。
選択したノートは数値入力と「変更を適用」でも編集できます。
ノートグリッドの右ドラッグで、枠に一部でも触れたノートを複数選択します。Command＋クリックで選択を追加・解除できます。
Delete / Forward Delete、または選択済みノートの右クリックメニューで、選択全体を 1 回の Undo として削除します。
未選択ノートの右クリックはその 1 音を選び、空白右クリックは選択解除だけです。文字入力中の Delete は文字を削除します。
選択済みノートの Option ドラッグと選択済みの棒のドラッグは、選択全体のベロシティを同じ量だけ変更します。
どれかが 0／127 に達したら全体を止め、強弱差を保ちます。つかんだ音の変更後の値を次の入力へ引き継ぎます。
選択済みノートの本体ドラッグは、相対時刻と音程を保って選択全体を移動し、離した時に 1 回の Undo として確定します。
つかんだ音をグリッドへ合わせ、Shift で吸着を解除します。時刻 0 や音域端では全体が止まり、入力長と入力ベロシティは変えません。
選択済みノートの端をドラッグすると、反対端を保って全体を同じ量だけ伸縮します。最短の音が 1 tick になるか時刻 0 に達すると全体が止まります。
つかんだ端を吸着し、Shift で解除します。一括伸縮では入力長・入力ベロシティを変えません。
Command＋ドラッグは元を残してノートを複製移動し、離すと複製側を選択します。
選択済みなら全体、未選択ならその 1 音を複製します。端から始めても伸縮せず、Shift で吸着を解除できます。
複製は長さとベロシティを保ち、単一 Undo / Redo・保存の対象です。Command＋クリックの選択切替は離した時に行います。
Command-T・メニュー・ツールバーのトラック追加は選択の下、アレンジ下部の「末尾にトラックを追加」は最上位末尾へ追加します。
子を持つフォルダはヘッダ左の記号か左右矢印で開閉できます。
展開中の追加は最後の子、折りたたみ中はフォルダ全体の外側になります。空トラックの追加では音源候補を自動で開きません。

Tab / Shift-Tab は次 / 前のノート、上下は半音（Option で1オクターブ）、左右は現在のグリッド幅の移動、Shift-左右は右端の長さ変更です。
複数選択では全体を同じ差分で動かし、時刻・音域・最短長の共通境界で止めます。キーリピートも順番に処理し、1 回のキー入力を 1 回の Undo にします。
Return は一時停止／再開、Delete は削除、Escape はドラッグの取消です。
鍵盤の横にはディグリー（I〜VII）を表示します。表示する調と長短調は画面内の設定で、プロジェクトの調を変更しません。

変更は Rust のアクションとジャーナルへ記録し、プロジェクトの履歴へ自動コミットします。Undo / Redo は Command-Z / Shift-Command-Z。左右と下部のペインは Option-Command-1 / 2 / 3、コマンドパレットは Shift-Command-P で開閉します。アレンジはスクロール、ピンチで時間、Option-ピンチで高さ、Shift-ピンチで両軸を拡大します。

Space は再生／停止、Command-. は停止です。停止は記憶した開始位置へ戻り、一時停止はその場から再開します。
Return と再生ボタン・メニューはその場で一時停止／再開します。入力欄は確定を、サンプル・FX の一覧は配置を優先します。
両エディタのルーラーをクリックすると開始位置を変え、ドラッグするとループ範囲だけを変えます。
既存ループの左右端は、ルーラー上端のグリップをドラッグして片端だけ調整できます。
アレンジは四分音符、ピアノロールは現在のノートグリッドへ吸着し、Shift で吸着を外します。
ループのオン／オフは別操作です。Escape で確定前のドラッグを取り消します。
拍を指定する「移動」は現在位置だけを変えます。「音声出力」ではシステム出力への追従か機器を選び、レートとバッファ長を確認できます。

「プラグイン」で CLAP 一覧を開き、ダブルクリックで選択トラックへ挿入します。
Enter ならブラウザを開いたまま挿入します。同梱の Sine Pad も一覧から通常の音源として挿入します。
アレンジのトラック名付近を Command クリックで複数選択、Shift クリックで範囲選択できます。
候補を右クリックし「選択トラックすべてに追加」で一括挿入し、1 回の Undo でまとめて戻せます。
複数選択したトラックのヘッダかインスペクターで Mute / Solo を切り替えると、操作後の値へ全選択トラックをそろえ、1 回の Undo で戻せます。
選択外のソロは維持します。ピアノロール右側の Solo / Mute はその行だけの操作です。
音量・パンの数値入力は、入力したトラックを基準に全選択トラックへ同じ dB 差・パン差を適用し、1 回の Undo で戻せます。
ヘッダのトリプルクリックかインスペクターで入力します。最大音量やパン端では全体の差分を制限し、相対関係を保ちます。
無音のトラックを基準に音量を上げる時は、単独選択か無音でない別の基準を使います。
ヘッダの読み上げの増減も、音量は 1 dB、パンは 5% の共通差分で選択全体を調整します。上限では全体が止まり、無音の基準からの増加は理由を表示します。
ヘッダのドラッグ・既定値リセットも、押下時の選択全体を相対調整し、1 回の操作を 1 回の Undo として記録します。
リセットは基準の 0 dB／中央を目指し、他の対象の限界では全体が止まります。Escape と 3 回目のクリックは試聴全体を取り消します。
実画面・VoiceOver・聴感はユーザー確認待ちです。
下部の「デバイス」は選択トラックのデバイスを処理順に横へ並べ、各デバイスが公開する全パラメーターをスライダーで変更できます。
ドラッグ中の値はそのまま聴こえ、離した時に 1 回の Undo として記録します。停止中は再生を始めずにプラグインを起動します。
初回の出力準備中は、未取得の一覧に「音声出力を準備中」と表示します。
出力の準備が終わってもプラグインが応答していない間は、パラメーターの読込み表示へ切り替わります。
各デバイスの検索欄は名前とモジュール名で絞り込み、ピンのボタンで項目をそのデバイスの最上部に固定します。
ピン留めはプロジェクトに保存し、複製したデバイスにも引き継ぎます。
ノートエディタ（⌥⌘3）とデバイス（⌥⌘4）はツールバー・メニューから個別に開閉し、両方開くとアレンジ・ピアノロール・デバイスの順に積みます。
デバイスは高さ 300 pt を保ち、ピアノロールの高さは境界で調整できます。⌥⌘5 は開閉状態を変えずにアレンジを隠す／戻す切替です。
開閉と高さはウィンドウ設定に記憶し、プロジェクトの保存・Undo へは入りません。
デバイス名の左の開閉ボタンで列を折りたためます。名前・バイパス等は残し、検索と一覧だけを隠します。
開閉は音・Undo・保存を変えず、トラックや下部の表示を切り替えても保持し、文書を開き直すと展開へ戻ります。
デバイスの「オフライン」は記録済み設定を残してプラグインのヘルパーを解放します。
解除すると設定から読み直します。同じトラックの音声素材はオフライン中もそのまま通ります。
音源のないトラックのノートは無音で、エフェクトは入力音を処理します。挿入済みのプラグイン名をクリックすると、そのプラグインのウィンドウが開きます。
候補から 1 つ追加した時も自動で開きます。開いてもキー入力は Echode に残り、ウィンドウの中をクリックした時だけプラグインへ移ります。
デバイス列とインスペクターの名前の横の窓アイコンは、その独自ウィンドウが開いていることを示します。
別アプリの操作中に一時的に隠れていてもアイコンは残ります。窓の表示状態は保存・Undo の対象外です。
履歴から以前の版へ戻せ、音声ファイルは選択トラックへ取り込めます。ループとメトロノームは再生設定です。

右のファイル欄の「フォルダを選択」でサンプルフォルダを登録します。
検索欄に入力すると、登録した全フォルダの下にある音声・MIDI・`.echode` を名前で検索します。
フォルダ一覧も制作向けの種類だけを表示し、MIDI は「読込みは未対応」と表示します。
「サンプルフォルダ」から移動・登録解除でき、登録は次回起動時にも保持します。
素材を追加・削除したら更新ボタンで一覧を読み直します。
音声のダブルクリック・Return・「音声を取り込む」は、操作時の選択トラックと再生ヘッド位置へ配置します。
グリッドへ丸めず、ブラウザを開いたままにします。選択時には素の音を先頭から 1 回試聴します。
長い素材は読み込みながら鳴らし、一覧の下に同じ読込みからの波形・長さ・読込み状態を表示します
（[試聴の設計](docs/decisions/0151-streaming-sample-audition.md)）。
ブラウザ表示中は試聴出力を保持します。自動試聴をオフにしても右矢印と再生ボタンで試聴でき、波形のクリックで開始位置を指定できます。
試聴音量と自動試聴の設定は記憶し、曲の再生・音量・編集履歴とは独立します
（[ADR 0152](docs/decisions/0152-browser-audition-controls.md)）。
アレンジのクリップを選んで Command-D を押すと、現在のクリップ長を使って直後へ複製します。時刻を拍へ丸めず、MIDI の中身は元と独立します。
複製側を選択し、1 回の Undo / Redo・保存の対象になります。アレンジにフォーカスがある時だけ有効で、キーの押し続けでは連続複製しません。
重なる既存クリップは移動と同じ「置き換え」で扱います。複数クリップの一括複製は未対応です。
ブラウザや Finder から音声ファイルを 1 つアレンジへドラッグすると、その行のポインター位置へ配置します。
現在の拍グリッドへ吸着し、Shift を押している間は解除します。最終行より下（空のプロジェクトも含む）では最上位末尾に新しいトラックを作ります。
トラック作成と取込みは 1 回の Undo で戻せます。複数ファイルの同時ドロップと、同トラックの既存クリップに重なる配置はまだ受け付けません。

## アプリから WAV を書き出す

ファイルメニューの「音声を書き出す」（⇧⌘E、コマンドパレットにも表示）で、形式・レート・余韻・ディザ・ピークノーマライズを選びます。
初回は 24 bit PCM、出力のレート（出力未準備なら 48 kHz）、プラグインの余韻、ディザなしです。
ノーマライズは既定で無効です。有効時は曲全体・余韻の左右共通のサンプルピークを指定値（−120〜0 dBFS、初期目標 −1）へ合わせます。
数値欄が空・不正・範囲外なら理由を表示し、修正するまで書出しを開始しません。前の有効値で代用しません。
桁区切りは使わず、余韻とピーク目標の小数点は表示ロケールに合わせます。無効にした余韻・ノーマライズの欄は検証対象外です。
設定は準備後にプロジェクト内の `export.json` へ保持し、パッケージの移動・コピー先でも引き継ぎます。
旧版のこの Mac のパス設定は、次の書出しの準備時に移行します。設定の保存に失敗しても書出しは続け、下部の「詳細」に警告を残します。
出力先を確定すると、記録済みの曲と参照する素材・プラグイン状態を専用パッケージに固定し、同梱 CLI の別プロセスで書き出します。
出力先は元パッケージの外だけを受け付け、開始時に解決した親フォルダへ固定します。後でフォルダのリンク先を変えても追従しません。
外のファイルを指す出力リンクは、参照先ではなくリンク自身を置換します（[ADR 0260](docs/decisions/0260-pinned-gui-export-destination.md)）。
準備中は編集の反映を待つことがありますが、その後は編集・再生・別文書への切替を続けられます。
準備後は下部に処理済みの率を表示し、全フレーム処理後もファイルの同期・公開が終わるまでは 99% と「書出しを仕上げ中」に留めます。
下部の「書出しを取り消す」で途中取消を要求できます。処理の区切りと片付けを待つ間は「書出しを取消中」となります。
取消を認めた場合は既存の出力を保持します。公開が先に終わった場合は完了、別の失敗は失敗として「詳細」に表示します。
準備中のコピーや実行中のプラグイン処理は即時に中断せず、取消や完了まではアプリを終了しないでください（[ADR 0256](docs/decisions/0256-export-cancellation.md)）。
完了後は下部の「Finder で表示」で、実際に書き出したファイルを選択表示できます。Finder を自動では開きません。
文書切替後も完了した書出し先を使い、次の書出しの開始・失敗・取消では前回ファイルの表示ボタンを残しません。
保存前の下書きやライブのプラグイン状態そのものではなく、確定済みの状態が対象です（[ADR 0254](docs/decisions/0254-gui-snapshot-export.md)）。

## CLI で WAV を書き出す

CLI と隔離ヘルパー、同梱音源を同じ版でビルドし、プロジェクトと出力先を渡します。

```sh
cargo build --release -p echode-cli -p echode-plugin-host
bash scripts/build-bundled-plugins.sh release
target/release/echode render Song.echode mix.wav --format pcm24 --sample-rate 48000
```

`--format pcm16` は 16 bit PCM、`--format pcm24` は 24 bit PCM、`--format float32` は 32 bit float のステレオ WAV です。
省略時は従来どおり float です。
PCM はフルスケールで飽和します。`--dither tpdf` で量子化前に TPDF ディザを加えられます（既定は `--dither none`）。
同じ版・入力・設定なら繰り返し書出しのバイト列は一致し、無音にも微小なノイズを加えます。float への TPDF は拒否します。
`--normalize-peak-db -1` で、余韻を含むミックスのサンプルピークを −1 dBFS へ合わせます（範囲 −120〜0、既定は無効）。
左右共通の一定ゲインをディザ・量子化の前に掛け、無音は無音のままです。LUFS・トゥルーピーク・リミッターではありません。
1 回のミックスを同じ出力フォルダの一時領域へ float で保存して処理するため、最終 WAV に加えて 1 フレーム 8 バイトの空き容量が必要です。
後段の変換中も「仕上げ中」となり、取消できます。ノイズシェーピングはしません（[ADR 0258](docs/decisions/0258-peak-export-normalization.md)）。
長さの指定がなければ曲の終端とプラグインの申告する余韻を含めます。
`--tail-frames N` は申告値の代わりに出力レートの N フレームを曲末へ足します（48 kHz の `96000` は 2 秒、`0` は余韻なし）。
無限の余韻にも使え、プラグインがなければ指定分の無音を足します。
`--frames N` は従来どおり先頭からの総フレーム数で、`--tail-frames` とは併用できません（[ADR 0250](docs/decisions/0250-explicit-export-tail.md)）。
`--progress-json` を付けると、標準出力へ版 1 の NDJSON で処理済み・総フレーム数と `rendering` / `finalizing` / `complete` を出します。
率は余韻込みで、準備中は未確定です。標準エラーの診断と `exported` 行は変えず、成功の最終判定には終了コードを使ってください。
パイプへ渡す場合は実行中に読み続けてください（[ADR 0255](docs/decisions/0255-export-progress.md)）。
`--cancel-stdin` を任意指定すると、標準入力への任意の 1 バイトまたは EOF で途中取消を要求できます。
制御側は実行中はパイプを開いたままにし、取消時に閉じてください。オプションなしでは stdin の EOF は取消になりません。
取消を認めた時だけ終了コード 130 と `export cancelled` を返し、`complete` / `exported` は出しません。公開後の要求では完成ファイルを取り消しません。
出力先は元のプロジェクトパッケージの外にしてください。パッケージ自身・内部のファイル・内部を指すリンクは、復旧や書込みの前に拒否します。
相対パスとフォルダのリンクも解決して判定します（[ADR 0259](docs/decisions/0259-export-destination-boundary.md)）。
失敗時は既存の出力を保ち、完成後のディレクトリ同期だけが失敗した場合は出力を残して耐久性不明を返します。
RIFF の長さが 4 GiB のサイズ欄を超えると、拡張子はそのままで RF64 へ自動で切り替えます。
フレーム数は最大 `u32::MAX` のままです（[ADR 0249](docs/decisions/0249-rf64-wav-export.md)）。

## MCP でヘッドレスのセッションへ接続する

既存の `.echode` パッケージを指定して、別のターミナルで `target/release/echode serve PACKAGE SOCKET` を起動します。実行ファイルは `cargo build --release -p echode-cli` で作れます。MCP クライアントには、その実行ファイルの絶対パスを command、`["mcp", "SOCKETの絶対パス"]` を args として指定します。

同じビルドの serve と mcp を使います。MCP は登録済みアクションのツール、まとめた編集、Undo / Redo、概要とトラックの読み取りを提供します。編集は既存のジャーナルへ記録されます。起動中の GUI アプリへの接続と再生・機器操作は初版の対象外です。GUI で開いている同じパッケージを serve で開き直さないでください。接続範囲と検査は [ADR 0115](docs/decisions/0115-phase2-mcp.md) を参照してください。
同じ値の設定や、全体として元に戻る一括編集も成功しますが、Undo・Redo・ジャーナル・自動保存は変えません。
成功時の Action／配列は依頼を受理した結果であり、新しい Undo の段を作ったことを意味しません（[ADR 0182](docs/decisions/0182-noop-edits.md)）。
破損した保存版から後退したセッションの編集は、復旧の確認が済むまでエラーになります。
CLI / MCP には確認の入口を設けていないため、原本を保全したうえでアプリから復旧を確認してください。
