# Echode

macOS 専用のオープンソース DAW。Phase 1 を完了し、Phase 2 を開始しました。[現在の範囲と制約](docs/status.md)、[Phase 2 の進め方](docs/phase2.md)、[資料の入口](docs/README.md)、[計画](docs/PLAN.md)、[設計](docs/ARCHITECTURE.md) を参照してください。

## 開発を始める

M4 ファミリー以降の Apple Silicon、macOS 27 以降、Xcode 27 と Rust を使います。Rust は `rust-toolchain.toml` に固定しています。CPU の対象方針は [ADR 0112](docs/decisions/0112-m4-minimum.md) を参照してください。

```sh
make doctor           # 環境、アプリと検査結果の古さを確認
make setup            # 通常検査の追加ツールを初回に用意
make setup-bridge     # 橋渡しの動的検査用ツールを初回に用意
make app              # target/Echode.app を作る
make verify-plan      # 変更に応じた検査を確認
make verify           # 自動検査と実機検査の記録を確認
make debug-report     # 既存の検査ログと診断資料を収集
```

エージェントは [AGENTS.md](AGENTS.md) と [開発手順](docs/development.md) を読んで作業してください。検査の実行・見送りと有効期限は [検査手順](docs/verification.md)、失敗の調査は [デバッグ手順](docs/debugging.md) にまとめています。`make check` は通常検査と必須の製品回帰を実行し、追加検査の選択は `make verify` が行います。`just` が入っていれば、定義された同名レシピも使えます。

`make app` は、ログインキーチェーンに `Echode Local` があればその証明書で、なければ ad-hoc で署名します。証明書は `make sign-setup` で作成できます。配布は `make dist`、XcodeGen のプロジェクト生成は `make xcode`。Xcode のライセンスに未同意なら、利用者がターミナルで `sudo xcodebuild -license` を確認してください。

## 開発用アプリの操作

`target/Echode.app` を開き、開始画面・ツールバー・Command-N の「新規プロジェクト」から、保存先と名前を指定して `.echode` パッケージを作成します。
起動時に前回のプロジェクトを開けなかった場合も、エラーを閉じて新規作成できます。
トラックを追加して、下部のピアノロールで打ち込めます。
空白の左ドラッグで開始位置を固定してノートを追加し、横移動で長さ、上下で音高を変えて、離した時に確定します。
Shift で開始・終端の吸着を解除できますが、新規ドラッグの最短長は現在のグリッド幅です。
空白の単クリックでノートを追加します。単一ノートの選択・追加・長さ変更で、その長さを次の入力へ引き継ぎます。
入力長は全トラックで共通、追加・長さ変更の Undo / Redo でも戻ります。グリッドに丸め直さず、プロジェクトの再オープン時に初期化します。
ダブルクリックの 2 回目は追加を重ねません。Return も記憶した長さで挿入します。
編集トラックを切り替えても、ピアノロールの時間・音域・ズームを保ちます。
エディタを閉じて開き直しても保ち、プロジェクトを開き直すと初期化します。
既存ノートはドラッグで移動、両端のドラッグで長さを変更します。
Shift を押している間はノートの移動・伸縮のグリッド吸着を解除し、グリッド未満の長さにもできます。
Option＋上下ドラッグでは、音高・時刻・長さを変えずベロシティだけを変更し、離した時に 1 回の Undo として確定します。
値は 0〜127（0 は無音）で、下端の棒とドラッグ中の数値に表示します。単一選択・調整後の値を全トラックの次の入力へ引き継ぎます。
入力ベロシティの記憶は Undo で戻さず、文書を開き直すと 100 に戻ります。ノートの値自体は Undo / Redo・保存の対象です。
選択したノートは数値入力と「変更を適用」でも編集できます。
Command-T・メニュー・ツールバーのトラック追加は選択の下、アレンジ下部の「末尾にトラックを追加」は最上位末尾へ追加します。
子を持つフォルダはヘッダ左の記号か左右矢印で開閉できます。
展開中の追加は最後の子、折りたたみ中はフォルダ全体の外側になります。空トラックの追加では音源候補を自動で開きません。

Tab / Shift-Tab は次 / 前のノート、上下は半音（Option で1オクターブ）、左右は16分音符の移動、Shift-左右は長さ変更、Return は挿入、Delete は削除、Escape はドラッグの取消です。鍵盤の横にはディグリー（I〜VII）を表示します。表示する調と長短調は画面内の設定で、プロジェクトの調を変更しません。

変更は Rust のアクションとジャーナルへ記録し、プロジェクトの履歴へ自動コミットします。Undo / Redo は Command-Z / Shift-Command-Z。左右と下部のペインは Option-Command-1 / 2 / 3、コマンドパレットは Shift-Command-P で開閉します。アレンジはスクロール、ピンチで時間、Option-ピンチで高さ、Shift-ピンチで両軸を拡大します。

Space は再生／停止、Command-. は停止です。停止は記憶した開始位置へ戻り、一時停止はその場から再開します。
一時停止は再生ボタンまたはメニューから行います。Return の一時停止／再開はまだ接続していません。
両エディタのルーラーをクリックすると開始位置を変え、ドラッグするとループ範囲だけを変えます。
既存ループの左右端は、ルーラー上端のグリップをドラッグして片端だけ調整できます。
アレンジは四分音符、ピアノロールは現在のノートグリッドへ吸着し、Shift で吸着を外します。
ループのオン／オフは別操作です。Escape で確定前のドラッグを取り消します。
拍を指定する「移動」は現在位置だけを変えます。「音声出力」ではシステム出力への追従か機器を選び、レートとバッファ長を確認できます。

「プラグイン」で CLAP 一覧を開き、ダブルクリックで選択トラックへ挿入します。
Enter ならブラウザを開いたまま挿入します。同梱の Sine Pad も一覧から通常の音源として挿入します。
アレンジのトラック名付近を Command クリックで複数選択、Shift クリックで範囲選択できます。
候補を右クリックし「選択トラックすべてに追加」で一括挿入し、1 回の Undo でまとめて戻せます。
下部の「デバイス」は選択トラックのデバイスを処理順に横へ並べ、各デバイスが公開する全パラメーターをスライダーで変更できます。
ドラッグ中の値はそのまま聴こえ、離した時に 1 回の Undo として記録します。停止中は再生を始めずにプラグインを起動します。
初回の出力準備中は、未取得の一覧に「音声出力を準備中」と表示します。
出力の準備が終わってもプラグインが応答していない間は、パラメーターの読込み表示へ切り替わります。
各デバイスの検索欄は名前とモジュール名で絞り込み、ピンのボタンで項目をそのデバイスの最上部に固定します。
ピン留めはプロジェクトに保存し、複製したデバイスにも引き継ぎます。
ノートエディタ（⌥⌘3）とデバイス（⌥⌘4）はツールバー・メニューから個別に開閉し、両方開くとアレンジ・ピアノロール・デバイスの順に積みます。
デバイスは高さ 300 pt を保ち、ピアノロールの高さは境界で調整できます。⌥⌘5 は開閉状態を変えずにアレンジを隠す／戻す切替です。
開閉と高さはウィンドウ設定に記憶し、プロジェクトの保存・Undo へは入りません。
デバイス名の左の開閉ボタンで列を折りたためます。名前・バイパス等は残し、検索と一覧だけを隠します。
開閉は音・Undo・保存を変えず、トラックや下部の表示を切り替えても保持し、文書を開き直すと展開へ戻ります。
デバイスの「オフライン」は記録済み設定を残してプラグインのヘルパーを解放します。
解除すると設定から読み直します。同じトラックの音声素材はオフライン中もそのまま通ります。
音源のないトラックのノートは無音で、エフェクトは入力音を処理します。挿入済みのプラグイン名をクリックすると、そのプラグインのウィンドウが開きます。
候補から 1 つ追加した時も自動で開きます。開いてもキー入力は Echode に残り、ウィンドウの中をクリックした時だけプラグインへ移ります。
デバイス列とインスペクターの名前の横の窓アイコンは、その独自ウィンドウが開いていることを示します。
別アプリの操作中に一時的に隠れていてもアイコンは残ります。窓の表示状態は保存・Undo の対象外です。
履歴から以前の版へ戻せ、音声ファイルは選択トラックへ取り込めます。ループとメトロノームは再生設定です。

右のファイル欄の「フォルダを選択」でサンプルフォルダを登録します。
検索欄に入力すると、登録した全フォルダの下にある音声・MIDI・`.echode` を名前で検索します。
フォルダ一覧も制作向けの種類だけを表示し、MIDI は「読込みは未対応」と表示します。
「サンプルフォルダ」から移動・登録解除でき、登録は次回起動時にも保持します。
素材を追加・削除したら更新ボタンで一覧を読み直します。
音声のダブルクリック・Return・「音声を取り込む」は、操作時の選択トラックと再生ヘッド位置へ配置します。
グリッドへ丸めず、ブラウザを開いたままにします。選択時には素の音を先頭から 1 回試聴します。
長い素材は読み込みながら鳴らし、一覧の下に同じ読込みからの波形・長さ・読込み状態を表示します
（[試聴の設計](docs/decisions/0151-streaming-sample-audition.md)）。
ブラウザ表示中は試聴出力を保持します。自動試聴をオフにしても右矢印と再生ボタンで試聴でき、波形のクリックで開始位置を指定できます。
試聴音量と自動試聴の設定は記憶し、曲の再生・音量・編集履歴とは独立します
（[ADR 0152](docs/decisions/0152-browser-audition-controls.md)）。
ブラウザや Finder から音声ファイルを 1 つアレンジへドラッグすると、その行のポインター位置へ配置します。
現在の拍グリッドへ吸着し、Shift を押している間は解除します。最終行より下（空のプロジェクトも含む）では最上位末尾に新しいトラックを作ります。
トラック作成と取込みは 1 回の Undo で戻せます。複数ファイルの同時ドロップと、同トラックの既存クリップに重なる配置はまだ受け付けません。

## MCP でヘッドレスのセッションへ接続する

既存の `.echode` パッケージを指定して、別のターミナルで `target/release/echode serve PACKAGE SOCKET` を起動します。実行ファイルは `cargo build --release -p echode-cli` で作れます。MCP クライアントには、その実行ファイルの絶対パスを command、`["mcp", "SOCKETの絶対パス"]` を args として指定します。

同じビルドの serve と mcp を使います。MCP は登録済みアクションのツール、まとめた編集、Undo / Redo、概要とトラックの読み取りを提供します。編集は既存のジャーナルへ記録されます。起動中の GUI アプリへの接続と再生・機器操作は初版の対象外です。GUI で開いている同じパッケージを serve で開き直さないでください。接続範囲と検査は [ADR 0115](docs/decisions/0115-phase2-mcp.md) を参照してください。
